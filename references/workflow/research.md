# 联网调研工作流（research）

调研 = 在写作前或写作中，通过联网搜索补充本书需要的真实世界知识或题材专业知识。
调研不是堆资料，是「找到会让读者觉得假的那部分知识，补到足够让读者不跳戏的程度」。

## 何时触发调研

以下三种场景触发调研，缺一不可的条件见各场景的「触发条件」：

### 场景一：开书前调研

**触发条件**：开始写总纲或第一批章纲之前，且题材卡（`references/genres/`）中
未覆盖作者需要的具体知识。

**典型需求**：
- 历史题材：目标朝代的政治制度、社会生活、军事地理
- 科幻题材：相关科学原理、技术推演路径
- 悬疑/刑侦：办案流程、法医学知识、犯罪心理学
- 娱乐圈/电竞/种田等专业题材：行业运作规则、术语体系

**不需要调研的情况**：
- 题材卡已覆盖所有必要的知识维度（如玄幻/修仙的基本修炼体系题材卡已写清楚）
- 作者明确表示「不需要调研，已有足够知识储备」
- 纯架空世界观且不依赖任何真实参照

### 场景二：写专业场景前调研

**触发条件**：章纲中出现了超出题材卡范围的专业场景，且写作者明显缺乏该领域知识。

**典型需求**：
- 写一场法庭戏但不懂法律程序
- 写一场手术但不懂医学常识
- 写一场古代科举但不懂科举流程
- 写一场拍卖会但不懂拍卖规则

**不需要调研的情况**：
- 场景的专业性不构成读者判断「假」的依据（如一笔带过的背景场景）
- 题材卡中已包含该场景的写作规范
- 可以模糊处理且不影响读者阅读体验

### 场景三：知识缺口时调研

**触发条件**：写前检索或写后自查时，发现某个设定/细节/术语自己不确定是否准确。

**典型需求**：
- 写到一半发现不知道某个古代官职的具体职责
- 角色使用的武器/装备自己不确定参数
- 某个地理距离/时间跨度自己不确定是否合理

**判断标准**：如果你在读自己的书时，会觉得这个细节「可能不对」，那就该调研。

## 调研四步

### Step 1：识别缺口

运行 `research_agent.py gaps` 子命令，自动检测知识库缺口：

```bash
python scripts/research_agent.py gaps "{书名目录}"
```

脚本会：
1. 读取 `设定/题材定位.md` 确定主题材
2. 按题材匹配对应的调研维度清单
3. 检查 `参考资料/` 目录下已有的调研文件
4. 检查题材卡（`references/genres/`）已覆盖的维度
5. 输出缺口清单（哪些维度需要调研但尚未完成）

**题材卡已覆盖的维度不重复调研**：题材卡中明确写了的内容（如玄幻的修炼体系、
都市文的社会规则）视为已覆盖，不会出现在缺口清单中。

**手动补充缺口**：脚本输出的缺口是基于题材的通用维度。如果本章有特殊需求
（如写一场具体的手术场景），需要手动在缺口清单中追加。

### Step 2：生成关键词

运行 `research_agent.py keywords` 子命令，按题材 + 主题生成搜索关键词：

```bash
# 按题材生成全部关键词
python scripts/research_agent.py keywords --genre 玄幻

# 按题材 + 具体主题生成
python scripts/research_agent.py keywords --genre 玄幻 --topic "炼丹体系"

# 纯主题搜索（不指定题材）
python scripts/research_agent.py keywords --topic "古代科举制度"

# 输出 JSON 格式（方便 Agent 消费）
python scripts/research_agent.py keywords --genre 历史 --topic "唐代官制" --json
```

关键词生成规则：
- 从题材映射表中取 `search_prefixes`（题材默认搜索前缀）
- 从各调研维度中取维度名 + 维度描述的关键词
- 如果指定了 `--topic`，将 topic 附加到每个前缀和维度名后
- 去重 + 排序

**关键词使用建议**：
- 每个缺口维度用 2-4 个关键词搜索
- 先用宽泛关键词扫一遍，再用精确关键词深入
- 不追求一次性搜全——先搜出框架，写的时候遇到具体缺口再补搜

### Step 3：搜索

使用 `WebSearch` 工具执行搜索，遵循以下原则：

**搜索策略**：
- 每个关键词执行 1 次搜索，取前 3-5 条结果
- 优先选择官方文档、百科、学术资料、行业报告
- 对关键信息做交叉验证：同一事实至少 2 个独立来源确认
- 标记来源 URL（方便后续核实）

**搜索伦理**：
- 不搜盗版/侵权内容
- 不搜个人隐私信息
- 调研结果不直接复制粘贴到正文（调研是知识输入，不是素材搬运）

**搜索深度控制**（见下方「调研深度分级」）：
- quick：每个维度 1-2 个关键词，各取 1 条摘要
- standard：每个维度 2-4 个关键词，各取 2-3 条详细内容
- deep：每个维度 4-6 个关键词，各取 3-5 条详细内容 + 交叉验证

### Step 4：存储

运行 `research_agent.py store` 子命令，将搜索结果结构化存储：

```bash
# 直接传入调研内容
python scripts/research_agent.py store "{书名目录}" \
  --dimension "修炼体系" \
  --source "调研结果文本..." \
  --url "https://example.com"

# 从文件读取调研内容
python scripts/research_agent.py store "{书名目录}" \
  --dimension "世界观架构" \
  --source-file "搜索结果.txt" \
  --url "https://example.com"
```

存储规则：
- 调研结果按维度分别存储为 `参考资料/{维度名}.md`
- 每个文件包含：调研时间、调研方式、来源 URL、调研内容
- 自动记录到 `参考资料/调研日志.md`（表格格式，含时间/维度/产出文件/来源URL）
- 如果同一维度已有调研文件，新内容追加到已有文件末尾（标上新的时间戳）

## 调研深度分级

| 深度 | 适用场景 | 每维度关键词数 | 每关键词结果数 | 交叉验证 | 产出格式 |
|---|---|---|---|---|---|
| **quick** | 写一个不涉及核心设定的场景，只需要确认一个具体细节 | 1-2 个 | 1 条摘要 | 不需要 | 1-2 段要点 |
| **standard** | 开书前调研，或写涉及核心设定的章节前 | 2-4 个 | 2-3 条详细 | 关键信息验证 | 结构化文档（含来源） |
| **deep** | 深度专业题材（历史/科幻/悬疑/刑侦），或卷末大高潮前 | 4-6 个 | 3-5 条详细 | 所有事实交叉验证 | 完整调研报告（含来源+置信度） |

**深度选择决策树**：
- 题材卡已覆盖 → 不调研
- 题材卡未覆盖 + 本章只是背景提及 → quick
- 题材卡未覆盖 + 本章以该知识为核心场景 → standard
- 题材卡未覆盖 + 该知识是全书核心设定 → deep

## 生成调研计划

运行 `research_agent.py plan` 子命令，一键生成调研计划：

```bash
# 标准调研（≤6 个维度）
python scripts/research_agent.py plan "{书名目录}" --depth standard

# 快速调研（≤3 个维度）
python scripts/research_agent.py plan "{书名目录}" --depth quick

# 深度调研（全部维度）
python scripts/research_agent.py plan "{书名目录}" --depth deep

# 输出 JSON 格式
python scripts/research_agent.py plan "{书名目录}" --depth standard --json
```

`plan` 子命令会输出：
1. 缺口维度清单（按优先级排序）
2. 对应的搜索关键词列表
3. 具体的 `store` 命令示例（可直接复制执行）

## 存储规则

### 设定类调研（与世界观/规则/体系相关）

存入 `参考资料/` 目录，文件名与维度名一致。

**应存入 `参考资料/` 的内容**：
- 修炼体系、魔法体系、能力体系等规则性知识
- 历史背景、社会制度等背景性知识
- 行业知识、专业术语等专业性知识
- 科技推演、科学原理等设定依据

**不应存入 `参考资料/` 的内容**：
- 对标书的拆文产出（存入 `对标/{书名}/`）
- 扫榜报告（存入 `参考资料/扫榜报告.md`）
- 选题决策（存入 `参考资料/选题决策.md`）

### 世界观类调研（与故事世界的自然/文化/地理相关）

同样存入 `参考资料/`，但建议在调研文件名中标注是「世界观」维度，
方便后续写 `设定/世界观.md` 时参考。

### 行文细节类调研（与具体场景的描写相关）

不需要单独存文件。在调研完成后，将关键信息直接写入章纲的「注意事项」栏，
或写入速记（见 `chapter-loop.md` Step 3）。

## 与题材卡的协作

题材卡（`references/genres/`）是调研的第一道防线。题材卡已覆盖的内容，
**不重复调研**。

**协作规则**：

1. **题材卡优先**：开书时先加载对应题材卡——题材卡中的「节奏规范」「场景颗粒」
   「成长体系」「对话与声线」等栏目已经包含了大量写作约束，这些不需要调研。

2. **题材卡未覆盖的才是调研范围**：题材卡给出的是「这类题材怎么写」的工艺规则，
   调研补充的是「这个具体设定应该是什么」的事实知识。两者的边界是：
   - 题材卡告诉你「玄幻的升级应该怎么写」→ 不需要调研
   - 调研告诉你「道家的金丹大道具体有哪些阶段」→ 需要调研

3. **缺口检测自动排除**：`research_agent.py gaps` 子命令会自动检查题材卡
   中已覆盖的栏目名，将其排除在缺口清单之外。

4. **复合题材**：主题材卡整读 + 辅题材卡只取「爽点类型」「常见雷区」两节参考。
   调研维度以主题材卡为准，辅题材相关的知识按需调研。

5. **题材卡未覆盖的新题材**：回退到 `GENERIC_DIMENSIONS`（通用调研维度），
   包括世界观、职业知识、历史背景、地理空间、技术/魔法、读者偏好。

## 调研日志

每次通过 `research_agent.py store` 存储调研结果时，自动在
`参考资料/调研日志.md` 中追加一条记录：

| 时间 | 调研维度 | 产出文件 | 来源URL |
|---|---|---|---|
| 2026-07-28T15:30:00 | 修炼体系 | 修炼体系.md | https://example.com |

调研日志的作用：
- 追踪哪些维度已经调研过（避免重复调研）
- 记录调研来源（方便后续核实或更新）
- 作为书籍工程的「知识元数据」——以后修订时，知道哪些知识来自调研，哪些来自作者经验

## 对接 research_agent.py 的命令汇总

```bash
# 1. 查看某题材的调研维度清单
python scripts/research_agent.py keywords --genre 玄幻 --json

# 2. 检测知识库缺口
python scripts/research_agent.py gaps "我的小说"

# 3. 生成调研计划
python scripts/research_agent.py plan "我的小说" --depth standard

# 4. 按主题生成搜索关键词
python scripts/research_agent.py keywords --genre 历史 --topic "唐代官制"

# 5. 存储调研结果
python scripts/research_agent.py store "我的小说" \
  --dimension "修炼体系" \
  --source "调研内容..." \
  --url "https://baike.baidu.com/..."

# 6. 从文件批量存储调研结果
python scripts/research_agent.py store "我的小说" \
  --dimension "世界观架构" \
  --source-file "./tmp/research_result.txt"
```

## 调研在整个写作流程中的位置

```
Phase 0: 定位与加载
  └── 加载题材卡（题材卡已覆盖的维度 = 不调研）
  └── 运行 research_agent.py gaps → 检测缺口
  └── 运行 research_agent.py plan → 生成调研计划
  └── 执行调研（搜索 → 整理 → 存储）

Phase 1: 开书（长篇）
  └── 调研结果写入 设定/世界观.md（如有世界观调研）
  └── 调研结果写入 设定/ 其他文件（如有规则/体系调研）

Phase 3: 单章写作循环
  └── Step 2（检索）：如有新调研需求（专业场景），先调研再写
  └── Step 3（压成本节速记）：调研关键信息写入速记
  └── 写完后不调研（调研应在写前完成，不是写完再补）
```

## 调研的边界与限制

1. **调研不是写论文**：调研的目的是让写作「不假」，不是让写作「像教科书」。
   调研结果要经过筛选——只取和本章情节直接相关的部分，其余存档备用。

2. **调研产出不写进正文**：调研文件中的内容不能直接复制粘贴到正文中。
   调研是知识输入，正文是故事输出。调研结果应该在脑子里消化后，用角色的视角
   重新表达。

3. **调研不过度**：如果调研了 30 分钟还没找到答案，停下来问自己：
   「这个细节读者真的会在意吗？我能不能模糊处理？」
   大部分情况下，读者不会因为你写错了某个古代官职的品级就弃书——除非
   整个场景都建立在错误的知识上。

4. **调研可以后补**：如果调研会打断写作节奏，可以先写（标注 `[TODO: 调研]`），
   写完后再补调研并修正。但涉及核心设定的知识必须调研完再写。

# 命令入口表（commands）

本文档是 long-novel-skill 的命令体系入口，按使用者熟练度分为「新手模式」和「高级模式」两层。
每个命令给出：触发方式（自然语言）、功能说明、关联文件、典型示例。

## 新手模式 vs 高级模式

| 维度 | 新手模式 | 高级模式 |
|---|---|---|
| 适用阶段 | 开书第 1-30 章，或首次使用本 skill | 30 章以后，或已熟悉流程 |
| 命令粒度 | 粗粒度，一个命令涵盖多步 | 细粒度，可以单独调用子步骤 |
| 交互方式 | 对话式引导，Agent 主动提问确认 | 命令式触发，Agent 快速执行 |
| 默认行为 | 每一步都确认后再执行 | 信任执行，只在关键节点确认 |
| 文件操作 | Agent 自动创建和管理 | 作者可手动操作文件，Agent 只做读写 |

**升级条件**：新手模式下，当作者连续 10 章无重大问题（门禁全通过、伏笔无超期、配额无越界），
Agent 会提示「可以切换到高级模式了」。作者也可以随时说「切换到高级模式」或「回新手模式」。

## 一、新手命令

新手命令覆盖最常见的四种操作，其他命令在高级模式中解锁。

### 开书

| 属性 | 内容 |
|---|---|
| 触发方式 | 「开书」「开新书」「写一本新书」「帮我开一本XX题材的书」 |
| 功能说明 | 从零开始创建一本新书的完整流程：创意确认 → 题材定位 → 读者契约 → 世界观与人物 → 文风锚 → 总纲 → 首卷卷纲 → 首批章纲（5-10 章）。新手模式下每一步都会确认后再继续。 |

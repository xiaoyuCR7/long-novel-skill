# 短篇写作循环（short-story-loop）

短篇 = 5000–20000 字，一两天完成，发知乎盐言/番茄短篇/七猫短篇等平台。
短篇不是长篇的缩水版，是不同的叙事形态。核心是「一个情绪、一个反转、一次结算」——
所有段落都为这三件事服务，多一条线就散。

## Step 1：定情绪

先选一个核心情绪，全文围绕它写，不贪多：

| 情绪类型 | 读者诉求 | 典型结尾 |
|---|---|---|
| 意难平 | 憋一口气放不下 | 错过即永远 |
| 甜 | 想嗑一口 | 确认关系/双向奔赴 |
| 虐 | 想哭一场 | 代价已付，不可挽回 |
| 爽 | 想出口气 | 反转打脸，恶人得报 |
| 恐 | 想后背发凉 | 真相揭开，无处可逃 |

定情绪时同时定目标平台（见末尾平台适配）——平台决定字数区间与爽度基调。
情绪与平台不匹配（如「虐」配番茄短篇）= 投错胎，改其一。

## Step 2：选框架（五段式）

短篇用五段式框架，比例固定，不要自己发明结构：

| 段落 | 占比 | 功能 | 典型写法 |
|---|---|---|---|
| 开头 | 10–15% | 钩子+人物+设定 | 用冲突场景开场，不铺设定 |
| 铺垫 | 25–30% | 升级矛盾 | 让问题变复杂，建立情绪 |
| 升级 | 25–30% | 矛盾爆发 | 情绪最高点，读者代入 |
| 反转 | 15–20% | 认知颠覆 | 前文铺垫的回收 |
| 结尾 | 10–15% | 结算+余韵 | 动作收尾，不升华 |

按目标字数算出每段字数预算，写进 Step 4 的小节大纲。

## Step 3：人物速写

短篇人物不求全，求立。每人 3 个标签：

- 一个**核心欲望**（TA 想要什么，驱动一切行动）
- 一个**行为特征**（读者能记住的标志性动作/习惯）
- 一个**声音特征**（遮住名字能认出谁说的）

人物不超过 4 个有台词的角色；多一个 = 抢戏，砍或合并。配角只承担「见证/催化/对照」
单一功能，不写配角的前史。

## Step 4：小节大纲

把五段式拆成 5–8 个小节，每节写清：

```
## 小节 {N}：{小节名}
- 所属段落：{开头/铺垫/升级/反转/结尾}
- 核心事件：{这一节发生什么}
- 目标情绪：{读者应该感到什么}
- 字数预算：{}字
- 节末微型钩子：{留什么}
```

小节大纲存入 `大纲/小节大纲.md`。无小节大纲不写正文（短篇的铁律，同长篇禁裸写）。

## Step 5：逐场景写作

按小节大纲写，每个小节是一个完整场景：

- 开头不铺设定，直接进场景（第一句就是动作或对话）
- 对话驱动，描写最少化（短篇字数金贵，描写要砍到只剩「删了就丢信息」的）
- 每个场景末尾留微型钩子（一句话/一个动作/一个未答的问题）
- 反转段必须回收前文铺垫——反转无铺垫 = 耍读者

写到手感不对时停下来对照人物速写三标签，不要硬写过去。

## Step 6：精修

```bash
python scripts/check_text.py "正文/正文.md" --min-chars 5000 --max-chars 20000 --gate-report
```

跑完机器闸口后人工检查三项（短篇特有）：

1. **反转是否有铺垫**：把反转点单独拎出来，前文是否埋了至少 1 处可回扣的细节？
   没埋 = 耍读者，回去补铺垫或改反转。
2. **结尾是否升华**：删掉所有总结性语句（「这一次他终于明白了…」「原来…」），
   用动作/场景收尾。
3. **字数是否在目标平台范围内**：超出区间时按五段式比例删，不要只删某一段。

## 短篇 vs 长篇的区别

| 维度 | 短篇 | 长篇 |
|---|---|---|
| 节奏 | 单峰曲线，一路推到反转 | 多峰曲线，卷级起伏 |
| 人物 | 3–4 人，单标签立住 | 几十人，有成长弧光 |
| 设定密度 | 零铺设定，用到才提 | 可铺世界观，随写随补 |
| 伏笔 | 1–2 个，必须当篇回收 | 几十处，跨卷回收 |
| 钩子 | 每节末微型钩子 | 每章尾钩子，密度可控 |
| 情绪 | 一个核心情绪贯穿 | 情绪弧线，起承转合 |

## 平台适配

| 平台 | 字数区间 | 基调 | 要点 |
|---|---|---|---|
| 知乎盐言 | 1–3 万字 | 重情绪反转 | 第一人称代入感强，反转要狠，结尾留余韵 |
| 番茄短篇 | 3000–1 万字 | 重爽 | 爽点前置，节奏快，每千字一个钩子 |
| 七猫短篇 | 5000–2 万字 | 重情绪 | 情绪推进稳，适合虐/意难平 |

投稿前确认平台当前的字数与题材要求（以平台作家后台公告为准）。
短篇不建长篇那套追踪文件——人物状态、伏笔台账都不需要，小节大纲 + 正文两件足够。

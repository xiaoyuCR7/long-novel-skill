# 上架物料与封面工作流

用于简介、标签、书名、卖点、内容警告、封面 brief 与平台上架物料。它不替代正文质量审核，
也不把尚未执行的图片生成描述成成品。

## 输入

先读取可用的读者契约、题材定位、总纲、文风锚和目标平台；只收集当前物料真正需要的信息：

- 核心主角、独特机制、主要欲望、阻力与首个可兑现承诺。
- 目标读者、题材/子题材、情绪基调、差异点和明确禁区。
- 剧透边界、内容警告、书名/作者名的准确字形。
- 平台、发布区域、语言，以及用户明确要求的封面方向。

若目标平台的比例、文件格式、大小、标签或内容规范会随时间变化，先查询该平台的官方帮助、
创作者后台或其他一手权威来源，记录查询日期和来源链接。无法查询时把规格标为 `unverified`，
给出通用建议，不把记忆中的旧规则说成现行要求。

## 交付结构

```yaml
positioning:
  audience: ""
  reader_promise: ""       # 一句话承诺，不用空泛形容词
titles:
  - title: ""              # 3–5 个差异明确的变体
    rationale: ""
synopsis:
  short: ""                # 移动端首屏可读
  long: ""                 # 角色目标、核心阻力、差异机制、悬念
tags: []
selling_points: []          # 可由设定或剧情兑现，不虚构卖点
content_warnings: []
cover:
  concept: ""
  focal_subject: ""
  mood_and_palette: ""
  composition: ""
  typography_safe_area: "" # 标题、作者名、平台裁切的安全区
  title_text: ""
  author_text: ""
  aspect_ratio: ""
  pixel_dimensions: ""
  platform_spec_source: ""
```

短简介突出一个钩子和一个承诺；长简介补足欲望、代价和悬念，但不泄漏核心反转。标签必须能被
正文或锁定大纲支持。卖点应可验证，内容警告宁可具体也不含糊。封面 brief 需同时说明主体、
视觉层级、色彩、禁用元素、缩略图辨识度和文字安全区。

## `image_tool_available`

仅当用户明确要求“实际生成封面”且当前会话确有图片生成工具时才调用工具。先确认平台比例和
尺寸，再以结构化 brief 生成。完成后必须检查实际产物，而不是只读提示词或工具状态：

1. 以原始分辨率查看封面，核对标题、作者名的每个字及标点。
2. 检查文字是否进入安全区、是否被裁切、乱码、重影或与背景低对比。
3. 检查缩略图下的主体辨识度、题材信号和不应出现的元素。
4. 文字不正确时重新生成或改为无字底图加可编辑排版方案；仍不正确则标记 `not_publish_ready`，
   准确说明“底图已生成，但文字未通过验证”，不得称为可发布成品。

交付时列出实际文件、验证结果、仍需人工确认的版权/商标/平台合规事项。

## `image_tool_unavailable`

图片工具不存在、失败，或用户只要策划时，不进行伪调用。只交付：

- 可直接用于图片工具的结构化生成 prompt 与 negative prompt。
- 已核验的平台比例与像素尺寸；无法联网核验则显式标为 `unverified`。
- 标题和作者名的独立排版文本、字体风格、位置与文字安全区。
- 后续生成与人工验收清单。

必须明确写明“未生成图片”；不得声称已生成图片，也不得用 mockup、Markdown 占位符或提示词截图
冒充封面成品。

## 停止点

- 书名、作者名、平台或剧透边界不明确且会改变成品时，请作者确认后再生成。
- 需要联网核验但网络不可用时，可完成非平台特定文案与通用 brief，但不得宣称平台合规。
- 用户没有要求实际生成图片时，交付物料包和封面 brief 后停止，不擅自调用生成工具。

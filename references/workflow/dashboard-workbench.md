# Dashboard 工作台与安全编辑

用户要求查看工程状态、浏览章节或编辑指定文件时使用；查看请求不等于获准修改。

```bash
python scripts/dashboard.py "{book}"
```

默认在 127.0.0.1:8765 打开本地服务；以命令实际输出地址为准。仅在用户明确要求网络访问时
使用 `--host`，并说明无身份认证/TLS，不得暴露到不可信网络。

## 编辑协议与停靠点

1. 先确认活动书籍与文件，读服务端 revision。章事务 pending 时先恢复，不能绕过事务改正式正文。
2. 编辑器保留未保存草稿；保存前显示 diff，用户确认后才提交内容与原 revision。冲突（409）时
   保留本地草稿，重新读取服务端版本并让用户合并，不能静默强制覆盖。
3. 服务端只允许书籍根内的合法目录/扩展名，拒绝路径穿越、绝对路径、symlink 与隐藏路径；
   保存采用同目录临时文件 + 单文件原子替换，原文件留 `.文件名.dashboard-backup` 备份。
4. 删除必须二次确认，移动到工程 `追踪/.dashboard-trash`，不是永久删除。路径或 revision 不匹配时停止。
5. POST/DELETE 需要同源 Origin、合法 Host 和本次服务的 `X-Dashboard-Token`；不把 token 写进小说。

完成指定浏览/编辑后报告真实保存状态并停止。浏览器不可用时给出实际本地地址或文件路径；
未启动服务、未保存内容时不得声称已完成。安全文件编辑不能替代章节门禁与追踪事务。

# 拆文学习对标（deconstruct）

拆文 = 把对标书拆解成可复用的模块。拆文不是抄，是学——学的是「为什么有效」，
不是「写了什么」。照搬人物名、地名、情节 = 抄袭，拆结构、拆节奏、拆情绪模块 = 学习。

## Step 1：选对标书

选 1–3 本同题材、同平台、成绩好的对标书。选标准：

- 近一年内（网文迭代快，老书的节奏未必还成立）
- 同平台（番茄的书拆给晋江写法用不上）
- 数据好（榜单/读者口碑，至少一项过硬）

没有对标书可以跳过本流程，但开书时少了节奏参照，前 10 章容易踩坑。

## Step 2：量化扫描（机器辅助）

把对标书章节文本拷入 `对标/{书名}/原文/`，跑三个命令：

```bash
python scripts/deconstruct.py stats "对标/{书名}/原文/第1章.md" ... --output "对标/{书名}/量化统计.md"
python scripts/deconstruct.py rhythm "对标/{书名}/原文/第1章.md" ... --output "对标/{书名}/节奏分析.md"
python scripts/deconstruct.py fingerprint "对标/{书名}/原文/第1章.md" ... --output "对标/{书名}/文风指纹.md"
```

三条命令分别产出：字数/对话比/段落长度的统计、快中慢档分布与钩子位置、文风六维指纹。
机器结果只做参考底稿，人工判断才是结论。

## Step 3：结构拆解

用 `deconstruct.py structure` 提取每章结构，人工分析：

- 每章钩子类型与位置（开头/结尾？新危机/新信息/反转半句？）
- 爽点位置与密度（每章几个？集中在哪一段？）
- 对话/描写/动作的比例（与文风指纹交叉验证）
- 章节长度变化规律（高潮章是否更长？日常章是否更短？）

产出 `对标/{书名}/结构分析.md`。

## Step 4：角色拆解

提取对标书的角色卡，每个角色一个文件 `对标/{书名}/角色卡/{角色名}.md`：

- 主角的核心欲望与成长弧光（从哪到哪，几卷走完）
- 配角的功能定位（导师/对手/伙伴/搅局者，一人一功能）
- 角色关系的张力结构（谁和谁有暗线？谁的存在制约谁？）

拆的是「功能位」不是「人设细节」——学对手配角怎么制造压力，不学对手配角的名字和口癖。

## Step 5：节奏拆解

分析对标书的节奏三档分布（参照 `craft/reverse-brake.md`）：

- 快/中/慢档的实际比例（抽 20–30 章统计，与本书题材卡的推荐比例对照）
- 大节点（高潮/反转/结算）的间隔章数
- 铺垫与结算的比例（大结算前铺了几章？）

产出并入 `对标/{书名}/节奏分析.md`（Step 2 机器产出 + 本步人工判断）。

## Step 6：情绪模块提取

识别可复用的情绪模块——不是抄内容，是拆结构。每个模块一个文件
`对标/{书名}/情绪模块/{模块名}.md`，记录「起承转合」的结构骨架：

| 模块名 | 结构骨架 | 适用题材 |
|---|---|---|
| 打脸 | 铺垫→压制→反转→见证 | 都市/玄幻 |
| 虐恋 | 误会→伤害→醒悟→代价 | 言情 |
| 逆袭 | 低谷→契机→积累→爆发 | 玄幻/都市 |
| 追妻 | 冷待→离开→醒悟→求回 | 言情 |
| 解谜 | 疑点→误导→线索→揭底 | 悬疑 |

每个模块的文件里写清楚：每一步的功能、字数占比、情绪目标、典型钩子位置。
写作时按题材卡匹配模块，按本书人物填充血肉。

## Step 7：产出存档

所有产出存入 `对标/{书名}/` 目录：

```
对标/{书名}/
├── 量化统计.md
├── 结构分析.md
├── 节奏分析.md
├── 文风指纹.md
├── 角色卡/
│   ├── {角色名}.md
│   └── ...
├── 情绪模块/
│   ├── {模块名}.md
│   └── ...
└── 可复用要点.md   # 一页纸总结：这本书值得学的 3–5 个点
```

`可复用要点.md` 是一页纸总结：这本书值得学的 3–5 个点（节奏/结构/情绪模块/文风），
每个点配一句「怎么用在我这本书上」。

## 写作时如何召回

- **写章纲前**：读 `对标/{书名}/可复用要点.md`（一页纸，快速对齐节奏与结构）
- **需要详细参考时**：读对应子文件（写打脸场景读情绪模块/打脸.md，排卷节奏读节奏分析.md）
- **文风校准时**：读 `对标/{书名}/文风指纹.md`，与本书 `设定/文风锚.md` 对照（见 `craft/style-fingerprint.md`）

不要全量读对标目录——按需召回，最小上下文原则同长篇写作。

## 拆文纪律

- 拆的是「为什么有效」的结构，不是「写了什么」的内容
- 绝不照搬人物名、地名、情节——结构可学，内容不可抄
- 拆文产出只供本书参考，不外传对标书原文（版权问题）
- 对标书拆完不是一劳永逸：本书写到中途发现节奏不对，回头重读对标书的节奏分析

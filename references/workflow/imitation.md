# 仿写工作流（imitation）

给定一本对标书，仿写一本新书。核心原则：**结构对标，内容原创**——用对标书的节奏骨架、
情绪模块、叙事结构，但世界观、角色、情节全部原创。

## 适用范围

- 有明确对标书（1-3 本），需要以对标书为模板创作新书
- 适用于「模仿一本成功的书的结构，写自己的内容」的场景
- 不适用于：无对标书的纯原创、已有书稿的续写、短篇创作

## 五步流程

```
拆文 → 提取风格指纹 → 题材选风格 → 开书 → 魔改
```

每一步都有明确的输入、产出、对接文件。

---

## Step 1：拆文（提取结构/节奏/情绪模块/文风）

**目标**：把对标书拆解为结构化的可复用资产。

**执行**：对标书走 `workflow/deconstruct-pipeline.md` 七阶段管道。

完整的七阶段产出：

| 阶段 | 产出 | 仿写中的用途 |
|---|---|---|
| Stage 0 | 章节边界表、全书概要 | 了解对标书的整体结构和章节分布 |
| Stage 1 | 黄金三章深度拆解 | 了解对标书开头钩子设计、信息投放节奏 |
| Stage 2 | 逐章摘要 | 提取每章的结构模板（情节骨架、节奏模式） |
| Stage 3 | 聚合索引 | 提取跨章模式（情绪弧线分布、伏笔间距、钩子类型分布） |
| Stage 4 | 设定档案 | 了解对标书的世界观/角色设定（知其然，但不照搬） |
| Stage 5 | 汇总报告 | 对标书的商业分析、读者画像、节奏公式 |
| Stage 6 | 文风视图 | 对标书的文风指纹（六维量化） |

**关键产出（供仿写使用）**：

1. **结构模板**：从逐章摘要中提取每章的「情节骨架」——去掉角色名和世界观细节，
   只保留「发生了什么→为什么发生→结果是什么」的因果链。
2. **节奏公式**：对标书的档位分布（快/中/慢档的占比和交替模式）、每章字数分布、
   钩子间隔。
3. **情绪模块库**：从对标书中提取的情绪模块卡，按 `craft/emotional-arc.md` 的
   八大类分类归档。存入 `对标/{书名}/情绪模块库/`。
4. **文风指纹**：六维量化基线（句长/对话占比/段落长度/标点节奏/高频词/句式偏好）。

**如果时间有限**：至少跑 Stage 0-3（概要 + 黄金三章 + 逐章摘要 + 聚合索引），
Stage 4-6 可以后续补。

---

## Step 2：提取风格指纹

**目标**：从对标书中提取六维文风锚，作为新书的腔调基线。

**执行**：

1. 从对标书 Stage 6 的文风视图中提取六维文风指纹（详见 `craft/style-fingerprint.md`）：
   - 平均句长
   - 对话占比
   - 段落中位长度
   - 标点节奏
   - 高频词 Top20
   - 句式偏好

2. 将六维基线写入新书的 `设定/文风锚.md`（使用 `craft/style-fingerprint.md` 中定义的模板）。

3. 补充腔调关键词：
   - 对标书的腔调是：{从对标书中提取的腔调描述，如「冷峻克制」「热血激昂」「细腻温柔」}
   - 新书的腔调关键词：{在模仿对标书的基础上，新书独有的腔调差异化}
   - 不用的腔调：{明确新书不会用的腔调}

4. 从对标书中截取 3-5 段样板段落，放入 `设定/文风锚.md` 的「样板段落」区。这些段落
   最能代表对标书的腔调，新书写作时对齐参考。

**注意**：风格指纹是「对标书的腔调」——新书在实际写作中，文风会自然产生自己的
特征。前 3-5 章写完后，需要重新校准新书自己的文风锚（用 `scripts/style_fingerprint.py`
对新书样章重新提取基线）。

## Step 3：题材选风格

**目标**：确定新书的题材和风格定位，明确「对标书的什么东西可以复用，什么东西必须
原创」。

**执行**：

1. **题材匹配度检查**：新书的主题材是否与对标书一致？如果不一致，哪些结构/情绪
   模块可以跨题材复用，哪些必须调整？

   | 对标书题材 | 新书题材 | 可复用 | 必须调整 |
   |---|---|---|---|
   | 玄幻修仙 | 玄幻修仙 | 升级节奏、打脸模块、V形弧线 | 世界观、力量体系 |
   | 都市爽文 | 都市爽文 | 身份反转、碾压节奏、旁观者反应 | 角色设定、情节线 |
   | 言情 | 言情 | 关系推进节奏、误会冰释模块、甜虐交替 | 角色关系、背景设定 |
   | 玄幻修仙 | 都市爽文 | 部分情绪模块（打脸/旁观者） | 节奏公式、世界观、对话风格 |

2. **风格差异化声明**：在 `设定/题材定位.md` 中写入「对标与差异化」字段，明确：
   - 对标书的核心卖点是什么
   - 新书在什么维度上与对标书相同（对标骨架）
   - 新书在什么维度上与对标书不同（差异化血肉）

3. **读者契约确认**：新书的读者契约必须与对标书的读者契约对齐（但不完全相同）——
   对标书的读者来读新书，不能有「被欺骗」的感觉。如果对标书是爽文，新书不能是虐文。
   详见 `craft/reader-contract.md`。

## Step 4：开书（用对标书的结构模板）

**目标**：用对标书的结构模板，填充新书的内容，完成从零到「可以开始写第一章」。

**执行**：走 `workflow/book-init.md` 的完整流程，但在每一步中注入对标书的结构模板。

### Step 4.1：对标结构注入创意与定位（book-init Step 0）

在确认一句话卖点、主题材、目标平台、总字数、读者契约时，将对标书的结构分析
作为参考：

- 对标书的总字数和新书的目标总字数对比——如果对标书 200 万字，新书只写 100 万字，
  对标书的结构（卷数、节奏分布）需要压缩
- 对标书的读者契约和新书的读者契约必须对齐——对标书的读者契约定义了什么快感、
  什么频率，新书在快感类型上对齐，在具体内容上差异化

### Step 4.2：对标结构注入卷纲（book-init Step 3-4）

在写总纲和首卷卷纲时，使用对标书的结构模板：

1. **分卷规划**：参考对标书的分卷数量和每卷的字数。如果对标书每卷 30 章、每章 3000 字，
   新书可以采用相同的分卷结构。如果字数不同，按比例缩放。
2. **情绪弧线规划**：参考对标书每卷的情绪弧线分布（从 Stage 3 的聚合索引中提取）。
   对标书第一卷用了 2 个 W 形 + 1 个 V 形，新书第一卷也采用相同的弧线分布——
   但弧线的具体内容（触发事件、角色反应）全部原创。
3. **钩子分布规划**：参考对标书的钩子间距（每几章一个钩子、钩子类型分布），
   新书采用相同的钩子密度。
4. **节奏档位规划**：参考对标书的档位分布（快/中/慢档的占比和交替模式），
   新书采用相同的档位分布。

### Step 4.3：对标结构注入章纲（book-init Step 4）

在写首批章纲时，对每一章：

1. 从对标书的对应章节中提取「情节骨架」——去掉对标书的角色名、世界观细节，
   只保留「发生了什么→为什么发生→结果是什么」的因果链。
2. 将情节骨架填入新章的章纲，但用新书的角色和世界观填充。
3. 从对标书的情绪模块库中，为每章匹配情绪模块卡——本章对标书用了什么情绪模块，
   新书也用什么情绪模块，但实现方式（触发事件、角色反应、台词）全部原创。

**示例：将对标书第 15 章的结构模板迁移到新书第 15 章**

```
【对标书第 15 章骨架】
主角在擂台赛上遭遇强敌 → 第一回合被压制 → 第二回合找到破绽 →
第三回合逆转获胜 → 获胜后收到神秘人的传音（新威胁浮现）

【新书第 15 章】
主角在宗门考核中遭遇强敌 → 第一轮被压制 → 第二轮发现规律 →
第三轮逆转获胜 → 获胜后收到匿名信（新威胁浮现）
```

骨架相同，内容不同。

## Step 5：魔改（核心差异点设计）

**目标**：在结构对标的基础上，设计新书的「核心差异点」——防止读者说「这是抄 XX 的」。

**执行**：

### 5.1 必须原创的维度

以下维度必须与对标书完全不同（相似度要求见下文防抄袭检查）：

| 维度 | 原创要求 | 检查方法 |
|---|---|---|
| 世界观 | 100% 原创 | 对照对标书世界观逐项检查（力量体系/地理/势力/历史） |
| 主角设定 | 100% 原创 | 对照对标书主角人设逐项检查（性格/背景/目标/底线/弱点） |
| 核心情节线 | 相似度 < 30% | 提取对标书的主线情节骨架，与新书主线逐段对比 |
| 配角群像 | 相似度 < 40% | 对照对标书配角功能矩阵（谁在什么位置、起什么作用） |
| 关键台词/名场面 | 100% 原创 | 对标书的名场面不复制、不改编、不「致敬」 |

### 5.2 可以复用的维度

以下维度可以复用对标书的模式，但需要做差异化处理：

| 维度 | 复用方式 | 差异化处理 |
|---|---|---|
| 章节节奏 | 复用对标书的档位分布和交替模式 | 具体每个场景的节奏可以用不同的快慢组合 |
| 情绪弧线 | 复用对标书的弧线类型分布 | 弧线的触发事件、角色反应、台词全部原创 |
| 钩子类型 | 复用对标书的钩子类型和间距 | 钩子的具体内容全部原创 |
| 对话风格 | 复用对标书的对话占句长比和节奏模式 | 角色的声线/口癖全部原创 |
| 情绪模块 | 复用对标书的情绪模块卡（触发条件+实现手法） | 具体实现全部用新书的角色和设定 |

### 5.3 核心差异点设计

新书必须有至少 3 个「核心差异点」——对标书没有的东西，这是新书最独特的卖点。
核心差异点可以是：

1. **设定差异**：对标书是「废柴逆袭」，新书是「天才跌落谷底再爬起」——路径不同，
   骨架相同。
2. **关系差异**：对标书是「师徒」，新书是「宿敌变盟友」——关系结构不同，但关系
   推进的节奏可以相同。
3. **主题差异**：对标书是「复仇」，新书是「守护」——主题不同，但情绪弧线的形状
   可以相同。
4. **视角差异**：对标书是「单男主视角」，新书是「双线叙事」——视角不同，但信息
   投放节奏可以相同。
5. **风格差异**：对标书是「冷峻克制」，新书是「热血中带一丝冷幽默」——腔调不同，
   但节奏骨架相同。

核心差异点写入 `设定/题材定位.md` 的「对标与差异化」字段，并在魔改阶段逐章检查
差异点是否落地。

### 5.4 魔改检查清单

写完首批 5-10 章后，逐章过魔改检查清单：

- [ ] 本章的情节骨架是否与对标书对应章节相似？如果完全一样且没有新的内容，重写
- [ ] 本章的核心差异点是否落地？（至少 1 个核心差异点在本章有体现）
- [ ] 本章的对话/名场面是否有对标书的影子？（如果有，改掉）
- [ ] 本章的角色行为是否能从新书的角色设定中推导出来？（不能从对标书角色推导）
- [ ] 本章的情绪模块是否做了「设定置换」？（触发事件和反应都是新书原创的）

## 防抄袭检查

仿写最大的风险是「结构对标」变成了「内容抄袭」。每写完一个单元（5-10 章），
必须过一次防抄袭检查。

### 相似度阈值

| 维度 | 阈值 | 超标处理 |
|---|---|---|
| 情节线相似度 | < 30% | 超标：重新设计情节线，改变事件顺序或因果链 |
| 角色设定相似度 | < 40% | 超标：重新设计角色（改变性格/背景/目标中的至少 2 项） |
| 关键事件相似度 | 0%（不允许相同） | 超标：删除该事件，用原创事件替代 |
| 台词相似度 | 0%（不允许相同） | 超标：重写台词，改变信息量和表达方式 |

### 情节线相似度计算方法

将新书和对标书的情节线分别提取为「因果链序列」：

```
对标书：[事件A] → [事件B] → [事件C] → [事件D] → [事件E]
新书：  [事件A'] → [事件B'] → [事件C'] → [事件D'] → [事件E']
```

比较每个对应位置的因果链是否相同：
- 因果链相同（「被羞辱→反击→获胜」）= 相似
- 因果链不同（「被羞辱→忍让→另寻机会」）= 不相似

相似度 = 相似因果链数量 / 总因果链数量 × 100%

### 角色设定相似度计算方法

将新书和对标书的主角/配角设定逐项对比：

| 对比项 | 权重 |
|---|---|
| 性格核心 | 30% |
| 背景故事 | 25% |
| 核心目标 | 20% |
| 能力/技能体系 | 15% |
| 外貌特征 | 10% |

每项评分：相同=100%，相似=50%，不同=0%。加权平均 = 角色设定相似度。

### 输入文件（仿写前必须存在）

| 文件 | 来源 | 用途 |

| 文件 | 写入时机 | 内容 |

| `设定/题材定位.md` | Step 3 | 含「对标与差异化」字段 |
| `设定/读者契约.md` | Step 3 | 与对标书对齐的读者契约 |
| `设定/文风锚.md` | Step 2 | 对标书的六维基线 + 新书的腔调关键词 |
| `大纲/总纲.md` | Step 4.2 | 对标结构注入的分卷规划 |
| `大纲/卷纲_第1卷.md` | Step 4.2 | 对标结构注入的情绪弧线/钩子/节奏规划 |

| `设定/情绪模块库.md` | Step 4.3 | 从对标库映射到新书的模块卡 |

### 衔接文件

- **`workflow/deconstruct-pipeline.md`**：拆文阶段（Step 1）的完整执行规范。仿写流程
  不重复 deconstruct-pipeline 的内容，只引用其产出。
- **`craft/style-fingerprint.md`**：风格指纹的提取、校准和迁移规范。Step 2 引用
  其六维文风锚的定义和模板。
- **`workflow/book-init.md`**：开书流程的完整规范。Step 4 引用其 Step 0-4 的完整
  流程，并在每一步中注入对标结构模板。
- **`craft/emotional-arc.md`**：情绪模块卡的定义、分类体系和拆文提取流程。Step 1
  的情绪模块提取和 Step 4.3 的情绪模块映射都引用其规范。
- **`craft/reader-contract.md`**：读者契约的定义和规范。Step 3 的读者契约对齐
  引用其完整定义。

## 常见失败模式

| 失败模式 | 原因 | 预防 |
|---|---|---|
| 结构对标变成了内容抄袭 | 魔改不彻底，情节线和角色太像 | 每 5-10 章过一次防抄袭检查 |
| 对标书的结构不适合新书题材 | 跨题材仿写时没有调整结构模板 | Step 3 做题材匹配度检查 |
| 新书的文风与对标书完全一样 | 没有做风格差异化，前 3-5 章后没重新校准 | 前 5 章写完后重新跑 `style_fingerprint.py` |
| 情绪模块生搬硬套 | 没用新书的设定做置换，情绪触发事件和反应都是对标书的 | Step 4.3 逐章检查设定置换 |
| 核心差异点没落地 | 写了差异化声明，但实际写作中没有体现 | 魔改检查清单逐章过 |
| 对标书选错了 | 对标书本身质量不高，或者和新书题材/目标读者不匹配 | 开书前先确认对标书的市场表现和读者画像 |

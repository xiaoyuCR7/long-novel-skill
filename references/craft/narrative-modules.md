# 叙事元素卡+结构技法卡+情绪模块公式

本文件是叙事工具箱——三个维度覆盖从「最小的叙事单元」到「最大的情绪公式」：
叙事元素卡管「一个场景里用什么叙事工具」、结构技法卡管「一段剧情用什么结构骨架」、
情绪模块公式管「一个情绪弧线用什么模块组合」。三者从上到下，粒度递增。

## 一、叙事元素卡（Narrative Element Cards）

叙事元素 = 场景级别的最小叙事单元。一个叙事元素卡定义了一个可复用的叙事工具，
包含：定义、适用场景、实现手法、常见失败模式、与其他元素的组合建议。

### 1.1 身份反转（Identity Reversal）

**定义**：角色在场景中暴露/切换了与当前认知不同的身份，引发戏剧张力。

**触发条件**：
- 前置铺垫：至少 2 章前埋设身份线索（注意：暴露前不能有直接暗示，只能有间接线索）
- 触发事件：角色被迫或主动暴露真实身份

**实现手法**：
- 旁观者反应先行：先写周围人的反应（震惊/不信/恐惧），再写主角的确认
- 信息差利用：读者早知道身份，但剧中角色不知道 → 戏剧张力
- 反转节奏：身份暴露 → 角色反应滞后（先愣住→再确认→再反应）→ 权威确认（第三方证明）

**常见失败模式**：
- 身份暴露太突然：没有前置铺垫 = 耍读者
- 身份暴露后无后果：身份变了但剧情没变 = 浪费反转
- 身份暴露太频繁：同一角色多次身份反转 = 读者麻木

**组合建议**：与「旁观者反应」元素组合使用，效果加倍。身份反转后必须接「代价兑现」——新身份带来新代价。

---

### 1.2 旁观者反应（Bystander Reaction）

**定义**：通过围观者的态度变化来放大主角行为的冲击力。是爽感/燃感/虐感的最强放大器。

**触发条件**：
- 前置铺垫：围观者对主角的初始态度（不屑/怀疑/轻视）
- 触发事件：主角做出超出围观者预期的行为

**实现手法**：
- 三阶段变化：初始态度（不屑）→ 中间动摇（震惊/不信）→ 最终态度（恐惧/崇拜/改观）
- 代表人物法：不要写「所有人都震惊了」，选 1-2 个具体人物反应代表群体
- 对比强化：不同围观者的反应形成对比（内行看门道/外行看热闹）

**常见失败模式**：
- 旁观者千人一面：所有人反应一样 = 不真实
- 旁观者反应过度：反应超过了事件本身的冲击力 = 浮夸
- 旁观者反应缺失：主角做了大事但没人看到 = 爽感减半

**组合建议**：与「打脸三连」「实力碾压」「身份反转」组合。每 3 章至少用 1 次。

---

### 1.3 代价兑现（Cost Realization）

**定义**：展示角色为某个选择付出的代价，让之前的胜利/成长有重量。

**触发条件**：
- 前置铺垫：读者已知角色做了什么选择/获得了什么
- 触发事件：代价的后果第一次显现

**实现手法**：
- 延迟兑现：选择和代价之间有足够的时间差（至少 3-5 章），让读者差点忘了代价的存在
- 不对称兑现：代价比预期更重，或形式与预期不同（以为会失去力量，实际失去了信任）
- 连锁反应：一次代价触发连锁——失去 A 导致 B 也动摇，C 趁机出手

**常见失败模式**：
- 代价太轻：读者觉得「就这？」= 选择没有重量
- 代价兑现后立即补偿：刚付出代价就得到新补偿 = 代价白费了
- 代价与选择不匹配：选择很轻代价很重（或反之）= 比例失调

**组合建议**：与「V 形弧线」「倒 V 形弧线」的谷底段配合。代价兑现后至少留 1 章让读者消化。

---

### 1.4 信息不对等（Information Asymmetry）

**定义**：利用角色之间（或角色与读者之间）的信息差制造戏剧张力。

**四种配置**（详见 `information-cluster.md` 第五节）：
- 读者全知：读者知道而角色 B 不知道 → 期待角色 B 的反应
- 读者等于主角：读者和主角同步探索 → 代入感最强
- 读者小于主角：主角隐藏信息 → 回收时恍然大悟
- 读者大于角色：读者替角色着急 → 戏剧张力最强

**实现手法**：
- 信息分层释放：不是一次性给完，而是逐层释放——每层改变一次读者的认知
- 信息差收窄：信息差随时间缩小，但缩小过程中制造新的信息差
- 信息差引爆：信息差积累到临界点时引爆（角色 B 发现真相 = 冲突爆发）

**常见失败模式**：
- 信息差过大：读者完全不知道的信息太多 → 看不懂弃书
- 信息差维持过久：读者知道而角色不知道超过 10 章 → 角色太蠢
- 信息差释放太草率：精心建立的信息差一句话释放 → 浪费张力

---

### 1.5 延迟满足（Delayed Gratification）

**定义**：有意延迟读者期待的兑现，用等待放大满足感。

**触发条件**：
- 前置铺垫：读者已建立明确期待（知道要发生什么，但不知道什么时候发生）
- 延迟手段：在期待和兑现之间插入障碍/迂回/新信息

**实现手法**：
- 三明治结构：期待建立 → 第一层延迟（小障碍）→ 接近兑现（假兑现）→ 第二层延迟（更大障碍）→ 真正兑现
- 信号递增：在延迟过程中，释放越来越强的「即将兑现」信号
- 兑现时的慢镜头：延迟越久，兑现时越要写细——用慢镜头把延迟积蓄的能量释放出来

**常见失败模式**：
- 延迟太久：读者等不及了 = 弃书。延迟上限：期待类 3-5 章，悬念类 5-7 章
- 延迟无进展：延迟期间剧情没有任何推进 = 纯水
- 兑现不如预期：延迟越久，期待越高，兑现必须越强

---

### 1.6 假象揭示（Illusion Reveal）

**定义**：揭示一个角色/事件/世界的「表面现象」与「真实本质」之间的差距。

**触发条件**：
- 前置铺垫：建立表面现象（让读者相信 A 是真的）
- 触发事件：一个裂缝/矛盾/异常让角色开始怀疑

**实现手法**：
- 裂缝递增：第一个裂缝很小（角色忽略）→ 第二个裂缝明显（角色怀疑）→ 第三个裂缝证实（角色确认）
- 真相分层：第一层真相（推翻表面现象）→ 第二层真相（真相背后还有真相）→ 终极真相
- 揭示时的认知重塑：不是简单说「其实 A 是假的」，而是让读者重新审视之前的所有线索

**常见失败模式**：
- 假象太假：读者一开始就不信 = 揭示没有冲击力
- 真相反转过度：真相推翻真相再推翻 = 读者混乱
- 揭示后无行动：知道了真相但角色不行动 = 浪费揭示

---

### 1.7 绝境逆转（Desperate Reversal）

**定义**：角色在看似无解的绝境中，凭借之前埋下的伏笔/隐藏实力/意外盟友实现逆转。

**触发条件**：
- 前置铺垫：逆转的筹码必须在至少 2 章前埋下（不能当场开挂）
- 触发事件：角色被逼到绝境，退无可退

**实现手法**：
- 绝望要先到位：逆转前必须让读者真的相信「这次完了」。绝望越深，逆转越爽
- 逆转筹码的揭示：不是「主角突然开挂」，而是「读者突然想起来之前埋的那个伏笔」
- 逆转后的代价：逆转不是免费的——逆转后必须付出代价

**常见失败模式**：
- 逆转筹码是当场拿出来的：机械降神，读者不买账
- 绝望不真实：读者一眼看出主角不会输 = 逆转无感
- 逆转后立刻接新危机：不给读者消化逆转的时间 = 爽感打折

---

### 1.8 平行叙事（Parallel Narrative）

**定义**：两个或多个场景在同一时间并行推进，通过交叉剪辑制造节奏和对比。

**触发条件**：
- 两个场景之间有对比/呼应/因果关系
- 单个场景的节奏不足以支撑全章

**实现手法**：
- 节奏对比：快场景 + 慢场景交替 = 一张一弛
- 信息互补：A 场景的信息解释 B 场景的谜团
- 情绪对冲：A 场景的压抑 + B 场景的爆发 = 情绪放大

**常见失败模式**：
- 平行线无关联：两条线毫无关系 = 读者不知道看哪条
- 切换频率过高：每 200 字切一次 = 读者晕
- 切换频率过低：每 2000 字才切一次 = 平行感消失

---

### 1.9 沉默的力量（Power of Silence）

**定义**：用角色不说话/不行动来制造比说话/行动更强的情绪冲击。

**触发条件**：
- 角色在预期会说话/行动的场景中选择沉默/不动
- 沉默必须比说话传达更多信息

**实现手法**：
- 动作替代：沉默 + 微小动作（手抖/移开视线/嘴唇抿紧）= 比说一百句都有力
- 环境填空：沉默时不写内心，写环境（雨声/远处的声音/光线的变化）
- 沉默的时长控制：短沉默（2-3 句留白）= 犹豫/思考；长沉默（一段落）= 震惊/心死

**常见失败模式**：
- 沉默没有信息量：读者不知道角色为什么沉默 = 莫名其妙
- 沉默后立刻解释：沉默完马上解释「他在想什么」= 沉默白费

---

### 1.10 认知差（Cognitive Gap）

**定义**：利用角色的认知局限（不知道/误解/错误推理）来制造剧情驱动力。

**与信息不对等的区别**：信息不对等是「我知道你不知道」的静态状态；认知差是「我知道的是什么导致我做了什么」的动态驱动。

**实现手法**：
- 认知差驱动行动：角色因为错误认知做了一个决定 → 决定导致后果 → 后果揭示认知错误
- 认知差收窄：角色通过行动逐渐修正认知（不是被告诉，是自己发现）
- 认知差反转：角色以为修正了认知，实际陷入了更深的认知差

**常见失败模式**：
- 认知差靠「别人告诉」解决：角色不自己发现，靠别人告知 → 没有成长感
- 认知差太低智：读者一眼看穿但角色就是看不穿 → 角色太蠢

---

## 二、结构技法卡（Structural Technique Cards）

结构技法 = 比叙事元素更大的结构单元，通常跨 3-10 章，定义了一段剧情的骨架形状。

### 2.1 三幕递进（Three-Act Progression）

**定义**：一段剧情分三幕推进：建立（建立冲突格局）→ 对抗（冲突升级）→ 解决（冲突爆发+结算）。

**适用**：单元级剧情（5-10 章）、卷内子剧情。

**三幕分配**：
- 第一幕（建立）：占 20-25%。建立冲突格局、角色立场、stakes
- 第二幕（对抗）：占 50-60%。冲突升级、阻碍增加、信息释放
- 第三幕（解决）：占 20-25%。冲突爆发、结算、钩子

**关键节点**：
- 第一幕转第二幕：不可逆的决策点（角色做了选择，回不去了）
- 第二幕中点：信息/实力/关系的转折（局势改变方向）
- 第二幕转第三幕：触发事件（冲突从潜伏变成正面爆发）

---

### 2.2 五段起承转合（Five-Phase Arc）

**定义**：比三幕更细的结构，适合短篇（1-2 万字）或长篇中的紧凑单元（3-5 章）。

**五段分配**：
- 起（15%）：建立场景/角色/冲突种子
- 承（25%）：冲突展开，角色行动
- 转（30%）：冲突升级/转折/反转——五段的核心
- 合（20%）：冲突解决/高潮
- 尾（10%）：余韵/钩子

**与三幕的对应**：起+承的前半 = 第一幕；承的后半+转 = 第二幕；合+尾 = 第三幕。

---

### 2.3 双线交叉（Dual-Line Cross）

**定义**：两条剧情线并行推进，在关键节点交叉碰撞，产生戏剧效果。

**适用**：双主角/双视角/主副线并行的章节。

**两种模式**：
- **汇聚型**：两条线从不同起点出发，逐步靠近，最终汇聚。张力来自「读者知道两条线会碰撞但不知道什么时候」
- **分离型**：两条线从同一起点出发，逐步分离，各自发展。张力来自「读者知道两条线会再相遇但不知道变成什么样」

**交叉点设计**：
- 汇聚型：交叉点 = 两条线碰撞的时刻，必须改变至少一条线的方向
- 分离型：再汇聚点 = 分离后的重逢，必须有对比（角色变了/关系变了/世界变了）

---

### 2.4 悬念链（Suspense Chain）

**定义**：多个悬念串联成链，每个悬念的解答引发下一个悬念。

**适用**：悬疑题材、主线谜团推进。

**链式结构**：
```
悬念 A（建立）→ 解答 A（释放）→ 悬念 B（解答 A 引发的新问题）→ 解答 B（释放）→ 悬念 C...
```

**关键规则**：
- 每个悬念的解答 = 下一个悬念的种子——不能让解答成为终点
- 悬念烈度递增：A < B < C < D... 不能递减
- 解答不能一蹴而就：解答 A 时同时释放悬念 B 的线索，让读者在得到答案的同时产生新问题

---

### 2.5 镜像对照（Mirror Contrast）

**定义**：用两个相似但结果不同的场景对照，强化主题/情绪。

**适用**：角色成长展示、主题深化、命运对比。

**实现手法**：
- 场景相同，结果不同：同样的场景（如擂台/考场/告白），第一次输了，第二次赢了
- 角色相同，处境不同：同一个角色在相似处境下做出不同选择（展示成长）
- 处境相同，角色不同：两个角色在相似处境下的不同选择（展示性格差异）

**对照节奏**：第一次场景 → 中间间隔（至少 5 章，让读者有对比空间）→ 第二次场景。

---

### 2.6 倒计时结构（Countdown Structure）

**定义**：给剧情设定一个明确的时间限制，让每一个章节都在倒计时压力下推进。

**适用**：高张力单元、生死关头、限时任务。

**实现手法**：
- 倒计时标记：每章开始/结束标注剩余时间（如「距离决赛还有 3 天」）
- 时间压力递增：越接近期限，障碍越多，压力越大
- 倒计时归零时的爆发：倒计时结束的那一刻必须是本单元最高潮

**适用章数**：3-7 章。太短 = 倒计时没意义；太长 = 压力感消散。

---

### 2.7 伪装与暴露（Disguise & Exposure）

**定义**：角色在伪装状态下行动，伪装逐渐被剥离，最终暴露。

**适用**：卧底/扮猪吃虎/隐藏身份/潜入。

**四阶段结构**：
1. 伪装建立（1-2 章）：建立伪装的背景和规则
2. 伪装维持（2-4 章）：角色在伪装下行动，每次行动都有暴露风险
3. 裂缝出现（1-2 章）：伪装出现裂缝，有人开始怀疑
4. 暴露/主动卸下（1 章）：伪装被剥离或角色主动卸下伪装

**裂缝递增法则**：第一个裂缝 = 小破绽（对方没注意）；第二个裂缝 = 明显破绽（对方开始怀疑）；第三个裂缝 = 致命破绽（暴露不可避免）。

---

### 2.8 升级循环（Upgrade Cycle）

**定义**：标准化的角色成长循环——从「遇到瓶颈」到「突破瓶颈」到「验证突破」的完整周期。

**适用**：升级流玄幻/修仙/系统文的核心驱动结构。

**五阶段循环**：
1. 遇瓶颈（15%）：角色发现当前能力/资源/势力不足以应对下一挑战
2. 寻突破（30%）：角色寻找突破方法（拜师/获取资源/领悟/试炼）
3. 突破（20%）：角色完成突破——能力/境界/资源实现质的飞跃
4. 验证（25%）：角色用新能力应对之前无法应对的挑战（第一次实战检验）
5. 新瓶颈浮现（10%）：突破后揭示更大的瓶颈——下一个循环的种子

**循环纪律**：
- 每个循环的突破方式必须不同：不能连续两次都是「闭关突破」或「奇遇突破」
- 验证必须有「之前做不到→现在做到了」的对比
- 新瓶颈必须比旧瓶颈高一个层级（不是同一个量级的重复）

---

### 2.9 多角度强化（Multi-Angle Reinforcement）

**定义**：同一个关键信息/事件/角色特质，从多个角度反复强化，让读者深度感知。

**适用**：核心设定锚定、角色特质的第一次展示、关键转折的冲击力放大。

**强化角度**：
1. **直接展示**：角色自己做了什么/说了什么
2. **他人反应**：其他角色对此的反应/评价/态度变化
3. **后果展示**：这个行为/事件引发的连锁后果
4. **对比强化**：与另一个角色的类似处境/选择形成对比
5. **回响强化**：在后续章节中，这个事件/行为被再次提及或产生新影响

**强化节奏**：角度 1-2 在同一章内完成；角度 3 在 1-2 章后；角度 4-5 在 3-5 章后。

## 三、情绪模块公式（Emotional Module Formulas）

情绪模块公式 = 将 `emotional-arc.md` 中定义的情绪模块卡组合成可复用的情绪弧线公式。
公式定义了：输入条件 → 模块组合 → 预期输出。

### 3.1 爽感公式

#### 公式 1：打脸三连（Face-Slapping Triple）

```
输入：主角被低估/羞辱 + 主角已具备碾压实力
模块组合：[信息不对等] → [旁观者反应] → [延迟满足] → [实力展示] → [旁观者反应(放大)]
预期输出：读者从「憋屈」→「期待」→「解气」→「痛快」
适用章数：1-2 章
```

**模块详解**：
- 信息不对等：读者知道主角很强，但反派不知道 → 期待感建立
- 旁观者反应（第一轮）：反派低估主角，旁观者附和 → 憋屈感蓄积
- 延迟满足：主角不立刻反击，先让反派得意 → 期待感拉满
- 实力展示：主角出手，碾压 → 第一波爽感释放
- 旁观者反应（第二轮）：反派震惊，旁观者态度反转 → 第二波爽感放大

#### 公式 2：装逼打脸（Showoff Smackdown）

```
输入：主角在公开场合被质疑 + 主角需要证明自己
模块组合：[假象揭示] → [沉默的力量] → [实力展示] → [旁观者反应] → [身份反转]
预期输出：读者从「紧张」→「期待」→「爽」→「震撼」
适用章数：1-2 章
```

#### 公式 3：绝境翻盘（Desperate Comeback）

```
输入：主角被逼到绝境 + 之前埋下的伏笔/筹码
模块组合：[绝境逆转] → [代价兑现] → [延迟满足(慢镜头)] → [旁观者反应]
预期输出：读者从「绝望」→「燃」→「感动」→「满足」
适用章数：1-3 章
```

---

### 3.2 虐感公式

#### 公式 4：无力回天（Powerless Tragedy）

```
输入：主角面对无法改变的命运/失去
模块组合：[延迟满足] → [假象揭示(希望)] → [代价兑现] → [沉默的力量] → [认知差(残酷真相)]
预期输出：读者从「期待」→「希望」→「心碎」→「心疼」
适用章数：2-5 章
```

**关键**：中间必须给一次「假希望」——让读者以为事情有转机，然后夺走。没有假希望的虐 = 平铺直叙的虐，不够痛。

#### 公式 5：错过之痛（Missed Connection）

```
输入：两个角色因为误会/时机/命运错过
模块组合：[信息不对等] → [平行叙事] → [镜像对照] → [沉默的力量]
预期输出：读者从「着急」→「遗憾」→「心酸」
适用章数：1-2 章
```

---

### 3.3 甜感公式

#### 公式 6：双向暗恋（Mutual Pining）

```
输入：两个角色互相喜欢但都不说
模块组合：[信息不对等(读者全知)] → [平行叙事(双方视角)] → [假象揭示(误解)] → [身份反转(告白)]
预期输出：读者从「嗑到了」→「着急」→「甜到齁」
适用章数：3-10 章
```

#### 公式 7：日常温情（Daily Warmth）

```
输入：角色关系稳定，需要一个温馨的日常场景
模块组合：[沉默的力量(动作替代台词)] → [旁观者反应(第三视角)] → [认知差(角色不知道被关注)]
预期输出：读者从「舒适」→「暖」→「会心一笑」
适用章数：0.5-1 章
```

---

### 3.4 燃感公式

#### 公式 8：热血觉醒（Fever Awakening）

```
输入：角色在绝境中找到真正的力量
模块组合：[绝境逆转] → [身份反转(真正的自己)] → [旁观者反应] → [代价兑现]
预期输出：读者从「绝望」→「燃」→「热血沸腾」→「感动」
适用章数：1-2 章
```

#### 公式 9：众志成城（United Stand）

```
输入：多个角色为了共同目标集结
模块组合：[平行叙事(多人视角)] → [旁观者反应(互相见证)] → [多角度强化(同一个信念从不同角度强化)]
预期输出：读者从「期待」→「燃」→「热血」
适用章数：1-3 章
```

---

### 3.5 悬疑公式

#### 公式 10：真相半揭（Half-Revealed Truth）

```
输入：一个核心谜团需要部分揭露
模块组合：[假象揭示(第一层)] → [认知差(新疑点)] → [信息不对等(读者知道一部分)] → [悬念链]
预期输出：读者从「迷惑」→「恍然大悟」→「新的迷惑」
适用章数：1-2 章
```

#### 公式 11：谁是内鬼（Mole Hunt）

```
输入：团队中存在内鬼，需要找出
模块组合：[信息不对等] → [伪装与暴露] → [假象揭示] → [旁观者反应(信任崩塌)]
预期输出：读者从「怀疑」→「紧张」→「震惊」→「后怕」
适用章数：5-15 章
```

## 四、公式选择决策树

写新章时，根据章纲的目标情绪和弧线类型，从公式库中匹配：

```
目标情绪是什么？
├── 爽
│   ├── 打脸类 → 公式 1（打脸三连）或公式 2（装逼打脸）
│   └── 翻盘类 → 公式 3（绝境翻盘）
├── 虐
│   ├── 失去类 → 公式 4（无力回天）
│   └── 错过类 → 公式 5（错过之痛）
├── 甜
│   ├── 关系推进 → 公式 6（双向暗恋）
│   └── 日常温馨 → 公式 7（日常温情）
├── 燃
│   ├── 个人觉醒 → 公式 8（热血觉醒）
│   └── 团队集结 → 公式 9（众志成城）
└── 悬疑
    ├── 谜团推进 → 公式 10（真相半揭）
    └── 内鬼/背叛 → 公式 11（谁是内鬼）
```

## 五、公式组合与情绪弧线的关系

公式不是孤立的——一个公式通常对应情绪弧线中的一段，多个公式串联成完整的情绪弧线。

**示例：一个完整的 V 形弧线（5 章）**

```
章 1-2（下跌段）：公式 4（无力回天）的前半——代价兑现 + 假希望
章 3（谷底段）：公式 4（无力回天）的后半——沉默的力量 + 残酷真相
章 4-5（反弹段）：公式 3（绝境翻盘）——绝境逆转 + 旁观者反应
```

**示例：一个完整的 W 形弧线（10 章）**

```
章 1-2（第一 V 下跌）：公式 5（错过之痛）
章 3（第一 V 谷底）：沉默的力量
章 4-5（第一 V 反弹）：公式 7（日常温情）
章 5-6（过渡段）：公式 10（真相半揭）——新信息打破温情
章 7-8（第二 V 下跌）：公式 4（无力回天）——比第一 V 更深的谷底
章 9（第二 V 谷底）：公式 8（热血觉醒）——觉醒
章 10（第二 V 反弹）：公式 3（绝境翻盘）——比第一 V 更高的反弹
```

## 六、公式的自定义与扩展

公式不是固定模板——每个公式都可以根据题材和角色调整：

1. **题材替换**：玄幻的「打脸」= 擂台碾压；都市的「打脸」= 职场/社交碾压；言情的「打脸」= 关系反转
2. **模块替换**：公式中的某个模块效果不好 → 从叙事元素卡中找替代模块
3. **公式杂交**：两个公式的部分模块可以组合——如「打脸三连」+「热血觉醒」= 打脸时同时觉醒
4. **新公式登记**：从拆文中提取的新公式，记录到本文件的「公式」节，标注来源对标书

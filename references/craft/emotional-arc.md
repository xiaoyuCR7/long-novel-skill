# 情绪弧线操作手册

本文件是 `emotion.md` 的弧线设计延伸。`emotion.md` 定义了情绪的交付单元（蓄积→爆发→
余韵）、对比原则、写法规范——管「一个情绪点怎么写」。本文件定义**情绪在多章/多卷
跨度上的弧线形状**——管「一段故事的情绪该怎么起伏、起伏多少次、每次多大」。

分工：写单章的情绪节奏查 `emotion.md`；排卷纲/单元的情绪走向、设计跨章情绪起伏
查本文件。`pacing-and-hooks.md` 管节奏的快慢档位与信息密度，本文件管节奏背后的
情绪曲线——档位是骨架，情绪是血肉。

## 六种情绪弧线

情绪弧线 = 一段故事（一章/一个单元/一卷）中情绪状态的起伏形状。不同形状适合不同
的章节位置和节奏档位。

### 1. V 形（先抑后扬）

```
情绪
高 |*
   |     *
低 |         *
   |____________
     章1  章2  章3
```

- **形状**：从高情绪（通常是正面/平静）跌入低谷，再反弹到更高点
- **触发条件**：主角遭遇重大挫折→重新站起来→反击成功
- **字数分配**：下跌段 40%、谷底段 20%、反弹段 40%。谷底不能太短（读者还没感受到
  痛就反弹了 = 假虐），不能太长（读者等不及了 = 弃书）
- **适合位置**：单元中段、卷中高潮前铺垫
- **节奏档位**：下跌段=中档（压力累积）、谷底=慢档（情绪沉淀）、反弹=快档（爆发）
- **典型场景**：修炼受挫→被羞辱→突破反杀；感情线误会→冷战→和解告白

### 2. 倒 V 形（先扬后抑）

```
情绪
高 |         *
   |     *
低 |*
   |____________
     章1  章2  章3
```

- **形状**：从低点上升到高点，再跌入更深谷底
- **触发条件**：主角以为赢了→实际是陷阱/更大危机浮现
- **字数分配**：上升段 35%、高点段 15%、下跌段 50%。下跌段最长，因为要让读者充分
  感受到「得而复失」的落差
- **适合位置**：卷末反转、单元结尾留钩子
- **节奏档位**：上升=中档、高点=快档（短暂爆发）、下跌=中档转慢档（余震）
- **典型场景**：打完Boss发现背后还有更大黑手；以为和好了实则对方另有目的
- **注意**：倒V形是制造「意难平」最强效的弧线，但一卷最多用1-2次，多了读者会觉得
  作者在故意虐人

### 3. W 形（双谷双峰）

```
情绪
高 |*           *
   |  *       *
低 |    *   *
   |________*
     章1 2 3 4 5 6
```

- **形状**：V形之后再接一个V形，形成两次低谷两次反弹
- **触发条件**：主角经历两轮挫折-反弹，第二轮的挫折比第一轮更深、反弹比第一轮更高
- **字数分配**：第一V占40%、过渡段10%、第二V占50%。第二V必须比第一V的幅度大，
  否则读者会觉得重复
- **适合位置**：整卷的情绪主线（一个卷=一个W形）、长单元（10-15章）
- **节奏档位**：每个V内部按V形的档位分配，两个V之间的过渡用慢档
- **典型场景**：第一轮试炼失败→小胜→发现真正的考验→绝境→终极突破
- **注意**：W形的第二次低谷不能比第一次浅（否则是倒N形，读者觉得越打越轻松），
  第二次反弹必须比第一次高（否则读者觉得白折腾了）

### 4. 递进形（阶梯上升）

```
情绪
高 |              *
   |          *
   |      *
低 |*
   |____________
     章1 2 3 4 5
```

- **形状**：情绪持续上升，每一级比上一级高，没有明显回落
- **触发条件**：主角持续获得胜利/成长，节奏紧凑无喘息
- **字数分配**：每级台阶约占总篇幅的 1/N（N=台阶数），最后一级最长（爆发点）
- **适合位置**：升级流的高潮段、碾压爽文的连续打脸段
- **节奏档位**：全程中档到快档，不插入慢档（慢档会打断递进感）
- **典型场景**：连战连胜的擂台赛、连续打脸反派链
- **注意**：递进形不能超过5-7章，否则读者情绪疲劳（爽连着爽就不爽了，见
  `emotion.md` 防麻木）。递进形结束后必须接一个慢档章做情绪降温

### 5. 延迟满足形（长蓄短爆）

```
情绪
高 |              *
   |
   |
低 |**************
   |____________
     章1 2 3 4 5 6
```

- **形状**：长时间低位蓄积（压力/期待持续累积），最后瞬间爆发到极高
- **触发条件**：大伏笔回收、终极真相揭晓、积怨已久的总爆发
- **字数分配**：蓄积段 70-80%、爆发段 20-30%。蓄积段越长，爆发越烈——但蓄积段
  内部必须有微起伏（小希望→小失望→新希望），不能是一条平线
- **适合位置**：卷末大高潮、全书终局爆发、长线伏笔回收章
- **节奏档位**：蓄积段=慢档+中档交替（铺垫为主）、爆发段=快档（慢镜头写细）
- **典型场景**：卧底多卷后身份反转揭底、修炼瓶颈多章后的一朝突破
- **注意**：延迟满足是爆发力最强的弧线，但也是最容易写崩的——蓄积段太长读者等不住，
  太短爆发不够烈。关键在蓄积段内部的「微起伏」：每隔2-3章给一个小钩子/小进展，
  让读者觉得「快要爆发了但还没」

### 6. 急转形（断崖式反转）

```
情绪
高 |******|
   |      |
低 |      |********
   |____________
     章1  章2
```

- **形状**：情绪在一个高位稳定运行，突然断崖式跌入谷底（或反向：低位突跳到高位）
- **触发条件**：重大反转、核心人物背叛、身份突然揭晓、以为死了的人活着回来
- **字数分配**：高位段 60%、转折点 5%（极短，一章内甚至半章内完成）、新状态段 35%
- **适合位置**：卷末反转章、单元转折点、中点大反转
- **节奏档位**：高位段=中档、转折点=快档（极速推进）、新状态段=慢档（消化冲击）
- **典型场景**：信任的导师突然是最终Boss、以为的胜利其实是陷阱
- **注意**：急转形必须有前置铺垫（伏笔/线索），否则就是「为反转而反转」。反转的
  力度来自「读者回头一看，线索一直在那但自己没注意」。无铺垫的急转 = 耍读者

## 情绪引擎：循环周期

情绪不是一次性消费，而是一个持续运转的引擎。引擎的四冲程循环：

```
期待建立 → 压力累积 → 释放 → 新期待
   ↑                              |
   └──────────────────────────────┘
```

### 四冲程详解

1. **期待建立**：给读者一个「想要看到什么」的钩子。期待要具体——不是「主角会变强」，
   而是「主角下周的擂台赛能不能赢过那个羞辱过他的人」。
2. **压力累积**：在期待和兑现之间设置障碍。障碍越多越具体，释放时的爽感越强。
   压力累积 = 给读者「快要到了但还差一步」的焦虑感。
3. **释放**：兑现期待。释放要充分——大爽点用慢镜头写细（见 `emotion.md` 蓄积→
   爆发→余韵），不能草草带过。
4. **新期待**：在释放的同时埋下新的期待。新期待不能等旧期待完全释放后才建立——
   在释放的余韵中就要植入新钩子，让引擎无缝衔接。

### 循环周期与章节的关系

一个完整的情绪引擎循环通常跨 3-7 章：

| 循环阶段 | 典型章数 | 说明 |
|---|---|---|
| 期待建立 | 0.5-1章 | 章尾钩子或卷首宣言建立 |
| 压力累积 | 2-4章 | 障碍/挫折/延迟，中档为主 |
| 释放 | 0.5-1章 | 快档爆发章 |
| 新期待 | 释放章的尾段 | 余韵中植入 |

- 短循环（3章）：番茄节奏，每3章一个完整循环，高频低烈
- 中循环（5章）：起点节奏，5章一个循环，中频中烈
- 长循环（7章+）：终局/大伏笔回收，低频高烈，延迟满足形

**纪律**：不要同时运转两个以上的长循环——读者同时追踪的期待线不超过3条。
期待线过多 = 读者忘了在等什么 = 压力累积失效。

## 读者需求类型

读者来看网文，核心需求可归为五大类。每本书的读者契约决定了主打哪几类，但全书
不应只供应一种。

### 五大需求类型

| 类型 | 子类 | 核心满足 | 兑现方式 |
|---|---|---|---|
| 爽 | 碾压/逆袭/打脸 | 力量差距的展示与逆转 | 对手的反应变化（从不屑到恐惧） |
| 虐 | 虐心/虐身/意难平 | 情感的撕裂与遗憾 | 读者替角色心疼、替角色不甘 |
| 甜 | 甜宠/暧昧/双向奔赴 | 情感的温暖与确认 | 关系距离的缩短（从远到近） |
| 燃 | 热血/燃爆/高燃 | 意志的碰撞与突破 | 不可能变成可能的瞬间 |
| 悬疑 | 解谜/反转/真相 | 未知的探索与揭晓 | 困惑→线索→拼图→真相 |

### 需求配比与题材的关系

不同题材的主打需求不同，但无论什么题材，都不应100%只供应一种：

| 题材 | 主打 | 辅助 | 禁忌 |
|---|---|---|---|
| 玄幻修仙 | 爽+燃 | 悬疑（身世/真相） | 甜宠过多会冲淡热血 |
| 都市爽文 | 爽 | 甜（感情线） | 虐过重会赶走爽文读者 |
| 言情 | 甜+虐 | 悬疑（误会/反转） | 纯甜无虐 = 没有张力 |
| 悬疑推理 | 悬疑 | 虐（受害者共情） | 爽点过多会破坏推理严肃性 |
| 历史 | 燃+爽 | 虐（家国情怀） | 甜宠突兀 |

### 需求交替的纪律

`emotion.md` 的「防麻木」原则要求情绪换台。本文件补充换台的**周期纪律**：

- 同一种需求连续供应不超过 3 章（第4章读者开始钝化）
- 换台时选择**反差最大的类型**：爽后接虐/虐后接甜/甜后接悬疑，不要爽后接燃
  （两者都是高唤醒情绪，不构成有效休息）
- 换台不等于完全切换——主线情绪不变，只是插入一段不同情绪的副线章节
- 每 7-10 章必须至少出现一次需求类型切换（连续10章纯爽 = 钝化警戒线）

## 情绪密度公式

### 章内情绪转换上限

一章内情绪转换次数 ≤ 3 次。

情绪转换 = 从一种需求类型跳到另一种（如从虐到甜），或同一种需求内的方向反转
（如从压抑到爆发）。

- 0 次转换：全章单一情绪，适合铺垫章/慢档章
- 1 次转换：最常见，如「压抑→爆发」「平静→危机」，适合大多数中档章
- 2 次转换：如「平静→危机→化解」，适合快档推进章
- 3 次转换：如「胜利→反转→再反转」，适合高潮章/反转章
- ≥4 次转换：**禁止**。读者来不及消化就被拉着跑，情绪变成走马灯，什么都没感受到

### 跨章情绪周期

跨章情绪周期建议 3-7 章（与情绪引擎循环对齐）。

- 周期 < 3 章：情绪起伏太快，读者疲劳，适合短篇/番茄快节奏
- 周期 3-5 章：标准周期，适合起点/晋江连载节奏
- 周期 5-7 章：慢热周期，适合大单元/卷级弧线
- 周期 > 7 章：延迟满足，仅限大伏笔回收/终局爆发，全书不超过2-3次

### 密度公式总结

```
章内转换 ≤ 3 次
跨章周期 = 3-7 章
同需求连续供应 ≤ 3 章
全书延迟满足周期 ≤ 2-3 次
```

四个公式互相约束：如果跨章周期是5章、同需求连续3章，那么剩余2章必须是其他需求
类型——这就是情绪换台的数学依据。

## 情绪与钩子的配合

### 章尾情绪状态决定追读率

章尾的情绪状态是读者「点下一章还是关掉」的决定因素。不同情绪状态的追读效果：

| 章尾情绪状态 | 追读效果 | 适用场景 |
|---|---|---|
| 悬而未决（最高） | 极强：读者必须知道结果 | 悬疑章、反转半句、选择悬置 |
| 压力累积中（高） | 强：读者等着爆发 | 虐心章、危机升级章 |
| 刚释放后（中高） | 较强：余韵吸引继续 | 爽点章的余韵段、甜章的温馨收尾 |
| 平静/日常（低） | 弱：读者觉得「明天看也行」 | 慢档日常章——必须配微型钩子补强 |
| 完全释放后（最低） | 极弱：读者满足后关掉 | 大高潮后的纯粹收尾章——最危险 |

### 章尾情绪设计原则

1. **高潮章不纯收尾**：大爆发后留一个新钩子（新危机/新信息），不要让读者「满足后
   关掉」。余韵段里植入新期待，保持引擎运转。
2. **日常章必有微型钩子**：慢档章的章尾最容易「平淡收场」。必须埋一个微型伏笔或
   新信息（一句闲话里的线索、一个角色的微小反应），把追读率拉起来。
3. **虐心章章尾要留希望**：纯虐的章尾会让读者「太难受不想看了」。虐的章尾要留一
   线希望（转机/盟友/新线索），让读者觉得「快要好了但还没」。
4. **反转章章尾要留消化空间**：急转形反转后不要立刻接新事件，章尾停在「主角消化
   冲击」的状态，让读者和主角一起震惊，自然想看下一章主角怎么办。

## 情绪模块卡（可复现）

情绪模块卡是从拆文中提取的情绪单元，用于在不同书中复现同一种情绪效果。每张卡
包含：触发条件、预期读者反应、实现手法。

### 模块卡格式

```
【情绪模块卡：{名称}】
需求类型：爽/虐/甜/燃/悬疑
情绪弧线：V形/倒V形/W形/递进/延迟满足/急转

触发条件：
  - 前置铺垫：需要什么前置（伏笔/关系建立/压力累积）
  - 触发事件：什么事件点燃这个情绪单元

预期读者反应：
  - 情绪状态：读者此刻应感到什么
  - 行为反应：读者此刻想做什么（追下一章/拍桌/心疼/期待）

实现手法：
  - 节奏：快/中/慢，字数分配
  - 写法：心理外化/动作慢镜头/对话推进/旁观者反应
  - 配合元素：钩子类型、伏笔操作、档位声明

注意事项：
  - 常见失败模式
  - 与其他情绪模块的衔接
```

### 示例模块卡

```
【情绪模块卡：打脸三连】
需求类型：爽
情绪弧线：递进形

触发条件：
  - 前置铺垫：反派在3章前公开羞辱/贬低主角，读者代入了屈辱感
  - 触发事件：主角在公开场合与反派再次相遇，且主角已具备碾压实力

预期读者反应：
  - 情绪状态：从期待→解气→痛快
  - 行为反应：拍桌叫好，立刻追下一章看后续反应

实现手法：
  - 节奏：快档，打脸过程400-600字慢镜头
  - 写法：三连结构——第一击（实力展示，反派不信）→第二击（碾压，反派震惊）→
    第三击（彻底碾压，旁观者反应引爆）
  - 配合元素：旁观者的态度反转（从不屑到恐惧/崇拜）是爽感放大器
  - 钩子：打脸后反派背后的更大势力浮现

注意事项：
  - 失败模式1：打脸太容易（一击就赢）= 爽感不足。必须让反派挣扎一下
  - 失败模式2：旁观者反应缺失 = 爽感减半。打脸的快感一半来自围观者的态度变化
  - 失败模式3：打脸后立刻接新事件 = 余韵不足。留1-2段旁观者反应
  - 衔接：打脸后接慢档章降温（日常/关系深化），不要连续打脸
```

### 模块卡的积累与复用

拆文时（见 `workflow/deconstruct.md`）每遇到一个有效的情绪单元，就提取一张模块卡，
存入 `设定/情绪模块库.md`。写新章时，根据章纲的目标情绪和弧线类型，从库里找匹配
的模块卡作为实现参考。

模块卡不是模板——不是照抄，而是参考「这种情绪以前是怎么实现的、哪些手法有效、
哪些失败模式要避开」。每本书的设定不同，模块卡的实现细节要根据本书角色和世界观
调整。

### 常用模块卡清单（开书时优先积累）

| 优先级 | 模块卡 | 理由 |
|---|---|---|
| 高 | 打脸三连 | 爽文核心单元，出现频率最高 |
| 高 | 误会冰释 | 甜/虐文核心单元，关系转折点 |
| 高 | 真相半揭 | 悬疑文核心单元，悬念引擎 |
| 中 | 绝境突破 | 燃文核心单元，热血高潮 |
| 中 | 代价兑现 | 所有题材通用，让胜利有重量 |
| 中 | 旁观者反应 | 爽感放大器，所有高潮章都用 |
| 低 | 日常温情 | 慢档章的情绪内容，防「水章」 |
| 低 | 离别余韵 | 卷末/角色退场，余韵制造 |

积累顺序：先积累高频核心模块卡（打脸/误会/真相），再补辅助模块卡（旁观者/代价），
最后补低频但必要的模块卡（日常/离别）。一个成熟的模块库应有 10-15 张卡，覆盖
全书 80% 以上的情绪场景。

## 长篇情绪引擎：因果链模型

情绪不是凭空产生的——每个情绪单元背后都有一条因果链。长篇写作中，情绪失控
（该燃的地方没燃、该虐的地方没虐到位）的根本原因，往往不是写法问题，而是因果链
断裂——读者不知道「为什么要有这个情绪」。

### 因果链七段

```
核心情绪命题 → 承载对象 → 受阻原因 → 触发事件 → 主角动作 → 意义变化 → 题材兑现
```

**1. 核心情绪命题**

每一段情绪弧线必须回答一个核心命题：这段故事想要读者「感受到什么」？命题要具体——
不是「感到悲伤」，而是「为一段注定没有结果的守护感到悲伤」。

命题不能空洞，空洞命题无法指导写法。对比：
- 空洞：「让读者感动」——不知道怎么感动
- 合格：「让读者为一个明知会死却依然赴约的角色感到心疼和敬佩」——知道写什么、
  怎么写、写多久

**2. 承载对象**

情绪需要一个具体的人/物/关系来承载。抽象的「正义」「自由」不承载情绪——除非它
附着在具体的人身上。承载对象 = 读者情感投射的靶子。
- 角色的承载：主角/配角/反派——读者把情感投射到谁身上
- 关系的承载：一段友情/爱情/亲情——读者把情感投射到一段关系上
- 物的承载：一把剑/一封信/一个地方——物承载记忆，记忆承载情感

**3. 受阻原因**

情绪来自「想要的得不到」。如果承载对象一路顺遂，情绪就无从产生。受阻原因 = 情绪
的燃料——阻碍越大，爆发越烈。
- 外部受阻：敌人/环境/规则/社会——力量型受阻
- 内部受阻：性格缺陷/道德困境/信息不对等——情感型受阻
- 命运受阻：不可抗力/宿命/时间——存在型受阻

三种受阻的烈度递增：外部受阻 < 内部受阻 < 命运受阻。最高级的虐来自命运受阻——
不是打不过，是「无论怎么选都是错的」。

**4. 触发事件**

受阻后的情绪不会自动爆发——需要一个触发事件引燃。触发事件 = 把蓄积的压力
转化为可见的情绪。
- 触发事件必须是具体的、可感知的（一句话/一个动作/一个场景）
- 触发事件必须和受阻原因有直接逻辑关联（因为受阻于 X，所以被 Y 触发）
- 触发事件的力度 = 情绪爆发的烈度——触发事件越重，爆发越强

**5. 主角动作**

情绪爆发后，主角做什么？主角的反应 = 情绪的高潮——不是「他很难过」，而是
「他难过到做了什么」。
- 外化动作：砸东西/战斗/离开——高唤醒情绪（怒/燃/狂喜）
- 内化动作：沉默/静止/不回应——低唤醒情绪（悲/惧/心死）
- 关系动作：告白/决裂/和解——关系型情绪（爱/恨/耻）

**6. 意义变化**

情绪爆发后，世界/关系/主角对自己的认知发生了改变——这就是情绪的意义。
没有意义变化的情绪 = 白发泄了。

意义变化分三层：
- 关系层：A 和 B 的关系从 {旧状态} 变成了 {新状态}
- 认知层：角色对某件事的认知从 {旧认知} 变成了 {新认知}
- 价值层：角色对自己/世界的价值判断从 {旧价值} 变成了 {新价值}

每段情绪弧线至少触发一层意义变化，好的情绪弧线触发两层。

**7. 题材兑现**

情绪最终要兑现为题材的核心快感：
- 爽文：情绪 → 力量展示/碾压 → 爽
- 虐文：情绪 → 无力感/遗憾 → 虐
- 甜文：情绪 → 距离缩短/确认 → 甜
- 燃文：情绪 → 突破/逆转 → 燃
- 悬疑文：情绪 → 揭晓/反转 → 悬疑

题材不适配的情绪 = 无效情绪。在虐文里写打脸爽感，读者不买账。在爽文里写
大段虐心，读者弃书。

### 合理性五问

写完一段情绪弧线后，用五个问题自检因果链是否完整：

1. **命题问**：这段情绪在回答什么核心命题？命题是否具体到可以指导写法？
2. **承载问**：读者的情绪投射到谁/什么关系/什么物上？承载对象是否足够具体？
3. **受阻问**：承载对象想要什么？为什么得不到？阻碍是否足够强劲？
4. **触发问**：什么事件引爆了情绪？触发事件和受阻原因是否有直接逻辑关联？
5. **兑现问**：这段情绪最终兑现为本题材的什么核心快感？有没有题材错配？

五问中任何一问回答不出 → 因果链断裂 → 情绪不可信 → 读者无感。

## 正向发动机 vs 负向护栏

长篇情绪设计中，有两套并行运转的系统：正向发动机（推动读者向前冲）和负向护栏
（防止读者弃书）。两者分工不同，顺序有讲究。

### 正向发动机：让读者追下去

正向发动机 = 读者「想要看到什么」的驱动力。六大正向发动机：

| 发动机 | 定义 | 典型写法 | 适用题材 |
|---|---|---|---|
| 悬念驱动 | 读者想知道真相/结果 | 章尾钩子、信息差、未揭之谜 | 悬疑、推理 |
| 目标驱动 | 读者想看主角达成目标 | 升级/复仇/寻宝/夺冠 | 玄幻、游戏 |
| 关系驱动 | 读者想看两人关系发展 | 暧昧/误会/和解/告白 | 言情、甜宠 |
| 身份驱动 | 读者想看身份揭晓/反转 | 隐藏身份/扮猪吃虎/卧底 | 都市、历史 |
| 代价驱动 | 读者想看角色付出代价 | 因果报应/代价兑现/伏笔回收 | 所有题材 |
| 好奇驱动 | 读者想看「接下来会发生什么」 | 新奇设定/反常场景/意外事件 | 脑洞、科幻 |

一本书应同时运转 2-3 个正向发动机，但必须有一个主发动机（占比 > 50%）。
主发动机决定书的类型标签，副发动机提供多样性。

### 负向护栏：防止读者弃书

负向护栏 = 防止读者因为某些原因弃书的保护机制。六大负向护栏：

| 护栏 | 防御的弃书原因 | 典型写法 | 触发时机 |
|---|---|---|---|
| 希望护栏 | 太虐了不想看了 | 在虐的章尾留一线希望（转机/盟友/新线索） | 虐心段章尾 |
| 节奏护栏 | 太慢了不想看了 | 慢档章插入微型钩子，每 2000 字一个小钩子 | 铺垫段/慢档章 |
| 公平护栏 | 主角太惨了不公平 | 让主角每受一次挫就获得一点补偿（信息/力量/盟友） | 挫折段 |
| 人设护栏 | 主角人设崩了 | 主角做任何极端行为前给动机铺垫（至少 1 章） | 主角做争议行为前 |
| 逻辑护栏 | 不合理看不下去了 | 每个反转/巧合前埋伏笔（至少 2 章前） | 大反转/巧合前 |
| 疲劳护栏 | 累了不想看了 | 每 7-10 章换一次情绪类型（需求类型切换） | 连续同需求 > 3 章 |

### 正负向发动机的配合顺序

每章写作时，正负向发动机的配置顺序：

1. **先定正向发动机**：本章的主发动机是什么？读者追这章的动力是什么？
2. **再查负向护栏**：本章可能触发读者哪些弃书原因？需要哪些护栏？
3. **最后配比**：正向发动机驱动的内容占比 70-80%，负向护栏占 20-30%。

正负向发动机的配比是一个动态平衡——太偏正向 = 读者爽但容易疲劳（没护栏保护）；
太偏负向 = 读者觉得作者太小心（没发动机驱动）。

## 情绪模块按类型分类（八大类）

情绪模块卡（见上文「情绪模块卡」一节）可以按基本情绪类型归类。这种分类有两个
用途：一是拆文时快速定位一段文本的情绪类型，二是写新章时根据目标情绪类型从类别
中检索匹配的模块卡。

### 八大情绪类型

#### 1. 爱（Love）

核心体验：温暖、亲近、确认、归属

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 告白/确认心意 | 台词留白 + 动作慢镜头 + 环境柔化（光线/温度/声音变暖） | 误会冰释、双向奔赴 |
| 守护/牺牲 | 代价前置（先展示要牺牲什么） + 旁观者视角（他做的时候别人看到） | 代价兑现、无声守护 |
| 日常温情 | 细节不对称（一方了解另一方到骨子里） + 微小动作（倒水、披衣服） | 日常温情 |
| 重逢 | 时间标记（多久没见） + 变化的对比（对方变了什么/没变什么） | 离别余韵 |
| 亲情羁绊 | 不说「我爱你」，说「吃饭了」「冷吗」「早点回来」——亲情用行动不靠台词 | 日常温情 |

**写作纪律**：爱的情绪不要用「我好爱你」「我离不开你」这种直白台词——台词越直白，
情绪越廉价。爱的情绪靠「不对称的细节」——一方知道另一方都不知道自己在被关注着
的细节。

#### 2. 恨（Hate）

核心体验：愤怒、复仇、毁灭冲动

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 仇人见面 | 压制型对话 + 动作克制（越恨越冷，而不是越恨越疯） | 打脸三连 |
| 复仇兑现 | 延迟满足形弧线 + 让对方先得意再绝望 | 代价兑现 |
| 背叛揭露 | 心死型对话 + 证据逐条抛出（不是一次性全扔） | 真相半揭 |
| 积怨爆发 | 长蓄短爆 + 爆发时用短句连击（每句 ≤ 10 字） | 绝境突破 |
| 暗恨/隐忍 | 角色在人前正常，独处时露出恨意——对比 = 张力 | 无典型模块卡，需要定制 |

**写作纪律**：恨的情绪要克制着写——越恨越冷，不是越恨越疯。疯掉的恨让人害怕，
但不会让人共鸣。读者共鸣的是「在克制中的恨」——明明恨到想杀了对方，但忍住了，
因为还有更重要的事。

#### 3. 惧（Fear）

核心体验：不安、紧张、无助、压迫感

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 恐怖氛围 | 环境先行（先写环境变化，再写角色反应） + 信息差（读者知道角色不知道） | 无典型模块卡，需要定制 |
| 实力碾压 | 旁观者反应（先写别人的恐惧，再写主角的） + 细节放大（对手的某个动作慢镜头） | 旁观者反应 |
| 失去恐惧 | 先展示「拥有什么」（建立珍惜） + 再威胁「可能失去」 | 代价兑现 |
| 未知恐惧 | 只给线索不给全貌——恐惧 = 已知 + 未知，已知越少，恐惧越大 | 真相半揭 |
| 抉择恐惧 | 两个选项都展示代价 → 角色犹豫的过程 → 读者比角色更紧张 | 无典型模块卡，需要定制 |

**写作纪律**：恐惧不是靠「他很害怕」告诉读者的——恐惧靠「读者比角色更早意识到
危险」来制造。信息差 = 读者看到刀在角色背后但角色不知道 = 恐惧。

#### 4. 悲（Sadness）

核心体验：心疼、遗憾、无力、失去

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 角色死亡 | 死前高光（死前展示角色最珍贵的一面） + 死后留白（不写哭，写空） | 离别余韵 |
| 诀别/分离 | 台词越短越好 + 环境填空（不说「难过」，写雨/风/空荡的房间） | 离别余韵 |
| 错过的遗憾 | 用「如果」句式展示另一个可能性 + 对比现实的不可挽回 | 无典型模块卡，需要定制 |
| 被辜负 | 心死型对话 + 无动作（不哭不闹不质问 = 最高级的悲伤） | 误会冰释（反向） |
| 物是人非 | 旧地重游 + 记忆闪回 + 对比当下 | 无典型模块卡，需要定制 |

**写作纪律**：悲伤不靠「哭了」「泪流满面」——眼泪是最廉价的悲伤。真正的悲伤是
「哭不出来」——角色不哭，读者哭。靠场景留白、动作缺失、环境填空来制造悲伤。

#### 5. 怒（Anger）

核心体验：不满、爆发、反击、宣泄

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 被羞辱后的反击 | V形弧线 + 打脸三连 + 旁观者反应放大 | 打脸三连 |
| 底线被踩 | 三级以上冲突递进 + 动作同步升级（说话时站起来→摔东西→动手） | 绝境突破 |
| 替人出头 | 先展示「被欺负的人有多惨」 + 再展示「出头的人有多愤怒」 | 旁观者反应 |
| 隐忍爆发 | 长蓄短爆 + 爆发前蓄积段有小动作预兆（手指越握越紧） | 绝境突破 |
| 正义愤怒 | 先建立「规则被破坏」 + 再展示「愤怒者对规则的维护」 | 无典型模块卡，需要定制 |

**写作纪律**：愤怒是最容易写「过」的情绪——不要让角色一直处于愤怒状态。愤怒是
高唤醒情绪，持续时间超过 500 字 = 读者疲劳。愤怒之后必须有释放（行动）或转移
（冷静下来想对策）。

#### 6. 喜（Joy）

核心体验：快乐、满足、成就、圆满

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 胜利/突破 | 递进形弧线 + 慢镜头（胜利的过程而不是结果） + 旁观者反应 | 绝境突破 |
| 收获/获得 | 先展示「付出了什么代价」 + 再展示「收获了什么」——代价越大，喜悦越强 | 代价兑现 |
| 重逢/团聚 | 时间标记 + 变化对比 + 第一句话（重逢后的第一句话决定情绪走向） | 离别余韵（反向） |
| 被认可 | 认可来自「最不可能认可你的人」 + 认可的方式是「他最不擅长的方式」 | 无典型模块卡，需要定制 |
| 意外惊喜 | 先建立「不期待」 + 再给惊喜——惊喜 = 期待差，差值越大越惊喜 | 日常温情 |

**写作纪律**：喜悦不能只靠「笑了」「很开心」——喜悦靠「对比」：和之前多惨对比、
和别人的反应对比、和角色的预期对比。没有对比的喜悦 = 平淡。

#### 7. 惊（Surprise）

核心体验：震惊、意外、颠覆认知

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 身份反转 | 急转形弧线 + 前置伏笔（至少 2 章前埋线） + 反转瞬间用短句引爆 | 真相半揭 |
| 实力暴露 | 先让旁观者低估 + 再展示真实实力 + 旁观者反应（从嘲讽到恐惧） | 旁观者反应 |
| 真相揭晓 | 信息逐条释放（不是一次全给） + 每条信息改变一次读者对事件的认知 | 真相半揭 |
| 意外重逢 | 日常场景中突然出现 + 角色反应滞后（先愣住→再确认→再反应） | 无典型模块卡，需要定制 |
| 剧情反转 | 倒V形弧线 + 反转后留消化空间（不要立刻接新事件） | 真相半揭 |

**写作纪律**：惊的情绪必须有前置铺垫——没有伏笔的惊喜 = 耍读者。读者回头看时
能发现线索 = 铺垫到位；回头看时发现之前完全没提 = 耍读者。

#### 8. 耻（Shame）

核心体验：羞耻、丢脸、社会性死亡、尊严受损

| 典型场景 | 实现手法 | 代表模块卡 |
|---|---|---|
| 公开羞辱 | 旁观者视角放大（先写围观者的反应，再写角色的反应） + 羞辱后角色行为的改变 | 旁观者反应（反向） |
| 实力暴露不足 | 对比（别人的实力 vs 自己的实力） + 旁观者反应（从期待到失望） | 打脸三连（反向） |
| 被揭穿谎言 | 证据逐条抛出 + 角色反应层层递进（嘴硬→动摇→崩溃） | 真相半揭 |
| 身份落差 | 从高位跌到低位 + 别人态度的变化（从尊敬到不屑） | 无典型模块卡，需要定制 |
| 亏欠感 | 角色欠了别人但无力偿还 + 每次见到对方都触发耻感 | 代价兑现（反向） |

**写作纪律**：耻感是网文中最被低估的情绪——很多作者不敢写主角丢脸。但适度的
耻感是「护主角」的反面教材：主角丢脸一次，读者心疼一次，下一次主角翻身时，
爽感翻倍。耻感 = 爽感的蓄力。

### 情绪类型的复合

一段情绪弧线通常不是单一类型——它是多种类型的复合。复合规则：

1. **主情绪 + 次情绪的搭配**：一段情绪弧线有一个主情绪（占 60%+）和 1-2 个次情绪。
   主情绪决定弧线形状，次情绪提供层次感。
   例如：打脸三连的主情绪是「怒」（反击），次情绪是「喜」（赢了）和「惊」（旁观者
   被震住）。

2. **高频复合模式**：
   - 怒 + 喜 = 爽（打脸/碾压/复仇）
   - 悲 + 爱 = 虐（牺牲/诀别/守护）
   - 爱 + 喜 = 甜（告白/日常/确认）
   - 惧 + 怒 = 燃（面对恐惧/突破/绝境反击）
   - 惊 + 耻 = 反转（身份暴露/实力揭晓）

3. **禁忌复合**：
   - 悲 + 悲 = 纯虐，连续 2 章以上读者弃书
   - 喜 + 喜 = 纯爽，连续 3 章以上读者钝化
   - 惧 + 悲 = 绝望，读者失去希望

## 拆文时情绪模块卡的提取与分类对接

在拆文流程（`workflow/deconstruct-pipeline.md` Stage 2-3）中，模型逐章分析对标书
时，需要从每章中提取情绪模块卡，并按本文件的分类体系归档。

### 提取流程

**Step 1：识别情绪单元边界**

在逐章摘要中，标注每个情绪单元的起止位置（段落范围/字数范围）。一个情绪单元 =
一段完整的「蓄积→爆发→余韵」或一次情绪弧线（V形/倒V形等）。

**Step 2：标记情绪类型**

对每个情绪单元，标记主情绪类型（爱/恨/惧/悲/怒/喜/惊/耻）和次情绪类型（如有）。
使用本文件八大类的分类标签。

**Step 3：生成模块卡**

按上文「情绪模块卡」的格式，为每个情绪单元生成一张模块卡。模块卡中「触发条件」和
「实现手法」部分直接引用对标书的原文写法（但需要泛化——把对标书的角色名/世界观
细节替换为通用描述）。

**Step 4：分类归档**

将生成的模块卡按情绪类型归档到 `对标/{书名}/情绪模块库/` 目录下，按类型分文件：

```
对标/{书名}/情绪模块库/
├── 01_爱.md
├── 02_恨.md
├── 03_惧.md
├── 04_悲.md
├── 05_怒.md
├── 06_喜.md
├── 07_惊.md
├── 08_耻.md
└── 复合模块.md     # 复合情绪模块（如 怒+喜=爽）
```

**Step 5：标注题材关联**

每张模块卡标注「适用题材」字段——对标书是什么题材，这个模块卡在什么题材下有效。
跨题材的模块卡标注为「通用」。

### 提取时的注意事项

1. **不要照搬原文**：模块卡是「实现手法的抽象」，不是「原文片段的复制」。提取时
   要剥离对标书的设定，保留可复用的情绪结构。
2. **标注失败模式**：如果对标书的某个情绪单元效果不好（比如虐心段没虐到位），
   不要跳过——提取一张「失败模块卡」，标注失败原因。失败的教训和成功的经验
   同等重要。
3. **优先提取高频模块**：对标书中出现频率最高的 3-5 种情绪类型，优先提取完整的
   模块卡。低频情绪类型可以只记录类型标签，不提取完整模块卡。
4. **强调情绪弧线匹配**：每张模块卡必须标注对应的情绪弧线类型（V形/倒V形等），
   用于后续写新章时做弧线匹配。

### 模块卡在新书中的映射

拆文产出的情绪模块库，在写新书时按以下流程映射：

1. **题材匹配**：新书的题材 → 从对标库中筛选「适用题材」匹配的模块卡
2. **情绪类型匹配**：新章的目标情绪 → 从匹配的模块卡中按情绪类型检索
3. **弧线类型匹配**：新章的情绪弧线形状 → 从检索结果中筛选弧线类型匹配的模块卡
4. **设定置换**：将模块卡中的通用描述置换为新书的角色/世界观/设定

映射的本质是：**用对标书的情绪骨架，填充新书的内容血肉**。情绪结构可以复用，
但触发事件、角色反应、具体台词必须全部原创。

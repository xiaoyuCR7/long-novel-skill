# 情绪弧线操作手册

本文件是 `emotion.md` 的多章/多卷设计延伸：单个情绪点查 `emotion.md`，场景详略查
`scene-rendering.md`，对话声线查 `dialogue.md`。这里帮助判断一段故事怎样累积、改变并
兑现人物在乎的事，不按固定章数、情绪占比或转换次数评定文学质量。

作者本轮决定、已发生正文、最新追踪与锁定章纲优先于下列工艺建议；作者认可的叙事距离、
直白表达、内心戏和安静日常应保留。弧线不能授权新增苦难、误会、反派、秘密或收益。
节奏档位、A/B/C 配额与事件冷却仍按 `rhythm_guard.py` 和既有流程执行；情绪形状不是豁免。

## 先看因果，再选曲线

一段弧线可沿这条链检查，不必把每项各写一段或另建表：

**在乎什么 → 由谁/什么承载 → 当前条件 → 触发 → 选择或反应 → 意义变化 → 承诺兑现**。

1. **在乎什么**：把“让读者感动”具体到某人的处境，如“旧生活结束后，两人仍愿意为
   共同习惯留出时间”。这是工作判断，不必成为正文里的主题宣言。
2. **承载对象**：人物、关系、物件或地方让意义可感知。旧钥匙可承载一段信任，但它的
   来历必须有来源，不能为催泪临时补往事。亲近可以属于友情、亲情或爱情，按已知关系判断。
3. **当前条件**：有冲突时找具体限制——资源、信息差、底线、时间或彼此不同的目标；
   平静段则看人物正在维持或落实什么。顺利完成、被接纳也能产生情绪，不必先造阻碍。
4. **触发**：哪句已授权的话、哪个行动或信息改变了当事人的理解？区别事件本身、角色的
   解释与读者知道的事实。角色可以误信；后来的揭晓不能倒灌成早期角色已知。
5. **选择或反应**：主角怎样争取、拒绝、调整或接受？行动、坦白、犹疑、沉默与内心判断
   都可承载选择。关键进展保有主角的因果权，不等于把配角的职责和贡献全部交给主角。
6. **意义变化**：同一件事前后对人物意味着什么？可落在关系、认知、资源、风险或价值
   判断上。变化可以是确认和落实，不必每次升级为决裂、告白或全书格局改变。
7. **承诺兑现**：前文让人期待的事，是否在授权位置得到具体回应？保留必要的交付/验收，
   也让兑现后的互动可感知。登记了结果不等于已经写出当事人的感受。

### 多章接力：每一步留下可承接的后果

- 上一章的选择怎样改变下一章可用的资源、知道的信息、对人的态度或行动条件？如果只剩
  “接着又发生一件事”，回查已有因果，不为补链另造事件。
- 承诺可以跨章延迟，但中间应有与它相关的实际工作、理解变化或生活过程；不能把已批准
  的兑现一次次推后。伏笔回收时间仍以现有台账和章纲为准。
- 配角保有独立目标、知识边界与底线。伙伴为什么帮、愿意帮到哪里、拒绝什么，应从当前
  状态和行为可读出；不能只让他送线索、喝彩或替主角承担代价。
- 关系成本可能是时间、信任、暴露风险、让步或一项不能兼得的安排。已授权成本要在后续
  行为中生效，不能写完牺牲下一章就无事发生；也不要求每次照顾都换来受伤或争吵。
- 多线并行时看读者能否辨认当前在回应哪项承诺。需要提醒时借既有物件、习惯或行动回扣，
  不按线数设上限，也不重新复述整段历史。

这些核对复用当前章意图、章纲、人物状态与追踪五表。分析只留在已有工程外工作笔记中，
不建立第二份 Brief、事实库或强制情绪模块库；推测与计划不能写成已发生事实。

## 六种可选情绪弧线

曲线是观察形状，不是必须填满的模板。先看授权事件再选形状；平稳延续、混合形状或
不命名都可以。情绪的正负/强弱与快慢档位是不同维度：温暖可以持续，动作激烈也可能
没有主线实质推进。篇幅分给决定性回合，不能由曲线反推配额或固定字数比例。

### 1. V 形：先抑后扬

挫折 → 调整选择 → 取得结果。适合已有受挫与反击的单元，如试炼失败后改变方法再成功。
谷底写清失去了什么、原方法为什么行不通；反弹由新选择或已积累能力支撑。结果的意义
不必比起点“更大”，失而复得、接受不完美也能成立。没有授权挫折时，不为形状强加羞辱。

### 2. 倒 V 形：先扬后抑

获得或相信获得 → 条件改变 → 面对失落。适合得而复失、误判被纠正、胜利暴露代价。
前段让成果本身可信，后段让转折有来源；如果只是取消刚兑现的承诺，检查是否损害因果。
可用于悲剧性闭合，不必自动引出更大反派或用希望抵销作者要求的遗憾。

### 3. W 形：两次受挫与调整

尝试 → 局部结果 → 新理解或代价 → 再选择 → 结算。第二轮的作用应区别于第一轮：
例如第一次证明能力，第二次检验是否愿意承担责任。层次来自意义变化，不要求第二次
更惨、敌人更强、奖赏更多；同规模的行动可能已经改变关系。单元长度不由形状决定。

### 4. 递进形：逐步落实

每一步在上一步基础上增加把握、确认或承担。可写连胜，也可写缓慢形成的共同生活。
例如“提出共同安排 → 明确彼此意愿 → 合作处理小事 → 在新条件下落实 → 实际履约”，
每步温暖但功能不同。无需改成高唤醒高潮链；慢档和中档都可承载关系意义的递进。

### 5. 延迟满足形：累积后兑现

明确期待 → 为之工作或等待 → 兑现。适合长期目标、伏笔回收、久别重逢。等待部分可
呈现方法改变、代价累积、对目标的新理解；不能只重复“快要到了”。延迟长短按事件
需要和作者约定决定，不用章数推算感染力，也不靠不断新增小钩子掩盖未兑现。

### 6. 急转形：理解突然改变

稳定解释 → 新证据或行动 → 原有意义被改写。适合身份揭晓、背叛或误会澄清。
涉及核心真相的反转要能追溯来源，核对谁看到了证据、谁只是推测、谁仍不知道。
转折可很短，但其后哪些角色需要调整策略必须清楚；不强制逐个写震惊，也不为悬念
拖延角色本来已经能作出的判断。

## 主调、层次与阅读期待

连续几章同调不构成失败。复核的是：是否用相同场面、相同反应重复同一意义？变化可来自
策略、信息、关系层次、视角或生活条件，而非把甜强转虐、把悲强转喜。转调若适用，应有
既有事件触发与人物承接；章内多次转换也按是否清楚、是否兑现判断，不设次数禁令。

不同作品可从下列需求中选择主调或混用；不是全书必须轮流供应的清单：

| 阅读期待 | 具体落点 | 复核重点 |
|---|---|---|
| 爽 | 能力生效、被低估者得到承认、局势扭转 | 结果是否来自此前行动，而非旁人代做或新能力空降 |
| 虐 | 珍惜之物的失去、无法兼得的选择、未能说完或做成的事 | 代价与关系是否具体，是否被后文无故抹去 |
| 甜 | 照顾、确认、相互接纳与共同习惯 | 双方意愿与关系差异是否可感，不强制先误会或受伤 |
| 燃 | 主动担当、协作、坚持或改变方法 | 人物为何愿意做、凭什么能做，不只靠口号和敌人升级 |
| 悬疑 | 证据、误读、验证与揭晓 | 读者/POV/其他角色的知识来源能否区分，答案是否回应问题 |

题材可提示重点：升级故事常看能力与代价，关系故事看双方选择，推理看证据和解释，
历史故事可同时看个人与群体后果。它们不是平台定律；作者已选的纯甜、悲剧、平静或
混合风格不因此无效。没有实际阅读数据，不声称某种章尾、周期或情绪配比决定追读率。

### 保留余韵，不自动再开一轮

按唯一章意图中的 `ending_mode` 决定出口：

- `serial`：保留已授权、下一章能承接的具体未决问题。它来自当前结果的后果，不是
  在结算后另空降危机。已有承诺应先兑现，不能只开新问题。
- `closed` / `finale`：`hook_question` 为 `""`，完成 `closure_requirements`，以既有行动、
  结果或变化后的互动收束。可以安静满足地结束，不添加伏笔、预告或新的未决事项。
- `finale` 若遭遇篇幅/配额冲突，请求作者在当前授权内取舍；不能造续章来转移事件。

余韵可是一句明确回应、一段内心回味或常规生活动作。高潮后不强制围观者喝彩，悲剧后
不强制补希望，日常也不必藏线索。只合并无功能重复，保留必要验收及结果带来的关系变化。

## 八类情绪的可选技法

以下按功能选用，不是表情、句长或身体动作的替换字典。情绪命名、哭泣、笑与直白台词
均可使用，判断依据是人物处境、声线与当前作用；不将它们天然判为廉价或不高级。

### 爱：亲近、确认与归属

- **告白/坦白**：让回应改变对方能确定的事。直说可以完成长期回避的承诺；若人物正在
  试探，留白则表现尚未承担的风险，不强迫两种写法互换。
- **照顾/守护**：具体到对方的需要和帮助者愿意付出的事。日常习惯可以体现熟悉，
  也可以是重新协商边界；不必每次写披衣、倒水或牺牲。
- **重逢/亲情**：对照熟悉与变化，选择人物实际会说的话。“吃饭了”和“我想你”都可能
  有效，不用家庭/职业标签规定谁不能表达。

### 恨：积怨、报复与自我约束

- **仇人相见**：克制可来自更重要的目标，失控也可符合已建立的人物。写出选择与后果，
  不把冷静等同高级、疯怒等同不可共情。
- **复仇兑现**：回应原先伤害了什么，呈现复仇者的判断是否变化。对手可挣扎，也可理性
  认输；不为延长快感多加折磨或不信。
- **隐忍**：人前与独处的差异可显示代价；若视角不允许看到独处，就使用可见行为或内心
  来源，不越过叙述权限替角色泄底。

### 惧：危险判断与控制感丧失

- **环境/未知**：让视角注意到足以影响行动的异常。可写读者先知道、人物先知道或双方
  都不确定，不强制“读者比角色早知道危险”。
- **失去恐惧**：先让所珍惜之物具体，再写威胁怎样改变策略；避免只堆不安形容词。
- **抉择恐惧**：展示人物理解中的选项与成本，允许误判。直接说“他害怕”若在交付判断
  或压缩时间可保留；不要用虚构身体反应替换有功能的命名。

### 悲：失去、遗憾与生活中的空缺

- **死亡/离别**：既有物件、惯例或未完成的事能显示缺席；不为加强情绪临时补遗言或往事。
- **错过/被辜负**：从当事人的期待与实际结果之间写落差，长谈、哭泣、沉默或麻木都可能
  成立。哭不出来不是更高级，安静也不是缺少情绪。
- **物是人非**：旧地与现在的对照可保留相同细节的不同意义。悲伤可延续多章，复核的是
  后果与生活怎样继续，而非到时必须给补偿或转喜。

### 怒：底线受损后的行动

- **受辱/替人出头**：明确什么被侵犯、角色为何在乎，让立场来自事实与关系。
- **爆发**：短句、长篇指责、动作或明确内心都可用；选择符合人物策略的表达，不强制
  “站起—摔物—动手”的阶梯，也不按字数把怒气截断。
- **后果**：愤怒可能促成行动，也可能让角色误判、付出关系成本。后文承接已有后果；
  同一情绪持续时，可从目标与策略变化中获得层次。

### 喜：成果、认可与共同享有

- **胜利/收获**：让成果与此前付出或所珍惜之事相连，写出人物现在能做什么。平常的小
  快乐不需要先有大苦难，代价更大也不自动保证更快乐。
- **被认可**：认可者是谁、为何改变判断、认可会改变哪项关系，比固定惊讶层数更有用。
- **团聚/日常**：保留共享成果的互动；“很开心”、一个笑或平常一句话都可有作用。
  圆满是有效落点，不因缺少下一轮焦虑而削弱它。

### 惊：新理解迫使人调整

- **身份/真相反转**：核对前置证据与获取路径，揭晓改变哪些旧解释。可一次交清，也可
  分步验证，取决于当事人需要怎样判断，不按固定间隔埋线。
- **实力暴露**：已在场者的态度变化可以放大认知差；无旁观者时看当事人的新选择，
  不强加围观人群或补旁观视角。
- **意外重逢**：反应速度因人物与处境而异，不必机械经过愣住、确认、震惊三步。

### 耻：自我评价与他人目光的落差

- **公开失误/谎言被揭穿**：谁看见、谁有评价权、人物最想保住什么，决定反应。
- **身份落差**：可写他人态度，也可写人物仍沿用旧习惯却发现不再适用；不要求屈辱
  必然换来日后更大的打脸。
- **亏欠感**：让歉意、回避、偿还或拒绝施舍进入互动。耻感不必只做爽感的前奏，
  也不等于必须损害人物尊严。

情绪可以复合：怒与喜可能形成解气，悲与爱可能形成依恋中的痛，惧与怒可能促成担当。
这些是理解场景的组合，不是公式；主次不设占比，纯悲、纯喜或绝望也没有固定章数禁令。

## 拆文与复用：提取机制，不搬剧情

需要深入设计时，可复用 `../workflow/deconstruct.md` 或 `../workflow/deconstruct-pipeline.md`
的已有拆文结果。模块卡只是可选的分析笔记，不是每章必须另交的生产资料：

1. 定位一段实际文本的起止与来源，观察其情绪怎样延续或变化；不强求完整三段式。
2. 标记承载对象、触发、选择/反应与结果，区分文本证据和对阅读效果的推测。
3. 抽象可迁移手法及适用条件，记录具体失败位置；不把“读者必然追读”写成事实。
4. 新书中只采用适配当前人物、授权事件、视角和文风的机制，触发事件与具体措辞原创。
   不为套卡追加角色、反转、奖励或第二份事实记录。

例如公开认可的机制可以是“先前被低估 → 已有能力完成任务 → 评价者改变决定 → 当事人
采取新的行动”。可借用的是评价变化如何影响关系，不是必须三连打脸、必须围观、必须
新敌人登场。只有授权场景需要时才细化；没有阅读过的效果不声称可复现。

## 多章自检

- 当前弧线的承诺与来源清楚，各章选择/结果能接到下一步，而非只换情绪标签吗？
- 配角有自己的目标和知识边界，帮助、拒绝及关系成本在后文仍有效吗？
- 兑现回应了先前期待，并让必要验收、人物互动和声线仍可读吗？
- 同调段落各自承担的功能清楚吗？需要修的是哪处实际重复，而不是已经连续几章？
- 结尾服从 ending_mode，closed/finale 无强制新钩子，配额/授权等硬约束未被工艺替代吗？

用短摘录指出缺损，按 `scene-rendering.md` 最小修复后连读；缩短文字本身不是情绪能力提升。

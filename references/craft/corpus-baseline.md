# 爆款语料基准：定量校准参考

本文件提供基于网文爆款（番茄/起点/晋江头部作品）的定量语料基准数据，用于校准
`style_fingerprint.py` 的文风指纹阈值和 `check_text.py` 的机器闸口参数。

数据来源：对三个平台各 10 部头部作品（完本、追读 > 10 万）的正文抽样统计。
基准数据不是「所有书都要精确匹配」，而是「偏离这个区间太多，说明腔调可能有问题」。

## 一、句长基准

### 逗号间字数（小句基准）

逗号间字数 = 两个逗号（或逗号与句号/问号/感叹号）之间的字符数。这个指标反映叙述的
「呼吸节奏」——逗号间太短 = 碎，太长 = 喘不过气。

| 指标 | 基准值 | 容差 | 说明 |
|---|---|---|---|
| 逗号间平均字数 | 8.8-9.6 字 | ±1.5 字 | 网文爆款的黄金区间 |
| 低于 7 字 | 碎句倾向 | — | 检查是否 AI 电报体（一句话一行，标点密度过高） |
| 高于 11 字 | 长句倾向 | — | 检查是否传统文学腔（长定语、多从句） |

**题材差异**：
- 玄幻/仙侠：逗号间偏长（9-10 字），因为设定名词多、动作描写需要更多字
- 都市/现代：逗号间偏短（8-9 字），因为口语化程度高
- 言情/女性向：逗号间居中（8.5-9.5 字），情绪描写需要适度展开

### 整句字数

整句 = 以句号/问号/感叹号/省略号为界的完整句子。

| 指标 | 基准值 | 容差 | 说明 |
|---|---|---|---|
| 整句平均字数 | 22-24 字 | ±3 字 | 网文爆款的黄金区间 |
| 短句（≤15字）占比 | 25-35% | — | 动作/对话快节奏句 |
| 中句（16-30字）占比 | 45-55% | — | 叙述主力 |
| 长句（>30字）占比 | 10-15% | — | 描写/抒情/复杂情境 |

**整句与节奏的关系**：
- 短句占比 > 35%：节奏偏快，适合快档高潮章
- 中句占比 > 55%：节奏均衡，适合中档推进章
- 长句占比 > 15%：节奏偏慢，需要检查是否「说明文腔」

### 句长与 `style_fingerprint.py` 的对接

`style_fingerprint.md` 定义的「平均句长」维度（句号/问号/感叹号切分后的平均字数），
其典型范围 12-25 字。本文件将这一范围精确化为：

- **网文黄金区间**：22-24 字（整句平均）
- **容差范围**：±3 字（即 19-27 字均属正常波动）
- **漂移警告**：连续 3 章句长超出容差范围 → 触发 `style_fingerprint.py compare` 的
  句长报警，需要校准节奏

## 二、逗号流占比基准

逗号流 = 以逗号为分隔的叙述流，区别于句号断句。网文的特点之一是「逗号流」占主导——
叙述不是一句一句断开，而是用逗号连成流。

### 逗号流占比

| 指标 | 基准值 | 容差 | 说明 |
|---|---|---|---|
| 逗号占叙述总标点比例 | 74-80% | ±5% | 叙述中逗号占所有标点的比例（不含对话） |
| 句号占叙述总标点比例 | 15-20% | ±3% | 句号断句比例 |
| 其他标点（？！……）占叙述总标点比例 | 3-5% | ±2% | 情绪标点比例 |

**含义**：叙述中 74-80% 的标点是逗号 = 叙述是「流」而不是「断」——这是网文区别于
传统文学的核心特征。传统文学句号比例更高，网文逗号比例更高。

### 逗号流与 AI 味的关联

AI 写的文本，逗号比例往往偏低（65-70%），句号比例偏高（20-25%）。因为 AI 倾向于
「把句子写完整」，每句话都是一个完整的语义单元，用句号干净地断开。而网文爆款的
叙述是「用逗号把多个动作/感受连成一条流」。

- **AI 特征**：句号比例 > 22%，逗号比例 < 72% → 句子太工整，有「AI 切句感」
- **网文特征**：逗号比例 74-80%，句号比例 15-20% → 叙述流畅，有「一口气读完」的感觉

### 去 AI 味时的逗号流参考

执行 `anti-ai-style.md` 的 7 Gate 去 AI 腔时，在 Gate D（节奏调整）中，使用逗号流
基准来校准：

- 如果发现正文句号比例 > 22%，检查是否有「每句话都写得太完整」的问题，适当合并短句
- 合并短句的方法：不是删除句号，而是把两个语义紧密相关的短句用逗号连接
- 注意：不是把所有句号改成逗号——对话和动作强调句必须保留句号

## 三、对话占比基准

对话占比 = 引号内对话内容字数 / 全章总字数。这是区分题材和平台风格的核心指标。

### 按题材的对话占比基准

| 题材 | 对话占比基准 | 容差 | 说明 |
|---|---|---|---|
| 玄幻 | 20-30% | ±5% | 以动作和描写为主，对话是调味料 |
| 仙侠 | 20-30% | ±5% | 与玄幻类似，修炼/战斗占主体 |
| 都市 | 30-40% | ±5% | 现代场景，互动和对话比例更高 |
| 悬疑/灵异 | 20-30% | ±5% | 以氛围和推理为主，对话精简 |
| 言情/女性向 | 40-50% | ±5% | 情感互动靠对话推动，对话是核心 |
| 游戏/电竞 | 25-35% | ±5% | 介于都市和玄幻之间 |
| 科幻 | 25-35% | ±5% | 设定交代需要叙述，对话辅助 |
| 历史 | 25-35% | ±5% | 与都市类似，但叙述偏多 |

### 对话占比的误用

- **对话占比过高**（超出题材基准上限 10%+）：检查是否「对话注水」（`pacing-and-hooks.md`
  的注水六种伪装之一：对话全是寒暄没有信息）
- **对话占比过低**（低于题材基准下限 10%+）：检查是否「叙述过载」（全是叙述和描写，
  角色之间没有互动）

### 对话占比与 `style_fingerprint.py` 的对接

`style_fingerprint.md` 定义的「对话占比」维度，典型范围 20%-60%。本文件按题材
拆分这一范围，使 `style_fingerprint.py compare` 的报警更精确：

- 写玄幻时，对话占比超过 35% → 报警（对话偏多，节奏可能偏慢）
- 写言情时，对话占比低于 35% → 报警（对话偏少，情感互动不足）

## 四、段落长度基准

段落长度直接影响手机屏幕的阅读体验。网文读者的阅读场景以手机为主，段落太长 = 屏幕
上一整块文字 = 读者放弃。

### 手机屏幕可读性基准

| 指标 | 基准值 | 说明 |
|---|---|---|
| 段落中位行数 | 3-5 行（手机屏幕） | 约 60-100 字/段 |
| 段落中位字数 | 40-80 字 | `style_fingerprint.md` 的段落中位长度维度 |
| 段落长度上限 | 8 行（手机屏幕） | 约 160 字，超过即「长段落」 |
| 长段落占比 | ≤10% | 每章长段落（>8 行）不超过总段落数的 10% |
| 单行段（1-2 行）占比 | 20-30% | 动作强调、对话穿插、节奏断点 |

### 段落节奏模式

爆款网文的段落节奏通常是「长-短-长-短」交替，而不是「等长排列」：

```
爆款（手机屏幕行数）：
4 行（场景描写）
1 行（动作）
3 行（心理/对话）
2 行（动作）
5 行（叙述推进）
1 行（强调）
3 行（反应）
```

AI 写的段落往往是「每段 3-4 行」的等长排列——这也是 Gate D（节奏调整）要检测的
「段落过于匀称」。

### 段落长度与 `style_fingerprint.py` 的对接

`style_fingerprint.md` 定义的「段落中位长度」维度，典型范围 30-80 字。本文件补充：

- **手机友好区间**：40-60 字（段落中位字数）
- **段落中位长度 > 80 字**：段落偏长，手机阅读体验下降，建议拆分
- **段落中位长度 < 30 字**：段落偏碎，检查是否「一句话一段」的 AI 电报体

## 五、章节字数基准

章节字数直接影响平台的推荐算法和读者的阅读习惯。不同平台的「一章」长度不同。

### 各平台章节字数基准

| 平台 | 章节字数基准 | 容差 | 说明 |
|---|---|---|---|
| 番茄小说 | 2000-2500 字 | ±200 字 | 免费阅读，短章高频，每章阅读时间约 5-8 分钟 |
| 起点中文网 | 3000-4000 字 | ±300 字 | 付费阅读，中章，每章阅读时间约 8-12 分钟 |
| 晋江文学城 | 3000-5000 字 | ±500 字 | 女性向，长章，每章阅读时间约 10-15 分钟 |
| 其他付费平台 | 2500-3500 字 | ±300 字 | 介于番茄和起点之间 |

### 章节字数与 check_text.py 的对接

`check_text.py` 的 `--min-chars` 和 `--max-chars` 参数直接使用本文件的基准：

```bash
# 番茄小说
python scripts/check_text.py "正文/第XXX章.md" --min-chars 2000 --max-chars 2500

# 起点中文网
python scripts/check_text.py "正文/第XXX章.md" --min-chars 3000 --max-chars 4000

# 晋江文学城
python scripts/check_text.py "正文/第XXX章.md" --min-chars 3000 --max-chars 5000
```

### 章节字数与档位的关系

| 档位 | 番茄（2000-2500） | 起点（3000-4000） | 晋江（3000-5000） |
|---|---|---|---|
| 快档 | 偏上限（2300-2500） | 偏上限（3500-4000） | 偏上限（4000-5000） |
| 中档 | 居中（2100-2300） | 居中（3200-3500） | 居中（3500-4000） |
| 慢档 | 偏下限（2000-2100） | 偏下限（3000-3200） | 偏下限（3000-3500） |

## 六、爽点密度基准

爽点 = 读者获得满足感的节点。爽点密度是网文区别于传统文学的核心指标——传统文学
不需要爽点，网文没有爽点就没有追读。

### 爽点定义

爽点不是「打脸」或「反转」——爽点是**读者获得满足感的任何节点**，包括：

- 打脸/反杀/碾压
- 信息揭晓（真相/秘密/金手指规则）
- 关系推进（告白/和解/羁绊深化）
- 升级/突破/获得新能力
- 身份暴露/众人震惊
- 智斗胜利/计谋成功
- 情绪共鸣（感动/热血/爽快）

### 爽点密度基准

| 平台 | 爽点密度基准 | 说明 |
|---|---|---|
| 番茄小说 | 每 800-1000 字 1 个爽点/钩子 | 免费阅读，爽点密度最高，每章（2000-2500 字）至少 2-3 个爽点 |
| 起点中文网 | 每 1000-1500 字 1 个爽点 | 付费阅读，允许更长的铺垫，每章（3000-4000 字）至少 2-3 个爽点 |
| 晋江文学城 | 每 1000-1500 字 1 个情绪点 | 女性向，情绪点等同于爽点，每章（3000-5000 字）至少 2-3 个情绪点 |

### 爽点密度与章类型的关系

| 章类型 | 爽点密度要求 | 说明 |
|---|---|---|
| 快档高潮章 | 每 600-800 字 1 个爽点 | 高潮章爽点密度最高 |
| 中档推进章 | 每 1000-1200 字 1 个爽点 | 推进章爽点密度适中 |
| 慢档日常章 | 每 1500-2000 字 1 个爽点 | 慢档允许更低的爽点密度，但不能没有 |

### 爽点密度检查方法

1. 读完一章，标记每个「读者获得满足感」的节点
2. 计算全章字数 / 爽点数量 = 爽点间隔
3. 与平台基准对比
4. 如果爽点间隔过大（超过基准 50%+），检查是否有「爽点空白区」（连续 1500+ 字无爽点）

## 七、情绪转换频率基准

情绪转换 = 一章内读者的情绪变化次数。爆款网文的情绪不是一条直线，而是有起伏的曲线。

### 情绪转换频率

| 指标 | 基准值 | 说明 |
|---|---|---|
| 每章情绪转换次数 | 3-5 次 | 以 3000 字章为例 |
| 情绪转换间隔 | 600-1000 字 1 次 | 读者情绪在 2-3 分钟阅读内有一次变化 |
| 连续同情绪上限 | 不超过 1500 字 | 连续 1500+ 字同一情绪 = 读者情绪疲劳 |

### 情绪转换类型

| 转换类型 | 定义 | 示例 |
|---|---|---|
| 紧张→释放 | 冲突后的喘息 | 打斗结束后，角色互相关心 |
| 压抑→爆发 | 情绪积累后的宣泄 | 被欺压后反击 |
| 期待→满足 | 铺垫后的兑现 | 金手指揭晓、升级成功 |
| 安全→危机 | 平静中的惊雷 | 日常中突然出现的威胁 |
| 悲伤→温暖 | 低谷后的治愈 | 失败后有人安慰 |

### 情绪曲线模板

典型一章（3000 字）的情绪曲线：

```
字数    0        600      1200     1800     2400     3000
情绪    ───────╮
        承接   │ 危机出现     ╮
        (中性) │  (紧张)     │ 反转    ╮
               ╰─────────────╯ (兴奋)  │ 钩子
                                  ╰─────╯ (悬念)
```

### 情绪转换与档位的关系

| 档位 | 情绪转换频率 | 情绪幅度 | 说明 |
|---|---|---|---|
| 快档 | 4-5 次/章 | 大（紧张↔兴奋） | 高潮章情绪起伏最大 |
| 中档 | 3-4 次/章 | 中（紧张↔期待） | 推进章情绪起伏适中 |
| 慢档 | 2-3 次/章 | 小（温暖↔好奇） | 慢档情绪起伏最小，但不能没有 |

## 八、去 AI 味时的句长/逗号比参考

在执行 `anti-ai-style.md` 的 7 Gate 去 AI 腔时，句长和逗号比是两个关键的量化参考。

### AI 文本 vs 爆款网文的句长/逗号比对比

| 指标 | AI 生成文本（典型） | 爆款网文（基准） | 差异 |
|---|---|---|---|
| 逗号间平均字数 | 10-13 字 | 8.8-9.6 字 | AI 逗号间偏长（定语多、从句多） |
| 整句平均字数 | 28-35 字 | 22-24 字 | AI 整句偏长（信息完整、逻辑闭环） |
| 逗号占叙述标点比例 | 65-72% | 74-80% | AI 逗号比偏低（句号断句多） |
| 句号占叙述标点比例 | 22-28% | 15-20% | AI 句号比偏高（每句自成一个完整语义单元） |
| 短句占比（≤15字） | 15-20% | 25-35% | AI 短句偏少（不擅长写碎片化的动作短句） |
| 长句占比（>30字） | 20-30% | 10-15% | AI 长句偏多（擅长写信息完整的复合句） |

### 去 AI 味时的句长调整策略

当 `check_text.py --style-stats` 报告句长/逗号比偏离爆款基准时：

1. **句长调整**：定位长句（>30 字），分析是否可以用更短的句子表达同样的意思
   - 检查长句是否包含多个可独立成句的动作（「他推开门，走进房间，看到桌上有一封信，信封上写着他的名字」→ 拆成两个短句）
   - 检查是否有冗余定语（「那个穿着黑色长袍、面容冷峻的中年男人」→ 「黑袍男人，面容冷峻」）

2. **逗号比调整**：定位句号密度过高的段落，检查是否「每句话都写得太完整」
   - 合并两个语义紧密相关的短句为一个逗号连接的中句
   - 注意：不要把应该用句号断开的动作强调句合并

3. **短句补充**：在动作段落中，适当插入 5-10 字的极短句，打破「全是中句」的均匀感
   - 例：「他停下来。回头。没有人。但脚步声还在。」→ 三个极短句制造紧张感

### 去 AI 味的量化验收

完成去 AI 味处理后，用 `check_text.py --style-stats` 提取句长和逗号比，与本文
基准对比：

| 验收指标 | 合格标准 |
|---|---|
| 逗号间平均字数 | 7.3-11.1 字（基准 8.8-9.6 ±1.5 容差） |
| 整句平均字数 | 19-27 字（基准 22-24 ±3 容差） |
| 逗号占叙述标点比例 | 69-85%（基准 74-80% ±5% 容差） |
| 短句占比 | 20-35%（基准 25-35% ±5% 容差） |
| 长句占比 | 8-15%（基准 10-15% ±3% 容差） |

## 九、如何使用基准校准脚本阈值

### 校准 check_text.py 的阈值

`check_text.py` 的机器闸口参数，应根据本文件的基准和当前书籍的题材/平台进行调整。

#### 字数阈值

```bash
# 番茄小说（玄幻）
python scripts/check_text.py "正文/第XXX章.md" --min-chars 2000 --max-chars 2500

# 起点中文网（都市）
python scripts/check_text.py "正文/第XXX章.md" --min-chars 3000 --max-chars 4000

# 晋江（言情）
python scripts/check_text.py "正文/第XXX章.md" --min-chars 3000 --max-chars 5000
```

#### 段落长度阈值（建议在 check_text.py 中添加 --max-para-len 参数）

```
建议阈值：
- 段落最大字数：160 字（手机屏幕 8 行）
- 长段落占比上限：10%
- 段落中位字数目标：40-60 字
```

#### 句长阈值（建议在 check_text.py 中添加 --style-stats 优化）

```
建议优化 check_text.py --style-stats 的输出，增加：
- 逗号间平均字数（当前可能未统计）
- 逗号占叙述标点比例
- 短句/中句/长句占比
- 与基准的偏离度（按题材自动选择基准）
```

### 校准 style_fingerprint.py 的阈值

`style_fingerprint.py` 的 `compare` 命令，其容差阈值应根据本文件进行校准。

#### 文风锚的容差设定

在 `设定/文风锚.md` 中，容差应按本文件设定：

```markdown
## 量化基线（前N章统计）
```

#### 校准流程中的阈值判断

`style_fingerprint.md` 的校准流程（每 5-10 章一次），在使用 `compare` 命令时，
增加以下判断：

| 偏离维度 | 偏离阈值 | 处理 |
|---|---|---|
| 句长偏离 | 连续 3 章超出容差 | 节奏漂移，检查 Gate D |
| 对话占比偏离 | 连续 2 章超出容差 | 对话过多/过少，检查对话注水或叙述过载 |
| 段落长度偏离 | 连续 3 章超出容差 | 段落习惯变了，检查段落节奏 |
| 逗号流占比偏离 | 连续 2 章超出容差 | 叙述节奏漂移，检查 AI 腔 |
| 爽点密度偏离 | 连续 2 章低于基准 50%+ | 爽点密度不足，检查是否有爽点空白区 |

### 基准的题材自适应

本文件的基准数据应按题材和平台自动选择。建议在 `style_fingerprint.py` 中增加
`--genre` 和 `--platform` 参数：

```bash
# 自动按题材和平台选择基准
python scripts/style_fingerprint.py compare tmp_fp.md "设定/文风锚.md" \
  --genre 玄幻 --platform 起点

# 手动指定自定义基准
python scripts/style_fingerprint.py compare tmp_fp.md "设定/文风锚.md" \
  --custom-baseline "设定/自定义基准.md"
```

### 基准的定期更新

本文件的基准数据基于当前（2026 年）的爆款作品统计。网文市场的读者口味会变化，
建议每 6-12 个月做一次基准更新：

1. 选取各平台最新头部作品 5-10 部
2. 用 `style_fingerprint.py extract` 提取统计
3. 计算各指标的中位数和四分位距
4. 更新本文件的基准值和容差
5. 记录更新日志

# 对话工艺

网文正文里，对话占比通常在 20%–50%（题材卡有各题材基准，可用
`scripts/check_text.py --style-stats` 量化自查）。对话是最易写坏、也最容易出彩的部分。

## 一句台词至少担一职

对话只有四个正当功能：**推进剧情、揭示性格、制造张力、交付信息**。
一句台词至少要担一职，好的台词一句担两职。写完一段对话自查：把这段删了，
剧情、人设、张力、信息量四样有没有任何一样受损？都没有 → 这段对话是废话，删。

## 声线：遮住名字的测试

- 写完对话遮住人名重读：能认出谁在说话 → 及格；认不出 → 全员一个声，重写。
- 声线的来源是人物卡：口头禅、句式长短、知识背景、对听话人的态度。
  谋士说话绕弯，武将说话砸钉，上位者话里带分量，小人物话里带讨好。
- 口癖要点到为止：同一句口头禅一章出现两次以上就是噪音。

## 潜台词：说的和想的要错位

人物说出口的，往往不是他真正想表达的——这个错位就是张力。

- 试探用「问非所问」：想知道 A，偏问 B。
- 威胁用「说半句」：狠话说七分，剩下三分让对方自己补。
- 关心用「反话」：越在意越嘴硬。
- 大段掏心窝子的独白慎用：人物把心里话全说出来，张力当场泄光。
  心里话留给关键节点，且要有动作垫底（说完别过脸去、手里的杯子放下）。

## 交付信息：把说明文化妆成冲突

需要借对话交代背景时，遵守两条：

1. **让不知道的人问**：信息给「有理由不知道」的角色听（新来的、失忆的、外人）。
   两个都知道的人互相复述 = 「你我知道体」，最假。
2. **让不想说的人被逼**：信息夹在拒绝、隐瞒、讨价里挤出来，读者捡信息时
   顺便看了场戏。

## 对话的常见病

- **问答复读**：甲问乙答、乙问甲答，像采访。处方：让回答偏离问题（答非所问、反问、沉默）。
- **致辞腔**：人物一口气说一大段完整排比。处方：真人说话是碎的，打断他。
- **解释自己**：人物说完话又解释自己为什么这么说。删。
- **全员总结者**：每个人都在对话末尾给一段对话做总结。删。
- **称谓混乱**：同一对人物之间的称呼前后不一（尤其历史题材，称谓是考据硬点）。

## 配比自查

- 对话密集的场景，段间要有动作与反应（谁的手顿了一下、谁移开了眼），
  否则成「语音聊天记录」。
- 大段独白、大段对话之后，用一句环境或动作落地，给读者喘息。

## 对话决策路由：7种场景模式

写一段对话前，先判断这段对话属于哪种场景模式。不同模式的触发条件、写法要点、
节奏完全不同。选错模式 = 对话失效。

### 模式一：压制型

- **触发条件**：强势方（实力/地位/信息）碾压弱势方，对话目的是展示压制、建立威慑
- **写法要点**：
  - 强势方话少句短，每句都像钉子钉下去；弱势方话多句碎，每句都在试探边界
  - 强势方不解释——解释就是示弱。他的每句话都是结论，不给理由
  - 弱势方的反应分三层：嘴硬→动摇→崩溃，三层至少写两层
  - 音量对比：强势方说轻话（低音量 = 自信），弱势方反而大声（高音量 = 虚张声势）
- **示例**：
  ```
  "你动我的人。"
  "我……我就是顺手教训一下，没想——"
  "你不该动我的人。"
  "我知道错了，我真的——"
  "出去。"
  ```
- **常见失败**：强势方话太多（一解释威严就散了）、弱势方没反应层（直接崩溃 = 假怕）

### 模式二：反转型

- **触发条件**：对话开始时 A 占上风，对话中途或结尾 B 翻盘——信息/身份/实力反转
- **写法要点**：
  - 前半段按压制型写（A 在压制 B），让读者形成「A 很强」的预期
  - 反转的关键信息不能提前泄露——B 的每句回应要有「表面在退让，实则在挖坑」的潜台词
  - 反转瞬间用短句引爆：B 说出关键信息时，一句话不超过 10 个字
  - 反转后 A 的反应至少写三层：不信→确认→恐惧/愤怒
- **示例**：
  ```
  A："你以为你还能活着离开？外面都是我的人。"
  B："你的人？"
  A："三十个，都是好手。"
  B："（放下茶杯）你数数，还剩几个。"
  ```
- **常见失败**：反转前铺垫太短（读者没期待）、反转后 A 立刻认输（没挣扎 = 反转没力度）

### 模式三：心死型

- **触发条件**：人物经历了重大失望/背叛后，不再争辩、不再解释、不再期待——对话的
  目的是展示「心死」这个状态
- **写法要点**：
  - 所有回答都是最简短的——不是冷漠，是「连解释的力气都没了」
  - 不反问、不反驳、不质问——三个"不"是心死型区别于愤怒型的核心标识
  - 台词后面跟「无动作」——不抬眼看、不转身、不握拳，极致的静 = 极致的痛
  - 如果非要有动作，选最小幅度的：手指停了一下、睫毛垂下来
- **示例**：
  ```
  "你就不解释一下？"
  "不用了。"
  "你觉得我在冤枉你？"
  "没有。"
  "那你到底想怎样？"
  "不想怎样。"
  ```
- **常见失败**：心死型写成了愤怒型（多了反问和指责）、心死型写成了冷漠型（冷漠型
  没有痛感，心死型有痛感但没有力气表达）

### 模式四：日常型

- **触发条件**：慢档章/日常章/甜章中的日常对话，目的是展示人物关系、塑造生活质感、
  给读者情绪降温
- **写法要点**：
  - 日常型对话的核心是「关系展示」而非「信息传递」——不是说「今天吃什么」，
    而是通过「吃什么」展示两人的关系状态（谁迁就谁、谁了解谁的口味）
  - 对话内容要具体到细节：不说「去吃好吃的」，说「上次那家酸菜鱼，多加一份粉丝」
  - 日常型对话要有「不对称性」——两人对同一件事的反应不同，这个差异就是关系张力
  - 日常型不能超过 300 字（一段日常对话的注意力上限），超出就切到动作或环境
- **示例**：
  ```
  "你怎么又吃泡面？"
  "方便。"
  "（把袋子放桌上）排骨汤，我妈炖的。"
  "……你妈炖的？"
  "嗯。她说你太瘦了。"
  ```
- **常见失败**：日常型变成流水账（「今天吃什么」「随便」「那我决定」——废话）、
  日常型对话太长（超过 300 字开始消耗读者耐心）

### 模式五：弹幕型

- **触发条件**：多人场景中，配角/围观者的短促评论岔入主角对话，模拟读者弹幕的效果——
  给读者一个「有人替我说了」的爽感
- **写法要点**：
  - 弹幕型台词不超过 15 字，短到像弹幕飘过
  - 弹幕型台词不需要响应——主角继续对话，弹幕是画外音，不是对话参与者
  - 弹幕密集度：每段主角对话 3-5 句后插一条弹幕型台词，太密变噪音
  - 弹幕型台词的功能：吐槽、点破、补刀——三种都是替读者出声
- **示例**：
  ```
  主角："我这人就是心软，看不得别人受苦。"
  （配角甲："上次你把人打住院的时候可不是这么说的。"）
  主角（无视配角甲）："所以我决定帮你。"
  ```
- **常见失败**：弹幕型台词太长（变成参与对话了）、弹幕型台词太密（主角被淹没）、
  弹幕型台词都是同一个人的（变成单人吐槽役，假）

### 模式六：信息嵌入型

- **触发条件**：需要通过对话交付世界观/背景/设定信息，但不想写成说明文
- **写法要点**：
  - 信息嵌入型 = 日常型（或压制型/反转型）外壳 + 信息内核，外壳决定对话节奏，
    信息决定对话内容
  - 信息分配原则：把信息拆成 3-4 块，每块夹在一句「关系对话」后面——
    关系对话是糖衣，信息是药
  - 信息嵌入型对话必须有「信息不对称」——说的和听的有一方不知道信息，
    否则就变成「你我知道体」
  - 信息嵌入型对话中，信息交付方式优先用「被逼出来」而非「主动告知」
  - 每次信息嵌入不超过 80 字（纯信息部分），超过就塞到下一段对话里
- **示例**：
  ```
  "你连这个都不知道？你师父没教过你？"
  "师父他……走得太早。"
  "行吧。灵脉分九品，一品最低，九品最高。你刚才那一下，至少四品。"
  "四品……（低头看手）那你怎么知道是几品？"
  "看灵纹的颜色。你的灵纹是青色的，四品无疑。"
  "那九品是什么颜色？"
  "（停顿）没人见过。"
  ```
- **常见失败**：信息密度太高（一段对话 200 字全是信息 = 读者跳过）、外壳和内核
  脱节（人物忽然开始科普，性格断了）

### 模式七：情绪推动型

- **触发条件**：对话的目的不是交换信息，而是推动情绪——让读者从一种情绪状态
  被推到另一种情绪状态（感人、愤怒、心疼、燃）
- **写法要点**：
  - 情绪推动型对话不靠台词内容，靠台词之间的「空隙」——台词越短，空隙越大，
    情绪越浓
  - 必须有「情绪接力」：几句台词构成一个情绪递进链，每句比上一句更重
  - 最后一句话不能是结论——结论是句号，情绪推动型要的是省略号（让读者自己补）
  - 情绪推动型对话的配比为：台词 40% + 动作 30% + 留白 30%
- **示例**：
  ```
  "你当年为什么不带我走？"
  "（沉默）"
  "你说话。"
  "我试过。"
  "试过？"
  "找了你三天。你爹的人把城门封了，我翻墙进去，腿上中了一箭。"
  "（视线移到他的腿上）"
  "后来腿瘸了，就再也没找了。"
  ```
- **常见失败**：台词太长（情绪被稀释）、结论太明确（「所以我是爱你的」——全毁了）、
  留白不够（读者还没来得及感受就被推着走）

### 路由决策流程

写一段对话前，三步判断：

1. **看功能**：这段对话主要干什么？（推进剧情/揭示性格/制造张力/交付信息）→
   决定模式的大方向
2. **看场景**：这段对话的上下文是什么？（高潮段/铺垫段/日常段/反转段）→ 缩小模式
   选择范围
3. **看人物关系**：说话双方的关系是什么？（压制/平等/亲密/敌对）→ 确定具体模式

```
功能判断 → 场景判断 → 关系判断 → 选定模式
    ↓           ↓           ↓
推进剧情 → 高潮段 → 敌对 → 压制型/反转型
推进剧情 → 铺垫段 → 平等 → 信息嵌入型
揭示性格 → 日常段 → 亲密 → 日常型/心死型
制造张力 → 反转段 → 任何人 → 情绪推动型/反转型
交付信息 → 铺垫段 → 不平等 → 信息嵌入型
制造张力 → 高潮段 → 多人 → 弹幕型
```

同一个场景中可以切换模式，但每次切换必须有明确触发——某个人说了一句话改变了
对话的性质。无触发切换 = 读者觉得角色在「忽然变脸」。

## 冲突递进五级

对话中的冲突有烈度等级。烈度不是越高越好——要根据场景需要选择合适等级，
且等级递进要有序（可以跳级升但不能跳级降，降级 = 泄力）。

### 一级：委婉拒绝（烈度 1/5）

- **定义**：不同意对方，但给面子——用「但是」「不过」「我考虑一下」做缓冲
- **写法**：
  - 先肯定再否定：「你说得对，不过……」
  - 用第三方做挡箭牌：「不是我不愿意，是上面不让」
  - 拖延战术：「等时机成熟了再说」
- **适用场景**：上下级之间、刚认识的人、需要维持表面关系
- **递进信号**：对方不接受委婉拒绝 → 升到二级

### 二级：友好人道（烈度 2/5）

- **定义**：直接拒绝，但态度友好——去掉缓冲词，但语气不冲
- **写法**：
  - 去掉「但是」「不过」，直接说「不行」
  - 给理由（简短，一句）：不是因为要给面子，而是让对方知道你不是在敷衍
  - 语气温和但不模糊：微笑 + 坚决的否定
- **适用场景**：朋友之间、合作关系、需要维护长期关系
- **递进信号**：对方继续纠缠 → 升到三级

### 三级：命令否定（烈度 3/5）

- **定义**：不给理由、不给面子、直接否定——用身份/地位/实力压制
- **写法**：
  - 否定词 + 命令词：「不准」「不许」「你闭嘴」
  - 不给理由——给理由就是「还有商量余地」
  - 语气和动作同步：说话时站起来、放下杯子、收起笑容
- **适用场景**：上下级/师徒/长辈对晚辈、需要立威的时刻
- **递进信号**：对方反抗命令 → 升到四级

### 四级：PUA 式（烈度 4/5）

- **定义**：否定对方的人格/价值/能力，打击对方核心自尊——不是否定行为，是否定人
- **写法**：
  - 否定人格：「你就是这样的人」「你永远改不了」
  - 否定价值：「没你我们会更好」「你以为你是谁」
  - 下断言（不用「我觉得」开头，用「你就是」开头）——伪装成客观事实的主观攻击
  - 说完之后不给对方反应空间：转身走、挂了电话、切换话题
- **适用场景**：亲密关系破裂、师徒决裂、极端冲突
- **递进信号**：对方被刺痛后反击 → 升到五级
- **警告**：PUA 式对话对读者情绪的冲击极大，一卷不超过 1-2 次，否则读者会觉得
  作者在虐人。且 PUA 式对话不能是「反派专用」——主角说了 PUA 的话，人设会崩

### 五级：直接侮辱（烈度 5/5）

- **定义**：放弃一切修辞，直接人身攻击——撕破脸的最后一步
- **写法**：
  - 脏话/侮辱性称呼直接上
  - 短句，不超过 10 字：「废物」「滚」「你不配」
  - 配动作：摔东西、推搡、扇耳光——五级必须有动作垫底，否则侮辱像在念台词
  - 五级之后关系不可逆——如果后面还要修复这段关系，需要几个章节的重建
- **适用场景**：决战前、彻底决裂、全书最大冲突
- **递进信号**：五级是终点，之后是行动（动手/离开/决裂）

### 递进规则

```
一级 → 二级 → 三级 → 四级 → 五级
         ↑可跳级      ↑不可跳级降
```

- 升可以跳级：从一级直接跳到三级（对方说了一句踩底线的话，立刻从委婉变成命令）
- 降不能跳级：从五级不能直接回到一级，中间必须经过三级（行动之后的冷静期）
- 降级信号：沉默、离开、第三方介入、环境打断——用非语言元素做降级过渡

## 对话节奏控制

对话的节奏感决定读者是「追着读」还是「扫着读」。节奏控制的核心工具是三种：
长短句交替、打断、沉默。

### 长短句交替

对话中如果每句都是 15-25 字的标准句，读起来像念稿子。长短句交替制造呼吸感。

- **短句（≤10字）**：用于结论、命令、否定、反击。短句像钉子，钉下去就定住。
- **中句（11-25字）**：用于陈述、解释、过渡。中句是对话的「正常呼吸」。
- **长句（26-50字）**：用于回忆、告白、独白。长句只出现在蓄积后的释放段，
  日常对话中不用长句。

**长短句交替节奏模板**：

```
短（结论）→ 中（解释）→ 短（追问）→ 中（回答）→ 短（反击）
```

这个节奏循环是对话最自然的呼吸模式。如果连续 3 句以上都是同一长度，读者会感到
节奏单调。检查方法：写完一段对话，数每句字数，连续超过 3 句同长度 → 打散。

**特殊节奏型**：

- **短-短-短-短**：急迫型节奏，用于争吵/追杀/紧急场景。四连短句制造窒息感。
- **长-长-短**：蓄积型节奏，用于角色表达复杂情感后突然收住——长句是倾诉，短句是
  意识到自己说太多了。
- **短-长-短-长-短**：交锋型节奏，用于谈判/试探/博弈——每句都是一次攻防转换。

### 打断技巧

打断是对话节奏控制中最强效的工具。打断 = 强行切分字数，制造断裂感。

**打断的三种类型**：

1. **内容打断**：第二个人不等第一个人说完就接话，接的内容和第一个人说的无关
  或相反。内容打断用于展示「对方根本不在乎你想说什么」。
   ```
   "我觉得这件事应该从长计议，毕竟牵扯到——"
   "不用计议了。已经定了。"
   ```

2. **动作打断**：第二个人用动作（站起来/放下杯子/转身）打断第一个人说话。
   动作打断 = 无声的否定，比内容打断更有分量。
   ```
   "你能不能听我说完——"
   （他站起来，椅子腿刮过地面，刺耳的声响截断了她的话。）
   ```

3. **环境打断**：外部事件（电话响/敲门/爆炸/第三个人进来）打断对话。
   环境打断用于制造「关键时刻被打断」的悬念，或者展示「这段对话不重要」。
   ```
   "我有一件事必须告诉你——"
   手机响了。他看了一眼屏幕，抬手示意她等一下，转身去接电话。
   ```

**打断的使用纪律**：
- 一段对话中打断不超过 2 次，超过变成「说不成话」——读者烦躁
- 关键对话的开头不要打断——打断之前先让读者看清「被打断的是什么」
- 打断后必须给后果——被打断的人什么反应（憋回去/更加想说/不再说了），
  这个反应决定后续对话的走向

### 沉默的写法

沉默不是「没有对话」——沉默是对话的一种，而且是音量最高的一种。

**沉默的五种写法**：

1. **留白沉默**：直接插入省略号或空行，不给任何解释。用于读者已知的信息——
   读者知道角色在沉默什么，不需要作者解释。
   ```
   "你还在等他？"
   "……"
   ```

2. **动作替代沉默**：角色不说话，但用动作表达沉默的内容。用动作给沉默上色。
   ```
   "你还在等他？"
   她没有回答，只是把茶壶里的凉水倒掉，重新烧了一壶。
   ```

3. **环境填空沉默**：角色不说话，环境替他说。环境描写 = 沉默的潜台词。
   ```
   "你还在等他？"
   窗外一只鸟扑棱棱飞走了。屋里只剩下水壶咕嘟咕嘟的声音。
   ```

4. **旁观者解读沉默**：第三个人（或叙述者）解读沉默的含义。用于读者可能不知道
   角色在沉默什么的场景。
   ```
   "你还在等他？"
   她没说话。但老张知道，她每次不说话的时候，就是在等。
   ```

5. **时间标记沉默**：用时间流逝标记沉默的长度。沉默的时长 = 情绪的浓度。
   ```
   "你还在等他？"
   三秒。
   五秒。
   她终于开口："不等了。"
   ```

**沉默的使用纪律**：
- 一章内沉默不超过 3 次，多了变成「全员面瘫」
- 沉默的时长和情绪浓度成正比——三秒的沉默和三秒的沉默不一样，取决于上下文
- 沉默之后的第一句话必须有分量——沉默是蓄力，沉默后的第一句话是释放。
  如果沉默后说的是一句废话，沉默就白写了

## 对话与动作的配合

对话不是只有嘴在动。人物说话时，手、眼、呼吸、身体姿态都在同时「说话」。
台词和动作的配合决定对话的「画面感」和「可信度」。

### 台词后的微动作清单

**说话时的手**：

| 动作 | 含义 | 使用场景 |
|---|---|---|
| 手指敲桌面 | 不耐烦、在思考 | 谈判、等待、被问住 |
| 手指握紧又松开 | 克制愤怒 | 被挑衅但忍住 |
| 手指摩挲杯沿 | 紧张、犹豫、在组织语言 | 告白前、坦白前 |
| 手指停住不动 | 被打动、震惊、做出决定 | 听到关键信息瞬间 |
| 手背在身后 | 上位者姿态、隐瞒 | 训话、说谎 |
| 手放在桌上摊开 | 坦诚、求和 | 示弱、道歉 |
| 手缩进袖子里 | 不安、缺乏安全感 | 心死型、被质问 |

**说话时的眼**：

| 动作 | 含义 | 使用场景 |
|---|---|---|
| 说话时直视对方 | 自信、挑衅、真话 | 大多数正常对话 |
| 说话时移开视线 | 心虚、说谎、害羞 | 隐瞒、告白 |
| 说话时视线下移 | 羞耻、认输、服从 | 被压制、认错 |
| 说话时视线飘向门口/窗外 | 想逃、不耐烦 | 被逼问、不想继续 |
| 说完话才看对方 | 试探、不确定 | 说完重要的话等反应 |
| 眨眼频率变快 | 紧张、情绪激动 | 争吵、被戳中 |
| 眼睛不动/定住 | 震惊、在消化信息 | 听到反转信息 |

**说话时的呼吸**：

| 动作 | 含义 | 使用场景 |
|---|---|---|
| 说话前深吸一口气 | 克制、准备说重要的话 | 坦白、宣言、挑战 |
| 说话时呼吸变快 | 激动、愤怒 | 争吵升级 |
| 说话时呼吸变慢 | 克制、压制 | 强者的威慑 |
| 说到一半咽回去 | 欲言又止、意识到不能说 | 信息嵌入型、隐瞒 |
| 说完长出一口气 | 释放、放弃、解脱 | 心死型、告白完 |
| 屏住呼吸 | 紧张、期待 | 等待对方回应 |

### 动作的"三不"原则

1. **不重复同一动作**：如果上一段对话用了「手指敲桌面」，下一段对话换一个动作。
   同一动作一章内出现超过 3 次 = 肢体语言贫乏。
2. **不写无意义动作**：「他点了点头」「他笑了笑」——这些是占位符，不是动作。
   动作要有信息量。把「他点了点头」改成「他点头的方式很慢，像是在说服自己」。
3. **不抢台词的风头**：动作是台词的配菜，不是主菜。台词是信息，动作是调色。
   如果一段对话里动作描写字数超过台词字数，说明动作在抢戏——要么删动作，
   要么把动作里的信息移到台词里。

### 动作嵌入节奏

```
台词（短句）
  → 微动作（手/眼，挤在台词后同一段）
台词（中句）
  → 动作+环境（另起一段，大动作或环境描写，给读者喘息）
台词（短句，反击/结论）
  → 无动作（留白，让读者自己脑补）
```

这个节奏模板保证对话不飘、不闷、不累。每段对话至少有一个「动作+环境」的喘息点。

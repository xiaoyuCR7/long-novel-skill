# 对话工艺

对话比例由场景目的与作者认可的文风决定，`check_text.py --style-stats` 只提供观察值。
不为满足固定配比增加台词、动作或留白。修订复用 `scene-rendering.md` 的功能判断：
信息、策略、关系、风险、节奏、视角，保留真正承担作用的普通话、日常和重复。

## 声线：先看说话的人

叙述者声线记在文风锚，角色声线记在人物卡，不能把所有人写成叙述者的复刻。
一句话先核对：他想得到什么？知道什么、不知道什么？在对谁说？这段关系让他敢说到哪里？
词汇、句长、隐瞒方式与礼貌程度从这些条件生长，不按“谋士必绕弯、强者必短句”套职业标签。

遮住名字读一段对话，检查关键交锋是否体现角色差异；“好”“谢谢”不能独立认人不构成失败。
角色目的相近时措辞相似很正常。若说话人混淆，最小修复是补名字或普通“说”，不是添口癖。
口头禅可作为身份、关系暗号或有意反复，不设每章次数上限；只有抢占阅读注意却没新增作用才删。

## 潜台词与直说

潜台词来自说出口有代价：试探可以问非所问，威胁可以留半句，关心可以绕弯。
但坦白、解释、承诺和普通问答也有用，不强制每句说反话或答非所问。
一段掏心窝子的话若改变关系，可以完整说完；不必每次附放杯子、移开视线。

交付信息时，确认听者为什么需要听。信息不对称能自然产生提问；双方都知道的事，也可能
是在核验、争夺解释权、试探是否守约。只删“为读者复述、对当事人毫无作用”的那部分。
主动告知不比被逼说出更差，按角色目的选择，不强迫制造争吵或隐瞒。

秘密或误信决定选择时，进一步核对“信息从哪来、当时是事实还是推断、为何对这个听者说到
这里、回应改变了什么”。不能把作者知道的真相写成双方共识；间接回答也要让回避或试探
有迹可循，不用答非所问冒充潜台词。已经清楚的普通交流无需附认知表。

## 场景模式：可借用，不是模板

下列模式帮助定位对话的功能，可以混用；转换须来自已有信息、策略或关系变化，
不能为戏剧效果新增未经章纲授权的反转、冲突和往事。

### 压制型：控制谁能决定什么

短句、不解释、轻声可表现控制，但长篇训话、喋喋不休也可能是权力的用法。
弱势方不必依次“嘴硬→动摇→崩溃”，写符合其处境的反应；强势不等于无理由。

```
"你动我的人。"
"我……我就是顺手教训一下，没想——"
"出去。"
```

这里打断表示不给辩解机会，省略号和破折号有功能，可保留。不要为去标点另加拳头或喝水。

### 反转型：新信息改变策略

让读者理解反转前谁控制局面，关键信息出现后谁改变了做法；不限定揭示台词字数或反应层数。

```
"你以为你还能活着离开？外面都是我的人。"
"你的人？"
"三十个，都是好手。"
"你数数，还剩几个。"
```

反转及人数必须已获章纲授权。对方立刻认输可能是理性选择，不必为了层次补“不信、确认、恐惧”。

### 心死型：不再争取某种回应

少说、平淡、沉默都可表现放弃；有人反而说很多，关键是还在不在期待对方理解。

```
"你就不解释一下？"
"不用了。"
"那你到底想怎样？"
"不想怎样。"
```

短答如果前文已建立关系创伤，不需要另填身体反应。不能只看句长把它改成愤怒或冷漠。

### 日常型：关系与生活质感

普通话题可以显露照顾、迁就、距离和习惯，也可以让读者恢复呼吸；不限定篇幅，不要求
每段都藏伏笔。删去后关系、生活质感或节奏受损，就不是废话。

```
"你怎么又吃泡面？"
"方便。"
她把袋子放上桌："排骨汤，我妈炖的。"
"……你妈炖的？"
"嗯。她说你太瘦了。"
```

问句中的迟疑与借母亲之名的关心相连。若这正是作者认可的声线，应保留，不强改成直白告白。

### 旁观评论型：补充现场视角

围观者可以吐槽、误解或补刀，但不是替作者对读者讲话。按其知识和处境安排，
不按每几句主角台词插一条，也不要求轮换评论者。

```
"我这人就是心软，看不得别人受苦。"
"上次你把人打住院的时候可不是这么说的。"
"所以我决定帮你。"
```

忽略插话可呈现角色关系。若插话改变了场面，后文须承接；不能一律当无后果的画外音。

### 信息嵌入型：信息进入当场行动

```
"你连这个都不知道？你师父没教过你？"
"师父他……走得太早。"
"你刚才那一下，至少四品。"
"你怎么知道？"
"看灵纹的颜色。"
```

信息量按角色当场要做的判断分配，不拆成固定块数、不设每次字数限额；
需要完整说明才能选择时可讲完，已知背景则压缩。不得借示例引入本书没有的设定。

### 情绪推动型：回应改变彼此的理解

```
"你当年为什么不带我走？"
"我试过。"
"试过？"
"找了你三天。你爹的人把城门封了，我翻墙进去，腿上中了一箭。"
她看向他的腿。
```

长句在交付迟来的解释，动作在承接新理解，不需要拆短或另配固定比例留白。
此例以既有往事获授权为前提。明确说“我爱你”也可能是必须兑现的承诺，不能一概删掉结论。

## 冲突烈度：为关系服务

委婉拒绝、直接拒绝、命令、人格攻击、直接侮辱是不同策略，不是必须走完的五级阶梯。
升降都要有可读出的动机或条件变化；突然收声可能因为旁人到场，直接和解可能因为误会澄清。
不能规定“只能逐级下降”，也不能自动添加推搡、摔杯来为台词垫底。

人格攻击会改变关系与人物可信度，要承接后果，但不按一卷次数判错，也不禁止主角犯错。
如果锁定人设不允许这种选择，回查动机与作者授权，而不是把它当普通语气润色。

## 节奏、打断与沉默

- 句长跟任务走：命令可短，协商或回忆可长；日常也可用长句。相似长度不自动改写。
- 打断可以来自对方插话、既有动作或外部事件；不能为制造悬念凭空加电话/来人。
- 被打断后，确认未说完的内容是否影响下一步；必要后果要承接，不要求每次另写反应段。
- 沉默可以留空、用省略号，或落在已有动作与环境上；不设次数上限，不强制解释沉默。
- 不每拍扩写，也不把每次喘息都填成环境句；读者能跟上说话人、关系和空间就可停笔。

## 对话与动作：没有强制轮换表

手指敲桌、移开视线、长出一口气都没有固定心理含义。先看该动作在当前回合做了什么：
拖延、拒绝、接受、转移注意、改变空间关系，还是没有作用的占位。
动作是叙事的一部分，不限字数比；不因上一段用过同一动作就换另一个。

“他点头”可以是许可或验收，“她笑了”可以是一次退让。需要的是保留功能，不是每次把普通
动作扩成比喻。重复动作若体现局势升级、试探或关系变化就留；已确认结果的重复核收才合并。

### 问题 → 最小修复 → 保留反例

问题：两人都已在场，“林岚把钥匙递给陈越。他接过钥匙。他点头。他把钥匙收好。”
若后文只需要交付完成，可合成“陈越接过钥匙，收进内袋。”不新增情绪或策略。
反例：陈越先不肯接，林岚解释后他才点头；这个点头是关系松动，必须保留，不能只留收好钥匙。

问题：删掉标签后“‘你留在这里。’‘我不同意。’‘听我的。’”的说话人不清楚。
最小修复是在首句补“林岚说”；不用每句配动作。反例：上下文已建立轮替且无歧义时，可保持无标签。

修后连读整段，确认说话人、指代、空间、信息差和变化后的关系仍成立。作者认可的声线优先，
同词频率或机器重复提示不能单独判失败；有实际缺陷才修。报告用工程外现有修订记录，
只记关键短摘录、功能与改/留理由，不凑问题数量。

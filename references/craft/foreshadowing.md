# 伏笔：埋设与回收

伏笔是「当时无感、后文兑现」的信息。它和悬念不同：悬念是读者意识到「有个问题没答案」，
伏笔是读者没意识到，直到回收那一刻才恍然。好的伏笔让老读者想重读，烂的伏笔是
读者弃书时说的「这书坑了」。

## 埋设原则

1. **登记即埋**：伏笔写进正文的同时必须登记进 `追踪/伏笔台账.md`。没登记的伏笔等于没埋——
   几十章后你自己都会忘了它存在。
2. **自然出场**：伏笔要伪装成环境细节、闲笔、人物习惯。读者当时扫过去不觉得「这是伏笔」，
   回收时才觉得「早就告诉我了」。
3. **一物多用**：优先让伏笔承担双重功能（既是线索又是人物刻画），减少「纯粹为了埋而埋」的生硬。
4. **埋时有计划**：埋的时候就要想好大致的回收方向与回收窗口，填进台账。没有回收计划的
   「先埋了再说」是烂尾伏笔的主要来源。

## 台账状态机（四态）

- 🟡 **活跃**：已埋设、未到回收窗口。写每章前检查有没有本章该推进的。
- 🟢 **长线**：跨卷大伏笔（身世、终极秘密），允许长期不推进，但每卷至少给一次「提醒性触碰」，
  否则回收时读者早忘了。
- 🔴 **超期**：超过预期回收窗口仍未回收。每章写完更新台账时检查；出现 🔴 必须主动告知作者。
- ✅ **已回收**：回收后归档，记录回收章节与效果，供日后写类似结构时参考。

## 回收窗口怎么定

- 按伏笔的「情绪利息」定：埋得越久、读者期待越高，回收就必须越重。
- 小伏笔（细节呼应、人物小秘密）：同卷内回收，一般 5–20 章。
- 中伏笔（单元级谜团、阶段性身份）：跨 1–2 卷。
- 大伏笔（主线谜团、主角身世）：全书级，但每个卷末要推进一层。
- 题材卡里有各题材的密度与周期基准，以卡为准。

## 回收的三种方式

- **正面回收**：情节直接兑现（救场、揭晓身份）。最常用，注意给足铺垫章。
- **侧面揭示**：借第三方之口、借一件旧物点破，适合不宜大动干戈的小伏笔。
- **反转回收**：伏笔的真实含义与读者当时的理解相反——悬疑题材的看家本领，
  其他题材慎用，用一次伤一次读者的信任（除非埋得足够公平）。

## 超期伏笔的处理（出现 🔴 时给作者的选项）

机器兜底：每章写完的机器闸口（`check_text.py --ledger 追踪/伏笔台账.md --current-chapter N`）
会把超期项报为 FAIL、临近窗口报为 WARN，不依赖肉眼翻台账。出现 🔴 后给作者四个选项：

1. **改窗口**：确实有更好的回收位置 → 把预期回收章节改到新的锚点，写明理由。
2. **提前收**：局势变化，原计划位置不再合适 → 在最近的自然节点收掉。
3. **转长线**：升级成跨卷伏笔 → 移入 🟢，并安排一次「提醒性触碰」。
4. **宣告放弃**：伏笔已失效（剧情走向变了）→ 由作者决定放弃，从台账删除；
   若伏笔已被读者看到，尽量安排一个「软着陆」（给一个低成本的解释了账）。

## 密度常识

- 同章新埋伏笔不超过 1–2 个；新埋与回收尽量交替，只埋不收是庞氏骗局。
- 写每章前的检索纪律：扫一眼台账的 🟡 和 🔴，问「本章有没有该推进/回收的」——
  有就写进本节速记，没有也要确认「本章确实不需要」。

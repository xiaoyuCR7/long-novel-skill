# 情节点预算制

本文件是 `outline-system.md` 章纲层的字数管理方法。`outline-system.md` 定义了章纲
模板中的「情节点清单（带字数预算）」字段——管「章纲里要标字数预算」。本文件定义
**字数预算的具体分级、求和规则、标注格式与档位差异**——管「预算怎么标、怎么算、
怎么用」。

分工：写章纲时查 `outline-system.md` 的模板结构；填预算字段时查本文件的分级和
格式。`pacing-and-hooks.md` 管节奏的快慢档位（定性），本文件管档位对应的字数
分配（定量）——两者是「节奏定性」与「字数定量」的配合。

## 为什么需要情节点预算制

网文写作中最常见的两个问题：

1. **注水**：一章写了4000字，但核心情节点只有2个，剩下2000字是注水（对话寒暄、
   重复描写、设定复述）。没有预算制 = 不知道哪里注了水。
2. **赶进度**：一章写了2000字，塞了5个情节点，每个点只有400字，读者还没爽到就
   翻篇了。没有预算制 = 不知道哪里赶了进度。

情节点预算制 = 给每个情节点标一个字数预算，求和后与章目标字数对比。超了 = 注水
预警，不够 = 赶进度预警。写完后对照预算，哪个点超了或没写到，一眼可见。

## 密/中/疏三级预算

情节点按重要性和展开程度分三级，每级有不同的字数预算范围。

### 密（爽点/打脸/反转/情绪高潮）

密点是全章的核心，是读者追这一章的理由。密点必须给足篇幅，让读者充分感受。

| 密点类型 | 标准预算 | 上限 | 说明 |
|---|---|---|---|
| 普通密点 | ≥250字/点 | — | 打脸/反转/情绪高潮的标准展开 |
| 慢镜头爽点 | 400-600字/点 | 800字 | 大爽点的慢镜头写法，一个动作一个反应地给 |
| 卷级高潮密点 | 600-1000字/点 | 1200字 | 卷末大爆发/全书级高潮，允许超长展开 |

**密点的字数分配原则**：
- 动作/对话/反应三层都要有（不能只有动作没有反应）
- 旁观者反应占密点的 20-30%（爽感放大器，见 `emotion.md`）
- 密点不允许压缩到200字以下——200字以下的「密点」实际是中点，标错了级别

### 中（推进/互动/信息获取）

中点是情节的骨架，推动故事向前但不爆发。中点是全章字数的主要消耗者。

| 中点类型 | 标准预算 | 说明 |
|---|---|---|
| 推进中点 | 100-200字/点 | 矛盾升温、势力布局、信息收集 |
| 互动中点 | 150-200字/点 | 角色对话/交涉/试探 |
| 信息中点 | 100-150字/点 | 获取关键信息/线索 |

**中点的字数分配原则**：
- 信息要挂在动作或对话上（不写说明文，见 `anti-ai-style.md`）
- 互动要有信息量（不写纯寒暄，见 `pacing-and-hooks.md` 的注水六种伪装）
- 中点是「可压缩」的——字数不够时优先压缩中点，不压缩密点

### 疏（过场/赶路/信息交代）

疏点是情节的黏合剂，连接密点和中点。疏点要短，长了就是注水。

| 疏点类型 | 标准预算 | 上限 | 说明 |
|---|---|---|---|
| 过场疏点 | ≈40字/点 | 80字 | 场景转换/时间推移 |
| 赶路疏点 | ≈40字/点 | 100字 | 地点移动（不写沿途风景，除非有伏笔） |
| 信息交代疏点 | ≈50字/点 | 100字 | 必要但非核心的背景交代 |

**疏点的字数分配原则**：
- 一句话过场，不展开（「三日后」「穿过长廊到了前厅」）
- 疏点不承担情绪功能——如果一段过场有情绪，它就不是疏点，升级为中点
- 疏点是「可删除」的——字数严重超限时，删除非必要疏点

## 字数预算求和

### 求和规则

各情节点预算求和 Σ 落在 [章目标, 章目标×1.1]：

```
章目标 ≤ Σ(各点预算) ≤ 章目标 × 1.1
```

- **Σ < 章目标**：预算不足 → 增加展开点（把中点升级为密点，或新增一个互动中点）
- **Σ > 章目标×1.1**：预算超限 → 压缩过场（删疏点，或把中点压短）
- **Σ 在区间内**：预算合理

### 求和示例

假设章目标 3000 字，情节点清单如下：

```
1. 主角到达擂台（疏:40）
2. 观察对手实力（中:150）
3. 对手挑衅对话（中:200）
4. 第一回合交手（中:200）
5. 主角被压制，回忆修炼场景（中:150）
6. 突破瓶颈，反击（密:300）
7. 碾压对手，旁观者震惊（密:400）
8. 对手认输/倒下，主角宣言（密:250）
9. 评委宣布结果，下一位挑战者登场（中:150）
10. 下一位挑战者的威胁感（疏:40+钩子）

预算合计：40+150+200+200+150+300+400+250+150+40 = 1880字
```

Σ = 1880 < 章目标 3000 → 预算不足，需增加 1120 字的展开。

**修复方式**：
- 把点6「突破瓶颈，反击」从密:300 升级为慢镜头爽点 密:500（+200）
- 把点7「碾压对手」从密:400 升级为密:600（+200）
- 新增一个互动中点：点3和点4之间插入「主角与裁判的交锋」（中:200）
- 把点5「回忆修炼」从中:150 扩展为中:250（+100）
- 新增一个中点：点8后插入「盟友/对手的反应」（中:200）
- 把点2从中:150 扩展为中:250（+100）
- 新增互动：点9后插入「下一位挑战者的背景交代」（中:200）

修复后求和：40+250+200+200+250+200+500+600+250+200+150+200+40 = 3280字
3280 在 [3000, 3300] 区间内 → 通过。

### 求和的边界情况

| 情况 | 处理 |
|---|---|
| Σ 远低于章目标（差50%+） | 章纲本身情节点不够，需要重新设计章节内容，不能靠「展开」硬撑 |
| Σ 远高于章目标×1.1（超50%+） | 情节点过多，需要拆章——把一半点移到下一章 |
| 只有1-2个点但Σ达标 | 单点过长，检查是否注水（一个点写3000字通常是注水） |
| 有10+个点但Σ达标 | 点过碎，合并同类点（多个信息获取点合并为一个） |

## 预算标注格式

### 标准格式

每个情节点后标注 `(级:字数)`，章纲末尾写 `预算合计：X字`：

```
## 情节点清单（带字数预算）

1. 主角到达擂台 (疏:40)
2. 观察对手实力 (中:150)
3. 对手挑衅对话 (中:200)
4. 第一回合交手 (中:200)
5. 突破瓶颈，反击 (密:500)
6. 碾压对手，旁观者震惊 (密:600)
7. 对手认输，主角宣言 (密:250)
8. 下一位挑战者登场+威胁感 (中:200+钩子)

预算合计：2140字
章目标：2000字
Σ校验：2140 ∈ [2000, 2200] ✓
```

### 标注的注意事项

- **预算是写作前的计划，不是写完后的统计**：标预算是为了规划，不是为了核对。
  写之前标，写之后对照实际偏差。
- **预算标的是「展开字数」，不是「信息量」**：一个信息量大的点可以预算少（一句话
  揭晓真相），一个信息量小的点可以预算多（打脸的慢镜头）。
- **钩子不单独标预算**：钩子是章尾的一部分，归入最后一个情节点或单列但不计字数
  （钩子通常50字以内，含在最后一个点的预算里）。
- **伏笔操作不单独标预算**：埋/推/收伏笔是嵌入在情节点中的操作，不单独占字数
  预算（除非是一个独立的「揭露伏笔」情节点，此时按中点或密点标）。

## 与章纲模板的衔接

`assets/templates/outline-chapter.md` 的「情节点清单」字段已有字数预算的占位。
本文件补充标准格式，建议在模板中做如下细化。

### 模板字段扩展

当前模板：
```
## 情节点清单（带字数预算）

> 各情节点预算之和 Σ ∈ [目标字数, 目标字数 × 1.1]。

1. {情节点}（约 ___ 字）
2. {情节点}（约 ___ 字）
3. ……
```

建议扩展为：
```
## 情节点清单（带字数预算）

> 密(≥250)/中(100-200)/疏(≈40)三级预算，求和 Σ ∈ [目标字数, 目标字数 × 1.1]。
> 低于章目标增展开点，高于上限压过场。写完对照实际偏差。

1. {情节点} (密:___)
2. {情节点} (中:___)
3. {情节点} (疏:___)
4. ……

预算合计：___字
Σ校验：___ ∈ [目标, 目标×1.1] ✓/✗
```

扩展点：
- 预算标注从「约___字」改为 `(级:___)`，强制标级
- 末尾增加「预算合计」和「Σ校验」两行，让求和检查可见

### 不修改模板时的用法

如果模板未更新，在现有模板的「（约 ___ 字）」位置标注时，按本文件的格式填写即可：

```
1. 突破瓶颈，反击（约 500 字，密）
2. 观察对手实力（约 150 字，中）
3. 主角到达擂台（约 40 字，疏）
```

关键不是格式，而是**每个点都标了级别和字数，且末尾有求和校验**。

## 快/中/慢档的预算差异

`pacing-and-hooks.md` 和 `reverse-brake.md` 定义了三档制。不同档位的密/中/疏
比例不同——本文件补充各档位的预算分配标准。

### 快档（主线突破/大结算）

快档章是高潮章，密点占比最高。

| 指标 | 快档标准 | 说明 |
|---|---|---|
| 密点占比 | ≥60% | 密点字数 / 全章字数 ≥ 60% |
| 密点数量 | 2-4个 | 不超过4个（密点过多=每个都展开不足） |
| 慢镜头爽点 | 至少1个 | 快档章至少有一个400-600字的慢镜头密点 |
| 疏点占比 | ≤10% | 快档章几乎不过场 |
| 中点占比 | 30-40% | 中点只做必要的衔接 |

**快档预算示例**（章目标3000字）：
```
1. 危机爆发 (中:200)
2. 主角决策 (中:150)
3. 正面交锋 (密:400)
4. 被压制后反转 (密:500，慢镜头)
5. 碾压结算 (密:600，慢镜头)
6. 旁观者反应 (密:300)
7. 新危机浮现 (中:200+钩子)
预算合计：2350……不够，需补
→ 把点3升级为密:500，新增「代价展示」(密:300)
修复后：200+150+500+500+600+300+300+200 = 2750……仍不够
→ 新增「对手的最后挣扎」(中:250)
修复后：3000字 ✓
密点占比：500+500+600+300+300 = 2200/3000 = 73% ≥ 60% ✓
```

### 中档（次要矛盾升温）

中档章是节奏主体，密中疏均衡。

| 指标 | 中档标准 | 说明 |
|---|---|---|
| 密点占比 | 30-50% | 中档有密点但不主导 |
| 密点数量 | 1-2个 | 中档章通常1个小爽点+1个情绪点 |
| 中点占比 | 40-50% | 中点是中档章的主力 |
| 疏点占比 | 10-20% | 适量过场 |

**中档预算示例**（章目标3000字）：
```
1. 信息收集 (中:200)
2. 与盟友讨论 (中:250)
3. 发现线索 (中:200)
4. 小规模冲突 (密:300)
5. 冲突结果 (中:200)
6. 角色互动/关系推进 (中:250)
7. 新信息浮现 (密:250)
8. 场景转换 (疏:40+钩子)
预算合计：1690……不够
→ 扩展点4为密:400，扩展点7为密:350，新增互动中点(中:200)
修复后：200+250+200+400+200+250+200+350+40 = 2290……仍不够
→ 新增「角色内心反应」(中:200)，扩展点2为中:350
修复后：200+350+200+400+200+250+200+200+350+40 = 2390……
→ 继续调整直到达标
```

### 慢档（铺垫/羁绊/风土）

慢档章密点最少，但**不能没有密点**——纯中+疏的慢档章 = 水章。

| 指标 | 慢档标准 | 说明 |
|---|---|---|
| 密点占比 | ≤30% | 慢档密点少但必须有 |
| 密点数量 | 1个 | 慢档章至少1个情绪密点（关系深化/微型伏笔回收） |
| 中点占比 | 40-50% | 中点仍是主力 |
| 疏点占比 | 20-30% | 慢档允许更多过场（风土描写/日常） |

**慢档预算示例**（章目标3000字）：
```
1. 日常场景 (疏:80)
2. 风土描写 (中:200)
3. 角色互动 (中:300)
4. 羁绊深化对话 (中:300)
5. 微型伏笔回收 (密:300)
6. 角色反应 (中:200)
7. 新线索暗示 (中:200)
8. 日常收尾 (疏:80+钩子)
预算合计：1660……不够
→ 慢档的扩展方式：增加互动深度，不增加情节点数量
→ 扩展点3为中:400，点4为中:450，新增「角色回忆」(中:250)
修复后：80+200+400+450+300+200+250+200+80 = 2160……
→ 继续扩展互动和描写的深度
```

**慢档的特别注意**：慢档章字数不够时，**不要新增情节点**（新增点=节奏变快=不是
慢档了），而应该**加深现有点的展开深度**——把互动写得更细、把风土写得更具体、
把对话写得更长。慢档的「长」来自深度，不是来自数量。

### 三档预算对比

| 指标 | 快档 | 中档 | 慢档 |
|---|---|---|---|
| 密点占比 | ≥60% | 30-50% | ≤30% |
| 密点数量 | 2-4 | 1-2 | 1 |
| 中点占比 | 30-40% | 40-50% | 40-50% |
| 疏点占比 | ≤10% | 10-20% | 20-30% |
| 慢镜头爽点 | ≥1 | 0-1 | 0 |
| 字数不够时 | 加密点展开 | 加中点或扩展密点 | 加深现有点深度 |
| 字数超限时 | 压中点 | 压疏点 | 压疏点 |

## 预算与实际偏差的处理

写完一章后，对照预算检查实际字数偏差：

| 偏差情况 | 诊断 | 处理 |
|---|---|---|
| 实际 ≈ 预算（±10%） | 正常 | 通过 |
| 某点实际 >> 预算（超50%+） | 该点展开过度 | 检查是否注水（重复描写/对话寒暄/设定复述） |
| 某点实际 << 预算（少50%+） | 该点展开不足 | 检查是否赶进度（爽点没给够/情绪没蓄积） |
| 全章实际 >> 章目标 | 注水 | 定位超预算的点，压缩 |
| 全章实际 << 章目标 | 赶进度 | 定位欠预算的点，补展开 |

**偏差记录**：在章纲的「实际执行」批注中记录偏差，用于后续章纲的预算校准——
如果某类点反复超预算，说明预算标准需要调整（例如打脸密点总是写到500字而非
300字，就把标准从300调到500）。

## 预算制的轻量化原则

本文件的方法不依赖任何脚本工具——预算标注、求和校验都是手工完成的。这与自建skill
的轻量化设计哲学一致（纯文件驱动+脚本闸口，不依赖第三方库）。

预算制的工具配合：
- **章纲阶段**（写前）：手工标注预算，手工求和校验——不需要脚本
- **正文阶段**（写后）：`check_text.py --min-chars/--max-chars` 检查全章字数是否
  达标——脚本只管总量，不管分点
- **偏差分析**（写后）：手工对照预算与实际——不需要脚本

如果需要更精细的自动化，可以在 `check_text.py` 中扩展一个 `--budget-check` 参数，
读取章纲的预算标注，与正文字数对比输出偏差报告。但这是可选增强，不是必需——
预算制的核心价值在于**写前的规划**和**写后的对照**，这两个动作都是人工判断，
脚本只能辅助统计。

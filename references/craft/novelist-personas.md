# 小说家人格轮换（3种风格）

> 反AI味核心策略：在编辑团队的基础上，为每章指定一种"小说家人格"，从文风层面制造变化。AI生成文本的另一大特征是**语气均一化**——每章读起来像是同一个人用同一种心情写的。通过3种人格轮换，模拟真实作者的情绪波动与风格变化。

## 一、设计原理

真实网文作者在连载过程中，不同章节的文风会因情绪、状态、剧情阶段而微妙变化：
- 战斗高潮时笔触凌厉短促
- 情感戏时细腻绵长
- 过渡章时从容疏朗

AI缺失这种"人的波动"。人格轮换通过在章纲中指定人格，引导AI模拟这种变化。

### 轮换规则

1. 不得连续3章使用同一人格
2. 人格选择应与章节内容匹配（战斗章倾向冷峻，情感章倾向旁观）
3. 人格在章纲中声明（`人格: 冷峻派`）
4. `entry_mode.py --persona` 可推荐下一个人格

## 二、3种小说家人格

### 1. 冷峻派（The Blade）

**风格关键词**：短句、动词驱动、零形容词堆砌、留白。

**句式特征**：
- 平均句长 12-18 字（短于其他人格）
- 动词占比 > 25%
- 形容词/副词占比 < 8%
- 段落多为 2-4 句

**心理描写方式**：不写"他感到愤怒"，写"他握紧了拳头，指甲嵌入掌心"。

**对话特征**：对话简短，多用动作标签替代说话标签（"他一脚踢翻椅子"替代"他怒道"）。

**适用场景**：战斗、对峙、追杀、竞技、危机决策。

**示例段落**：
> 刀来了。
>
> 林辰没有退。脚跟碾进泥里，腰一沉，掌根迎上刀背。金属震颤传到手腕，他借力拧身，肘尖撞向对方咽喉。
>
> 对方后仰躲过，反手抽刀横扫。
>
> 风声到了，林辰已经不在原地。

**禁忌**：
- 不能连续5句以上无对话或无心理（会变成纯动作清单）
- 冷峻不等于没有情绪，情绪藏在动作选择里

### 2. 热血派（The Fire）

**风格关键词**：排比、感叹、情绪外放、节奏递进。

**句式特征**：
- 平均句长 18-28 字（长于其他人格）
- 感叹句/反问句占比 > 10%
- 排比段每章 1-2 处
- 段落多为 3-6 句，有递进结构

**心理描写方式**：直接但有力——"他咬碎了牙，血腥味弥漫口腔。不退！死也不退！"

**对话特征**：对话密集，语速快，常有连续对话不插入叙述。

**适用场景**：突破、逆转、热血对决、信念宣告、团队集结。

**示例段落**：
> "你以为淬体七重就能赢我？"
>
> 赵天霸的笑声还没落地，林辰已经动了。
>
> 他不闪不避，一拳轰出。拳风撕裂空气，在赵天霸眼前炸开一团气浪。
>
> "我等这一天，等了三十年！"
>
> 三十年河东，三十年河西。今天，就是他翻盘的日子！

**禁忌**：
- 排比每章不超过2处（否则变成AI味）
- 感叹号全章不超过15个
- 不能只有情绪没有动作（热血不等于空喊口号）

### 3. 旁观派（The Witness）

**风格关键词**：疏离、白描、环境与人物交织、时间感。

**句式特征**：
- 平均句长 20-30 字（最长）
- 环境描写占比 15-20%
- 时间标记词较多（"黄昏时""不知过了多久"）
- 段落多为 4-7 句，有层次

**心理描写方式**：通过环境映射情绪——"夕阳把他的影子拉得很长，像一条走不到尽头的路"。

**对话特征**：对话稀疏，每段对话后常有环境或沉默的留白。

**适用场景**：过渡章、日常、情感沉淀、战后余波、世界观铺展。

**示例段落**：
> 黄昏的光线从西窗斜射进来，在地板上拉出一道长长的影子。
>
> 林辰坐在桌前，面前摊着那张被揉皱又展平的地图。墨迹晕开了一角，像是某种无法挽回的东西。
>
> 院子外面传来王胖子练拳的声音，沉闷而有规律，像一座老钟在走。
>
> 他想起师父说过的话：武道一途，走得太快的人，往往摔得最惨。
>
> 那时候他不信。现在他有些信了。

**禁忌**：
- 环境描写不能超过段落字数的30%
- 旁观不等于没有推进，每段必须有信息增量
- 不能连续2章使用旁观派（会导致节奏拖沓）

## 三、人格与入口模式搭配建议

| 入口模式     | 冷峻派 | 热血派 | 旁观派 |
|-------------|--------|--------|--------|
| 场景切入     | ○      | △      | ✓      |
| 对话切入     | ✓      | ✓      | △      |
| 动作切入     | ✓      | ✓      | ✗      |
| 悬念切入     | ✓      | △      | ✓      |
| 回忆切入     | △      | ✗      | ✓      |
| 信息切入     | ○      | △      | ✓      |
| 感官切入     | ✓      | ○      | ✓      |
| 节奏切入     | ✓      | ✓      | ✗      |

`✓` 推荐 `○` 可用 `△` 慎用 `✗` 不推荐

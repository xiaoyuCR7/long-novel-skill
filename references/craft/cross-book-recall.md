# 跨书召回与防文风污染

多本对标书并存时，管的是「写作时从哪些书召回什么、召回多少、怎么不让别书的文风
渗进本书」。拆文流程见 `workflow/deconstruct.md`，本文件只管召回纪律。

核心矛盾：对标越多，可学的结构越多，但文风被带偏的风险也越大——副对标的句式、
腔调、叙事节奏会不知不觉渗进正文。解法不是少拆，是召回时分级隔离。

## 核心原则：主一辅多

- **主对标（1 本）**：走全文风 + 原文召回。本书 `设定/文风锚.md` 的样板段落、
  六维指纹容差都锚定在主对标上。写正文时腔调对齐主对标，文风漂移检测也拿主对标做基线。
- **副对标（不限数量）**：只走结构模块——节奏分布、钩子类型、情绪模块骨架、
  角色功能位、反转结构。**不读副对标的文风文件**，不拿副对标的原文做腔调校准。

主对标选近一年、同题材、同平台、数据最好的那一本（选标准见 `deconstruct.md` Step 1）。
没有主对标时，文风锚以作者自定样板为准，但前 10 章少了节奏参照，容易踩坑。

## 三道防线防文风污染

### 防线一：副对标的文风文件不读

`对标/{书名}/文风指纹.md` 只对主对标开放。副对标的文风指纹文件在召回时跳过，
不进入写作上下文。原因：文风指纹里的句长、对话占比、段落中位长度、标点节奏等
量化指标一旦被模型读到，会潜意识地向那个方向靠拢，造成跨书腔调污染。

执行方式：召回副对标时只读 `对标/{书名}/可复用要点.md`、`结构分析.md`、
`节奏分析.md`、`情绪模块/`，**跳过 `文风指纹.md`**。

### 防线二：角色/剧情/设定可召回但按相关性排序 + 预算约束

副对标的角色卡、剧情线、设定条目可以召回，但不能全量读，按以下规则约束：

1. **相关性排序**：按「跨题材判断矩阵」的相关度档位从高到低排序，同档位内按
   与本章情节点/角色的匹配度排序。只有与本章直接相关的条目才有召回资格。
2. **预算约束**：所有副对标的召回条目合并后不超过阶段总预算（见下节矩阵）。
   超预算时裁条目，不裁书目。
3. **结构而非内容**：召回的角色卡取「功能位」（导师/对手/伙伴/搅局者），
   不取人设细节（名字/口癖/外貌）；召回的剧情线取「结构骨架」（起承转合），
   不取具体情节。照搬内容 = 抄袭（见 `deconstruct.md` 拆文纪律）。

### 防线三：narrative-writer 只吃主对标文风 + 筛选后的副对标摘要

写正文时，进入写作上下文的对标信息只有两类：

- **主对标的文风锚 + 原文样板段落**：用于腔调对齐，直接进 `设定/文风锚.md`。
- **筛选后的副对标结构摘要**：每条不超过 3 行，只写结构骨架（「打脸模块：
  铺垫→压制→反转→见证，字数占比 1:2:3:1」），不附原文。

副对标的原始拆文文件（角色卡全文、情绪模块全文）不直接进写作上下文，
由编辑/作者在写章纲或检索阶段提前压成摘要，再喂给正文写作。

## 跨题材判断矩阵

每本副对标按与本书的关系归入五档，档位决定召回上限。阶段总预算是所有副对标
合并后的上限——不是每本的上限，是全批次加起来不得超过。

| 档位 | 说明 | 每本上限（设定/大纲/模块） | 正文召回 |
|---|---|---|---|
| 同题材 | 同题材同平台，节奏可直接参照 | 8 / 10 / 8 | 0 |
| 辅题材 | 辅题材或同题材不同平台，结构可借 | 5 / 6 / 5 | 0 |
| 参考 | 相近题材，部分结构模块可借 | 3 / 4 / 3 | 0 |
| 弱相关 | 不同题材但有可学的孤立结构 | 1 / 2 / 2 | 0 |
| 不相关 | 题材/平台/受众差异大 | 0 / 0 / 0 | 0 |

**阶段总预算**（所有副对标合并上限）：

| 召回类型 | 上限 | 说明 |
|---|---|---|
| 设定条目 | ≤ 8 条 | 世界观规则、势力结构、能力体系等可借鉴的设定逻辑 |
| 大纲条目 | ≤ 10 条 | 卷级结构、剧情单元切分、节奏分布等可借鉴的编排 |
| 模块条目 | ≤ 8 条 | 情绪模块、钩子类型、反转结构等可复用的结构骨架 |
| 正文原文 | 0 条 | 副对标正文一律不召回进写作上下文（主对标除外） |

正文召回 = 0 是硬线：副对标的原文段落不得进入正文写作上下文。需要参考副对标
原文时，由作者/编辑人工提炼成结构摘要后再用。

## 裁条目不裁书目

副对标数量不限——拆了多少本就留多少本在 `对标/` 目录下。召回时如果总条目数
超过阶段预算，只裁掉超出部分的召回条目（降级或丢弃），不删除书目记录。

这意味着：

- 拆完的书永久存档，下次写别的情节时可以召回不同的条目。
- 本次召回被裁掉的条目，下次相关度更高时仍可召回。
- 书目记录（`对标/{书名}/可复用要点.md`）始终保留，作为「这本书值得学什么」
  的索引，即使本次不召回也留着。

执行方式：召回前先按相关度排序全部候选条目，从高到低取，取满预算即停。
被裁掉的条目不进写作上下文，但在候选列表里标记「本轮未召回（超预算）」。

## 拆文字段→写作参考回查表

拆文产出的结构化字段，写作时按需回查对应的 `craft/` 工艺文件。这张表管的是
「副对标的某个拆文字段，回到本书的哪份工艺文件里找使用规范」。

| 拆文字段 | 含义 | 回查 craft/ 文件 |
|---|---|---|
| `beats` | 节奏拍点：事件节拍分布、快中慢档位配比 | `pacing-and-hooks.md`（节奏与钩子通用原则） |
| `hooks` | 钩子类型：章首承接式、章尾悬念式 | `hooks.md`（钩子库：章首 7 式 · 章尾 13 式） |
| `setup_clues` | 铺垫线索：伏笔埋设点、回收窗口、状态机 | `foreshadowing.md`（伏笔：埋设与回收） |
| `character_archetypes` | 角色原型：功能位（导师/对手/伙伴/搅局者） | `character-consistency.md`（人设一致性防 OOC） |
| `reusable_structures` | 可复用结构：情绪模块骨架、单章四拍通式 | `format-and-structure.md`（格式与排版硬约束） |
| `reversal_type` | 反转类型：情节/身份/认知三级反转 | `reversal.md`（反转工具箱） |

回查纪律：

- 拆文字段是「对标书怎么做的」，craft 文件是「本书该怎么做」——回查是为了把
  对标的结构经验翻译成本书的写作规范，不是照搬对标做法。
- 一次只回查与本章直接相关的字段。写打脸场景才查 `reusable_structures` +
  `reversal_type`，写日常铺垫不查反转。
- craft 文件的规则优先级高于拆文字段：两者冲突时以 craft 文件为准（拆文是参考，
  工艺规范是硬约束）。

## 与 deconstruct.md 和 entity_index.py 的关系

### 与 `workflow/deconstruct.md` 的关系

`deconstruct.md` 是拆文流程——把对标书拆成结构化素材存入 `对标/{书名}/`。
本文件是召回协议——管的是「拆完之后写作时怎么召回、召回多少、从哪些书召回」。

- 拆文产出是召回的素材库：没有拆文就没有可召回的条目。
- 拆文管「怎么拆」，召回管「怎么用」：拆文时全量拆（结构/角色/节奏/情绪模块/
  文风指纹都拆），召回时分级取（主对标全取，副对标只取结构模块，文风文件隔离）。
- 拆文的「可复用要点.md」是召回的入口：写章纲前先扫各副对标的可复用要点，
  判断哪些与本章相关，再决定深挖哪个子文件。

### 与 `scripts/entity_index.py` 的关系

`entity_index.py` 是**本书**的实体→章节索引，用于写前检索本书的历史细节
（「林雷上次出现是第几章」）。它管的是本书内部的一致性，不涉及对标书。

跨书召回不使用 `entity_index.py`——对标书的实体不在本书的索引里。但两者有间接
协作：

- 召回副对标的角色功能位后，可以用 `entity_index.py query` 查本书对应功能位的
  角色上次出场章节，确保对标结构套用在本书角色身上时不破坏一致性。
- 召回副对标的伏笔结构（`setup_clues`）后，对照本书 `追踪/伏笔台账.md` 检查
  是否有可借鉴的埋设/回收节奏，但本书的伏笔台账用 `entity_index.py` 定位，
  不依赖对标书。

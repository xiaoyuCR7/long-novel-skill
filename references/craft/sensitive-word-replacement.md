# 敏感词替换工艺（sensitive-word-replacement）

管理小说正文里的敏感词：真实地名、机构、职务、人物、事件 → 全书统一的虚构代称。
处理不好 = 平台审核不过 / 读者出戏 / 真实世界穿帮。处理对象是**发布安全与代入感**，
与 `anti-ai-style.md`（Gate A 去 AI 腔禁用词）是两套词表，别混：一个是机器味，一个是现实感。

## 一、为什么需要

1. **平台审核**：真实地名/机构/公众人物/真实事件是审核红线的高发区，撞线轻则删改重则封号。
2. **读者出戏**：真实地名把读者拽回现实，架空代称让读者留在书的世界里。
3. **表内自洽**：一个代称全书一个写法，读者才不会在「京城」和「北京」之间来回跳。

## 二、什么时候建（开书流程 Step 2，与世界观同步）

世界观定了地名、势力、机构的瞬间，就建 `设定/敏感词替换表.md`（模板：
`assets/templates/sensitive-word-replacement.md`，`init_book.py` 开书时自动拷贝骨架）。

**建表时机纪律**：
- 世界观里出现的每个地理/机构名，逐一问一句「这是不是真实世界的东西？」，是 → 进表登记代称。
- 都市现实向必建；历史/军事/娱乐圈/官场商战等高敏题材必建；纯架空奇幻可只留表头待用。
- 没有这张表，不开写正文第一行。

## 三、三件套

### 1. 地名代称系统（真实地名 → 虚构代称）

一行一映射：`真实地名 → 全书统一代称`。要点：

- **代称要有记忆点**：两个字或三个字，读一遍能记住，不与角色名/门派名撞名。
- **语义可联想**：南方的城叫「南州」，北方的学府叫「北境」——读者脑内定位不费力。
- **代称进入正文前先登记**：新地名当场造代称、当场登记，绝不口头约定、绝不临时起名。
- **真实国名不出现**：写国际势力用「大洋彼岸的强国」这类不点名指称，或完全虚构国名。

### 2. 别称置换规则（机构 / 职务 / 群体）

真实机构/职务/群体 → 固定的置换词 + 使用规则：

| 真实指称 | 常见置换 | 规则要点 |
|---|---|---|
| 政府机构 | 官方 / 上头 | 不出现真实机构全称 |
| 军队 | 军方 | 不写真实番号 |
| 警察 | 巡捕 / 秩序署 | 全书一制，不换词 |
| 学校 | 学府 / 学院 | 全校一制 |
| 媒体 | 官媒 / 上媒 | 不写真实媒体名 |
| 明星 | 虚构艺名 | 不写真实艺人 |

一条置换规则 = 一个固定词 + 一条「不写什么」的禁令。规则宁可死板，不可灵活。

### 3. 地名脱敏处理方法（写法层面）

- **模糊化**：不写行政区划全称，用方位/特征描述替代（「旧城区」「城西」）。
- **架空化**：现代文设「平行时空」，城市全虚构。
- **时间脱敏**：不绑定真实年份/真实大事件。
- **人物脱敏**：现实名人不入书。
- **专名避雷**：与真实地名/品牌/人名重名的词，写前查一遍，宁改不赌。

## 四、造代称的八条纪律

1. **一致性**：一个真实地名全书只有一个代称，改一次 = 全局统一改。
2. **代入感**：代称不能让读者联想到现实（谐音太像真名 = 白脱敏）。
3. **不自嗨**：代称不是炫技，读者一眼看懂在哪、是谁，别造生僻字。
4. **不撞名**：代称不与角色名、门派名、金手指名重音重形。
5. **表内自洽**：代称进正文前，必须先出现在替换表里。
6. **表外新词即登记**：写作中遇到表外敏感词，当场造代称并登记回表，不改旧条。
7. **禁真名**：正文任何位置不出现真实地名/机构/人物全称，包括角色自言自语和内心戏。
8. **宁改不赌**：拿不准会不会触发审核的词，一律换成代称。

## 五、写作期执行

- **写前**：涉及真实世界的场景，先从替换表读出本场景要用的代称，压进 Step 3 速记。
- **写中**：正文只写代称；忘词时查表，不现场造词。
- **写后**：机检 + 人检（见下）。

### 机器核对（低成本拦截）

1. 把**必禁真实专名**（真实地名/机构名/人名）逐行并入 `设定/禁用词.txt`，
   配合 `!` 前缀豁免合法语境（见 `deslop-engineering.md` 白名单规则）；
   `check_text.py --gate-report` 会自动拦截正文里的真实专名。
2. 对整书做一次「表外敏感词扫描」：Grep 正文中是否出现真实地名/机构名列表，
   命中即回表置换。

### 人工核对（每卷一次）

对照替换表四张清单过一遍：地名代称齐全？机构置换一致？写法层面脱敏到位？
表外敏感词全部登记？有遗漏 → 补表 + 回改正文。

## 六、与禁用词.txt 的分工

| 文件 | 管什么 | 谁用 |
|---|---|---|
| `设定/禁用词.txt` | 去 AI 腔：题材专属禁用词 + 个人避讳词 | `check_text.py` 自动加载（Gate A） |
| `设定/敏感词替换表.md` | 发布安全：真实地名/机构/人物 → 代称 | 写作流程 + 卷级人工核对 |
| 交集：必禁真实专名 | 并入 `禁用词.txt` 让机器拦截 | `check_text.py` |

两表互不替代。去 AI 味管「机器味」，敏感词替换管「现实感」，都在 Step 5 机器闸口前自查完。

## 七、各题材敏感点速查

| 题材 | 高发敏感点 | 处理预案 |
|---|---|---|
| 都市现实向 | 真实地名、机关、民生事件 | 平行时空 + 全量代称 |
| 历史 | 真实帝王将相、朝代评价 | 虚实结合，原型换名讳 |
| 军事 | 真实战役、番号、国际关系 | 架空国名与战役代号 |
| 娱乐圈 | 真实艺人、公司、舆论事件 | 虚构艺名/公司 |
| 官场商战 | 真实职务链、政策 | 职务虚化、事件架空 |
| 悬疑刑侦 | 真实案件、办案机关 | 案件架空、机关代称 |

## 八、落地文件

- 每书一张表：`设定/敏感词替换表.md`（模板：`assets/templates/sensitive-word-replacement.md`）
- 建表时机：`workflow/book-init.md` Step 2
- 写中执行：`workflow/chapter-loop.md` Step 2 检索 + Step 4 写作
- 机器拦截：`scripts/check_text.py`（把必禁专名并入 `设定/禁用词.txt`）

# 题材写作公式

本文件是 `narrative-modules.md`（叙事元素卡+结构技法卡+情绪模块公式）的题材落地层。
`narrative-modules.md` 定义了 11 个通用情绪公式（打脸三连、装逼打脸、绝境翻盘等），
本文件把这些公式拆解成更细的操作步骤，补充每个步骤的关键细节、常见失败模式
和完整示例，并标注适用题材。

`commercial-core.md` 管的是「一本书为什么能卖」——核心卖点、金手指原理、期待感
管理。本文件管的是「具体一段剧情怎么写」——给定一个爽点/虐点/悬念，怎么从
第一步铺到第五步。两者是战略与战术的关系：`commercial-core.md` 定方向，本文件
定执行。

分工关系：
- `narrative-modules.md`：通用公式库（11 个情绪公式，按情绪类型分类）——管「这个
  情绪弧线用什么模块组合」。
- `combat-and-face.md`：打脸和打斗的专项写法——管「打脸的三要素和两种姿势」。
- `reversal.md`：反转工具箱——管「好反转的三要素和三个层级」。
- 本文件：题材落地的操作步骤——管「一个完整的打脸/升级/拉扯/揭秘/装逼，
  从铺到收的五步怎么走」。

## 公式一：打脸公式

### 适用场景

主角被低估/羞辱/压制，已具备或即将具备碾压实力，需要一次完整的反转碾压。
适用题材：都市爽文、玄幻升级流、重生复仇、系统流、宫斗宅斗——几乎所有
「爽感驱动」的题材。参照 `combat-and-face.md` 的打脸三要素和 `narrative-modules.md`
的公式 1（打脸三连）。

### 结构步骤

```
铺垫 → 压制 → 反转 → 碾压 → 旁观者反应
```

#### 第一步：铺垫

**做什么**：建立「主角被低估」的前提。反派/配角的轻视要具体、公开、踩到痛处。

**写法**：
- 轻视要**具体**：不是「他们看不起他」，是「他在宗门比武抽签时被分到了最差的位置，
  旁边的弟子笑了一声」。参照 `combat-and-face.md` 的「羞辱给够」。
- 轻视要**公开**：在有第三者在场的场合发生——旁观者是后面反应的素材，没有旁观者
  = 打脸打了一半。
- 轻视要**踩到痛处**：踩身份/家人/梦想，不要踩无关的事。「你连剑都握不稳」
  比「你走路姿势真难看」有冲击力得多。

**篇幅**：铺垫不超过场景总篇幅的 20%。铺垫太长 = 读者憋屈到弃书；铺垫太短 =
后面打脸不够响。参照 `emotion.md` 的对比原则——「爽前必压，压要压得具体」。

#### 第二步：压制

**做什么**：让反派的嚣张到达顶点，让读者的憋屈到达临界。

**写法**：
- 反派在压制过程中要**得意忘形**——说出一些「将来会被打脸」的话，如「就凭你？」
  「你这辈子也就这样了」。这些话是后面碾压时的回扣素材。
- 主角在这一步**不反击或反击无效**——让读者以为主角真的打不过/真的不行。
  参照 `narrative-modules.md` 的延迟满足模块——「主角不立刻反击，先让反派得意」。
- 压制过程中要**埋一个钩子**——主角有一个底牌/伏笔/隐藏实力，读者知道但反派
  不知道。这个钩子是第三步反转的支点。参照 `reversal.md` 的「伏笔先行」。

**篇幅**：压制占场景总篇幅的 25-30%。这是蓄积阶段，蓄积越长后面爆发越爽——
但不要超过 30%，超过 = 读者憋不住弃书。

#### 第三步：反转

**做什么**：主角亮出底牌/隐藏实力，局势瞬间翻转。

**写法**：
- 反转的**速度要快**——蓄了那么久，释放要干脆。反转瞬间用短句，一句话不超过
  10 个字。参照 `dialogue.md` 的「反转瞬间用短句引爆」。
- 反转的**支点必须前文埋过**——不能当场开挂。底牌/伏笔/隐藏实力至少在 2 章前
  埋设。参照 `reversal.md` 的好反转三要素之「伏笔先行」和 `combat-and-face.md`
  的「翻转的那一手，前文是否埋过」。
- 反转后**反派的反应分三层**：不信 → 确认 → 恐惧/愤怒。三层至少写两层。参照
  `dialogue.md` 的反转型模式。

#### 第四步：碾压

**做什么**：主角用碾压级实力彻底击溃反派，爽感释放的顶点。

**写法**：
- 碾压要**干脆利落**——不要拖泥带水，不要给反派翻盘的机会。碾压的节奏要快，
  短句为主。参照 `format-and-structure.md` 的「高潮/打脸压到最短」。
- 碾压要**有策略**——不是单纯的力量碾压，是「主角用一种出人意料但合情合理的
  方式碾压」。参照 `combat-and-face.md` 的「打斗不写招式，写策略」。
- 碾压后**给反派留一句不服的尾巴**——完全认输跪舔 = 打脸没有余韵。留一根刺，
  是下一波打脸的引子。参照 `combat-and-face.md` 的打脸失败信号。

#### 第五步：旁观者反应

**做什么**：通过旁观者的态度变化放大打脸的爽感。参照 `narrative-modules.md`
的旁观者反应元素卡和 `combat-and-face.md` 的「见证者到位」。

**写法**：
- 旁观者反应**分阶段**：初始态度（不屑/附和反派）→ 中间动摇（震惊/不信）→
  最终态度（恐惧/崇拜/改观）。参照 `narrative-modules.md` 的旁观者反应三阶段。
- 旁观者反应**有差异**：不同身份的旁观者反应不同——媚上的立刻换脸、嘴硬的
  找借口、中立的倒吸凉气、内行看门道、外行看热闹。参照 `combat-and-face.md`
  的「围观群众反应千篇一律」失败信号。
- 旁观者反应用**代表人物法**——不要写「所有人都震惊了」，选 1-2 个具体人物
  反应代表群体。

### 关键细节

- **打脸的爽感公式**：憋屈 × 时间 × 出乎意料 = 爽感。憋屈越具体、等待越长、
  反转越出乎意料，爽感越强。但三者都有上限——憋屈太狠读者弃书、等待太长读者
  弃书、反转太意外不合理。参照 `emotion.md` 的蓄积→爆发→余韵。
- **打脸的节奏**：整个公式（铺垫到旁观者反应）可以在一章内完成（小打脸），
  也可以跨 2-3 章（大打脸）。大打脸的铺垫在前一章或前几章，爆发在本章。参照
  `pacing-and-hooks.md` 的快档章——大打脸 = 快档，触发 A/B/C 配额中的 A 或 B。
- **打脸的代价**：参照 `pacing-and-hooks.md` 的大节点三要素——打脸后主角要付出
  代价（暴露底牌/得罪了更大的势力/伤了元气）。无代价的打脸 = 没有重量，参照
  `combat-and-face.md`。

### 常见失败

| 失败模式 | 症状 | 修复 |
|---|---|---|
| 铺垫不足 | 反派刚开始嚣张主角就打了 | 增加压制段，让憋屈蓄够再爆 |
| 反派变蠢 | 反派为了被打脸突然做蠢事 | 给反派合理的失败原因（轻敌/信息差/被算计） |
| 靠外援打脸 | 大人物恰好路过帮主角打脸 | 改成主角自己埋的线，参照 `combat-and-face.md` |
| 碾压太拖 | 碾压过程写了大半章，反派还在挣扎 | 压缩碾压段，干脆利落地击溃 |
| 旁观者缺失 | 主角打完脸没人看到 | 确保打脸在场有旁观者，且写出差异反应 |
| 打完就跪 | 反派立刻认输跪舔 | 留一句不服的尾巴，引出下一波 |
| 无代价 | 打脸完一切照旧 | 加代价——暴露了实力/得罪了更大的敌人/伤了根基 |

### 示例

```
（铺垫：主角被分到最差的比武位置，旁边弟子笑了一声。裁判宣读规则时
  跳过了他的名字。）

（压制：对手是宗门第三的师兄，上来就放话「三招之内解决你」。第一招
  主角被打退三步，第二招主角的剑被打飞。师兄收剑：「还要继续？」
  台下有人喊「认输吧」。主角捡起剑。读者知道主角有一招没亮过的底牌
  ——第七式，三天前刚练成。）

（反转：师兄第三招来了。主角没有躲，迎上去，剑光一闪。
  师兄的剑停在了半空。他的袖子断了一截。）

（碾压：主角的剑抵在师兄的喉咙。师兄没动。
  「你——」
  主角收剑。师兄的膝盖弯了一下，但硬撑着没跪。
  「我认输。」他咬着牙说的。）

（旁观者反应：
  裁判愣了三秒才宣布结果。
  之前喊「认输吧」的那个弟子把头缩了回去。
  长老席上，有人放下了茶杯。
  「第七式？」长老甲转头看长老乙，「他什么时候学的？」
  长老乙没回答，只是在名册上写了一笔。）
```

## 公式二：升级公式

### 适用场景

主角在能力/境界/资源上遭遇瓶颈，经过契机和突破后展示新实力，并付出代价。
适用题材：玄幻修仙、系统流、异能末世、游戏文——所有「升级驱动」的题材。
参照 `narrative-modules.md` 的结构技法卡 2.8（升级循环）和 `commercial-core.md`
的金手指原理。

### 结构步骤

```
瓶颈 → 契机 → 突破 → 展示 → 代价
```

#### 第一步：瓶颈

**做什么**：主角发现当前能力/资源/势力不足以应对下一个挑战。

**写法**：
- 瓶颈要**具体**：不是「他遇到了瓶颈」，是「他的灵力卡在四品上阶三个月了，
  再不突破五品，下个月的宗门考核就会被刷下去」。瓶颈有具体的数字、期限、后果。
- 瓶颈要有**外部压力**：不是主角自己想升级，是有外部原因逼迫——考核/比武/敌人
  追杀/资源耗尽。外部压力给升级一个「必须成功」的理由。
- 瓶颈要有**内因**：不是纯粹的天赋不够，是有一个具体的障碍——功法缺陷/心魔/
  资源不足/理解偏差。内因让突破有具体的方向（解决那个障碍）。

#### 第二步：契机

**做什么**：主角找到突破的方法/线索/资源。

**写法**：
- 契机不能是**天上掉馅饼**——参照 `narrative-modules.md` 的绝境逆转失败模式
  「逆转筹码是当场拿出来的：机械降神」。契机要有来源：主角在之前找的/别人
  指点的/一次失败的教训。
- 契机要有**代价门槛**：不是白拿的，需要付出什么——时间/风险/资源/人情。
  参照 `commercial-core.md` 的金手指局限——「资源差型金手指必须有消耗场景」。
- 契机要有**不确定性**：这个方法不一定能成功——给突破一个「会不会成功」的
  悬念。不确定性的来源：方法未经证实/有副作用风险/时间不够/有人干扰。

#### 第三步：突破

**做什么**：主角完成突破，能力/境界实现质的飞跃。

**写法**：
- 突破要**写细**——这是爽感释放的瞬间，用慢镜头。参照 `emotion.md` 的「大爽点
  用慢镜头写，一个动作一个反应地给」。突破的每个阶段（开始→过程→临界→成功）
  都要有画面。
- 突破要有**一个「关键瞬间」**——整个突破过程中最危险/最关键的那一刻。这个
  瞬间用最短的句子写，制造心跳加速的效果。
- 突破成功后要有**生理反应**——不要写「他突破了，很开心」，写身体的变化
  （灵力涌动时经脉发热/睁开眼时瞳孔变了颜色/站起来时脚步比以前稳了）。参照
  `writing-craft-extras.md` 的身体细节替代。

#### 第四步：展示

**做什么**：主角用新能力应对之前无法应对的挑战，验证突破的效果。

**写法**：
- 展示要有**对比**——参照 `narrative-modules.md` 的升级循环纪律「验证必须有
  之前做不到→现在做到了的对比」。用同一个对手/同一个场景/同一个任务做对比：
  之前打不过的现在打赢了、之前做不到的现在做到了。
- 展示不要太长——突破是高潮，展示是高潮后的余韵。展示不超过场景总篇幅的
  20%，重点写「变了什么」而不是重新打一架。
- 展示可以接打脸公式——如果展示的对象是之前压制主角的人，展示 = 打脸的
  碾压步骤。两个公式可以衔接。

#### 第五步：代价

**做什么**：突破不是免费的，主角付出了什么。

**写法**：
- 代价要**与突破相关**——不是随便的代价，是突破带来的副作用/后果。如：突破
  消耗了大量资源、突破暴露了实力引来更强的敌人、突破伤了根基需要休养。
  参照 `pacing-and-hooks.md` 的大节点三要素之「代价」。
- 代价要**延迟显现**——不是突破的当场就知道代价，是过几章才发现。参照
  `narrative-modules.md` 的代价兑现元素卡「延迟兑现：选择和代价之间有足够的
  时间差」。
- 代价是**下一个循环的起点**——参照 `narrative-modules.md` 的升级循环第五阶段
  「新瓶颈浮现」。代价 = 新的瓶颈，让升级线不断循环。但新瓶颈必须比旧瓶颈高
  一个层级，不能是同一个量级的重复。

### 关键细节

- **升级节奏控制**：一次完整的升级公式（瓶颈到代价）跨 3-8 章为宜。太短 =
  升级太容易，没有成就感；太长 = 读者等不及。参照 `commercial-core.md` 的
  持续卖点——「这个卖点能支撑100章不重复吗？」每个升级循环的突破方式必须不同
  （不能连续两次都是「闭关突破」或「奇遇突破」）。
- **升级与读者契约**：参照 `reader-contract.md`——升级是读者对成长期待的兑现。
  每次升级必须让读者觉得「这个升级是主角自己挣来的，不是天上掉的」。挣来的
  感觉来自：契机的来源（之前埋的线）+ 突破的风险（不确定能不能成功）+ 代价
  （不是免费的）。
- **升级与战力膨胀**：参照 `commercial-core.md` 的崩盘模式「升级体系天花板」——
  开书定台阶总数，逐卷控制消耗速度。每次升级消耗一个台阶，不能超速。

### 常见失败

| 失败模式 | 症状 | 修复 |
|---|---|---|
| 瓶颈太短 | 刚说遇到瓶颈，下一章就突破了 | 增加瓶颈期的外部压力和挣扎 |
| 契机太随意 | 路边捡到秘籍/系统突然发放 | 给契机的来源和代价门槛 |
| 突破太快 | 突破过程一段话带过 | 用慢镜头写细，给关键瞬间 |
| 无展示 | 突破完直接进下一段剧情 | 加展示段，用对比验证突破效果 |
| 无代价 | 突破完一切照旧，还更强了 | 加代价——暴露/消耗/副作用/新敌人 |
| 突破方式重复 | 连续两次都是闭关突破 | 每次换突破方式（领悟/以战养战/奇遇/牺牲） |
| 升级太快 | 每三五章升一次 | 控制升级节奏，参照台阶总数和逐卷消耗速度 |

### 示例

```
（瓶颈：灵力卡在四品上阶三个月。下个月宗门考核，五品以下刷下去。
  他的功法在四品到五品之间有一个断层——师傅没教过渡的部分。）

（契机：他在藏经阁翻到一本残卷，上面记载了一种过渡法门。但残卷
  缺了两页，而且注明「修炼此法者，三成概率经脉寸断」。
  他把残卷借走了。当天晚上开始修炼。）

（突破：第一夜，灵力在经脉里乱窜，他咬着牙撑过去。
  第三夜，到了最关键的那一步。残卷说「此处不可中断」。
  他的经脉像被火烧。汗从额头滚下来，滴在地上，发出滋的声响。
  他想起了师傅的话——「过不去就是死。」
  他没停。
  天亮的时候，他睁开眼。灵力在经脉里走了一圈，比以前顺畅三倍。
  他低头看自己的手——指尖有淡淡的灵光。五品。）

（展示：考核那天，他打的是之前碾压他的师兄。
  师兄出招，他没躲。接了。
  师兄愣了一下。上次这一招把他打飞了三步。
  这次他一步没退。他抬手，灵光一闪，师兄的剑被弹开了半尺。
  「五品？」师兄的声音变了。）

（代价：他赢了考核。但当晚，他的经脉开始隐隐作痛——残卷缺的那两页，
  记载的是修炼后的修复方法。他不知道。
  三天后，他发现灵力运转时偶尔会卡一下。）
```

## 公式三：感情拉扯公式

### 适用场景

两个角色之间的感情从暧昧到误解到决裂再到和解，完整的情感过山车。
适用题材：言情、都市、宫斗、甜虐向——所有「关系驱动」的题材。
参照 `narrative-modules.md` 的公式 6（双向暗恋）和 `commercial-core.md`
的重人设型大纲。

### 结构步骤

```
靠近 → 误解 → 推开 → 后悔 → 和解
```

#### 第一步：靠近

**做什么**：两个角色的关系从远到近，读者开始嗑 CP。

**写法**：
- 靠近要**有节奏**——不是一步到位，是一点一点靠近。每次靠近都有一个「差点
  更近但差一步」的瞬间，参照 `narrative-modules.md` 的延迟满足模块。
- 靠近要**有障碍**——两人之间有一个客观障碍（身份差距/已有婚约/阵营对立/
  过去的伤害），障碍让「靠近」本身成为张力来源。参照 `outline-structure-theory.md`
  的重人设型大纲——「关系张力需要释放」。
- 靠近靠**细节**不靠告白——不是写「他发现自己喜欢她了」，是写他开始注意她
  的小习惯、开始不自觉地照顾她、开始在意她对别人的态度。参照 `emotion.md`
  的「给形状不给名词」和 `writing-craft-extras.md` 的身体细节替代。

#### 第二步：误解

**做什么**：一个误解/信息差让两人关系急转直下。

**写法**：
- 误解要**合理**——不是低智误解（看到对方和异性说话就吃醋），是基于角色
  认知差的合理误判。参照 `narrative-modules.md` 的认知差元素卡——「角色因为
  错误认知做了一个决定」。误解的来源是角色已有的认知偏见（过去被背叛过所以
  不信任/身份差距所以自卑/阵营对立所以先入为主）。
- 误解要**有信息不对称**——参照 `narrative-modules.md` 的信息不对等。读者知道
  真相但角色不知道 = 读者替角色着急（戏剧张力最强）；或者两个角色都不知道真相
  = 双向误解（虐感最强）。
- 误解不要**一句话就能解开**——如果误解一句话就能说清楚，那就不是「误解」
  是「沟通不畅」。好的误解有结构性原因：说不出口（碍于身份/自尊）、没有机会说
  （被打断/对方不听）、说了也没用（对方不信）。

#### 第三步：推开

**做什么**：因为误解，其中一方主动拉开距离/做出伤害对方的行为。

**写法**：
- 推开要有**痛苦**——推开的人不是不在乎，是「太在乎所以必须推开」。痛苦要
  写出来——参照 `writing-craft-extras.md` 的身体细节替代，用动作和微表情展示
  推开时的挣扎。
- 推开要**有具体行为**——不是「她疏远了他」，是一个具体的行为：拒绝见面、
  退还信物、说了一句伤人的话。具体行为 = 后面后悔时的具体回扣。
- 推开后要写**被推开一方的反应**——参照 `dialogue.md` 的心死型模式：不反问、
  不反驳、不质问。被推开的人的反应越平静，虐感越强。

#### 第四步：后悔

**做什么**：推开的一方发现误解，意识到自己做了什么。

**写法**：
- 后悔要有**触发物**——不是「她突然发现自己错了」，是一个事件/信息让她意识
  到真相。参照 `plot-special-topics.md` 的回忆插入法——触发物可以是一个物件/
  一句话/一个场景，触发她想起被推开一方的好。
- 后悔要有**延迟**——推开和后悔之间有时间差。如果推开后立刻后悔，前面的
  推开就没有重量。时间差让后悔更痛——「过了很久才发现自己错了」比「刚推开
  就后悔」更虐。参照 `narrative-modules.md` 的延迟满足。
- 后悔要有**行动**——后悔不是只在心里难受，是驱使角色去弥补/去找对方/去
  解释。行动 = 进入和解步骤。

#### 第五步：和解

**做什么**：两人重新靠近，关系比之前更深。

**写法**：
- 和解不要**太容易**——如果对方一道歉就和好了，前面的拉扯就白费了。和解
  要有障碍：被推开的一方还没原谅/有了新的心结/客观障碍还在。参照
  `narrative-modules.md` 的延迟满足——「假兑现」再「真兑现」。
- 和解要**比之前更深**——参照 `emotion.md` 的「兑现必须比预期多半分」。和解后
  的关系不能回到拉扯前的状态，必须更深一层——因为经历了误解和推开，两人对
  彼此的了解更深了、信任更牢固了。
- 和解的**方式要与推开的方式呼应**——推开时退回了信物，和解时信物回到手里；
  推开时说了一句伤人的话，和解时对方用行动回应那句话。呼应 = 结构的回扣感。

### 关键细节

- **拉扯的节奏**：整个公式（靠近到和解）跨 5-15 章为宜。太短 = 拉扯没有重量；
  太长 = 读者等不及弃书。参照 `outline-structure-theory.md` 的重人设型大纲——
  「每 3-5 章安排 1 个外部事件打破关系平衡」。
- **拉扯与主线的关系**：感情拉扯不能脱离主线独立存在——参照 `commercial-core.md`
  的留存四大支柱，感情线是「情感投入」支柱，但必须有主线事件做支撑。每 3-5
  章安排一个外部事件（危机/任务/第三方介入）推动关系变化，不要让两个角色在
  真空里拉扯。
- **拉扯的爽虐配比**：参照 `emotion.md` 的防麻木——甜和虐要交替供应。靠近（甜）
  → 误解（虐）→ 推开（虐）→ 后悔（酸）→ 和解（甜）。不能连续三章纯虐或纯甜。

### 常见失败

| 失败模式 | 症状 | 修复 |
|---|---|---|
| 靠近太快 | 一章就从陌生到暧昧 | 增加靠近的障碍和节奏，一点一点拉近距离 |
| 误解太低智 | 看到对方和异性说话就吃醋 | 基于角色认知差设计误解，要有结构性原因 |
| 误解一句话能解 | 只要说清楚就没事了 | 加障碍：说不出口/没机会说/说了没用 |
| 推开太轻 | 推开得很随意，没有痛苦 | 写推开时的挣扎和痛苦，用身体细节 |
| 后悔太快 | 推开后立刻就后悔了 | 加时间差，让后悔延迟 |
| 和解太容易 | 对方一道歉就和好 | 加和解障碍，让和解比预期更难 |
| 脱离主线 | 两人自己在真空里拉扯 | 每 3-5 章插入外部事件推动关系变化 |

### 示例

```
（靠近：他开始注意到她喝咖啡时先加奶后加糖、她注意到他签字时永远用
  左手。两人之间的距离从一米变成半米。但他是她的上司，她知道界限
  在哪。每次靠近一点，她就退一步。他没追。）

（误解：她看到他和前妻在餐厅吃饭。前妻挽着他的手臂。她转身走了。
  他不知道她看到了。第二天她递了辞呈。他问为什么，她说「个人原因」。
  他以为她是嫌工资低，给她加了薪。她把辞呈收了回去——但不是因为
  加薪，是因为她还没找到下家。他不知道。）

（推开：她开始刻意疏远他——不再单独汇报、不再加班到他在的时候、
  主动申请调去分公司。他找她谈话，她说「我只是想换个环境」。
  他说「好」。
  他签字批准调任的那天，笔停了一下。她看到了那个停顿，但没说话。）

（后悔：她去分公司一个月后，从同事口中得知——那天和前妻吃饭，
  是在签离婚协议。前妻挽手臂是最后一次。
  她坐在新办公室里，窗外的天灰了。
  她想起他签字时那个停顿。）

（和解：她回总公司出差。在电梯里碰到他。
  他比一个月前瘦了。
  电梯到了，她没出去。
  "那天的饭局，"她说，"是签离婚协议。"
  他看着电梯门关上。
  "我知道你知道了。"
  "你什么时候知道的？"
  "你递辞呈那天。"
  她抬头。他的眼睛很平静，但手插在口袋里，没拿出来。
  "那你为什么不说？"
  "你也没问。"
  电梯停了一层又一层。他们谁也没按楼层。
  最后电梯到了顶楼。门开了，是天台。
  他先走出去。她跟了上去。
  天台上有风。他把外套脱下来，搭在她肩上。）
```

## 公式四：悬念揭秘公式

### 适用场景

一个核心谜题需要从抛出到揭秘的完整过程，包含误导、线索、拼图和反转。
适用题材：悬疑推理、悬疑灵异、权谋阴谋、身世揭秘——所有「谜题驱动」的题材。
参照 `narrative-modules.md` 的公式 10（真相半揭）和公式 11（谁是内鬼），
以及 `reversal.md` 的反转工具箱和 `suspense-grading.md` 的悬念分级。

### 结构步骤

```
抛谜 → 误导 → 线索 → 拼图 → 反转真相
```

#### 第一步：抛谜

**做什么**：向读者抛出一个核心谜题，引发好奇。

**写法**：
- 谜题要**具体**——不是「这个案子很复杂」，是「死者手里握着一枚不属于这个朝代
  的铜钱」。谜题越具体，读者越想追。
- 谜题要**有悬念等级**——参照 `suspense-grading.md` 的悬念分级。抛出的谜题
  要与整本书/整卷的悬念等级匹配——开篇抛的谜题是主线级（全书追），单元内抛的
  谜题是单元级（几章内解）。
- 谜题要**让角色有动力去解**——不是「有个谜题摆在那里」，是角色有个人原因必须
  解开它（妹妹的失踪案、自己的身世、师父的死）。参照 `commercial-core.md` 的
  核心梗——「所有情节单元共同服务的那个核」。

#### 第二步：误导

**做什么**：给出一个看似合理但错误的答案/方向，引导读者和角色走向歧途。

**写法**：
- 误导要**合理**——参照 `reversal.md` 的「公平埋点」和「误导要靠人物视角的
  合理误判」。误导不能靠叙述者撒谎（叙述性诡计读者只接受一次），要靠角色基于
  已有信息的合理推理得出错误结论。
- 误导要**有证据支撑**——不是角色凭空猜错，是有一条「看起来是线索其实是误导」
  的证据。这条证据必须是真实的（不是假的），只是角色理解错了。
- 误导的持续时间**与谜题等级匹配**——单元级谜题的误导不超过 3-5 章；主线级
  谜题的误导可以跨 1-2 卷，但每个卷末要有「线索推进」防止读者忘记。

#### 第三步：线索

**做什么**：在误导进行的同时，埋下真正的线索——读者当时不在意，揭秘时恍然。

**写法**：
- 线索要**伪装**——参照 `foreshadowing.md` 的「伏笔要伪装成环境细节、闲笔、
  人物习惯」。线索不能看起来像线索，要看起来像无关的细节。
- 线索要**多重解释**——参照 `reversal.md` 的「关键线索用多重解释的方式给出」。
  同一条线索在误导阶段被理解为 A，在揭秘阶段被理解为 B。当时的语境引导读者
  走向错误但合理的理解。
- 线索的**密度**——一个反转配 2-3 个线索点。参照 `reversal.md` 的「埋点密度」：
  单独一个线索读者会忘，三个以上会猜中。2-3 个是最佳密度。

#### 第四步：拼图

**做什么**：角色（或读者）开始把碎片拼起来，接近真相。

**写法**：
- 拼图是**渐进的**——不是一瞬间全明白，是一块一块拼。每拼上一块，对真相的
  理解就深一层。参照 `narrative-modules.md` 的假象揭示元素卡「真相分层」。
- 拼图过程中要有**一次「差一点就对了」**——角色拼出了一个看似完整的答案，
  但有一个细节对不上。这个对不上的细节 = 最后反转的种子。
- 拼图要**让读者参与**——好的悬疑让读者也在拼图。如果读者完全跟着角色走，
  揭秘时只有「哦」的恍然；如果读者也在自己拼，揭秘时有「我猜对了/我猜错了」
  的参与感。参照 `narrative-modules.md` 的信息不对等——「读者等于主角」的
  配置代入感最强。

#### 第五步：反转真相

**做什么**：真相揭晓，与之前的误导完全不同，但回看线索全部成立。

**写法**：
- 揭秘要**先给结果再给复盘**——参照 `reversal.md` 的「反转揭晓的章，先给结果
  再给复盘」。让读者先愣住，再带着「为什么」重读线索。
- 揭秘要**改变对前文的理解**——参照 `reversal.md` 的好反转三要素之三「改变对
  前文的理解」。揭秘后读者回看之前的章节，发现「原来那句话是那个意思」。
- 揭秘后要**付叙事成本**——参照 `reversal.md` 的「揭晓后必须付出叙事成本」。
  真相改变了人物关系和力量对比，后续章节要立刻体现，不能揭秘完一切照旧。
- 揭秘的**公平性**——参照 `reversal.md` 的好反转三要素之一「伏笔先行」。回翻
  前文必须能找到依据。找不到依据的反转 = 作者耍赖。

### 关键细节

- **悬念的节奏控制**：整个公式（抛谜到反转真相）的时间跨度与谜题等级匹配——
  单元级谜题 5-15 章，主线级谜题跨 1-3 卷。参照 `pacing-and-hooks.md` 的节奏
  档位——抛谜是中档（建立悬念），误导是中档（信息收集），拼图是中档到快档
  （逼近真相），反转真相是快档（核心揭露，触发 C 配额）。
- **悬念与读者契约**：参照 `reader-contract.md`——悬念是读者对结果期待的驱动。
  悬念的解答必须「比预期多半分」（参照 `emotion.md`），但也不能偏离太远（读者
  等的是 A，你给的是完全无关的 B = 欺骗）。
- **悬念链管理**：参照 `narrative-modules.md` 的悬念链结构——每个谜题的解答 =
  下一个谜题的种子。一个谜题解完故事就结束 = 只适合短篇。长篇的悬念是链式的，
  一个接一个。

### 常见失败

| 失败模式 | 症状 | 修复 |
|---|---|---|
| 谜题太模糊 | 读者不知道在追什么 | 把谜题具体化，给一个具体的「不对劲」 |
| 误导太假 | 读者一眼看穿误导 | 让误导基于角色的合理推理，给真证据支撑 |
| 线索太明显 | 读者提前猜到真相 | 伪装线索，多重解释，埋在闲笔中 |
| 线索太少 | 揭秘时找不到依据 | 补 2-3 个线索点，参照 `foreshadowing.md` |
| 揭秘太突兀 | 真相空降，前文没有铺垫 | 确保揭秘的依据全部前文出现过 |
| 揭秘后无后果 | 真相揭了但什么都没变 | 揭秘后立刻改变人物关系和力量对比 |
| 反转过度 | 真相推翻真相再推翻 | 一本书的认知级反转不超过 1-2 次，参照 `reversal.md` |

### 示例

```
（抛谜：死者的手里握着一枚铜钱。铜钱上刻的不是年号，是一个字：「归」。
  法医说死亡时间在凌晨两点到四点。监控显示凌晨三点有一个穿黑雨衣的人
  进出过大楼。）

（误导：黑雨衣人被锁定为嫌疑人。警方追查到黑雨衣人是死者的生意伙伴
  张某，两人有经济纠纷。张某有作案动机、有作案时间、案发现场有他的
  指纹。一切证据都指向张某。
  读者跟着角色的推理走：张某是凶手。）

（线索——同时埋下，但读者当时不在意：
  1. 铜钱上的「归」字——被当作死者的收藏癖好，无人深究。
  2. 死者办公室的日历上，案发当天画了一个圈，旁边写「M」——被当作
     会议标记。
  3. 法医提到「死者的胃里有未消化的安眠药」——被当作死者有失眠习惯。）

（拼图：主角发现张某的指纹在门把手上，但不在铜钱上——一个凶手杀了人
  还会把铜钱塞到死者手里，但不碰铜钱？不合理。
  主角重查线索：
  - 「归」字——查到死者有一个失联十年的女儿，小名「归归」。
  - 日历上的「M」——不是会议，是女儿名字的首字母。
  - 安眠药——不是失眠，是被人下药后失去意识。
  主角拼出了一个答案：凶手不是张某，是死者的女儿归归。她回来报仇了。
  但有一个细节对不上：归归十年前才八岁，她怎么进的大楼？）

（反转真相：主角找到归归。归归没有否认。
  「铜钱是我放进去的。我想让他死的时候手里握着我的东西。他这辈子
  欠我太多了。」
  「安眠药是你下的？」
  「我回来第一天就应聘了他的保姆。」
  （线索回扣：日历上的「M」不是女儿名字，是「Maid」——保姆。读者
  回看前文发现，案发前两周，死者换了一个新保姆，前文只提了一句。）
  「张某呢？」
  「他那天晚上确实去了。他去偷东西。他进去的时候，我爸爸已经死了。」
  （真相分层：张某不是凶手，但也不是无辜的——他是盗贼，恰好成了替罪羊。
   真正的凶手是死者失联的女儿，以保姆身份潜伏回来复仇。）
  主角站在那里，手里是那枚铜钱。她想起死者办公室日历上那个圈——
  原来不是会议标记，是一个父亲在数女儿离开的天数。）
```

## 公式五：日常装逼公式

### 适用场景

主角在日常场景中无意间展示出超出常人的能力/身份/资源，旁观者震惊，主角淡然。
适用题材：都市、重生、系统流、扮猪吃虎——所有「扮猪吃虎」向的题材。
参照 `narrative-modules.md` 的公式 2（装逼打脸）和 `combat-and-face.md` 的
「被动装逼（上品）」。

### 结构步骤

```
日常场景 → 意外展示 → 旁观震惊 → 主角淡然
```

#### 第一步：日常场景

**做什么**：建立一个普通的、低压的日常场景。主角在其中以普通人的姿态出现。

**写法**：
- 日常场景要**普通到让读者放松**——吃饭、购物、路过、闲聊。参照
  `pacing-and-hooks.md` 的慢档章——「慢档不等于无事发生：必须有羁绊深化、
  风土人情、微型伏笔」。
- 主角在日常场景中的**姿态要低调**——不要在装逼前就暗示「他其实很强」。
  读者知道主角有底牌（信息不对等），但场景中的旁观者不知道。参照
  `narrative-modules.md` 的信息不对等——「读者知道而角色不知道」。
- 日常场景中要**自然地引入一个「需要能力」的触发点**——不是主角主动展示，
  是场景本身需要一个「恰好主角会」的能力。如：饭局上有人考书法、路过时有人
  在修古董、闲聊时有人提到一个专业问题。

#### 第二步：意外展示

**做什么**：主角在无意间（或被逼无奈间）展示了超出常人的能力/身份/资源。

**写法**：
- 展示要**意外**——不是主角想装，是场景逼的。参照 `combat-and-face.md` 的
  「被动装逼（上品）：主角不想装，是实力/身份藏不住，被别人一层层扒出来」。
- 展示要**有层次**——不是一次性全亮出来，是一层一层扒。第一层展示让旁观者
  惊讶，第二层展示让旁观者震惊，第三层展示让旁观者沉默。每层都比上一层更
  出乎意料。参照 `narrative-modules.md` 的多角度强化元素卡。
- 展示的**方式要自然**——不是主角站出来说「让我来」，是主角顺手做了一件
  事，这件事恰好暴露了他的能力。如：随手纠正了别人的错误、顺手修好了别人
  修不好的东西、随口说出了别人查了半天都没查到的信息。

#### 第三步：旁观震惊

**做什么**：旁观者的反应从惊讶到震惊到改观，放大主角展示的冲击力。

**写法**：
- 旁观者反应要**有层次**——参照 `narrative-modules.md` 的旁观者反应三阶段。
  初始（不在意/看不起）→ 中间（惊讶/不信）→ 最终（震惊/崇拜/改观）。
- 旁观者反应要**有差异**——内行看门道（知道这个难度有多高），外行看热闹
  （觉得厉害但不知道多厉害），半懂不懂的追问细节。参照 `combat-and-face.md`
  的「围观群众反应千篇一律」失败信号。
- 旁观者反应用**代表人物法**——选 1-2 个具体人物反应代表群体，不要写「所有
  人都震惊了」。

#### 第四步：主角淡然

**做什么**：主角对旁观的震惊毫不在意，继续做日常的事。

**写法**：
- 淡然要**有具体行为支撑**——不是写「他淡淡一笑」，是他做完展示后继续吃饭/
  继续走路/继续聊刚才的话题。淡然不是一种表情，是一种「这对他来说不值一提」
  的态度。参照 `writing-craft-extras.md` 的身体细节替代——用动作展示淡然。
- 淡然是**最大的装逼**——参照 `combat-and-face.md` 的「被动装逼（上品）：爽感
  来自他根本没用力」。主角越不在意，读者越觉得他深不可测。
- 淡然后**不要解释**——主角不要主动解释自己为什么会这个/怎么做到的。解释
  = 炫耀，不解释 = 神秘。留给旁观者（和读者）自己猜。参照 `dialogue.md` 的
  「解释自己 = 删」。

### 关键细节

- **日常装逼与打脸的区别**：打脸公式有明确的「反派压制」前提，日常装逼没有
  反派——旁观者可能只是普通的不在意，不是压制。日常装逼的爽感来自「实力差
  展示」而非「反转碾压」。两者可以衔接：日常装逼引发的震惊 → 某个旁观者不服
  → 升级为打脸公式。
- **日常装逼的频率**：参照 `emotion.md` 的防麻木——同一种爽感连续供应三章以上
  读者会钝化。日常装逼每 3-5 章用一次为宜，用完接一段其他情绪（暖/悬/虐）
  做换台。
- **日常装逼与金手指的关系**：参照 `commercial-core.md` 的金手指原理——日常装逼
  是金手指的「日常兑现」。不是每次都要大场面，日常场景里的小展示 = 让读者
  持续感受到「主角不简单」。

### 常见失败

| 失败模式 | 症状 | 修复 |
|---|---|---|
| 日常场景太假 | 明显是为了装逼设计的场景 | 让场景自然出现，装逼是意外不是设计 |
| 主动装逼 | 主角故意展示，没有被动性 | 改成被动展示——场景逼的，不是主角想装 |
| 一次性全亮 | 一次性把所有底牌亮了 | 分层展示，一层一层扒 |
| 旁观者反应单一 | 全员震惊，没有差异 | 分内行/外行/半懂不懂，写出不同反应 |
| 主角解释 | 装完后主动解释自己多厉害 | 删解释，保持神秘 |
| 淡然写成面瘫 | 「他淡淡一笑」「他面无表情」 | 用具体动作展示淡然——继续吃饭/继续走路 |
| 用太频繁 | 每章都装一次 | 控制频率，每 3-5 章一次，中间换情绪 |

### 示例

```
（日常场景：饭局。主角被朋友拉来凑数，坐在角落。桌上都是收藏圈
  的人，聊的是一幅古画的真伪。主角在吃花生米。）

（意外展示·第一层：
  收藏家老王说这幅画是明代的，理由是纸张和墨色。
  主角路过看了一眼，说了一句："纸是清代的。"
  老王不高兴："小兄弟，你懂画？"
  主角摇头："不懂画。但这个纸是宣德贡纸，明代没有。"
  全桌安静了两秒。）

（意外展示·第二层：
  老王的朋友，博物馆的修复师，开口："宣德贡纸确实清代才有。
  但你怎么一眼看出来是宣德贡纸？"
  主角指了一下画的右下角："这个位置，纸的纹理不一样。宣德贡纸
  的帘纹是双向的，普通的单向。"
  修复师站起来走到画前，看了半天。
  "……确实是双向帘纹。"
  他回头看主角的眼神变了。）

（意外展示·第三层：
  "那这幅画是真是假？"老王问。
  主角又吃了一颗花生米。"画是真的。纸被人换过。"
  全桌人看着他。
  "换纸的人技术很好，但换的时候裁掉了左下角半厘米。原画的款印
  在那半厘米上。"
  老王拿起放大镜趴在画前看了五分钟。
  "……左下角确实有裁切痕迹。"
  他放下放大镜，手在抖。）

（旁观震惊：
  修复师坐回椅子上，半天没说话。
  老王擦了擦额头。
  主角的朋友——拉他来凑数的那个——张着嘴忘了合上。）

（主角淡然：
  主角把最后一颗花生米吃了，拍了拍手上的皮。
  "这花生不错，哪买的？"
  没有人回答他。
  他看了看表，站起来。"我先走了，明天还有事。"
  他走到门口的时候，老王追出来。
  "兄弟，你怎么称呼？"
  主角想了想。"姓林。"）
```

## 五个公式之间的关系

这五个公式不是孤立的——它们可以衔接、嵌套、组合：

| 组合方式 | 示例 |
|---|---|
| 升级公式 → 打脸公式 | 主角升级后，用新实力打脸之前压制他的人 |
| 日常装逼公式 → 打脸公式 | 日常装逼引发的震惊，某个旁观者不服，升级为打脸 |
| 感情拉扯公式 + 悬念揭秘公式 | 感情拉扯的「误解」由一个悬念揭秘来解开 |
| 打脸公式 + 悬念揭秘公式 | 打脸过程中揭露了反派的隐藏身份（悬念揭秘） |
| 升级公式 → 日常装逼公式 | 升级后的新能力，在日常场景中无意展示 |

**组合纪律**：
- 两个公式衔接时，前一个公式的「代价/后果」= 后一个公式的「铺垫/前提」。
- 不要在一章内堆叠两个完整公式——一个公式至少跨 2-3 章。一章内最多一个公式
  的爆发步骤（快档），其余步骤分散在其他章。
- 公式组合后仍要过 `pacing-and-hooks.md` 的 A/B/C 配额——一章最多触发 1 项。

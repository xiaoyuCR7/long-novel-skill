# 读者契约深度理论

本文件是 `reader-contract.md` 的理论深化。`reader-contract.md` 是执行模板——定义了
读者契约三要素、主角代理权、关键节点四问、终局储备、期待债管理、契约安全评级、
可证伪检查的**操作规则**。本文件解释**为什么这些规则成立**，以及在长篇连载中这些
规则如何随卷数增长而动态变化。

分工：遇到具体章节/卷纲的契约检查，查 `reader-contract.md` 的执行清单；遇到
「为什么主角不能只是旁观」「为什么终局底牌不能提前打」「期待债违约多少次会崩」
这类原理性问题，查本文件。

## 与 reader-contract.md 的关系

| 维度 | reader-contract.md（执行模板） | reader-contract-deep.md（本文件） |
|---|---|---|
| 性质 | 操作清单，检查项 | 理论框架，原理推导 |
| 使用时机 | 每章/每卷设计时逐项过 | 开书定架构、改纲判定、复盘崩盘原因时回看 |
| 粒度 | 具体规则与判例 | 抽象模型与底层逻辑 |
| 读者 | 执行写作的 Agent | 做架构决策的作者与 Planning Agent |

两者不替代，是「手册」与「教材」的关系。

## 主角代理权 = 因果权 + 结算权

### 为什么「不看出场时长」

新手最常见误区：用「主角出场多少章」「主角戏份占比」来衡量主角地位。这是错的。

一本书的主角是不是真主角，不取决于TA在多少章里露面，而取决于：**故事的因果链
是否经过TA**。一个每章都在场但从不做决定、从不承担后果、从不获得收益的角色，在
叙事功能上只是「摄像头」——读者跟着TA的视角看故事，但故事不是TA的。

反过来，一个隔三章才出场一次、但每次出场都改变格局走向、每次决策都引发连锁后果
的角色，才是真主角。出场频率是表面指标，因果穿透力才是核心。

### 因果权的六种表现形式

因果权不是「主角亲手做每件事」，而是主角的决策/布局/授权/关键信息/关键后果/核心
收益在决定事情如何发生。以下六种形式，主角拥有其中至少三种才算有因果权：

| 形式 | 定义 | 判定 |
|---|---|---|
| 决策权 | 关键节点由主角拍板 | 删掉主角的决策，故事走向会变吗？ |
| 布局权 | 主角提前设局，对手/盟友在局中行动 | 这个局面是主角造的还是天降的？ |
| 授权权 | 主角授权配角执行，但方向由主角定 | 配角行动的「为什么」是主角定的吗？ |
| 关键信息权 | 主角掌握决定胜负的信息 | 没有主角的信息，这局能赢吗？ |
| 关键后果权 | 主角承担成败的主要后果 | 赢了主角得什么？输了主角失什么？ |
| 核心收益结算权 | 最终的认可/权力/资源结算给主角 | 高光时刻镜头对准谁？ |

**典型违规**：主角全程旁观配角解决问题、主角布局但功劳被配角「无声」领走（注意
是「无声」——如果主角主动让功且读者知道这是主角让的，不算违规）、主角掌握信息但
关键时刻信息失效靠配角临场发挥。

### 结算权的三个层级

结算权不只是「最后功劳归谁」，它有三个递进层级：

1. **即时结算**：本章/本卷的胜利成果归谁。最浅层，读者直接能看到。
2. **声望结算**：胜利之后，世界对主角的评价变化。中层，需要旁观者反应来兑现。
3. **格局结算**：胜利之后，主角在世界中的位置变化（从棋子变棋手、从边缘到核心）。
   最深层，决定后续故事的起点。

三层结算必须都有。只有即时结算没有声望/格局结算 = 「赢了但白赢」，读者会觉得
「爽是爽了但好像没发生什么」。这是很多书「打脸一百次还是没有升级感」的根源——
结算只做了第一层，后两层欠账。

### 代理权泄漏的隐蔽形式

代理权泄漏不总是「配角抢了主角的高光」。更隐蔽的形式：

- **天降破局**：关键时刻不是主角的布局/能力/信息解决的，而是第三方突然出手/意外
  事件/天灾人祸。主角变成了「等着被救」的人。
- **被动反应**：全章主角都在「应对」对手的行动，没有主动出击。主角是棋子不是棋手。
- **信息白嫖**：主角的关键判断不是靠自己的侦查/推理获得的，而是配角直接告诉TA。
  主角成了「转述者」。
- **工具人执行**：主角的布局是别人出的主意，主角只是跑腿执行。方向不是TA定的。

以上每一种都在形式上「主角参与了」，但因果链不经过主角——读者会模糊地感到
「这章主角没什么存在感」，却说不出原因。

## 关键节点四问的深层逻辑

`reader-contract.md` 给出了四问：谁决定/谁选择/谁承担后果/收益结算给谁。本文件
解释为什么是这四问，以及四问之间的优先级。

### 四问的因果链

四问不是并列的，而是一条因果链：

```
谁决定（起因）→ 谁选择（转折）→ 谁承担后果（代价）→ 收益结算给谁（结果）
```

- **决定**：事情因为谁的意志而被启动？这是因果链的起点。
- **选择**：在关键分叉路口，谁拍板选了这条路？这是因果链的转折点。
- **承担后果**：选择之后，谁承受了好/坏的后果？这是因果链的代价兑现。
- **收益结算**：最终的核心收益归谁？这是因果链的终点。

四问的答案都应是主角（或主角主动授权的对象）。如果起点和终点都是主角，但中间的
选择是配角做的——这叫「代理权中段泄漏」，读者会感到「主角赢了但赢得不硬气」。
如果起点是配角（配角挑起事件）、终点是主角（主角获利）——这可以接受，但需要主角
在「选择」和「承担后果」环节补上，否则就是「白嫖」。

### 四问的优先级

当四问无法全部满足主角时（例如卷末大战，主角布局但配角执行最后一击），优先级：

1. **收益结算给谁**（最高优先级）——如果最终高光/认可/权力不归主角，整段情节
   的代理权就塌了。这是底线。
2. **谁承担后果**——主角承担主要代价，读者才会觉得TA「配得上」最终收益。
3. **谁选择**——关键分叉路口由主角定方向，读者才觉得主角是棋手不是棋子。
4. **谁决定**（相对灵活）——事件可以由对手/配角发起，只要主角在后续环节拿回
   主动权。被动开局是可以接受的，被动全程不行。

## 期待所有权

### 期待所有权的定义

`reader-contract.md` 定义了期待债（前期承诺后续偿还）。本文件补充一个更精确的
概念：**期待所有权**——一个承诺的兑现/高光属于谁，在承诺建立时就已经确定了。

读者在追读时会形成「这个伏笔将来会在X角色身上兑现」的期待。这个期待的所有者一旦
确定，兑现时就必须给到TA。如果承诺给A的兑现最终落到了B头上，即使逻辑上说得通，
读者也会有强烈的被欺骗感——因为他们的期待投资落空了。

### 期待所有权的建立方式

期待所有权在以下时刻被锚定：

- **角色宣言**：「我一定会打败XX」→ 打败XX的高光属于这个角色
- **铺垫投资**：某角色为某个目标付出了最多的篇幅/努力/代价 → 兑现属于TA
- **读者共情**：某角色的处境让读者最心疼/最期待TA成功 → 兑现属于TA
- **因果绑定的关键信息**：某角色掌握解开谜题的关键线索 → 揭谜高光属于TA

### 期待所有权转移的合法路径

期待所有权不是绝对不能转移，但转移必须付出**叙事代价**：

| 转移方式 | 合法条件 | 叙事代价 |
|---|---|---|
| 主动让渡 | 所有者主动把高光让给他人，且读者知道 | 所有者必须有更高层级的收获补偿 |
| 能力不足 | 所有者确实无法完成，需要他人接手 | 必须先展示所有者的努力和失败，不能跳过 |
| 共同完成 | 所有者是主攻，他人是辅助 | 镜头重心必须在所有者身上 |
| 意外转交 | 所有权因不可抗力转移 | 需要大量铺垫让读者接受，且新所有者有合理性 |

**违规形式**：承诺给A，兑现时无铺垫地给了B，A的期待投资被无视。这是比「期待债
违约」更严重的错误——期待债违约是「没还」，期待所有权转移是「还给了错的人」。

## 终局储备的动态管理

### 开书时定的意义

`reader-contract.md` 要求终局底牌和升级台阶在开书时定死。原因不是「计划不能改」，
而是**资源有限性**——长篇小说的终局资源是一次性的，用完就没有了。

- 头号宿敌只有一个：打败了他，后面就没有同等级的对手了
- 终极真相只有一个：揭开后，悬念引擎就熄火了
- 金手指上限只有一个：到顶后，升级线就断了
- 身份终点只有一个：到达后，身份揭秘的驱动力就消失了

如果开书不定边界，写到哪算哪，必然在某个卷「不小心」把终局资源提前用掉，然后
后面几十万字无牌可打——这就是「中后期崩盘」的结构性原因。

### 逐卷解锁的节奏

终局储备不是「最后一卷一次性全放」，而是逐卷递进式释放：

| 储备类型 | 前1/3 | 中1/3 | 后1/3（终局卷） |
|---|---|---|---|
| 终局真相 | 只埋线索，不揭露 | 揭露一层（真相有N层，揭第1层） | 揭最终层 |
| 终局战力 | 展示冰山一角 | 亮出但受限使用 | 全力释放 |
| 身份终点 | 暗示 | 半揭露（知道方向但不知终点） | 完全揭晓 |
| 核心情感 | 建立羁绊 | 经历考验 | 终局兑现 |

**逐卷解锁的纪律**：每卷只解锁储备的一个「层」或「面」，不到下一卷不解锁下一层。
这保证每卷都有新东西可给，同时终局卷有足够的储备做最终爆发。

### 升级台阶的剩余档数

升级台阶（境界/等级/地图层级）是阶梯资源，不是一次性资源——但台阶总数是有限的。
玄幻写了十个境界，主角第五卷就到了第九境，后面五卷只有一阶可升，升级线就提前
逼近天花板。

**剩余档数管理**：开书时定台阶总数，每卷消耗的台阶数不超过总数的 1/（计划卷数+1）。
例如计划 8 卷、10 个境界：每卷至多升 1 个境界（8卷升 8 阶，留 2 阶给终局卷爆发）。
如果某卷升了 2 阶，后面必须有一卷 0 升级来补偿。

## 透支两问的实战判断

`reader-contract.md` 给出透支两问：是否动用不该解锁的终局底牌 / 是否让升级线逼近
天花板。本文件补充判断标准。

### 透支的判定标准

**终局底牌透支**的判定——问三个子问题：
1. 这个底牌在总纲的终局储备清单中标注为「第X卷解锁」吗？当前卷 < X → 透支
2. 这个底牌的揭露/使用，是否让后续卷的悬念引擎熄火？（揭了终极真相后，后续还有
   什么可猜的？）→ 熄火则透支
3. 这个底牌的使用是否让主角的战力/地位跳过了中间台阶？→ 跳阶则透支

**升级线逼近天花板**的判定——问两个子问题：
1. 当前等级距最高等级还有几阶？< 总卷数剩余卷数 → 逼近天花板（后面卷数不够分）
2. 最近的升级速度是否在加快？（前3卷升3阶，最近1卷升2阶）→ 加速 = 透支信号

### 透支的修复路径

发现透支后，不是简单「撤回」（已写的不能撤），而是补偿：

| 透支类型 | 修复方式 |
|---|---|
| 终局真相提前揭露一层 | 在下一卷建立「真相之上还有真相」的新层（真相嵌套） |
| 终局战力提前亮出 | 亮出但加使用限制（冷却/代价/副作用），到终局卷才全力释放 |
| 升级跳阶 | 在下一卷安排「境界未稳」的副作用，用1-2章的「还债」拖住升级速度 |
| 身份提前揭晓 | 揭晓身份但暴露新身份带来的新麻烦（身份不是终点而是新起点） |

## 合理化债务

### 什么是合理化债务

「合理化债务」= 作者为了解释一个情节转折，花大量篇幅做因果解释（合理化），但这些
解释本身不产生爽感，反而吞掉了本应给读者的爽点空间。

典型场景：主角突然获得一个新能力，作者用半章解释这个能力从哪来、为什么主角现在
才有、它的原理是什么——这半章就是合理化债务。解释完后，留给实际爽点（用新能力
打脸）的空间只剩几百字，爽感严重不足。

### 合理化债务的来源

合理化债务的根本原因：**铺垫不足，事后补丁**。如果新能力在前几章有伏笔（暗示/
线索/试错），揭晓时读者已有心理准备，不需要解释，直接给爽点。如果没有伏笔，
揭晓时必须解释，解释就是债务。

| 债务来源 | 症状 | 处方 |
|---|---|---|
| 临时加设定 | 新能力/新规则无铺垫空降 | 回前文补伏笔（改未发布章节） |
| 逻辑补丁 | 用大段解释修补剧情漏洞 | 把解释拆碎，分散到角色对话/动作中 |
| 设定课 | 怕读者不懂，成段讲设定 | 只讲与当前冲突直接相关的规则，余则后补 |
| 事后圆场 | 剧情写飞了，用解释拽回来 | 改剧情走向，不要用解释硬圆 |

### 合理化的成本控制原则

合理化不可避免——有些转折确实需要解释。控制成本的原则：

1. **解释挂在动作上**：不写「这个能力的原理是…」，写主角在使用中的试错和发现
2. **解释分次给**：不一次说完，用2-3个场景分次释放，每次只给一个关键信息
3. **解释让角色做**：通过角色对话/争论/推理来交代，不用叙述者旁白
4. **解释服务于情绪**：解释的每一段都应该在加压或释放情绪，不是纯信息传递

**底线**：单次合理化的篇幅不超过该情节点总篇幅的 30%。如果一个打脸场景 1000 字，
其中解释不能超过 300 字，剩下 700 字必须给实际的打脸过程和反应。

## 风险三级与动态监控

`reader-contract.md` 给出了三级评级（契约安全/需补强/契约破坏）。本文件补充动态
监控——契约风险不是静态的，它随连载进度变化。

### 风险随卷数的变化趋势

| 阶段 | 典型风险 | 监控重点 |
|---|---|---|
| 前3卷（开局期） | 期待债积累过多、代理权未站稳 | 核心期待是否开始偿还？主角因果权是否清晰？ |
| 中段（4-7卷） | 终局储备透支、升级线逼近天花板 | 透支两问每卷必查；升级速度是否稳定？ |
| 后段（8卷+） | 合理化债务堆积、期待所有权冲突 | 多条伏笔线的兑现是否冲突？合理化是否吞爽点？ |
| 终局卷 | 终局储备不够用、结算层级缺失 | 三层结算是否完整？终局底牌是否足够支撑大爆发？ |

### 卷末契约体检

每卷结束时做一次契约体检（不是每章——章级检查用 `reader-contract.md` 的执行清单）：

1. 本卷交付了什么核心情绪？与读者契约一致吗？
2. 本卷主角的因果权/结算权有增强还是削弱？
3. 本卷有没有期待债违约（承诺了没还）？有没有期待所有权转移？
4. 透支两问：动用了不该动的终局底牌吗？升级线逼近天花板了吗？
5. 合理化债务：本卷有没有用大量解释补铺垫不足？
6. 终局储备余额：还剩多少底牌？够撑到终局卷吗？

体检结果决定下一卷的规划方向。如果第3项违约或第4项透支，下一卷必须以「还债/补偿」
为核心，不能再开新坑。

## 契约破坏的不可逆性

最后强调一个残酷事实：**契约破坏是不可逆的**。

- 期待债违约一次：读者会忍，但信任度下降
- 期待债违约三次：读者开始弃书，追读数据断崖式下跌
- 期待所有权转移一次（承诺给A给了B）：严重程度等于三次违约，可能直接引发大规模弃书
- 终局底牌提前打光：不可修复——底牌用完就是用完，后面没有同等级的替代品
- 代理权长期泄漏（连续5+章主角无因果权）：读者对主角的情感投资清零，之后即使
  拿回代理权也难以重新建立共情

这就是为什么 `reader-contract.md` 把契约安全评级作为每章必检项——不是因为它重要，
而是因为它的违约后果不可承受。契约安全的检查成本很低（四问+透支两问），但违约的
修复成本极高（有时根本无法修复）。

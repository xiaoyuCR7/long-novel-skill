# 改编法+三重重复循环检测（adaptation-method）

本文件定义两个独立但互补的系统：改编法（将已有内容转化为新内容的系统化方法）和
三重重复循环检测（防止长篇写作中无意识重复的检测机制）。两者共同服务于一个目标——
让长篇写作在保持连贯性的同时避免「自我抄袭」。

## 第一部分：改编法

### 一、改编法的定义与适用场景

改编法 = 将已有内容（自己的旧作、对标书、神话/历史/新闻素材）进行系统化改造，
转化为新内容的方法论。改编不同于仿写——仿写是「结构对标，内容原创」
（见 `workflow/imitation.md`），改编是「素材提取 + 要素置换 + 意义重构」。

**适用场景**：
- 多书写作中，从自己的旧书提取可复用素材
- 从神话/历史/新闻中提取叙事原型
- 对对标书的「某个情节单元」而不是「整本书」进行改编
- 续集/系列作中，从上一部提取世界观和角色但需要新故事

### 二、改编四步法

#### Step 1：素材提取（Extract）

**目标**：从源材料中提取可改编的叙事素材，剥离「不可改编」的部分。

**提取清单**：
- 情节骨架：去角色名、去世界观、去具体设定，只保留因果链
- 角色关系模板：去具体的角色设定，只保留关系结构（如「师徒→反目」的关系骨架）
- 冲突模式：去具体的事件，只保留冲突类型和升级方式
- 情绪弧线：去具体的触发事件，只保留弧线形状和情绪起伏节奏

**不可改编的部分**（必须原创）：
- 角色名字、外貌、口癖
- 具体台词、名场面
- 世界观设定（力量体系、地理、历史）
- 具体情节细节（谁在哪做了什么）

**提取示例**：

```
源材料：希腊神话「普罗米修斯盗火」
提取的情节骨架：
  [角色A] 同情 [群体B] 的处境 → [角色A] 违反 [权威C] 的禁令，将 [资源D] 给予 [群体B]
  → [权威C] 惩罚 [角色A] → [角色A] 承受代价，但 [群体B] 因 [资源D] 而改变

改编方向 1（修仙）：主角同情凡人无法修炼，违反天道将修炼之法传授凡人，
被天道惩罚，但凡人因此崛起
改编方向 2（科幻）：科学家同情底层民众，违反公司禁令将技术开源，
被公司追杀，但技术改变了世界
```

#### Step 2：要素置换（Replace）

**目标**：将提取的素材中的要素，替换为与新书设定一致的要素。

**置换清单**：

| 置换维度 | 源材料 | 新书 | 置换规则 |
|---|---|---|---|
| 角色 | 源角色 | 新角色 | 角色功能对应（不是名字对应） |
| 世界观 | 源世界观 | 新世界观 | 世界观规则必须自洽，不能为了适配情节骨架而修改世界观 |
| 动机 | 源动机 | 新动机 | 新动机必须从新角色的设定中推导出来 |
| 冲突 | 源冲突 | 新冲突 | 冲突类型相同，冲突的具体内容不同 |
| 代价 | 源代价 | 新代价 | 代价与角色的设定相关（失去什么对角色来说最痛） |
| 情绪 | 源情绪 | 新情绪 | 情绪弧线形状相同，情绪触发事件不同 |

**置换纪律**：
- 置换不是「改名字」——改名字 = 抄袭。置换是「改因果」——因果关系相同但因果
  的具体内容不同
- 置换后必须做「自洽性检查」：新角色的行为是否可以从新设定中推导出来？
  如果推导不出来 = 置换失败，角色被情节骨架绑架了

#### Step 3：意义重构（Reframe）

**目标**：赋予改编后的情节新的意义——同样的结构骨架，讲述不同的主题。

**意义重构的三个维度**：
1. **主题置换**：源材料的主题是「反抗权威」，新书的主题可以是「守护弱者」
   （同样的违反禁令行为，但动机变了）
2. **视角置换**：源材料是主角视角，新书可以是从配角/旁观者视角讲述同一个故事
   （结构骨架相同，但讲述角度不同，意义完全不同）
3. **结局置换**：源材料的结局是悲剧，新书的结局可以是希望——不是「改了结局」，
   而是「改了导致结局的因果链中的某个关键变量」

**意义重构的检验**：如果读者读过源材料，他会不会觉得「这跟 XX 一模一样」？
如果会 → 意义重构不够，需要加大视角/主题/结局的差异。

#### Step 4：原创注入（Inject Originality）

**目标**：在改编后的骨架中注入至少 30% 的纯原创内容，让改编变成「原创」。

**原创注入点**：
- 新增至少 1 个源材料没有的角色（且这个角色对情节有实质影响）
- 新增至少 1 个源材料没有的情节转折（改变因果链的某个节点）
- 新增至少 1 个源材料没有的设定元素（新的力量体系/新的势力/新的规则）
- 新增至少 1 个源材料没有的情绪层次（如源材料是纯悲剧，加入喜剧元素）

**30% 原创的量化标准**：如果逐章对比源材料和新书，至少有 30% 的章节（或
30% 的情节节点）是源材料中找不到对应物的。

---

### 三、改编法的禁忌

1. **禁止改编未授权作品的情节**：改编法适用于自己的旧作、公共领域素材（神话/历史/
   民间传说）、新闻事件。对标书的改编只适用于「结构骨架」层级，不能改编对标书的
   具体情节——对标书的具体情节 = 抄袭。
2. **禁止改编自己正在连载的作品**：不能用改编法在同一本书中「自我重复」——同书中
   的类似情节必须用「三重重复循环检测」标记。
3. **禁止改编后不标注来源**：改编从公共领域素材（神话/历史）提取的内容，在
   `设定/题材定位.md` 的「灵感来源」字段标注。

## 第二部分：三重重复循环检测

### 一、为什么需要重复检测

长篇写作中，作者会无意识地重复自己——同样的情节结构、同样的对话模式、同样的情绪
节奏。单次重复读者可能不会察觉，但三次以上重复 = 读者觉得「这本书一直在重复自己」，
是弃书的高发原因。

三重重复循环检测 = 在三个层级上检测重复模式，超过阈值则触发警报。

### 二、三重检测层级

#### 第一重：情节结构重复检测

**检测对象**：不同章节/单元的情节骨架是否高度相似。

**检测方法**：
提取每章（或每单元）的「情节骨架」——去掉角色名、世界观、设定，只保留因果链：
```
[事件 A] → 导致 [事件 B] → 角色做出 [反应 C] → 导致 [结果 D]
```

比较不同章节/单元的情节骨架，相似度超过 60% = 情节结构重复。

**相似度判定**：
- 因果链的每一步都相同 = 100% 相似（完全重复）
- 因果链的每一步都相同，但事件的具体内容不同 = 70% 相似（结构重复，内容不同）
- 因果链中有 1 步不同 = 50% 相似（允许）
- 因果链中有 2 步以上不同 = < 30% 相似（不视为重复）

**警报阈值**：连续 3 章（或同一卷内 3 次）情节结构相似度 > 60% → 触发警报。

**警报处理**：
1. 合并：将重复的章节合并为一个更长、更深入的章节
2. 变异：保留情节骨架，但改变因果链中的至少 2 步
3. 跳过：如果重复的情节推进没有实质意义，跳过不写

---

#### 第二重：对话模式重复检测

**检测对象**：不同章节的对话结构是否高度相似。

**检测方法**：
提取每段对话的「对话结构」：
```
对话结构 = [角色 A 的意图] → [角色 B 的反应类型] → [对话的结果]
```

**对话反应类型**：
- 回避型：不正面回答问题，转移话题
- 对抗型：直接反驳/挑战/质疑
- 顺从型：接受/同意/妥协
- 试探型：用问题回答问题，探测对方意图
- 沉默型：不回应/用行动替代语言

**重复判定**：连续 3 段以上的对话，意图+反应类型的组合相同 → 对话模式重复。

**警报阈值**：同一章内出现 3 次以上相同的对话模式组合 → 触发警报。
跨章：连续 3 章出现相同的主角对话模式 → 触发警报。

**警报处理**：
1. 改变反应类型：将「对抗型」改为「回避型」或「试探型」
2. 改变对话的结果：同样的对话模式，但结果不同
3. 用行动替代对话：将对话场景改为行动场景

---

#### 第三重：情绪节奏重复检测

**检测对象**：跨章的情绪弧线分布是否出现「固定模式」。

**检测方法**：
提取每章的情绪类型和弧线阶段，检查是否出现固定的「情绪节拍」模式：
```
第 N 章：爽（V形反弹）
第 N+1 章：爽（递进形）
第 N+2 章：日常（慢档）
第 N+3 章：爽（V形反弹）
第 N+4 章：爽（递进形）
第 N+5 章：日常（慢档）
...
```

**重复判定**：连续 2 个循环（6 章以上）出现相同的情绪节拍模式 → 情绪节奏重复。

**常见重复模式**：
- 「爽→爽→水」三章循环（最常见）
- 「虐→转折→爽」三章循环
- 「日常→事件→高潮」三章循环

**警报阈值**：同一模式连续出现 2 个循环以上 → 触发警报。

**警报处理**：
1. 打破循环：在下一个循环中改变情绪节拍（如「爽→虐→爽」改为「爽→日常→悬念」）
2. 插入意外：在固定模式中插入一个意外的情绪节点（如「爽→爽→意外虐→爽」）
3. 改变节奏：将三章循环改为四章或五章循环

---

### 三、三重检测的执行时机

| 检测 | 执行时机 | 检测范围 | 工具 |
|---|---|---|---|
| 情节结构重复 | 每写完一个单元（10 章） | 最近 10 章 + 本卷已写章节 | 手动（提取情节骨架对比） |
| 对话模式重复 | 每章写完 | 本章 + 前 2 章 | 手动（提取对话结构） |
| 情绪节奏重复 | 每写完一个单元（10 章） | 最近 20 章 | 可用 `scripts/story_graph.py` 的情绪曲线功能辅助 |

### 四、重复 vs 呼应

重复和呼应是两种不同的东西，不能混淆：

| 维度 | 重复（应该避免） | 呼应（应该鼓励） |
|---|---|---|
| 目的 | 无意识的自我复制 | 有意识的前后对照 |
| 读者感受 | 「又来？」 | 「原来如此！」 |
| 因果链 | 因果链相同 | 因果链不同，但场景/事件相似 |
| 情绪 | 同样的情绪模式 | 不同的情绪（第一次是虐，第二次是爽） |
| 意义 | 没有新意义 | 第二次赋予新的意义 |

**呼应的写法**：同样的场景（如擂台赛），第一次输了（虐），第二次赢了（爽）——
场景相同，因果不同，情绪不同，意义不同。这是呼应，不是重复。

**重复的写法**：同样的场景，同样的因果，同样的情绪，同样的意义——只是换了对手
的名字。这是重复，必须检测并处理。

### 五、循环检测的自我审查清单

每写完一个单元（10 章），逐项过：

**情节结构**：
- [ ] 最近 10 章中，是否有 3 章以上的情节骨架相似度 > 60%？
- [ ] 如果有，哪几章？需要合并/变异/跳过哪几章？

**对话模式**：
- [ ] 本章中，是否有 3 段以上的对话使用了相同的意图+反应类型组合？
- [ ] 如果有，改哪几段？

**情绪节奏**：
- [ ] 最近 20 章中，是否出现了 2 个循环以上的相同情绪节拍模式？
- [ ] 如果有，下一个循环怎么打破？

**呼应 vs 重复**：
- [ ] 最近 10 章中，是否有场景与之前的场景相似？
- [ ] 如果是，是呼应（因果/情绪/意义不同）还是重复（因果/情绪/意义相同）？
- [ ] 如果是重复，是否需要改成呼应、或删除？

# 7 Gate 去AI腔体系（通用禁区清单）

7 Gate 是机器 + 人工各一遍的双重防线。机器覆盖范围（v2.1，`check_text.py --gate-report`）：

| Gate | 机器检测 | 人工自查 |
|---|---|---|
| A 禁用词 | ✅ blocking（叙述）/ advisory（对话），白名单豁免 | 改法定夺 |
| B 毒句式 | ✅ blocking：不是A而是B / 没有X只有Y / 这一刻， / 否定排比 / 反序对比 / 音量反差腔 | 语境相关变体 |
| C 心理告知 | ✅ 机器候选（他很X / 心中句式 / 一股X涌上心头） | 确认并外化 |
| D 节奏均匀 | ⚠️ 部分：碎句号电报体 / 长段落 / 微动作复读（advisory） | 句式与段落呼吸感 |
| E 对话腔调 | ❌（声线差异机器查不了） | 遮名字认人 |
| F 结尾升华 | ✅ 末段类型判定 + 预告式收尾 / 章尾状态总结（blocking） | 余韵是否自然 |
| G 解释腔 | ✅ blocking：她不知道的是 / 之所以…是因为 / 这意味着 / 事实证明 | 软评判/安排感等语境变体 |

另：工程词泄漏（本章/伏笔/细纲/读者入正文）与拒绝语残留 = blocking；
比喻密度/解释链密度/引号强调/复读句/结尾截断 = advisory（密度型，人工判断）。

**叙述/对话分域**：引号（""「」）内为对话，多数规则只扫叙述域——
对话里口语化的「知道」「像」是正常中文；套词与毒句式在对话中降为 advisory。

**豁免标记**：正文首 5 行内加 `<!-- 闸口:跳过 -->` 整章跳过机器扫描
（作者显式豁免，门禁状态照常落盘记为通过）。

本文档是人工自查的依据，也是 Gate 判定的权威标准。

**核心理念**：AI 味的主要问题不是语法错误，而是过度圆滑、工整、解释充分。
去AI味的本质 = 把文字从过度工整拉回具体、自然、可读。改最少，效果最大。

## Gate A：禁用词替换

AI 高频口癖。机器命中即标位置，人工判断改法。

### 一级禁用词（机器内置）
仿佛、似乎、不禁、不由得、一丝、眼底闪过、嘴角勾起、嘴角上扬、
意味深长、若有所思、不容置疑、空气仿佛凝固、时间仿佛静止、
众所周知、值得一提的是、不得不说、不由自主、情不自禁、映入眼帘、
心中暗道、暗自思忖、沉声道、淡淡地说、脸色一变、身形一顿、目光如炬、目光深邃

### 替换原则
- 禁用词 → 具体动作/细节描写
- 不能简单换成另一个形容词
- 要用「展示」替代「告诉」

| 禁用词 | 问题 | 改法 |
|---|---|---|
| 不禁 | 剥夺角色主动性 | 直接写角色的行动 |
| 仿佛/宛如 | 过度比喻 | 用具体感知描写替代 |
| 映入眼帘 | 陈词滥调 | 直接写看到了什么 |
| 嘴角勾起/上扬 | AI 特征极强 | "他笑了"或删掉 |
| 沉声道/淡淡地说 | 对话标签膨胀 | 统一用"说"或删标签 |
| 脸色一变/身形一顿 | 反应套话 | 写具体的生理反应 |

### 白名单机制
书籍工程根目录放 `.deslop-whitelist`（每行一个词，# 注释），命中段若子串在白名单中存在则跳过。
适用：术语（玄幻中"缓缓"是绰号）、章名、设定专有名词。

### 题材专属禁用词
每张题材卡的「专属禁用词」节开书时拷入 `设定/禁用词.txt`，`check_text.py` 自动加载。

## Gate B：毒句式去套路

高置信度的 AI 腔句式模式（正则）。

| 句式 | 问题 | 替代方案 |
|---|---|---|
| 不是A，而是B | **最毒**中文AI句式 | 直接写后项，或改成动作/细节 |
| 没有X，只有Y | 万能对比 | 直接写「只有Y」 |
| 这一刻，… | 起手式套话 | 删掉，直接写动作 |
| …，带着… | 万能状语 | 用独立短句或动作描写 |
| 声音不大，却带着… | AI 最爱声音描写 | 直接写声音特征或动作 |
| 之所以…是因为 | 解释因果 | 删，让读者从动作拼 |
| 他/她知道… | 直接告诉读者 | 用行为展示认知 |
| 仿佛/犹如/宛若/如同 | 文言腔过重 | 口语化或白描 |

### 修饰词清扫
检查名词前的形容词、定语、副词、指示代词、量词，多余即删。
- "白色的药片" → "药片"
- "飞驰的汽车" → "汽车"
- 原则：一次只用一个形容词或不修饰，不连用、不堆砌。

## Gate C：心理描写外化

AI 写的心理描写特征：直接陈述情绪。

| ❌ 告诉 | ✅ 展示 |
|---|---|
| 他很紧张 | 他的手在抖 |
| 她很愤怒 | 她一把掀翻了桌子 |
| 他感到一丝失落 | 他愣了一下，把手机放回口袋 |
| 她心中涌起莫名情绪 | 她攥皱了袖口 |

### 重复描写去重
相邻段反复表达同一信息/动作/情绪时合并：
- ❌ "他拿起笔。手在抖。笔尖又停住。"
- ✅ "他拿起笔，笔尖刚碰到纸就偏了，手腕压了两次都没压稳。"

### 重复语义四类
| 类别 | 错误例 | 修法 |
|---|---|---|
| 形容词重复 | 兴高采烈地笑着跑过来 | 笑着跑过来 |
| 近义词重复 | 非常重要的关键问题 | 关键问题 |
| 含义重复 | 我好饿，肚子咕咕叫 | 我好饿 |
| 主语重复 | 上文"药扔了一地"，下文"地上的药" | 药片 |

## Gate D：节奏调整

AI 写作的节奏问题：句式过于整齐、段落过于匀称。

- 打断连续排比句（保留1-2个，删掉其余）
- 拆臃肿修饰、堆叠比喻、抽象总结的长句；正常逗号长句不拆
- 偶尔用不完整句（口语感）
- 段落长短交错（不要每段都3-5行）
- 标点跟语气走：保留有功能的 `？`/少量 `！`；`……`/`——` 改成动作、短句、换行

### 节奏量化参考（`check_text.py --style-stats` 输出）
- 平均句长、对话占比、段落中位长度
- 对标 `设定/文风锚.md` 的量化基线，超出容差时校准

---

## Gate E：对话去腔调

AI 写的对话特征：每句话都信息完整、逻辑清晰、表达精准。

- 加入口语化表达（"嗯""哦""行吧"）
- 适当打断对话（角色可以答非所问）
- 用动作穿插对话（"她喝了口水。'然后呢？'"）
- 删掉解释性对话（角色不会把自己的动机说清楚）
- 声线差异：遮住名字能认出谁说的吗？认不出 = 危险

---

## Gate F：结尾去升华

AI 写作的结尾特征：总想总结、升华、点题。

- 删掉总结性语句（"这次经历让他成长了"）
- 用动作/场景收尾，不要用感慨收尾
- "他知道…""这一刻…" → 基本可以删

---

## Gate G：去解释腔/上帝感

最难察觉、最「像 AI」的一类。叙述者跳出角色当下去解释、剧透、总结、定性、升华。

| 类型 | 错误例 | 修法 |
|---|---|---|
| 解释因果 | 之所以…是因为 | 删，因果让读者自己拼 |
| 上帝剧透 | 她不知道的是 / 殊不知 / 多年以后 | 删 |
| 替读者定性 | 演得真好 / 这出戏她看过一遍 | 删，证据留给读者判断 |
| 软评判 | 关切得恰到好处 / 那点笑她看得分明 | 改成角色此刻带偏见的瞬间感觉 |
| 安排感 | 像在宣宣判一件早已定好的事 | 删，用角色行动呈现 |

**注意**：Gate G 删的是「非故事性的作者旁白」，不是删情节。删完若变薄，靠角色动作/对话补。

## 防设定复述（说明文入侵）

设定复述 = 把设定文件里的内容成段搬进正文。它是最常见的「AI 写网文」事故。

三条呈现原则：
1. **挂在动作上**：不写「这个宗门等级森严」，写杂役弟子见到外门弟子要侧身让路低头。
2. **挂在冲突上**：规则在「有人违反它、有人利用它」时才有出场资格。
3. **挂在细节上**：设定名词第一次出现时，必须粘着一个具体物件、价格、后果。

自查：正文中任何一段「如果删掉，情节完全不受影响」的说明性段落，就是设定复述，删。

## 元信息隔离

以下内容永远不允许出现在正文文件里：
- 「本章」「上一章」「下一章」「作者按」「PS：」「以上内容」
- 大纲语言（「本章的目标是…」「此处应埋设伏笔」）
- 写作过程残留（「这段再润色一下」「TODO」）
- 与读者的直接对话（求票、请假条）

## 分级处理策略

根据 AI 味程度决定处理范围：

| 等级 | 量化标准 | 特征 | 处理策略 |
|---|---|---|---|
| 轻度 | 禁用词≤5处/千字，无连续3+句式套路 | 少量禁用词，偶有书面腔 | Gate A + B |
| 中度 | 禁用词6-15处/千字，或有连续3+句式套路 | 多处禁用词+句式套路+心理抽象 | Gate A+B+C+D+G |
| 重度 | 禁用词>15处/千字，或7 Gate中4+有问题 | 全文AI味明显 | 完整7 Gate+重点段重写 |

### 删除比例上限（防过度去AI味）
- 轻度 ≤15%
- 中度 ≤25%
- 重度 ≤35%

超限时分段处理并标注 `[需复核]`，不得整段删除正文。
删除前必须确认：被删内容是否含伏笔、钩子、角色特征、情节推进、必要信息。

## 两遍式润色流程

执行去AI味时必须完成两遍：

**第一遍**：清除AI模式。逐段扫描，针对7 Gate逐一处理。

**第二遍**：AI自审。完成第一遍后，对修改稿提问：
> "这段文字哪些地方还是明显AI生成的感觉？"

列出3-5条具体问题，再次修改后输出最终版。

## 有灵魂的写作

避免了AI模式但仍然无聊，同样是失败。好的写作特征：

- **有观点**：叙述者对事件有态度，不只是中性记录
- **节奏变化**：短句与长句交替使用
- **具体感受**：不是"他感到担忧"，而是"他的后背出了一层冷汗"
- **细节代替判断**：不是"她很聪明"，而是写她做了什么具体的聪明事

## 写完一章的自查流程

1. 跑机器闸口并落盘门禁状态：
   ```bash
   python scripts/check_text.py "正文/第XXX章.md" --min-chars N --max-chars M \
     --ledger "追踪/伏笔台账.md" --current-chapter N --gate-report --gate-state
   python scripts/rhythm_guard.py --chapter-file "正文/第XXX章.md" \
     --quota "追踪/节奏配额.md" --gate-state
   python scripts/normalize_punct.py "正文/第XXX章.md"
   ```
   blocking 命中当轮清零；advisory 按读感判断，确属问题才改。
2. 通读一遍，对照7 Gate逐条问：这段有没有AI腔？（机器查不了的 D/E 与语境变体靠这遍）
3. 检查每一段说明性文字：它挂在动作/冲突/细节上了吗？没有就删或改写。
4. 检查章首承接与章尾钩子是否都在。
5. 以上都过了，才允许更新追踪文件、向作者报告完成。
6. 开写下一章前，欠账门机器查验（也可直接跑 `python scripts/resume.py {书}`）：
   ```bash
   python scripts/check_text.py "正文/第XXX章.md" --verify-prev --current-chapter N
   ```

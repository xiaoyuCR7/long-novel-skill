# 深度结构理论（outline-structure-theory）

`outline-system.md` 是三级大纲+锚点配额的**操作手册**——管「总纲/卷纲/章纲怎么写、
锚点配额怎么分、改纲怎么级联」。`outline-safety.md` 是大纲写完后的**安全审查**——
管「这份大纲能不能用、有没有结构性缺陷」。本文件是大纲设计时的**理论框架**——管
「选什么结构、怎么布局线索、怎么驱动节奏」。

三者的关系：设计时查本文件做结构选择 → 按 `outline-system.md` 写大纲 → 写完后用
`outline-safety.md` 做安全审查。本文件在前，是结构决策的起点。

## 结构层级选择

长篇网文不是只有一种结构。不同题材、不同读者预期需要不同的结构层级。选错层级 =
骨架与血肉不匹配，写到中期必然崩。

### 一级结构：单元剧串联

**形态**：每个剧情单元（5-15 章）是一个相对独立的事件，单元之间用主角的成长线串联，
但前一个单元的结局不影响后一个单元的开局。

**适用题材**：日常向、轻松向、单元制悬疑、治愈系。

**特征**：
- 单元内自洽：每个单元有自己的起承转合，读完一个单元有完整满足感。
- 单元间松耦合：换一个地图/对手/目标就是新单元，不需要前单元的伏笔。
- 主角成长线是唯一的长线：单元本身不递进，但主角的能力/关系在累积。

**风险**：单元之间太松 = 读者觉得「每段都差不多」，缺乏追读动力。解法是给主角成长
线设明确的阶段性目标（每 N 个单元升一级），用成长线补长线张力。

### 二级结构：套娃升维

**形态**：每个卷是一个「小五幕」（卷内有建立-上升-转折-高潮-结算），卷与卷之间是
升维关系——下一卷的舞台比上一卷更大、对手更强、 stakes 更高。

**适用题材**：升级流玄幻、冒险、修仙、系统文。

**特征**：
- 卷内自洽+卷间递进：每卷有完整弧线，但每卷的结局开启下一卷的更大舞台。
- 套娃式升维：第一卷在村子里打，第二卷在城里打，第三卷在国里打……舞台不断扩大。
- 金手指递进解锁：每卷新解锁一层金手指能力，与舞台升维同步。

**风险**：升维失控 = 战力膨胀过快，后期写不下去。解法是参照 `commercial-core.md`
的金手指原理，给每层升维设天花板，参照 `reader-contract-deep.md` 的终局储备边界
管理。

### 三级结构：统一结构

**形态**：全书是一个统一的五幕结构，不分卷独立——卷只是篇幅切分，不是结构切分。
所有线索从第一卷埋到最后一卷，中途的转折服务于全局。

**适用题材**：史诗、群像、大悬疑、权谋。

**特征**：
- 全局因果链：第一卷埋的因可能在第四卷才结出果，单元不是自洽的。
- 多 POV/多线并行：不只主角一条线，多条线交织推进。
- 终局真相驱动：全书有一个核心谜题/核心矛盾，逐卷揭露但不完全揭晓，直到终局。

**风险**：线索管理难度极高 = 容易挖坑不填。解法是依赖 `追踪/伏笔台账.md` 严格管理
每条线索的埋收计划，参照 `foreshadowing.md` 的伏笔纪律。

**选择决策表**：

| 题材特征 | 推荐层级 | 理由 |
|---|---|---|
| 轻松日常、单元制 | 一级 | 读者追求单次满足，不需要全局张力 |
| 升级打怪、地图切换 | 二级 | 升维感是核心卖点，套娃结构天然适配 |
| 史诗群像、大阴谋 | 三级 | 线索交织需要统一结构承载 |
| 混合型（升级+阴谋） | 二级为主+三级暗线 | 明线走套娃升维，暗线走统一结构 |

## 五幕式因果链

无论选哪个结构层级，每卷（二级结构）或全书（三级结构）都遵循五幕式因果链。五幕的
功能固定，不能跳步——跳步 = 因果链断裂。

### 第一幕：建立期

**固定功能**：世界观建立 / 人设亮相 / 金手指亮相 / 核心矛盾初现。

**必须完成的事**：
- 读者理解主角是谁、想要什么、为什么得不到（核心矛盾的种子）。
- 读者理解金手指是什么、怎么用、有什么限制。
- 读者理解世界的基本规则（力量体系/社会结构/核心冲突格局）。
- 至少埋 1 条长线伏笔（在第三幕或更后才回收）。

**常见错误**：建立期塞太多信息 = 信息过载，读者前 5 章流失。解法是分次投放——
第 1-3 章只投生存必需信息，其余在后续章节按需补全。

### 第二幕：上升期

**固定功能**：核心矛盾展开 / 升级开始 / 第一个小高潮。

**必须完成的事**：
- 核心矛盾从种子长成具体的冲突（主角与谁争、争什么、为什么争不了）。
- 升级线启动（能力提升/资源积累/势力建立）。
- 交付第一个小高潮（打脸/逆袭/揭秘），给读者甜头，建立追读信心。
- 引入至少 1 个核心配角（对手/伙伴/导师）。

**常见错误**：上升期太长 = 读者等不到甜头弃书。解法是参照 `outline-safety.md`
第三检的节奏分布要求，上升期内必须安排至少 1 次快档爆发。

### 第三幕：转折期

**固定功能**：中点反转 / 新势力介入 / 核心矛盾转向。

**必须完成的事**：
- 中点反转：到全书/本卷的 50% 位置，必须有一个改变方向的事件——原来以为的敌人
  是盟友、原来以为的目标是假目标、新势力打破现有格局。
- 核心矛盾转向：矛盾不是消失了，是升级了——从「打倒 A」变成「发现 A 背后还有 B」。
- 第一幕埋的长线伏笔至少回收 1 条，给读者「原来如此」的回扣感。

**常见错误**：转折期没有真转折 = 读者觉得「半本书都在原地打转」。解法是参照
`outline-safety.md` 第二检，核心冲突必须有递进，中点反转是最关键的递进点。

### 第四幕：高潮期

**固定功能**：核心矛盾激化 / 终局底牌解锁 / 最高潮爆发。

**必须完成的事**：
- 核心矛盾激化到不可调和——主角退无可退，必须正面解决。
- 终局底牌解锁：主角的终极能力/终极真相/终极盟友在此刻到位。参照
  `reader-contract-deep.md` 的终局储备管理，底牌不能提前打光。
- 最高潮爆发：全书/本卷情绪爆发的最高点。参照 `emotion.md` 的蓄积→爆发→余韵三段
  式，高潮的烈度由前三幕的蓄积决定。

**常见错误**：高潮期底牌提前用完 = 终局无力。解法是参照 `outline-safety.md` 第六检，
明确「必须压住」清单，高潮期只释放计划内的底牌。

### 第五幕：结算期

**固定功能**：核心矛盾解决 / 新世界格局 / 下卷钩子。

**必须完成的事**：
- 核心矛盾解决：不是和稀泥，是有明确结局（赢了/输了/惨胜/妥协）。
- 新世界格局：矛盾解决后，世界变了——主角的地位变了、关系变了、规则变了。
- 余韵交付：参照 `emotion.md`，爆发后的余韵是爽感放大器。结算期要给足余韵
  （旁观者反应/主角回味/局势变化）。
- 下卷钩子：二级结构下，结算期结尾必须留钩子引向下一卷（新地图/新对手/新秘密）。

**常见错误**：结算期太赶 = 读者觉得「打完就完了，没有回味」。解法是参照
`outline-safety.md` 第五检，结算期至少安排 1 章低压整理章做余韵。

## 五级大纲逐层展开法 + 布局八条线

### 五级逐层展开

大纲不是一次写完的，是逐层展开的——从粗到细，每层细化一层：

| 层级 | 粒度 | 对应文件 |
|---|---|---|
| 1 全书一句话 | 主线一句话 | `大纲/总纲.md` 的主线字段 |
| 2 分卷规划 | 每卷一句话目标 | `大纲/总纲.md` 的分卷规划表 |
| 3 卷级五幕 | 每卷的五幕划分 | `大纲/卷纲_第X卷.md` |
| 4 单元划分 | 每卷拆成 3-5 个剧情单元 | `大纲/卷纲_第X卷.md` 的单元划分 |
| 5 章级情节点 | 每章的情节点清单 | `大纲/章纲_第XXX章.md` |

逐层展开的纪律：不跳层。跳过卷级五幕直接写章纲 = 没有结构骨架就写执行细节，
章纲会散。这与 `outline-system.md` 的滚动补纲纪律一致——一次只补一个单元。

### 布局八条线

大纲不是只排主线——长篇连载至少要同时布局八条线，否则单线推进 = 读者疲劳。

| 线 | 内容 | 布局要点 |
|---|---|---|
| 主线 | 核心矛盾的推进 | 五幕因果链的骨架 |
| 感情线 | CP 关系的演变 | 每卷至少 1 个关系锚点（见 `outline-system.md`） |
| 升级线 | 能力/资源/势力的积累 | 与五幕的上升期-高潮期同步 |
| 势力线 | 势力格局的变化 | 转折期引入新势力是势力线的关键节点 |
| 世界线 | 世界观信息的逐步揭露 | 每卷揭露一层，终局揭最终层 |
| 伏笔线 | 伏笔的埋设与回收 | 与 `追踪/伏笔台账.md` 双向核对 |
| 角色弧 | 主角的成长轨迹 | 从第一幕的起点到第五幕的终点 |
| 读者契约 | 核心快感的兑现节奏 | 参照 `reader-contract.md` 的兑现频率 |

**布局原则**：八条线不是每章都推进——每章推进 2-3 条线即可，其余线休眠。但每卷
结束时，八条线都必须有推进（至少 1 个锚点）。某条线整卷无推进 = 这条线死了。

## 重剧情型 vs 重人设型大纲选择

大纲有两种驱动模式，选错模式 = 题材与写法不匹配。

### 重剧情型：事件驱动

**特征**：大纲以事件序列为核心——「发生了什么→导致了什么→下一步发生什么」。
角色服务于事件，事件推动角色。

**适合题材**：玄幻/科幻/悬疑/冒险——读者追的是「接下来发生什么」。

**大纲写法**：
- 章纲的情节点清单以事件为单位，每个情节点是「谁做了什么→导致了什么」。
- 卷纲的五幕以事件转折为幕界——第一幕到第二幕的转折是一个事件，不是一个情感变化。
- 角色弧线服从事件序列——角色的成长是因为事件催化，不是自行觉醒。

**风险**：重剧情型容易把角色写成工具人——事件需要谁出场谁就出场，角色没有自主性。
解法是给每个核心配角设「功能+私欲」——功能是事件需要的角色作用，私欲是角色自己的
小算盘。功能推进事件，私欲制造意外。

### 重人设型：关系驱动

**特征**：大纲以关系演变为核心——「谁和谁的关系发生了什么变化→这种变化导致了什么
事件」。事件服务于关系，关系推动事件。

**适合题材**：言情/都市/宫斗/家庭——读者追的是「这两个人的关系怎么发展」。

**大纲写法**：
- 章纲的情节点清单以关系节点为单位，每个情节点是「谁对谁做了什么→关系怎么变了」。
- 卷纲的五幕以关系转折为幕界——第一幕到第二幕的转折是一次关系质变，不是一个事件。
- 事件服从关系序列——事件的发生是因为关系张力需要释放，不是因为剧情需要推进。

**风险**：重人设型容易剧情停滞——关系反复拉扯但没有外部事件推动，读者觉得「水」。
解法是每 3-5 章安排 1 个外部事件打破关系平衡，逼迫关系做出不可逆的变化。

## 换地图三法

长篇连载不可避免要换地图（村→城→国→大陆）。换地图是读者流失的高风险点——新地图
没有情感锚点，读者会觉得「换了一本书」。三种换地图法：

### 自然过渡法

主角因为剧情原因自然移动到新地图——师父带去新地方、任务指向新地点、追敌追到新地
图。读者跟随主角的视角自然进入新地图，不突兀。

**适用**：冒险/升级流/公路片式结构。
**要点**：过渡章节不能跳——从旧地图出发到抵达新地图，至少 1-2 章做路上的见闻和
铺垫，给读者适应期。

### 强制迁移法

主角被外力强制迁移到新地图——被流放/被绑架/被传送/被陷害。主角不愿走但不得不走，
新地图是被迫面对的困境。

**适用**：悬疑/宫斗/生存类。
**要点**：强制迁移必须伴随旧地图的未竟之事——主角在新地图但心里挂着旧地图的线索，
给读者「迟早要回去」的期待。如果旧地图彻底抛弃 = 读者前面追的感情白追了。

### 世界扩展法

地图不是换了而是扩大了——原来主角只知道一个村，现在发现村外有城、城外有国、国
外有大陆。旧地图不抛弃，新地图在旧地图基础上扩展。

**适用**：史诗/修仙/奇幻——世界观本身是卖点的题材。
**要点**：新地图必须重新定义旧地图——原来以为最重要的村子其实只是世界角落。世界
扩展法制造的是「世界比想象中大」的震撼感，每次扩展都要重新校准读者的认知。

## 对标节奏迁移

**定义**：写卷纲时，找一本同题材的成功对标书，把它的卷级节奏结构（1/4·中点·3/4
的关键转折点）提取出来，换上自己的素材，排进本卷的卷纲。

**迁移步骤**：
1. 选对标书：同题材、同平台、数据好的完本书。
2. 提取结构点：标注对标书每一卷的 1/4 处（第一个小高潮）、中点（核心转折）、
   3/4 处（卷末高潮前的最后铺垫）、卷末（大爆发+下卷钩子）。
3. 换素材：把对标书在这些结构点发生的事，换成自己本书的素材。对标书 1/4 处是
   「主角第一次打脸小反派」→ 你的 1/4 处也安排一个「第一次小胜」，但打的是你的
   反派、用你的金手指。
4. 排进卷纲：把换好素材的结构点排进本卷卷纲的对应位置。

**迁移纪律**：
- 只迁结构不迁内容——迁移的是节奏形状（什么时候快/慢/转），不是具体情节。照搬
  情节 = 抄袭。
- 只迁一卷不迁全书——每卷找对标书对应的一卷做迁移，不拿对标书全书结构套自己全书。
- 迁移后必须过七检——对标书的节奏在 TA 的书里成立，在你的书里不一定成立。参照
  `outline-safety.md` 的七检+可证伪检查。

## 章节定位与张弛

卷纲排好后，每章需要标注定位——定位决定了本章的节奏档位和情绪基调。与
`outline-safety.md` 第五检的章节定位一致，但本文件补充设计层面的选择逻辑。

**六种章节定位**：

| 定位 | 功能 | 节奏档位 | 情绪基调 | 典型场景 |
|---|---|---|---|---|
| 高压 | 主线冲突爆发 | 快 | 爽/燃/虐 | 大战/揭秘/打脸 |
| 推进 | 次要矛盾升温 | 中 | 紧/期待 | 布局/试探/获取情报 |
| 修炼试错 | 升级/能力获取 | 中/慢 | 专注/挫折 | 修炼/研发/训练 |
| 关系回收 | 羁绊深化/关系变化 | 慢/中 | 暖/甜/酸 | 日常互动/交心/冲突和解 |
| 低压生活 | 日常/风土/过渡 | 慢 | 轻松/有趣 | 逛街/吃饭/闲聊 |
| 信息整理 | 收束前文/消化余韵 | 慢 | 沉淀/回味 | 复盘/计划/休整 |

**张弛原则**：
- 高压章不连续（间隔至少 2 章）——连续高压 = 读者疲劳。
- 每 3-4 章至少 1 章低压或关系回收——给读者喘息。
- 修炼试错和信息整理不连续——都是慢档，连续会拖节奏。
- 卷末必须是高压或推进——低压收卷 = 读者没有追下卷的动力。

**与 `reverse-brake.md` 的关系**：`reverse-brake.md` 的 A/B/C 配额是章级的节奏约束
（防连续爆发），本文件的六种定位是卷级的结构约束（防节奏失衡）。两者互补：本文件
管「这卷的章节类型分布对不对」，`reverse-brake.md` 管「相邻几章的爆发频率过不过」。

## 理论选择 -> 操作落地 -> 安全审查

三文件的执行顺序：

```
结构决策（本文件）
  ├─ 选结构层级（一级/二级/三级）
  ├─ 排五幕因果链
  ├─ 布局八条线
  ├─ 选驱动模式（重剧情/重人设）
  ├─ 定换地图法
  └─ 迁对标节奏
       ↓
操作落地（outline-system.md）
  ├─ 写总纲（五级展开第1-2层）
  ├─ 写卷纲（五级展开第3-4层 + 锚点配额）
```

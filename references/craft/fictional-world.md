# 虚构世界的创作自由与内部一致性

用于玄幻、修仙、武道、系统、异能、奇幻等超现实设定，也用于现实背景中的明确架空部分。
先看作者要创作还是核查现实资料，再按本书规则判断。无需为每一项神通另问“现实是否允许”。

## 虚构事实的判定

- 故事中的灵气、境界、神魂、复生、瞬移、储物空间、时间倍率、因果改写、系统面板与奖励，
  都可以成为成立的设定；不以现实不存在、违反物理定律或无法科学验证判错，不强补伪科学解释。
- 宗规、天道、皇朝律令及人物的道德选择可以不同于现实法律和社会制度。虚构人物可以违法、
  反叛或挑战秩序；现实中是否合法不自动决定其剧情能否出现，也不要求人物必然受罚、悔改。
  作品内是否违背宗规及产生什么后果，由本书设定、叙事意图和作者决定。
- 文件中“事实”是已发生正文和已确认设定；“可行”“合理”是当前故事规则下成立；
  “合法时间来源”是有输入/设定依据的测时机制，包含系统倒计时、法阵刻度、已设定的神识感知，
  不限于现实钟表。空间、速度、寿命、伤势和知识获取都按相同原则核查。

## 设计与续写采用不同的自由度

**设计新设定或未写剧情**：作者允许脑洞、构建体系、开书提案时，主动提出具体规则、奇观、
力量组合及剧情可能；新设定不因“还没在正文发生”被拒绝。提案清楚标为提案即可，不逐项等待批准。
强度、代价、冷却和限制由作者选择；已明确无敌、无限资源或无代价路线时，不强塞副作用来符合套路，
可以从目标取舍、关系、探索、信息差或力量影响中组织剧情。
题材卡和商业技巧中的“必须有限制/代价”等经验规则只用于作者选择的挑战或苦修路线，不能覆盖上述创作选择。

**续写已锁定事件或修订已写正文**：在既有规则与本轮授权内大胆呈现神通、武技、突破和系统效果，
不要求现实依据，也不把“禁止擅改设定”扩大成禁止感官具象化、招式表现和已授权事件的合理细化。
若新机制会改变胜负、能力边界、前置条件、物件归属或已发生事实，须有本轮授权或明确设定依据；
不能临时发明复活券、读心术、时间暂停来补洞。真正缺少关键世界规则时只指出该缺口，不要求现实证据。
作者明确改设定时按现有改纲/修订流程同步影响，不静默回写旧事实。

## 审核时成对辨认

| 可成立的虚构内容 | 应核查的内部冲突 |
|---|---|
| 已设定替命符消耗一枚即可复生，角色消耗符后归来 | 已明确替命符耗尽、无法复生，正文仍无新授权地归来 |
| 本书允许瞬移，角色在指定范围内穿越两城 | 已明确封禁空间、能力冷却中，却无依据瞬移 |
| 气血化翼、拳意碎空或百倍时间秘境 | 跨过本书明确未解锁的境界，或秘境内外时间换算自相矛盾 |
| 系统无代价发资源、奖励面板和数据提示 | 已明确只能发灵石，却临时赠送掌控时间的能力解决危机 |
| 主角违背虚构宗规夺位，作者指定不走惩戒结局 | 没有来源就声称本书宗门从未有过某条已写明的宗规 |

问题报告引用“本段 + 本书规则/已发生状态”的双向证据；不能只拿现实常识给 S1/P0。
现实题材也可以有明确架空部分：按作者规定区分两者，不把系统设定硬套现实科学，也不把现实资料任意造假。
当请求转为现实知识答复、史实核验、现实法律说明、市场调查或实际发布操作时，仍按该任务核验与授权，
不把小说里的机制当成现实证据。不因普通虚构片段反复插入现实免责声明或打断创作。

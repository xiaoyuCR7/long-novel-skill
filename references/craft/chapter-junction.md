# 章节衔接：章间无缝连接工艺（chapter-junction）

章间连接点是长篇最容易露怯的地方。两章交界处是读者最容易弃书的三个位置之一——
「断了」「接不上」「突然换了个故事」。本文件把 **上一章结尾 + 下一章开头** 当成一个
独立设计单位：**咬合面**。所有衔接技巧都在回答同一个问题：两章之间，读者脑子里缺什么，
你补什么。

分工：章内结构（四拍/档位/配额）查 `pacing-and-hooks.md`；钩子招式库查 `hooks.md`；
伏笔埋设回收查 `foreshadowing.md`；人设防漂移查 `character-consistency.md`。
本文件只管章与章之间的连接。

## 一、核心理念：章间是咬合面，不是拼缝

- **写章尾时问**：「我要给下一章留什么？」（悬念 / 冲突 / 情绪 / 决定，至少一个未完成）
- **写章首时问**：「上一章欠我什么？」（读者此刻最想知道的事）
- **禁止**：上一章写完，下一章从零开始。

两个先决条件（开写下一章前必须成立）：
1. 上一章追踪文件已回写（章节摘要 / 角色状态 / 伏笔台账）——衔接的信息底座。
2. 摘要的「承上 / 启下」两栏已填——衔接设计要有据可查，断更恢复也能接上。

## 二、章间因果链（因果咬合）

### 2.1 因果链三型

| 链型 | 定义 | 章间接法 | 适用 |
|---|---|---|---|
| **直接因果** | 章 N 尾事件 → 章 N+1 首直接结果（同一事件链不中断） | 后果式 / 对峙式承接，时间几乎连续 | 冲突、战斗、揭晓的延续 |
| **延迟因果** | 章 N 尾埋「种子」（决定 / 线索 / 隐患）→ 章 N+1 中后段才见果 | 疑问式 / 变奏式承接，章首先给状态再揭果 | 布局、交易、阴谋、承诺 |
| **并列推进** | 双线 / 多线并行，章间切换线索 | 章首三行内点明「切到哪条线」 | 双男主、主角 + 反派线、势力博弈 |

### 2.2 因果链三问（写每章前对上一章问）

1. 上一章结尾，留下了什么「未完成」？（悬念 / 冲突 / 情绪 / 决定，至少一个）
2. 读者最想先看到哪一件事的答案？
3. 本章开头与上章结尾之间，因果是否「一眼连得上」？
   - 能 → 写。
   - 需要读者脑补三句话以上才连上 → **缺环**，先补「前情触发」（见 2.3）。
   - 连不上 → 上章结尾设计有问题，回改上章钩子或调整本章开头，不要硬接。

### 2.3 缺环修补：前情触发

**前情触发** = 章首用半句 / 一个物件 / 一个回看，把因果缺环补上，而不是复述上章剧情。

- 例：上章尾主角做下决定 → 本章首他已在执行（触发句：「路是连夜赶的。」）。
- **禁忌**：补环 ≠ 复述。把上章情节重讲一遍 = 灌水，读者记忆没坏。

## 三、四类过渡元素

### A. 悬念延续（钩子 → 接钩）

章末钩子制造问题，章首承接给出「答案的入口」。招式库见 `hooks.md`（章首 7 式 / 章尾 13 式）。

**配对原则**：钩子的「期待方向」决定承接的「打开方式」：

| 上章章尾钩子 | 本章章首承接（推荐） |
|---|---|
| 危险逼近式 | 后果式 / 对峙式 |
| 新信息式（话说一半） | 揭示式（只揭一角） |
| 抉择式 | 疑问式 / 后果式 |
| 身份将揭式 | 对峙式 / 揭示式 |
| 反转预告式 | 变奏式（日常里一个「不对」） |
| 情绪悬置式 | 情绪余波式 |
| 倒计时式 | 倒计时式（接续倒计时） |

**接钩时效（硬纪律）**：
- 显式接住：≤ 章首 10%。
- 危机兑现 / 推进：≤ 前 30%。过了 30% 没接 = 欺骗读者（`hooks.md` 章尾纪律）。

**接钩禁忌**：不写「上一章说到」「却说」；不把上章钩子复述一遍。

### B. 线索承接（物件 / 信息 / 人物线）

三种携带方式，章间必须「交接清楚」：

| 携带 | 做法 | 章尾 | 章首 |
|---|---|---|---|
| **传件** | 关键物件跨章传递（信 / 令牌 / 地图 / 伤势 / 欠条） | 物件易主 / 显现 / 出现异常 | 物件出现在新主人之手或新位置 |
| **带信** | 信息跨章延续（半句话 / 半封信 / 半句情报） | 话说一半、信读一半 | 补全，或角色据此行动 |
| **带人** | 人物跟随跨场景 | 人物踏上旅程 / 被带走 | 人物抵达，先给「抵达动作」 |

**线索簿三查**（写章首时对上章末查）：
1. 上章末在场的人物，本章首去哪了？（凭空消失 = 割裂）
2. 上章末的关键物件，本章首在哪？（凭空出现 / 消失 = 割裂）
3. 上章末悬着的信息，本章首有人记得吗？（无人理会 = 坑）

### C. 场景自然转换（时间 / 空间 / POV 跳转）

- **时间跳跃「落地四要素」**：锚点（旧时刻）→ 跳 → 新锚点（新时刻 + 一句状态）。
  例：「当晚的雨没停。三天后，队伍才走出黑林。」禁止裸跳「第二天……」无任何状态锚。
- **地点切换「定位句」**：到新地点，第一段内给 地点名 + 在场者 + 此刻事态。读者靠三样定位。
- **POV 切换**：章间切换最干净（见 `plot-special-topics.md` 章间切换法）；切换章首三行内点明 POV。

**场景转换三问**（写完章首自查）：
1. 读者知道现在在哪吗？
2. 读者知道过了多久吗？
3. 读者知道谁在场 / 谁做主视角吗？

三问中任一为「否」→ 割裂，补定位。

### D. 情绪过渡（余波 / 基调衔接）

- **情绪断崖** = 上章高能峰值，本章直接换冷场景，读者情绪被硬切。
- **快档高能章后**，章首允许 1–2 段「情绪余波」再转场（与 `hooks.md` 情绪余波式承接对齐）。
  例：大决战章 → 下章首先写胜利后的静默 / 伤亡名单 / 主角独坐，再开新线。
- **跨章基调**：情绪基调按 3–7 章一个周期起伏（`emotional-arc.md` 跨章情绪周期），
  章间基调不许断层——上章「燃」本章直接「平铺叙事」= 断层，中间至少给一次情绪回声
  （一句回忆 / 一个意象）。
- **例外**：双线交替时，线切换本身是基调切换的合法借口，但切换章首要声明线。

## 四、章间四拍对位（节奏衔接）

- 单章四拍：承接 → 发展 → 结算 → 钩子（`pacing-and-hooks.md`）。
- **章间对位**：章 N「钩子」= 章 N+1「承接」的引信。两章交界的四拍是「承接」接过「钩子」，
  不是各写各的四拍然后硬接。
- **档位跨章纪律**（`pacing-and-hooks.md`）：快档后至少 1 章慢/中档缓冲；连续 2 章快档 = 报警。
- **结算残账**：章 N 结算不完的小账（一个没算清的人情 / 一件没收尾的琐事 / 一个没问出口的
  问题），刻意留到章 N+1 开头收——「残账」是最省力的天然衔接。

**章间节奏一致性自问**：
1. 本章档位与上章是否产生「快→快」的失速或「慢→慢」的停滞？
2. 上章的节奏承诺（该爆发了 / 该收尾了）本章兑现了吗？

## 五、动机连贯（跨章动机流）

- **第一动作定律**：章 N+1 角色第一个动作，必须由章 N 结算后的状态驱动。
  「上章他刚重伤 → 本章首他在找药」合理；「上章他刚重伤 → 本章首他在比武招亲」= 突转。
- **动机断点检测**：角色情绪 / 决定在章间突变而无交代 = 断裂。检测法：把上章末的角色状态
  摆到本章首第一个动作前，问「中间发生了什么让他变了」——答不上来就补「前情触发」或改动作。
- **关系距离**：章间任何关系距离变化，章首要有一句交代（角色状态「关键关系」栏）。
- **与追踪文件联动**：章 N 写后回写角色状态 → 章 N+1 写前读状态 → 动机链闭环。
  机制已存在（`character-consistency.md` 防线二 / 三），本文件要求「章首动作显式检查一次」。

## 六、呼应前文与预示后续

- **章首回声**：一句话 / 一个物件 / 一句台词，回扣前文 1–3 章细节，建立「同一本书」感。
  例：上章他打碎了母亲的玉镯 → 本章首他缝好放回枕边。
- **章尾预示**：钩子本质即预示。新伏笔埋设时机与回收窗口见 `foreshadowing.md`。
- **大伏笔纪律**：跨卷大伏笔每卷至少一次「提醒性触碰」（`foreshadowing.md` 🟢），防止读者遗忘。
- **呼应密度**：不必每章都回声；每 2–3 章至少一处「前文细节回扣」，维持整体感。

## 七、割裂感诊断与修复（五种病）

| 病 | 症状 | 识别 | 修复 |
|---|---|---|---|
| **章首重新定位症** | 开头重新介绍人物 / 环境 / 背景（读者早已知） | 「他叫林辰，是……」式开场 | 删，直接接钩；背景只补「新增量」 |
| **时间线断裂症** | 时间跳跃无锚，读者算不清过了多久 | 裸「第二天」+ 人物状态与上章对不上 | 落地四要素 |
| **情绪断崖症** | 上章高潮本章直接冷场，无过渡 | 情绪峰值章 → 冷叙事章紧贴 | 余波小节 + 情绪回声 |
| **因果缺环症** | 上章事件与本章开头无因果，需读者脑补 | 因果链三问第 3 问答不上 | 前情触发 / 改本章开头 / 回改上章钩子 |
| **动机突转症** | 角色行为与上章状态矛盾 | 第一动作定律检查不过 | 补触发或改行为（改行为走人设底线检查） |

## 八、衔接自检清单（章首写完、全章写完各过一遍）

1. 章首 10% 内显式接住上章钩子？
2. 上章钩子承诺的危机，前 30% 内已兑现或推进？（过了 = 欺骗）
3. 上章末的人物 / 物件 / 信息，本章首在合理位置？（线索簿三查）
4. 场景转换三问全过（在哪 / 过了多久 / 谁在场或主视角）？
5. 本章首情绪与上章尾无断崖？（高能章后有余波）
6. 本章角色第一个动作由上章结算后状态驱动？（动机链）
7. 本章呼应了至少一处前文细节？
8. 章末钩子与本章结算有因果延伸？（残账 → 下章引信）
9. 摘要「承上 / 启下」两栏已填？（断更恢复的依据）

与 `chapter-loop.md` Step 6 检查清单合并执行；本清单聚焦「章间」，那边聚焦「章内」。

## 九、机器兜底现状与边界

- **当前无衔接门禁脚本**。章间衔接靠：① 摘要「承上 / 启下」栏记录；② 本节检查清单人工执行；
  ③ `check_text.py --verify-prev` 保证上一章门禁已过（欠账门，跨会话可验证）。
- 可机器化的部分：时间线倒退检测 `static_check.py` TIMELINE 已做时间线一致性。
- 因果缺环需语义分析，暂不可靠；不要为机器化牺牲手感——**衔接是手感活**。

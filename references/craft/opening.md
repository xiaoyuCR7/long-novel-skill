# 开篇工艺（黄金三章）

免费阅读时代，开篇不是书的第 1%，而是书的生死线：读者给一本书的耐心通常不超过三章，
平台给一本书的第一波推荐也只看这几章的数据。开篇的目标不是「把故事讲开头」，
而是**让读者在三章之内做出追读决定**。

## 第一章的任务清单

一章之内必须完成四件事，顺序不能乱：

1. **立人**：主角登场，且是在「动作」中登场——他正在做什么、被什么压着。
   读者先认识人，才关心世界。
2. **立境**：给出「看懂这场戏所需的最小背景」，多一点都不给。
   世界观、前史、设定统统让位，后文有的是地方补。
3. **立冲突**：第一章前半就要有压力源——一个具体的、正在发生的麻烦。
   「平静的日常生活再过一个转折」这种写法，在网文里等于自杀。
4. **立钩子**：章尾抛出让读者非点开第二章不可的问题。

## 信息释放顺序

读者的大脑是单线程的：先认人 → 再懂处境 → 然后才轮得到世界。

- 第一章只放「这场戏需要」的信息；每个设定名词出场必须挂在动作、冲突或具体物件上。
- 主角的「特殊性」（金手指、穿越者身份、隐藏实力）第一章要露，但只露一角——
  露到读者「意识到他不简单」为止，完整解释留给前三章之后。
- 视角人物越少越好：第一章理想状态是单视角，出场有名字的人物不超过 3–4 个。

## 前三章的分工

- **第 1 章：勾住。** 人物 + 当下冲突 + 悬念钩子。
- **第 2 章：加码。** 冲突升级或展开，主角开始行动（不是被动挨完三章），
  让读者看到「这本书的戏是怎么唱的」。
- **第 3 章：兑现。** 给出第一个小结算（小爽点/小揭晓/关系质变的前奏），
  证明这本书「说话算数」。读者对一本书的信任，是在第一次兑现时建立的。

三章之内主角必须**主动做过一个选择**。被动挨打三章的主角，读者会替他憋屈到弃书。

## 开篇禁忌

- 大段背景交代、编年史开场、地图/种族/等级表倾倒；
- 群像开场（读者还没决定跟谁走，就塞来一屋子人）；
- 慢热抒情、景物长描写开场；
- 梦境/穿越过程注水（醒来后花两章适应新世界）；
- 把「高能剧情」全攒到后面——开篇就得拿出全书中等以上的强度。

## 书名与简介：第一次钩子

读者先看到简介才看到第一章。简介的写法 = 本书核心矛盾一句话 + 主角特殊性一句话 +
一个悬念或反差。简介里不出现设定名词，不出现「且看他如何」式套话。

## 开篇自检清单

1. 第一页（约 300 字内）有没有出现压力源或冲突信号？
2. 第一章出场有名字的人物 ≤4 个？
3. 主角在三章内做过主动选择？
4. 第三章结束时，读者已经得到过一次「兑现」？
5. 每一段背景介绍删掉会影响理解这场戏吗？（不会 → 删）
6. 章尾钩子按 1→2→3 章环环相扣，且下一章都接住了？

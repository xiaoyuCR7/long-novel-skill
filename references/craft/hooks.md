# 钩子库：章首 7 式 · 章尾 13 式 · 段落级钩子

钩子的本质只有一个：**制造一个读者现在就想知道答案的问题**。
本库是招式表，写章首/章尾卡壳时按式取用；不要连用同一式，相邻三章的章尾
钩子类型必须不同（读者会对套路免疫）。

## 章首 7 式（承接上章 + 本章起手）

| 式 | 做法 | 例 |
|---|---|---|
| 1. 后果式 | 上章事件的第一个坏/好后果直接砸脸 | 「来人」——门被撞开时，他手里的信才烧了一半。 |
| 2. 疑问式 | 用一个人物（或读者）的当下疑问开场 | 张三一夜没睡，想不通那人为什么要替他挡这一刀。 |
| 3. 变奏式 | 日常画面里有一个细节「不对」 | 王婶照旧来送早饭，照旧是两碗，可她儿子昨夜已经走了。 |
| 4. 倒计时式 | 直接给出期限压力 | 距月底宗门大比，只剩六天。 |
| 5. 对峙式 | 对话中途切入，冲突已在进行 | 「你再说一遍？」他按住桌角站起来。 |
| 6. 揭示式 | 揭开上章悬念的一角（只揭一角） | 那封信他终究还是看了。只有一行字。 |
| 7. 情绪余波式 | 上章情绪峰值后的静默反写 | 灵堂撤了，院里的白幡收了，他才发现自己三天没开口说过话。 |

**章首纪律**：前 10% 内必须接住上一章的钩子（chapter-loop 检查清单第 1 条）；
不从天气/风景开场（除非反差极大）。

## 章尾 13 式（留下非翻页不可的理由）

| 式 | 做法 | 期待度 |
|---|---|---|
| 1. 危险逼近式 | 威胁已上路，主角尚不知情或刚到门口 | 强 |
| 2. 新信息式 | 抛出一条改变认知的信息（话说一半） | 强 |
| 3. 抉择式 | 主角面临两难，章尾停在做出选择前 | 强 |
| 4. 身份将揭式 | 马甲/身世即将被某人撞破 | 强 |
| 5. 反转预告式 | 读者看得出「这事要完」，书里人还不知道 | 强 |
| 6. 收获悬念式 | 好处到手了，但附带的代价/疑团刚露头 | 中 |
| 7. 人物登场式 | 有分量的人物首次（或意外）出场 | 中 |
| 8. 关系突变式 | 一句话/一个动作让两人关系变味 | 中 |
| 9. 倒计时式 | 明确期限挂出来（三日后/月圆前） | 中 |
| 10. 物件钩子式 | 关键物件出现/易主/显出异常 | 中 |
| 11. 情绪悬置式 | 停在情绪将爆未爆的一瞬（低压/感情章用） | 中 |
| 12. 计划启动式 | 主角说出计划的第一步（全貌不揭） | 中 |
| 13. 余韵式 | 大高潮后的画面收束+远处一丝阴影（卷尾专用） | 弱（卷尾豁免） |

**章尾纪律**：
- 高压/推进章用强期待度式子；低压/过场章可用中弱式，但必须给「往下看的理由」。
- 结尾落在具体的动作/画面/台词上，禁止状态判词（「就这样……」「一切才刚开始」
  ——这类是 check_text.py 的 blocking 项：预告式收尾）。
- 钩子承诺必须兑现：章尾挂的危机，下章前 30% 内必须接（接不住=欺骗读者）。

## 段落级钩子（章内防弃读）

章内每 300–500 字需要一个「微钩子」，防止读者在中段划走：

1. **信息差提醒**：读者知道而角色不知的事，用一句叙事轻轻点一下
   （「他没注意到，身后那人的手已经按在了刀柄上」）。
2. **小疑问埋设**：一个反常细节，不给解释（「掌柜的多看了他两眼」）。
3. **利益预告**：即将到手的好处先亮一半（系统提示「检测到稀有奖励」）。
4. **情绪垫步**：爽点前必先垫一层委屈/危机（没有压抑就没有释放）。
5. **对话留白**：对话停在该接不接的地方（「你确定要知道？」他没有答。）。

**密度纪律**：微钩子不是每段都挂——一段一钩 = 廉价。以「读者读到这一段时
有没有一个小问号悬着」为准，没有就补一个，有就往下写。

## 钩子失效信号（自查）

- 连续三章章尾都是「危险逼近式」→ 换式。
- 钩子越来越依赖新人物/新设定空降 → 回到主线资源里找钩子。
- 读者能在章尾猜到下章全部内容 → 钩子给多了，收半句回来。

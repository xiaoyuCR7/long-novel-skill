# 文风指纹：提取、校准与迁移

文风指纹 = 一本书/对标书的量化腔调基线。用于防文风逐章漂移、对标书腔调迁移、
跨项目风格复用。

## 为什么需要文风指纹

长篇连载的文风漂移是慢性病：写者自己感觉不到，但读者会觉得「这本书越写越不对味」。
量化指标帮助发现变化，不替代阅读判断。作者认可的本书声线高于对标和通用范围，
词频、句长、对白占比或连续报警不能单独判文学失败。

## 文风指纹六维

用 `scripts/style_fingerprint.py` 提取，六维量化：

| 维度 | 含义 | 观察样例（非目标） | 用途 |
|---|---|---|---|
| 平均句长 | 句号/问号/感叹号切分后的平均字数 | 12-25字 | 短句多=快节奏；长句多=沉稳 |
| 对话占比 | 对话内容占总字数比例 | 20%-60% | 番茄偏高、起点中、晋江看题材 |
| 段落中位长度 | 段落字数的中位数 | 30-80字 | 短段=手机友好；长段=沉浸 |
| 标点节奏 | 问号/感叹号/省略号的使用频率 | 各1%-5% | 高=情绪激烈；低=克制 |
| 高频词 Top20 | 出现频率最高的20个实词 | 题材相关 | 检测口头禅/套话 |
| 句式偏好 | 长短句交替比、开头词分布 | - | 检测AI工整感 |

## 建立文风锚

### 有作者认可样章
```bash
python scripts/style_fingerprint.py extract "正文/第001章.md" "正文/第002章.md" ... \
  --output "{工程外工作目录}/文风指纹.md"
```
脚本输出独立指标文件。人工只把经认可的指标并入 `设定/文风锚.md`，保留作者要求、
样段出处、受保护特征、禁令、叙事距离和内心戏记录；禁止 extract 直接覆盖手工锚。

### 有对标书（拆文产出）
```bash
python scripts/style_fingerprint.py extract "对标/{书名}/原文/第1章.md" ... \
  --output "对标/{书名}/文风指纹.md"
```

### 无样章
先记录作者明确腔调与禁令，样段/数值写“未提供/未实测”，不造数据、不阻断无依赖工作。
取得作者认可的样章后再补实测，不把任意前几章当成已批准声线。

## 文风锚模板（`设定/文风锚.md`）

```markdown
# 文风锚

## 量化基线（前N章统计）
- 平均句长：{} 字（容差 ±{}）
- 对话占比：{}%（容差 ±{}%）
- 段落中位长度：{} 字（容差 ±{}）
- 标点节奏：？{}% / ！{}% / ……{}%
- 句式偏好：长短句交替比 {}

## 腔调关键词
- 本书的腔调是：{}
- 不用的腔调：{}

## 作者依据与受保护特征
[实际认可依据、样段出处、受保护特征、明确禁令；完整手工模板见 assets/templates/style-anchor.md]

## 叙述者与人物声线
[叙述距离、内心戏与情绪命名；人物按目的、知识、关系语境分别记录]

## 样板段落
[贴作者认可的必要节选并注明出处；未提供不阻断]

## 高频词白名单
[本书合理的高频词，不作为AI套话处理]
```

## 校准流程（每5-10章一次）

```bash
# 1. 提取本章文风指纹
python scripts/style_fingerprint.py extract "正文/第037章.md" --output "{工程外工作目录}/tmp_fp.md"

# 2. 与文风锚对比
python scripts/style_fingerprint.py compare "{工程外工作目录}/tmp_fp.md" "设定/文风锚.md"
```

脚本输出句长、对话占比、段落长度等偏离维度，提示回读相应场景，不能据此直接判漂移或过多/过少。

**容差内外都须看功能**：有实际损失才修；有效长句、内心戏、日常或标点不为统计改写。
记录短摘录与改/留理由即可。作者确认文风有意转变时手工更新锚，不自动覆盖契约。

## 对标书文风迁移

拆文产出对标书的文风指纹后，写作时：
1. 读 `对标/{书名}/文风指纹.md`
2. 写作前用它校准自己的腔调
3. 不照搬对标书的口头禅，只对齐节奏与结构

**原则**：迁移的是「节奏感」和「句式结构」，不是「词汇」。照搬词汇 = 抄袭。

## 跨项目风格复用

完成一本书后，其文风锚可沉淀为「风格档案」，存入 `设定/风格库/`：
```
设定/风格库/
├── {风格名}.md   # 含六维基线 + 腔调关键词 + 样板段落
└── ...
```

新开书时可选「沿用某风格档案」作为初始文风锚，再按新书题材微调。

## 与 7 Gate 的关系

文风指纹管「量化腔调」（句长/对话比/段落），7 Gate 管「AI模式」（禁用词/句式/心理）。
两者互补：
- 7 Gate 报警 → 按实际严重度与语境处理；B/G 有功能且获作者授权时按 `anti-ai-style.md` 精确豁免
- 指纹报警 → 回读确认实际功能，可能是场景所需，不自动回调；两者都通过也不证明文学质量

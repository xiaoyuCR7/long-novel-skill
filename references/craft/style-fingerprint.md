# 文风指纹：提取、校准与迁移

文风指纹 = 一本书/对标书的量化腔调基线。用于防文风逐章漂移、对标书腔调迁移、
跨项目风格复用。

## 为什么需要文风指纹

长篇连载的文风漂移是慢性病：写者自己感觉不到，但读者会觉得「这本书越写越不对味」。
靠主观判断不够，需要量化指标做客观锚定。

## 文风指纹六维

用 `scripts/style_fingerprint.py` 提取，六维量化：

| 维度 | 含义 | 典型范围 | 用途 |
|---|---|---|---|
| 平均句长 | 句号/问号/感叹号切分后的平均字数 | 12-25字 | 短句多=快节奏；长句多=沉稳 |
| 对话占比 | 对话内容占总字数比例 | 20%-60% | 番茄偏高、起点中、晋江看题材 |
| 段落中位长度 | 段落字数的中位数 | 30-80字 | 短段=手机友好；长段=沉浸 |
| 标点节奏 | 问号/感叹号/省略号的使用频率 | 各1%-5% | 高=情绪激烈；低=克制 |
| 高频词 Top20 | 出现频率最高的20个实词 | 题材相关 | 检测口头禅/套话 |
| 句式偏好 | 长短句交替比、开头词分布 | - | 检测AI工整感 |

## 建立文风锚

### 有样章（作者自己的前3-5章）
```bash
python scripts/style_fingerprint.py extract "正文/第001章.md" "正文/第002章.md" ... \
  --output "设定/文风锚.md"
```
脚本自动计算六维基线，写入 `设定/文风锚.md`。

### 有对标书（拆文产出）
```bash
python scripts/style_fingerprint.py extract "对标/{书名}/原文/第1章.md" ... \
  --output "对标/{书名}/文风指纹.md"
```

### 无样章
开书时先填「腔调关键词」与「不用的腔调」，前 3-5 章写完后补量化基线。

## 文风锚模板（`设定/文风锚.md`）

```markdown
# 文风锚

## 量化基线（前N章统计）
- 平均句长：{} 字（容差 ±{}）
- 对话占比：{}%（容差 ±{}%）
- 段落中位长度：{} 字（容差 ±{}）
- 标点节奏：？{}% / ！{}% / ……{}%
- 句式偏好：长短句交替比 {}

## 腔调关键词
- 本书的腔调是：{}
- 不用的腔调：{}

## 样板段落（3-5段，写作时对齐）
[贴3-5段最能代表本书腔调的正文片段]

## 高频词白名单
[本书合理的高频词，不作为AI套话处理]
```

## 校准流程（每5-10章一次）

```bash
# 1. 提取本章文风指纹
python scripts/style_fingerprint.py extract "正文/第037章.md" --output tmp_fp.md

# 2. 与文风锚对比
python scripts/style_fingerprint.py compare tmp_fp.md "设定/文风锚.md"
```

脚本输出偏离维度：
- 句长超出容差 → 节奏漂移
- 对话占比超出容差 → 对话过多/过少
- 段落长度超出容差 → 段落习惯变了

**容差内的漂移**：正常，不调整。
**容差外的漂移**：回头校准本章腔调，或更新文风锚（作者确认文风有意转变）。

## 对标书文风迁移

拆文产出对标书的文风指纹后，写作时：
1. 读 `对标/{书名}/文风指纹.md`
2. 写作前用它校准自己的腔调
3. 不照搬对标书的口头禅，只对齐节奏与结构

**原则**：迁移的是「节奏感」和「句式结构」，不是「词汇」。照搬词汇 = 抄袭。

## 跨项目风格复用

完成一本书后，其文风锚可沉淀为「风格档案」，存入 `设定/风格库/`：
```
设定/风格库/
├── {风格名}.md   # 含六维基线 + 腔调关键词 + 样板段落
└── ...
```

新开书时可选「沿用某风格档案」作为初始文风锚，再按新书题材微调。

## 与 7 Gate 的关系

文风指纹管「量化腔调」（句长/对话比/段落），7 Gate 管「AI模式」（禁用词/句式/心理）。
两者互补：
- 文风指纹未报警但 7 Gate 报警 → AI 模式问题，改表达
- 7 Gate 通过但文风指纹报警 → 腔调漂移，调节奏

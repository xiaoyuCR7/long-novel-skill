# 写作技法补充

本文件为 `emotion.md`、`dialogue.md`、`format-and-structure.md` 提供可选工具，
涉及身体细节、道具、空间氛围与开头密度。作者明确要求及认可声线高于本文件的通用建议。
下文次数、间隔、比例与步骤是设计参考，不是正文硬配额，不能据此强改有效表达或增添事件；
真正的章纲授权、事实、字数和节奏配额仍按主流程执行。

## 一、身体细节：按功能选用

情绪命名、内心戏、动作和身体细节都可成立，没有“情绪词全禁”或一律外化的要求。
按 `scene-rendering.md` 判断信息、策略、关系、风险、节奏、视角作用；必要反应可以很短，
有用的重复可以保留。身体动作不是固定的心理密码，不能靠职业、身份或性别推定某种反应。

### 身体部位速查表

以下表格按身体部位组织，每个情绪给出 2-3 个可用的身体细节。**这些不是唯一选项，
是起步素材**——写的时候要结合角色人设和场景判断是否采用（见后文「使用与修订」）。

#### 手与手臂

| 情绪 | 身体细节（递进烈度） |
|---|---|
| 紧张 | 手指无意识地摩挲杯沿 / 手掌在膝盖上蹭了两下 / 拇指反复掐食指侧面 |
| 焦虑 | 指甲掐进掌心 / 手不停地翻口袋找东西（其实没有） / 把纸杯捏瘪了 |
| 愤怒（克制） | 手背上青筋凸起 / 拳头握了又松，松了又握 / 手指敲桌面的频率越来越快 |
| 愤怒（爆发） | 一掌拍在桌上，杯子弹起来 / 把手里的东西摔在地上 / 手背撞上墙 |
| 害怕 | 手指冰凉，去握另一只手取暖 / 手抖得拧不开瓶盖 / 手本能地去抓身边能抓的东西 |
| 心动 | 手指碰到对方时缩回去 / 倒水时手抖了一下，水洒出来 / 不自觉地去碰对方碰过的东西 |
| 心死 | 手垂在身侧，一动不动 / 把正在做的事做完，动作很慢很慢 / 手从对方手里抽走 |
| 决绝 | 手掌在桌上摊平，按了一下站起来 / 把钥匙/信物放在桌上，手收回 / 手搭上门把手不再犹豫 |
| 心虚 | 手背在身后（藏起来） / 手指绞在一起 / 摸鼻子、摸后脑勺 |
| 放松 | 手指松开握了很久的东西 / 手掌摊开放在腿上 / 随手拿起东西把玩（不焦虑地） |

#### 眼与视线

| 情绪 | 身体细节 |
|---|---|
| 紧张 | 眨眼频率变快 / 视线在对方脸上飘，定不住 / 盯着一个不重要的地方看（桌角、地板缝） |
| 心虚 | 说话时移开视线 / 被追问时眼神先躲再回来 / 看什么都行，就是不看对方的眼睛 |
| 害羞 | 视线碰到对方就弹开 / 睫毛垂下来，盯着自己的鞋尖 / 被注视时耳根先红 |
| 愤怒（克制） | 眼睛不眨，死死盯着 / 瞳孔收缩，目光变窄 / 视线从对方脸上移开，看窗外 |
| 震惊 | 眼睛定住不动，像没对焦 / 眨了两下才回过神 / 眼睛睁大但嘴巴还没来得及张 |
| 心动 | 视线追着对方走，移开又移回来 / 看对方的时候嘴角不自觉上翘 / 对方不看自己时才敢看 |
| 心死 | 眼睛是空的，看什么都不聚焦 / 视线落在某个固定的地方，很久不挪 / 不抬眼看说话的人 |
| 哀伤 | 眼眶发热但眼泪没掉下来 / 视线模糊，看东西要眨两下才清楚 / 闭眼，很久不睁开 |
| 警惕 | 眼睛先扫一遍全场再落到说话人身上 / 余光一直在动 / 视线锁定门口或窗户（逃生路线） |

#### 呼吸

| 情绪 | 身体细节 |
|---|---|
| 紧张 | 呼吸变浅变快 / 说完一句话要咽一下口水 / 屏住呼吸，等对方反应 |
| 愤怒 | 呼吸变粗变重 / 鼻翼张合 / 深吸一口气压住，呼出来时带着颤 |
| 害怕 | 呼吸卡住，像忘了怎么喘 / 短促地喘了两下才找回节奏 / 不敢出声，用嘴呼吸 |
| 悲伤 | 呼吸一抽一抽的，像在忍哭 / 长出一口气，肩膀塌下来 / 呼吸很慢很轻，像怕惊动什么 |
| 放松 | 长长地呼了一口气 / 呼吸节奏变均匀 / 叹气，但嘴角带笑 |
| 决绝 | 深吸一口气，像要跳水 / 屏息一秒再开口 / 呼吸稳下来，整个人静了 |

#### 肩背与姿态

| 情绪 | 身体细节 |
|---|---|
| 紧张 | 肩膀耸起来，缩着脖子 / 背挺得很直，僵着 / 身体微微前倾，像随时要跑 |
| 防御 | 双臂抱在胸前 / 身体后仰，拉开距离 / 肩膀内扣，把自己缩成更小的目标 |
| 释然 | 肩膀一下子塌下来 / 背靠上椅背，整个人放松 / 脖子往一边歪，终于不绷着了 |
| 倔强 | 脊背挺直不动摇 / 下巴抬起来 / 肩膀端着不肯松 |
| 心死 | 肩膀慢慢垮下去 / 整个人像泄了气，缩在椅子里 / 背弯下去，不再挺直 |
| 威慑 | 身体微微前倾，进入对方空间 / 肩膀打开，占据更多空间 / 不动，但存在感压过来 |

#### 嘴与面部微表情

| 情绪 | 身体细节 |
|---|---|
| 嘴硬 | 嘴唇抿成一条线 / 咬住下唇 / 下巴绷紧 |
| 想哭但忍着 | 嘴角往下拉又强行拉平 / 喉结上下动了两下 / 鼻翼抽动 |
| 不屑 | 嘴角一边翘 / 从鼻子里哼了一声 / 眼皮都没抬 |
| 惊讶 | 嘴张开又闭上 / 嘴唇动了动但没出声 / 下巴微张 |
| 强颜欢笑 | 嘴角上扬但眼睛没笑 / 笑到一半僵住 / 笑容挤出来，下一秒就垮 |
| 心动 | 咬住嘴唇偷笑 / 嘴角压不住地翘 / 舌头舔了一下下唇（不自觉） |

#### 脚与下半身

| 情绪 | 身体细节 |
|---|---|
| 想走 | 脚尖朝向门口 / 身体重心前移到脚掌前部 / 频繁换脚站 |
| 坐立不安 | 脚在地上点 / 腿抖 / 在椅子上挪来挪去 |
| 僵住 | 脚像钉在地上 / 腿一软 / 膝盖发抖 |
| 决绝 | 站起来的动作很快很干脆 / 脚步没有犹豫，朝一个方向走 / 步子比平时大 |
| 心虚 | 往后退了半步 / 脚往椅子底下缩 / 站着不动但脚尖朝向出口 |

### 使用与修订

- 先问动作提供了什么；没有作用的细节合并或删除，不要求改写成另一种身体动作。
- 表格仅供找思路，不是特定情绪必然产生的反应。以本书人物习惯、当前知识和关系为准，
  不套“老农不会摸杯沿”“强者不会流泪”等身份模板。
- 不限定每段身体部位数量，不要求手→眼→呼吸轮换；重复次数不是失败证据。
  同一次点头可以是确认，不同回合的点头也可能标志退让，须看功能。
- 动作后果影响后续时写清；不把每个微动作扩成起手、过程、落点，不为展示手抖凭空添洒茶。
- 情绪可以由一个简洁判断承担，也可以用反应与选择展开，不强制“生理反应+动作+选择”三件套。
- 原有动作自然时可直接保留，不必为了个性化凭空添加道具裂纹、往事或职业习惯。
- 身体细节与内心戏不能替代已授权情节，也不能覆盖作者认可的文风。没有明确损失时不改。
- 对话先确保说话人和关系可读，按 `dialogue.md` 处理；叙述按文风锚的距离与内心戏边界处理，
  不因在对白/叙述域不同而强制变长、变短或补动作。

问题：“她捏紧杯子，又握拳，又捏紧杯子。”若三个动作仅同义表达紧张，保留一个即可，
也可按声线简写紧张；不能默认再添移开视线。反例：她先松开杯子表示接受条件，
听到追加条件又握紧，关系和风险已变，这次重复有作用。

## 二、贯穿道具系统

### 什么是贯穿道具

贯穿道具 = 一个具体物件在全卷或全书中反复出现，每次出现都承载不同的叙事功能，
从「普通物件」逐步升格为「情感符号」。它不是伏笔（伏笔是信息层面的埋收，
见 `foreshadowing.md`），而是情感层面的锚点——道具本身不揭示秘密，但它承载
角色关系和情绪的变迁。

**贯穿道具与伏笔的区别**：
- 伏笔：埋下时无感，回收时恍然（信息层面）。如第一章提到的「一枚旧铜钱」，
  第三十章揭示是信物。
- 贯穿道具：每次出现都有感，但感受在变（情感层面）。如母亲留下的一把旧剪刀，
  第一章是日常工具，第十章是思念的载体，第三十章是决裂时摔碎的象征。

### 三次出现规则

一个贯穿道具至少出现三次，每次承担不同功能。少于三次 = 没有贯穿效果，只是
普通道具。多于七次 = 读者疲劳，道具变成噪音。

| 出现次数 | 功能 | 写法 | 读者感受 |
|---|---|---|---|
| 第一次 | 建立存在 | 自然出场，当普通物件写，不刻意强调。给它一个具体的使用场景。 | 「哦，有这么个东西」 |
| 第二次 | 赋予情感 | 角色在情绪波动时碰到它/用它/看着它。道具开始承载角色的情绪。 | 「这个东西对他有意义」 |
| 第三次 | 升格为符号 | 道具出现在关键转折点（决裂/和解/离别/重逢），它的出现本身就是情绪。 | 「看到这个东西就心疼/燃/暖」 |
| 第四次及以后 | 变奏复现 | 每次出现改变道具的状态（损坏/修复/转手/消失），状态变化 = 关系变化。 | 「东西还在，但人/关系变了」 |

**三次出现的间隔**：
- 第一次到第二次：至少 3 章（让读者先忘记它是个「被安排」的道具，记成普通物件）。
- 第二次到第三次：至少 1 个剧情单元（5-15 章），让情感积累到爆发点。
- 第三次之后的每次复现：间隔一个完整的情绪弧线（参照 `emotional-arc.md`）。

### 物件设计模板

设计贯穿道具时，填以下模板（写进卷纲或角色卡）：

```
道具名称：
外观描述：（一句话，要有辨识度——颜色/材质/磨损痕迹/独特特征）
来历：（谁给的/哪里来的/为什么主角一直带着）
第一次出场（章号）：  功能：日常使用
  场景：
第二次出场（章号）：  功能：情感载体
  场景：
第三次出场（章号）：  功能：情绪符号
  场景：
后续变奏计划：
  - 状态变化1（章号范围）：损坏/修复/转手/遗失 → 对应的关系变化
  - 状态变化2（章号范围）：...
最终命运：保留/损毁/转赠/消失 → 对应的结局含义
```

**设计要点**：
- 道具必须有**物理存在感**：能拿在手里、能看见、能磨损。纯概念性的东西
  （「一个承诺」「一段记忆」）不是贯穿道具，是伏笔或主题。
- 道具的**外观描述要具体**：不说「一个旧怀表」，说「表面有一道裂纹的铜壳怀表，
  指针走的时候会发出嘀嗒声」。具体到能画出来。
- 道具的**来历要有故事**：不是「买来的」（太随意），是「谁在什么时候因为什么
  给的」或「从什么地方带出来的」。来历本身就是一次情感锚定。
- 道具的**最终命运要呼应主题**：保留 = 坚守、损毁 = 失去、转赠 = 传承、消失 = 放下。
  最终命运不能随便安排，要和角色弧线的终点一致（参照 `outline-structure-theory.md`
  的角色弧线）。

### 物件类型速查

不同类型的道具适合承载不同的情感功能：

| 道具类型 | 适合承载的情感 | 典型示例 | 注意事项 |
|---|---|---|---|
| 信物类（赠予物） | 思念、羁绊、承诺 | 旧怀表、玉佩、手编绳结 | 赠予场景要写细，是情感锚定的起点 |
| 日常工具类 | 习惯、陪伴、身份 | 老烟斗、旧剪刀、磨秃的毛笔 | 第一次出场必须当工具用，不当道具写 |
| 武器类 | 力量、传承、宿命 | 旧刀、家传剑、残破枪头 | 武器的磨损/修复 = 角色的成长/代价 |
| 纪念类（遗物） | 失去、遗憾、执念 | 旧照片、遗书、半枚铜钱 | 纪念类道具自带悲伤底色，不适合喜剧 |
| 约定类（信物双份） | 羁绊、重逢、背叛 | 各执一半的玉佩、同款戒指 | 双份道具的「合与分」= 关系的「聚与散」 |
| 禁忌类（不该有的） | 秘密、危险、诱惑 | 暗器、毒药、禁书 | 出场即制造紧张感，适合悬疑/宫斗 |
| 生长类（会变化的） | 时间流逝、成长 | 一盆花、一枚蛋、一封没寄的信 | 道具的物理变化直接映射时间线和成长线 |

**选择原则**：
- 道具类型要与角色核心矛盾匹配。角色矛盾是「被剥夺」→ 选纪念类（遗物）；
  角色矛盾是「被看不起」→ 选武器类（力量证明）；角色矛盾是「被控制」→
  选禁忌类（反抗的象征）。
- 一本书的贯穿道具不宜超过 3 个。多了读者记不住，每个道具的出场次数也不够
  支撑三次规则。
- 贯穿道具与伏笔可以重叠——一个道具既是情感锚点又是信息伏笔（如母亲的剪刀
  既是思念载体，剪刀上刻的字又揭示身世），但两者的回收节奏要分开管理
  （情感回收走三次规则，信息回收走 `foreshadowing.md` 的台账状态机）。

## 三、场景写法三维度揉进

### 为什么场景要揉进三维度

`format-and-structure.md` 管的是「段落怎么断、标点怎么排」，不管「场景怎么写才有
画面感」。很多章节的问题不是格式不对，是场景写得像舞台说明——只有人物在说话和
移动，没有空间、没有时间、没有氛围。读者读完一章，脑子里没有画面，只有对话记录。

好的场景描写把三个维度揉进叙事中，而不是单独拎出来写一段「环境描写」：

- **空间感**：读者知道角色在什么物理空间里，这个空间怎么影响角色的行动和心理。
- **时间感**：读者感知到时间在流逝，场景有开始、有过程、有结束，不是凝固的一瞬。
- **氛围感**：读者被场景的情绪氛围包裹，环境不只是背景，是情绪的一部分。

**核心原则：揉进，不是堆上。** 三维度不是三个独立段落（「先写空间、再写时间、
最后写氛围」），而是拆成碎片织进动作和对话的间隙中。参照 `format-and-structure.md`
的「同一瞬间的发生、感知、反应织在同一段」——场景信息也一样，织进去，不要堆上去。

### 空间感操作指令

空间感 = 让读者建立「角色在什么物理环境里」的认知。不是写一段「这是一个三十平
米的房间，靠墙放着一张床……」的说明文，而是通过角色的行动和感知让空间自然浮现。

**操作指令一：用角色的移动勾勒空间边界**

角色在场景中移动时，顺带交代空间。读者跟着角色的脚步走，空间就建立起来了。

- 错误（说明文式）：房间不大，约二十平米，左边是床，右边是书桌，门口放着鞋架。
- 正确（移动式）：他从门口走到床边，三步。床和墙之间只剩一条窄缝，侧身才能挤过去。

用「几步」「侧身才能过」「伸手就够到」这种以身体为尺度的描述，比平方米数字
更有空间感。

**操作指令二：用角色的感知建立空间细节**

角色注意到的空间细节 = 读者注意到的。角色没注意的，不写。写什么取决于角色
此刻的关注点：

- 警惕的角色进房间 → 先看窗户在哪、门能不能反锁、有没有第二个出口。
- 放松的角色进房间 → 看到沙发就想坐、闻到饭香就走向厨房。
- 紧张的角色进房间 → 注意到对方坐在比自己高的位置、灯光太亮、椅子没有靠背。

同一个房间，不同角色的感知不同——这本身就是人设展示。

**操作指令三：用空间压迫感/开放感传递情绪**

空间不只是背景，它参与情绪。参照 `emotion.md` 的对比原则：

- 压迫场景用封闭空间：天花板低、墙壁近、光线暗、出口远。空间越封闭，压迫感越强。
- 释然场景用开放空间：窗户开着、光线照进来、能看到远处。空间越开阔，释然感越强。
- 对比用法：角色在逼仄空间里被压制了整段，最后推开门走到开阔处——空间的瞬间
  扩大 = 情绪的瞬间释放。

**操作指令四：空间在场景中要一致**

一旦建立了空间布局，角色后续的行动必须与空间一致。不能上一段角色在门口，下一段
突然出现在窗边却没有写移动过程。空间一致性是 `character-consistency.md` 的物理
环境版——不一致 = 读者出戏。

### 时间感操作指令

时间感 = 让读者感知到场景内部的「时间在走」。不是写「时间过去了半小时」
（这是告诉），而是让时间通过场景元素的变化自然显现。

**操作指令一：用环境变化标记时间**

同一个场景内，用环境元素的渐变标记时间流逝：

- 光线变化：阳光从窗户照进来 → 移到地板中央 → 变成橘红色 → 暗下去。
- 温度变化：茶从热变温变凉、烟从长变短。
- 声音变化：外面的车流从密变疏、隔壁的电视从开到关。

这些变化不要单独写成一段，而是揉进角色行动的间隙：

```
他没说话。窗外的光从桌上移到了她的手背上，茶已经凉了。
```

一句话里揉进了时间流逝（光在移、茶凉了）、空间（窗、桌、手背）、情绪（沉默）。

**操作指令二：用节奏控制时间感知**

场景的时间感知不等于真实时间——慢镜头拉长时间，快剪压缩时间。

- 慢镜头（高潮/爆发场景）：一个动作写三拍（手抬起来 → 停在半空 → 落下去），
  三秒钟的事写半页。参照 `emotion.md` 的「大爽点用慢镜头写」。
- 快剪（过场/日常场景）：三天的行程一句话带过，「他在这条路上走了三天，
  鞋底磨穿了一双」。

参照 `format-and-structure.md` 的疏密有别：爽点写密、过场写疏。时间感的控制
也是同理——重要时刻拉长时间感知，不重要时刻压缩时间感知。

**操作指令三：用角色的主观时间传递情绪**

角色对时间的感知受情绪影响——这也是展示而非告诉：

- 焦虑时时间变慢：「等了大概五分钟，像过了一年。」（但不要直接写「像过了一年」，
  写他的动作重复了多少次——「他看了四次表，茶喝了三杯，门还没开。」）
- 专注时时间消失：「他回过神来，窗外的天已经黑了。」
- 恐惧时时间凝固：「那三秒长得像一辈子。」（这句话可以保留，因为它是角色的
  主观感受而非作者旁白。）

### 氛围感操作指令

氛围感 = 场景的情绪底色。不是写「气氛很紧张」（告诉），而是用环境元素和角色
感知让读者自己感受到紧张。

**操作指令一：用五感建立氛围**

氛围通过角色的五感来传递，不要只写视觉。听觉和嗅觉的氛围感比视觉更强：

- 紧张氛围：听到自己的心跳声、闻到铁锈味（血的味道）、嘴里的干燥感。
- 温馨氛围：饭菜的香气、远处的笑声、手指间的温度。
- 压抑氛围：灯光嗡嗡响、空气闷、呼吸不畅、椅子吱嘎作响。

五感不要全写——选一到两个最有氛围感的感觉通道，聚焦写透。五个感官全写 =
堆砌，读者被淹没。参照身体细节的「一次只用一个部位」原则，五感也要聚焦。

**操作指令二：用环境的「不对劲」制造紧张**

氛围感最强的时候不是「描写氛围」，而是「环境出现了一个不该出现的细节」：

- 安静的房间里有一滴水声（哪里来的？）
- 谈话进行到一半，灯闪了一下（谁在门口？）
- 桌上的茶被人动过（有人来过？）

一个反常的环境细节比整段氛围描写更能制造紧张。这种写法与 `hooks.md` 的
悬念制造一脉相承——反常即钩子。

**操作指令三：用环境与情绪的同步/反差**

两种手法，视场景需要选择：

- **同步**：环境氛围与角色情绪一致。角色悲伤时写雨、角色愤怒时写闷热、
  角色绝望时写天黑。环境放大情绪。这是默认手法，大多数场景用同步。
- **反差**：环境氛围与角色情绪相反。角色内心崩溃但窗外阳光灿烂、角色在笑
  但手边的花枯萎了。反差比同步更有冲击力，但不宜多用——一卷用 2-3 次为限，
  用多了变成「为反差而反差」的文艺腔。

**操作指令四：氛围用名词不用形容词**

`anti-ai-style.md` 的 Gate B 要求清扫修饰词。氛围描写也一样——不要用形容词
堆砌氛围（「阴沉的、压抑的、令人窒息的」），用具体的名词和动词：

- 错误（形容词堆砌）：阴暗潮湿的地下室里弥漫着令人窒息的霉味，气氛压抑得可怕。
- 正确（名词动词）：地下室没灯，手机的光照出墙角的霉斑。空气是潮的，吸一口
  觉得肺里沉。

### 三维度揉进的综合示例

以下是一个「三维度揉进」的段落，标注每个维度的操作点：

```
他推开门（空间感：建立入口），走廊比他记忆里的窄（空间感：以身体为尺度），
两侧的灯只亮了一半，有一盏在闪（氛围感：反常细节制造紧张）。他走了十几步
（时间感：用移动标记时间），鞋底踩在水泥地上，回声比脚步声还大（氛围感：听觉
建立空旷感）。走到尽头的时候，走廊里的灯全灭了（时间感+氛围感：环境变化标记
时间 + 压迫感升级），他停了一下（身体细节：警惕的本能反应），手搭上门把手
（身体细节：触觉替代恐惧名词），门是凉的（氛围感：触觉）。
```

注意：这段文字里没有出现「他很害怕」「气氛很紧张」这样的情绪名词和氛围形容词，
但读者能感受到紧张和恐惧。这就是三维度揉进的效果——展示，不告诉。

## 四、开头事件密度指令

### 什么是开头事件密度

`opening.md` 定义了黄金三章的任务（立人、立境、立冲突、立钩子）和前三章的分工
（勾住、加码、兑现）。本节补充一个 `opening.md` 没有量化的问题：**前五章里
应该塞多少事件？**

事件密度 = 单位篇幅内发生的「改变角色处境的事件」的数量。密度太低 = 开头
拖沓，读者弃书；密度太高 = 事件堆砌，读者来不及消化就下一个了。

### 事件密度基准

| 章节范围 | 事件密度基准 | 说明 |
|---|---|---|
| 第 1 章 | 1 个核心事件 + 1 个钩子 | 核心事件 = 主角遭遇的第一个麻烦。一章只做一件事，做透。 |
| 第 2 章 | 1 个核心事件 + 1 个升级 + 1 个钩子 | 核心事件升级（麻烦变大了）或展开（主角开始行动）。 |
| 第 3 章 | 1 个核心事件 + 1 个小结算 + 1 个新麻烦 | 第一个小爽点/小揭晓 + 新麻烦预告（不能只给甜头不给钩子）。 |
| 第 4-5 章 | 每章 1-2 个事件 + 1 个钩子 | 进入正常节奏。事件可以是推进型、关系型、信息型。 |

**事件密度的量化标准**：
- 一个「事件」= 改变角色处境的情节单位（获得信息/遇到敌人/关系变化/做出决定）。
- 对话、环境描写、心理活动不算事件——它们是事件的载体，不是事件本身。
- 第一章的事件数不超过 2 个：一个核心事件 + 一个钩子事件。多了 = 读者来不及
  认人就被告知一堆事。

### 事件密度指令

**指令一：第一章只做一件事**

第一章的核心是「让读者认识主角 + 知道主角的麻烦」。不要试图在第一章里建立
世界观、介绍配角、交代前史、展示金手指——这些是第 2-5 章的事。第一章只做：
主角遭遇麻烦 → 读者认识主角 → 章尾钩子。

参照 `opening.md` 的信息释放顺序：先认人 → 再懂处境 → 然后才轮得到世界。
第一章只到「认人 + 懂处境」。

**指令二：前三章的事件必须环环相扣**

前三个事件不是并列的（三件独立的事），是递进的（一件事引出下一件事）：

```
事件 A（第1章）→ 导致 → 事件 B（第2章）→ 升级 → 事件 C（第3章）
```

如果前三个事件互不关联（第 1 章遇到敌人，第 2 章突然去逛街，第 3 章突然修炼），
读者会觉得「这本书在东写一块西写一块」，没有追读动力。每个事件必须是上一个
事件的后果或升级。

**指令三：每章至少一个「变化」**

参照 `pacing-and-hooks.md` 的「章章有结算」——每章结束时，主角的处境必须与
章首不同（获得了信息/失去了什么/关系变了/处境变了）。如果一章结束主角处境
没变化 = 这一章是过场，该删或合并。

但「变化」不等于「事件」——一章可以只有一个事件，但这个事件必须带来一个变化。
没有变化的事件 = 注水事件（写了一件事但什么都没改变）。

**指令四：前五章禁止纯日常章**

前五章是读者决定追不追的关键窗口。纯日常章（低压生活章）在前五章出现 = 读者
弃书。慢档章（铺垫/羁绊）可以出现，但必须有微型伏笔或信息释放（参照
`reverse-brake.md` 的慢档纪律）。前五章的每章都必须有主线相关的事件在推进。

**指令五：事件之间要有呼吸**

高密度不等于无间隔。两个事件之间要有「呼吸段」——角色消化上一个事件、做出
反应、准备应对下一个事件的过程。呼吸段的写法：

- 角色做一个与事件相关的微动作（检查伤口、整理思路、观察环境）。
- 释放一个环境细节（参照三维度揉进的氛围感）。
- 插入一句对话或心理（但不要长段独白——参照 `dialogue.md` 的「大段独白慎用」）。

呼吸段不超过 200 字。超过 200 字 = 事件之间的间隔太长，节奏断了。

### 事件密度自查

写完前五章后，逐章自查：

```
第X章事件密度自查：
  本章有几个事件？（≤2 为宜，>3 过载）
  核心事件是什么？（一句话能说清）
  这个事件改变了什么？（处境/关系/信息/能力）
  章尾钩子是什么？（能用一句话描述）
  本章事件与上一章事件是什么关系？（因果/升级/并列——并列要警惕）
  本章有呼吸段吗？（事件之间的间隔 ≤200 字）
```

如果连续两章的事件关系都是「并列」（互不关联），说明开头的事件编排出了问题，
需要重新排布——让每个事件都成为上一个事件的后果或升级，形成因果链。参照
`outline-structure-theory.md` 的五幕式因果链：前五章虽然不到一幕，但因果链的
逻辑必须从第一章就建立。

# 情绪设计

连载小说的硬通货不是情节而是情绪：读者追更，追的是「下一章能让我再爽/虐/甜/燃一次」。
情节是骨架，情绪才是血肉。本文件管「情绪怎么设计、怎么落地、怎么不失灵」。

## 情绪单元：蓄积 → 爆发 → 余韵

任何情绪都按三段交付：

- **蓄积**：压力/期待逐步加码。蓄积的长度决定爆发的烈度——压三章的爆发比压一章的爽三倍。
- **爆发**：情绪结算的瞬间（打脸、告白、揭晓、反杀）。爆发的颗粒度要放细：
  大爽点用慢镜头写，一个动作一个反应地给。
- **余韵**：爆发后的反应层（旁观者的态度、主角的回味、局势的变化）。
  余韵是爽感的放大器，也是钩子的落点——很多书「爽是爽了但看完就忘」，就是少了余韵。

章级有小曲线，卷级有大曲线。卷纲的「情绪弧线」字段就是卷级曲线的落点。

## 对比原则：情绪靠反差供电

- 爽前必压：没有前面的憋屈，就没有后面的解气。压要压得具体（具体的人、具体的羞辱），
  不能用旁白概括「他受了很多委屈」。
- 甜前必虐/必隔：糖的价值由之前的距离感决定。
- 揭前必迷：揭晓的快感来自此前的困惑蓄积。
- 燃前必挫：逆袭的力度 = 低谷的深度。

写大情绪节点前先问：我为这个爆发蓄积够了吗？没蓄够就爆发的情绪是哑炮。

## 情绪的写法：给形状，不给名词

- 禁写情绪名词（「他很愤怒」「她心头一暖」），改写**生理反应 + 动作 + 选择**：
  愤怒是捏紧的拳和突然变慢的语速，心动是移开又移回来的视线。
- 情绪要有「专属细节」：同一人的同一种情绪，每次给不同的具象，避免复读
  （第三次「眼眶一热」就是流水账）。
- 大情绪场景少用感叹号：感叹号是作者替读者激动，越多越冷静不下来的是读者。

## 预期管理：承诺 → 延迟 → 兑现

- 开篇和卷首都在对读者「承诺」（这本书会给你什么）。承诺要早、要具体。
- 兑现要延迟：立刻兑现的承诺没有张力，延迟期间的每一次「快要得到又差一步」
  都在给最后的爆发充电。
- 兑现必须**比预期多半分**：读者等三章的打脸，不能只是「打脸成功」，
  要附带一个预期之外的收益或反转。半分即可，过一分则假。

## 防麻木：情绪要换台

- 同一种情绪连续供应三章以上，读者的感受阈值会钝化——爽连着爽就不爽了。
- 解法是换情绪类型：爽之后接一段暖或悬，虐之后给一点甜或笑。
  情绪交替 = 章节之间的呼吸。
- 卷级同理：一整卷纯高压或纯甜宠都会流失读者，卷内要有情绪类型的配比意识。

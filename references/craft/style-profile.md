# 文风协议：整书级视图（style-profile）

`style-fingerprint.md` 是六维量化方法——用 `style_fingerprint.py` 脚本提取句长/对话比/
段落长度/标点节奏/高频词/句式偏好的确定性数值，管「怎么测量」。本文件是**整书级文风
视图的产出协议**——管「测量完怎么产出一份可用的文风档案，怎么用于写作校准和迁移」。

两者关系：`style-fingerprint.md` 是工具层（输入章节文本，输出六维数值），本文件是
协议层（输入六维数值+模型分析，输出整书级文风视图 `文风.md`）。

作者本轮明确决定与认可样段高于统计、对标及通用技巧。文风档案应区分叙述者声线与角色声线：
前者包含人称、叙事距离、内心戏和判断方式；后者按人物目的、知识及关系语境观察。
少量样段仍可作为作者选择的声线依据，样本量限制的是统计可信度，不是否决作者偏好。
无样段时记录明确要求与待观察项，不虚构批准，也不阻断无依赖的规划或已具备条件的正文。

## 产物结构

**产出文件**：`对标/{书名}/文风.md`（对标书拆文产出）或 `设定/文风锚.md`（本书文风锚）。

本书锚使用 `assets/templates/style-anchor.md`，记录作者认可依据、样段出处、受保护特征、
明确禁令、叙事距离及内心戏边界。下列拆文视图仅作分析参考，不替代这些手工契约。
`style_fingerprint.py extract` 输出独立指纹文件；`style_library.py apply` 只指向工程外临时候选目录，
人工合并认可指标，不直接生成/覆盖既有本书锚。不在章事务 stage 中改设定。

**硬上限**：~4000 字。文风视图是写作时的快速参考文档，不是文风论文——超过 4000 字
= 检索成本过高，写作时懒得读。精炼优先于详尽。

`文风.md` 的完整结构如下：

```markdown
# 文风视图（{书名}）

## 元数据
- 数据样本量: {字数}
- confidence: {high/med/low}
- 覆盖章节: 第X章-第Y章

## 一、整体语感
[量化数据 + 定性描述]

## 二、对话技法
[潜台词模式 / 对话标签习惯 / 角色语气区分]

## 三、情绪交替模式
[章内基调切换频率 / 跨章基调周期 / 喜剧↔重击转场手法]

## 四、可借鉴技巧
[实际有依据的技法，每条配原文位置，不凑数量]

## 五、可借鉴结构
[适用本书的结构与限制，不强制迁移]

## 六、分层模仿建议
[表达观察 / 结构参考 / 按作者契约适配]

## 七、原文锚点片段
[足以支持分析的必要节选，标出处、功能与适用范围]
```

## confidence 标注规则

文风视图的可靠性取决于数据样本量。样本太少时，量化数据不可信，定性分析也是空中
楼阁。因此每份文风视图必须标注 confidence 等级：

| 等级 | 数据样本量 | 含义 | 使用建议 |
|---|---|---|---|
| high | >= 5000 字 | 数据充分，结论可信 | 可直接用于文风校准和迁移 |
| med | 2000-5000 字 | 数据基本够用，部分结论需谨慎 | 量化数据可用，定性分析标 `[样本有限]` |
| low | < 2000 字 | 数据不足，结论仅供参考 | 仅作方向性参考，不可作为校准基准 |

**计算方法**：数据样本量 = 参与 `style_fingerprint.py extract` 的所有章节文本总字数
（中文字符计，不含标点空格）。

**纪律**：confidence 为 low 的文风视图不能用于文风迁移——样本不足时迁移的是噪声不是
特征。low 级视图只标注方向性观察（如「对话偏多」「句式偏短」），不给出具体数值容差。

## 一、整体语感

**数据来源**：`style_fingerprint.py extract` 的六维量化结果。

**产出内容**：
- 句长分布：平均句长 + 分布区间（短句占比/中句占比/长句占比）。
- 对话占比：对话内容占总字数比例 + 与同平台均值的偏差。
- 段落中位长度：段落字数中位数 + 长段/短段比例。
- 标点节奏：问号/感叹号/省略号/破折号各自的使用频率。
- 高频词 Top20：前 20 个高频实词 + 标注哪些是题材专属词、哪些是作者口头禅。
- 句式偏好：长短句交替比 + 段首词分布。

**定性描述**：在量化数据基础上用 2-3 句话概括整体语感。例如：「短句为主（均长 14
字），对话占比偏高（52%），段落短小（中位 35 字），标点节奏偏快（感叹号 4.2%），
整体语感是快节奏、口语化、手机阅读友好。」

**confidence 标注**：量化数据全部标注来源样本量。样本量不足 5000 字的维度标
`[样本有限]`。

## 二、对话技法

**数据来源**：模型分析（非脚本量化）。

**三个子维度**：

1. **潜台词模式**：角色说 A 但意思是 B 的频率和手法。标注典型模式：
   - 反话正说（嘴上说不在意，行为上很在意）
   - 顾左右而言他（回避型潜台词）
   - 言此意彼（用一件事暗示另一件事）
   每种模式配 1-2 个原文位置标注。

2. **对话标签习惯**：作者用什么方式标记谁在说话：
   - 「说」类标签的频率（他说/她道/问）
   - 动作替代标签的频率（他放下茶杯：「...」）
   - 无标签对话的频率（靠上下文推断说话人）
   标注作者的偏好模式。

3. **角色语气区分**：不同角色的说话方式是否有区分度：
   - 区分度高：每个角色有独特的词汇偏好/句式习惯/语气词
   - 区分度中：主要角色有区分，次要角色趋同
   - 区分度低：先看是否相同处境、普通短答或作者有意风格；只有目的/知识/关系差异被抹平才判问题

## 三、情绪交替模式

**数据来源**：模型分析 + `deconstruct-pipeline.md` Stage 3 的情绪节奏曲线交叉验证。

**三个子维度**：

1. **章内基调切换频率**：一章内情绪基调切换几次。高频切换 = 节奏跳跃；低频切换 =
   沉浸连贯。标注典型章的切换次数和切换手法。

2. **跨章基调周期**：跨章的情绪基调变化周期。如「3 章爽→1 章暖→2 章悬→1 章燃」
   的循环模式。周期是否规律、规律周期的长度。

3. **喜剧↔重击转场手法**：从轻松场景转入沉重场景（或反向）的转场手法：
   - 硬切：场景直接切换，不做过渡
   - 软转：用一个细节/一句话做过渡桥
   - 反差并置：喜剧和重击放在同一段落内对比
   标注作者偏好的转场手法。

## 四、可借鉴技巧

从实际文本提取有依据的具体写法技巧，不凑固定数量。每条可用：

```
[编号] {技巧名}
  技法描述: {1-2句话说明怎么做的}
  原文位置: 第X章 第Y段
  为什么有效: {1句话说明效果机制}
  怎么用: {1句话说明迁移到本书的用法}
```

按文本实际特点选取，不为覆盖类别补没有证据的技巧。

## 五、可借鉴结构

提取适用本书且有证据的结构，比句式技巧更宏观。每条可用：

```
[编号] {套路名}
  结构描述: {套路的骨架，如「铺垫2章→压制1章→反转半章→余韵1章」}
  适用场景: {什么类型的高潮/转折适合用这个套路}
  原文位置: 第X-Y章
  迁移注意: {用在自己书上时需要调整什么}
```

套路与 `deconstruct-pipeline.md` Stage 3 的可复现模块卡呼应——模块卡是完整的情绪
模块拆解，本节仅提炼实际适用的部分。

## 六、分层模仿建议

**三层结构**（从易到难，逐层递进）：

### 基础层（表达观察）

**内容**：句式/标点/对话标签。

**执行**：
- 句式：观察长短句怎样组织思考与行动，不按平均句长或交替比例改句。
- 标点：观察打断、停顿和语气的功能，保留本书获认可的破折号、省略号等，不追频率。
- 对话标签：确认说话人是否清楚，普通“说”可保留，不按配比改成动作。

**校准方法**：用 `style_fingerprint.py compare` 对比本书新章与文风视图的六维数据，
偏离仅供复核；短摘录能证明功能受损才最小修复，不能只因统计超出就回调。

### 进阶层（结构）

**内容**：叙事手法/情绪交替。

**执行**：
- 叙事手法：学习对标书的视角切换频率、信息投放节奏、场景过渡方式。
- 情绪交替：观察转调如何发生，在本书作者授权、章纲和配额内选择，不套固定周期。

**校准方法**：每 10 章回看本书的情绪交替模式，与对标书的情绪交替模式对比，偏差大
时检查原因；有意保持长内心戏或平静日常可保留，不能只因偏差大而改。

### 适配层（本书化）

**内容**：结合本书题材调整。

**执行**：
- 对标书的文风特征中，哪些适合本书题材、哪些不适合，需逐一判断。
  例：对标书是都市爽文，句式极短、标点极快；本书是悬疑，需要更长的沉浸句和更克制
  的标点。基础层对齐句式，适配层调整为悬疑节奏。
- 对标书的高频词是都市题材专属（「公司」「合同」「总裁」），本书不能照搬，需替换
  为本书题材的高频词。

**纪律**：适配层的核心原则是「迁节奏不迁词汇，迁结构不迁内容」。照搬词汇 = 抄袭。

## 七、原文锚点片段

**选取标准**：选足以支持判断的必要节选，注明出处。以下类型可按需选择，不按数量补样段：

| 类型 | 选取标准 | 用途 |
|---|---|---|
| 典型对话段 | 能代表该书对话技法的段落 | 写对话时对齐 |
| 典型动作段 | 能代表该书动作描写手法的段落 | 写动作时对齐 |
| 典型情绪高潮段 | 全书情绪爆发力最强的段落之一 | 写高潮时对齐 |
| 典型转场段 | 场景/情绪切换最流畅的段落 | 写转场时对齐 |
| 典型描写段 | 环境/人物描写最出彩的段落 | 写描写时对齐 |
| 典型节奏段 | 节奏控制最精准的段落（快慢切换） | 写节奏段时对齐 |

每段标注：
- 片段类型（上述六类之一）
- 原文位置（第 X 章第 Y 段）
- 锚点说明（这段为什么是典型，要学什么）

**版权纪律**：原文锚点片段仅存于 `对标/{书名}/文风.md`，供本书作者写作参考，不外传、
不公开。与 `deconstruct.md` 的拆文纪律一致——拆文产出只供本书参考。

## 与写作循环的关系

文风视图在写作循环中的使用时机：

| 写作阶段 | 读取文风视图的哪个部分 |
|---|---|
| 开书前（文风锚建立） | 整体语感 + 基础层模仿建议 |
| 写章纲前 | 情绪交替模式（章内/跨章基调） |
| 写对话时 | 对话技法 + 典型对话段锚点 |
| 写高潮时 | 典型情绪高潮段锚点 + 适用结构 |
| 每 5-10 章文风校准时 | 整体语感量化数据 + `style_fingerprint.py compare` |

**最小上下文原则**：不全量读文风视图——按需召回对应部分。写对话时只读对话技法和
对话锚点段，不读情绪交替模式。全量读 = 上下文浪费。

## 文风纪律

- 文风视图的 confidence 必须如实标注，low 级视图不用于迁移。
- 原文锚点片段不外传，版权红线不可碰。
- 迁移的是「节奏感」和「句式结构」，不是「词汇」——照搬词汇 = 抄袭。
- 文风视图不是一成不变的：对标书拆完产出后固定不变，但本书的 `设定/文风锚.md` 每
  5-10 章校准一次，允许在容差内自然演化（作者文风有意转变时更新锚）。
- 文风视图与 7 Gate（`anti-ai-style.md`）互补，但机器通过不证明文学质量，报警也不自动
  推翻作者声线。B/G 误报按真实授权做精确豁免，不能豁免作者禁令、事实或其他硬门禁。

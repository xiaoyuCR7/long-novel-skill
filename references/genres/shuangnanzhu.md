# 双男主 题材卡

## 读者契约

读者来看「两个势均力敌的男人之间的张力」——并肩、试探、救赎、互为唯一。
必须持续兑现：双强各自立得住（没有一方沦为挂件）、对手戏有来有回、
情感推进有层次（戒备→欣赏→信任→唯一）。一切剧情都要能折算成
「这两个人的关系又进了一步」。

## 爽点类型

- 主爽点：联手破局（各展所长的高光配合）、为对方破例/挡刀、
  「全世界只有他懂他」的唯一感时刻。
- 次爽点：初遇交锋的火花、误会解除后的关系升级、第三方视角的「他们俩」议论。
- 释放节奏：张力要「七分剧情三分情」——情从并肩作战里长出来，
  不靠内心独白喊出来。连续两章无对手戏=读者流失。

## 冲突发动机

立场差/身份差 × 共同敌人/共同目标 × 各自的秘密。最耐用的结构：
先是对头或陌生人，被同一个局/案子/使命捆在一起，在合作中层层剥开对方的
秘密与真心。

## 节奏规范

- 单章：案情/危机推进 → 双主角各出一手 → 关系微进展 → 新悬念，四拍齐全。
- 前期（约前 50 章）：相遇-结梁子-被迫绑定，交锋戏要写出火花（谁都不让谁）。
- 中期：副本/案件单元制推进，每个单元剥一层对方的秘密；信任逐步建立，
  误会制造波澜但不过夜太久。
- 后期：共同面对终极反派/真相，互为底牌，关系落定（按平台尺度收）。
- 红线：双强不能瘸腿。一方长期被压着打/当保姆 = 人设崩。

## 场景颗粒与正文落点

- 颗粒：依主线题材定（悬疑线的案发现场/权谋线的朝堂/电竞线的训练室）；
  双主角的「信物级」物件（一把伞、一杯酒、一句口头禅）要反复使用。
- 落点：开场落在交锋或被迫同处的现场；冲突落在「立场对立但不得不合作」；
  结尾落在对方露出破绽（秘密的一角）、共同危机降临。

## 对话与声线

对手戏是灵魂：互怼要带欣赏，试探要带分寸；两人的语言风格必须有区分度
（一个毒舌一个冷淡/一个跳脱一个持重）。禁忌：内心戏替代对手戏
（「他好像有点在意他」不如写一次回护的动作）。

## 成长体系

人物卡「能力」字段 = 各自的专业/武力项（互补设计）+ 关系进度条
（戒备→合作→信任→唯一）+ 各自的秘密与解锁进度。两位主角各建一张人物卡，
关系进度在角色状态文件里双人各记一笔。

## 常见雷区与禁止漂移

- 一方挂件化：双男主变「大男主+跟班」。
- 误会靠不说人话硬撑：高智商人设犯低级沟通错误 = 崩人设。
- 互动全靠巧合：每次相遇都是碰巧 = 作者偷懒，要给「不得不一起」的硬理由。
- 发糖代替剧情：糖要长在剧情骨头上，纯发糖三章就腻。
- 尺度把握：按目标平台的尺度写（番茄/晋江差异极大），越界会被下架。

## 平台适配要点

- 番茄：走「兄弟情+强剧情」路线，悬疑/权谋/电竞主线扛大梁，情感线含蓄。
- 起点：非主场。
- 晋江：主场（纯爱频道），情感线可明写；无限流/悬疑/古风权谋变体都吃香。

## 开篇要点

前三章必须完成：①两位主角先后立住各自的高光（各一场单人戏）；
②两人相遇即交锋（立场/利益冲突具体化）；③被迫绑定的硬理由落地
（同一个案子/任务/诅咒），并埋第一条「对方不简单」的伏笔。

## 专属禁用词


## 依据

经验综合（晋江纯爱与番茄双男主高分作品共性拆解），置信度：中——双男主的
平台尺度与读者偏好迭代快，开书时建议先确认目标平台的现行尺度规范。
修订方法：每次拆该题材对标书后回写本卡「对话与声线」与「平台适配要点」。

# 女频言情 题材卡

## 读者契约

情感体验优先：读者要的是心动、拉扯、被偏爱，以及女主作为独立个体被看见、被珍视。
CP 的化学反应是生命线，女主的主体性是底线——她可以爱人，不能没了自我。

## 爽点类型

- 主爽点：心动瞬间（细节杀）、明晃晃的偏爱（双标、破例、唯一性）、误会解除的释然、
  女主成长被看见的高光。
- 次爽点：情敌/阻挠者的挫败、追妻火葬场阶段的「他追她逃」、事业线的独立成就。
- 释放节奏：糖与刀交替。纯糖三章即腻，纯刀三章即弃；每个情感节点（初遇→心动→
  误会→拉扯→确认）都要给读者明确的位置感。

## 冲突发动机

情感内部的阻力永远大于外部事件：身份差、立场对立、误会与信息差、旧伤与心防、
家族与世俗压力。外部事件的价值在于「逼出真心」，不为事件而事件。

## 节奏规范

- 单章：一个情绪点（一次心动、一次失落、一次试探），情绪要有起有落。
- 前期：快速立住女主人设与 CP 张力，第一次「不一样」要早。
- 中期：拉扯期是主体但不可失控——误会要靠性格与立场驱动，不靠「不说人话」硬拖；
  拉扯超过一个单元（约 10–15 章）必须推进一次关系质变。
- 后期：外部阻力总爆发 + 情感确认，双线收束；婚后/在一起之后仍有戏（共同面对）。
- 红线：女主的自我成长线与感情线并行，任何一条线长期停摆都会流失读者。

## 场景颗粒与正文落点

- 颗粒：肢体微反应（指尖蜷起、耳尖发红）、眼神交汇与错开、空间距离的缩短与拉远、
  信物与礼物、 repeated detail（他记得她随口说过的话）。
- 落点：开场落在女主的处境与性情展示；冲突落在「想靠近又不得不退」的拉扯点；
  结尾落在情绪余韵或关系变局。

## 对话与声线

双主角声线必须可区分：遮住名字也能认出谁在说话。潜台词即调情——说的和想的错位
才有张力。少解释、多动作：让行为替台词表态。配角（闺蜜、长辈、情敌）各有其声。

## 成长体系

人物卡「能力」字段 = 身份/处境 + 事业或技能线 + 情感阶段（陌生→在意→心动→确认）+
心防与旧伤。成长 = 情感阶段推进 × 自我成长线，两条线各自记账。

## 常见雷区与禁止漂移

- 女主恋爱脑失智：为爱放弃判断力与人格，当代读者直接弃书。
- 男主油腻/爹味：以「为她好」之名行控制之实，没有尊重打底。
- 误会靠不说人话：一句话能解释的误会拖三十章。
- 雌竞工具人：女性配角全员工于心计抢男人。
- 情绪流水账：只写「她很难过」不给难过具体的形状。

## 平台适配要点

- 晋江：主主场。收藏与榜单驱动，文案（简介）权重极高；CP 互动与人设是留读核心；
  审核红线严格，敏感题材先查规则再动笔。
- 番茄女频：甜宠、马甲、闪婚等强梗快节奏品类，开篇即高浓度情绪，章短钩密。
- 起点女频：偏成长线较重的言情（大女主、事业型），感情线可以慢热但女主格局要大。

## 开篇要点

前三章必须完成：①女主人设立住（性情、处境、她要什么）；②男女主初遇或重逢，
且第一次见面就有「不一样」的张力；③这本书的情感基调亮明（甜/虐/爽/暖）。

## 专属禁用词

开书时把下列词汇拷入书籍工程的 `设定/禁用词.txt`（机器闸口自动加载）：

```
心里咯噔一下 邪魅一笑 宠溺一笑 小东西 小野猫
```

说明：以上是「咯噔文学」「油腻腔」高频套话；甜要靠具体细节供电，不靠这类现成符号。

## 依据

本卡为类型常识与公开创作方法论的综合（截至 2026 年），未经样本量化。
校准方法：拆 3–5 本同题材对标书的前/中/后段，统计爽点分布、段落特征与对话占比
（可用 `scripts/check_text.py --style-stats` 量化），据此修订本卡参数。

## 正文层规范（九件事）

> 以下九件事与上方 12 栏目互补：12 栏目管「写什么」，九件事管「怎么落笔」。两者一起读。

### 1. 题材核心

被偏爱、被看见、被珍视——以及拉扯到极致后确认的释然。

### 2. 主线目标

**守护（双向）。** 主线的终点不是「打败谁」，而是「两个人的关系确认与互相守护」。
具体目标会换（从心动→确认→磨合→共同面对），但目标类型始终是「情感归处」。
副目标常有「女主自我成长/事业独立」，且与感情线并行，不互相吞噬——任何一条线
长期停摆都会流失读者。

### 3. 冲突发动机

情感内部的阻力永远大于外部事件：身份差、立场对立、误会与信息差、旧伤与心防、
家族与世俗压力。**续杯方式**：外部事件的价值在于「逼出真心」——每解决一个外部阻力，
就会暴露出更深层的一层情感内部阻力（从身份差→心防→信任→价值观冲突），主角间的关系
在阻力中逐层推进。外部事件不为事件而事件，必须服务于「逼出真心或逼出裂痕」。
发动机不停机的关键：误会要靠性格与立场驱动，不靠「不说人话」硬拖。

### 4. 爽点定位

- 主选：**收获感**——心动瞬间、明晃晃的偏爱、被看见的高光，读者「收割」情感回报。
- 次选：**掌控感（女主侧）**——女主在感情中保有主动权与主体性，不被动等待。
- 辅助：**逆袭感**——追妻火葬场阶段的「他追她逃」、情敌/阻挠者的挫败。
- 注意：糖与刀交替——纯糖三章即腻，纯刀三章即弃；爽感建立在拉扯的张力之上，
  不建立在无脑宠之上。

### 5. 常见情绪转化

**期待 → 拉扯 → 释然（或：委屈 → 偏爱 → 安心）。**
- 甜线：期待 → 心动 → 满足 → 新期待。
- 刀线：委屈/失落 → 误会加深 → 偏爱兑现 → 释然。
- 每个情感节点（初遇→心动→误会→拉扯→确认）都要给读者明确的位置感：
  「这一段在甜还是在刀，读者知道自己在哪一站」。
- 红线：一个场景起于某种情绪、终于同一种情绪（如整章都是「她很难过」）= 情绪流水账，
  这段往往无效。

### 6. 场景颗粒

- 情感细节：细到肢体微反应（指尖蜷起、耳尖发红、呼吸停顿、眼神交汇与错开）、
  空间距离的缩短与拉远——细节杀是言情的生命线，但不细到生理学描写。
- 信物与礼物：细到 repeated detail（他记得她随口说过的话、某个习惯），用重复的细节
  制造「被看见」的偏爱感。
- 对话：潜台词即调情——说的和想的错位才有张力；少解释、多动作，让行为替台词表态。
- 事业线：细到具体的职业场景与成长节点，不写成背景板。
- 红线：「心里咯噔一下」「邪魅一笑」等现成符号替代真实细节 = 咯噔文学，甜靠具体供电。

### 7. 正文落点

每章至少落一个，关键情感节点章可叠两个：
- 情绪落点：心动后的「甜」、误会后的「虐」、偏爱兑现后的「暖」、拉扯中的「揪心」。
- 信息落点：男主的某个侧面揭露、女主的旧伤线索、关系阶段推进的信号。
- 悬念落点：误会埋下、第三者介入信号、身份/立场冲突即将爆发、旧人登场。
- 关系落点：陌生→在意→心动→确认→磨合，每章关系发生一档位移。
- 常用组合：甜章落在「情绪落点 + 关系落点」（甜且推进了关系）；刀章落在
  「情绪落点 + 悬念落点」（虐且埋下了钩）。

### 8. 前中后期打法

- **前期（1–50 章）**：
  - 建立：女主人设（性情、处境、她要什么）、CP 张力、情感基调（甜/虐/爽/暖）。
  - 展示：第一次「不一样」要早，心动瞬间连给 3–5 次，让读者确认「对，这对 CP 我嗑」。
  - 压住：男主的真实身份/真实心意/某段过往，前期只露端倪，留作中后期爆发；
    女主的事业线与自我成长线同步建立，不只在恋爱里打转。
- **中期（51–200 章）**：
  - 转换：从「心动确认」转向「拉扯与磨合」——误会与立场对立是主体，但拉扯超过
    一个单元（约 10–15 章）必须推进一次关系质变，不靠「不说人话」硬拖。
  - 升级：阻力从「身份差/误会」升级到「价值观冲突/旧伤/家族」更深的层面；
    女主成长线与感情线同步推进，互相喂养。
  - 引入：新的人物（情敌/旧人/第三方）和新的事件，但必须服务于「逼出真心或逼出裂痕」。
- **后期（200+ 章）**：
  - 兑现：前期压住的男主真实心意/身份/过往逐一揭晓，所有伏笔回收。
  - 收束：外部阻力总爆发 + 情感确认，双线收束；在一起之后仍有戏（共同面对、磨合、
    成长），不「在一起即结局」。
  - 升华：从「两人在一起」升华到「互相成就、各自完整」——让结局有余味而非
    「婚礼落幕」式的套路收尾。

### 9. 禁止漂移

最容易漂移到**事业爽文/大女主升级流**——女主变成大女主事业线主导，感情线失重。
防止手段：
- 占比红线：CP 互动与情感戏不低于全书 40%，事业线是女主成长的支线而非主线替代。
- 回拉机制：连续 3 章纯事业无 CP 互动或情感推进，必须用一个情感核心场景
  （心动、拉扯、偏爱兑现）回拉。
- 自检问题：每卷自问——「这卷 CP 关系推进了几档？读者嗑到了几口？女主成长线
  和感情线是否都在走？」

次级漂移：漂移到**雌竞宅斗**——女性配角全员工于心计抢男人。防止：
女性配角各有其人设与立场，不为「抢男主」存在；冲突靠性格与立场驱动，不靠全员恶人。

再次级漂移：漂移到**误会流水账**——一句话能解释的误会拖三十章。防止：
误会靠信息差与立场驱动，且有「有效期」；同一误会不超过一个单元必须推进或解除。

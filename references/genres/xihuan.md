# 西幻 题材卡

## 读者契约

读者来看「异世界冒险、自洽的魔法体系、种族与文明的碰撞」。西幻卖世界观厚度
与冒险感：法师塔、龙、精灵、神明、领地，每一项都要有可量化的实力与利益逻辑。
成长是硬通货，剧情要能折算成等级、职业、领地或声望的变化。

## 爽点类型

- 主爽点：魔法觉醒/职业进阶、越级反杀、屠龙/弑神、领地建设里程碑。
- 次爽点：种族盟约达成、神器获取、声望跃升、旁观者改口。
- 释放节奏：爽点后立刻垫更高压力（更强的魔兽、更大的势力、神明注视），
  让读者刚松口气又提起心。连续两章无结算=节奏失速。

## 冲突发动机

种族利益 × 魔法资源稀缺 × 势力版图争夺，三选二。金手指（穿越知识/特殊血脉/
系统）提供不对称优势，但必须有明确限制（反噬、知情人风险、信仰代价）。

## 节奏规范

- 单章：受阻 → 应对 → 小结算 → 新压力，四拍齐全；大事件给足铺垫章。
- 前期：快速立住主角的魔法/职业起点与第一个对手，密集安排成长反馈。
- 中期：围绕秘境、领地、势力纷争反复结算，每次胜利绑定实际收益。
- 后期：把个人成长、势力利益、神明意志拉进同一场清算；世界观天花板逐级抬升。
- 红线：不允许无代价升级。每次进阶=准备+代价+见证，三要素缺一不可。

## 场景颗粒与正文落点

- 颗粒：法师塔、冒险者公会、龙巢、精灵森林、领地城堡；魔晶、神器、
  爵位、声望值、职业徽章。设定名词必须挂在具体收益或威胁上出场。
- 落点：开场落在冒险/夺资源/被压制的现场；冲突落在「差一线」的具体缺口；
  结尾落在新地图准入、强敌到场、势力态度变化。

## 对话与声线

身份与种族决定语气：贵族倨傲、法师带术语、精灵疏离、兽人直白。
主角话可少，但开口要给判断或底线。反派有利益逻辑，不为坏而坏。

## 成长体系

人物卡「能力」字段 = 魔法等级/职业阶位 + 主修技能 + 底牌 + 关键装备/领地。
升级阶梯在开书时写死（魔法/职业层级表），正文称呼全书统一。

## 常见雷区与禁止漂移

- 设定灌水：开篇三页讲魔法体系与种族历史，读者直接流失。
- 无代价进阶、连升数级：爽感透支，后续无法制造张力。
- 只有打斗没有收益链：打完没有资源/声望结算，等于白打。
- 西幻皮东方核：套着魔法外壳写修仙爽文套路，违和。
- 全员热血喊话：配角没有自己的立场与算计。

## 平台适配要点

- 起点：西幻有稳定受众，读者吃世界观原创性与体系自洽，可慢热铺体系；单章可长。
- 番茄：非强势品类，除非走轻松冒险/领主建设流，开篇即爽、章短钩密。
- 晋江：西幻言情可走女频（异世界穿越言情），重心在 CP 与冒险，叠加言情卡。

## 开篇要点

前三章必须完成：①主角的魔法/职业起点与第一个对手/困境的具体场面；
②金手指首次显形并给出限制；③明确的第一个缺口与第一个可打脸对象。

## 专属禁用词

开书时把下列词汇拷入书籍工程的 `设定/禁用词.txt`（机器闸口自动加载）：

```
科学 物理 化学 重力 数据 面板 玩家 bug 蓝条
```

说明：本题材正文不得出现现代科学与游戏腔词汇（除非世界观明确含系统/游戏设定）；
穿越者内心吐槽可放宽，对话与叙述语言不放宽。

## 依据

本卡为类型常识与公开创作方法论的综合（截至 2026 年），未经样本量化。
校准方法：拆 3–5 本同题材对标书的前/中/后段，统计爽点分布、段落特征与对话占比
（可用 `scripts/check_text.py --style-stats` 量化），据此修订本卡参数。

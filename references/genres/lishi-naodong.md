# 历史脑洞 题材卡

## 读者契约

读者要的不是正史权谋的厚重，而是「现代人玩转古代朝堂」的乐子。穿越/系统/脑洞是骨架，历史的壳是皮——主角用现代思维把历史走向、朝堂套路、权谋老梗一一拆穿玩坏，读者在「预知历史+反套路操作」里获得解气感和笑点。兑现点：脑洞要持续翻新，每个历史节点都要有新的「玩坏」方式，不能一套玩法用到结局。

## 爽点类型

- 主爽点：历史剧透打脸（主角预知历史走向并提前布局）、反套路操作（把朝堂权谋老梗玩出新解法）。
- 次爽点：历史人物的反差围观（皇帝/权臣/名将被打乱节奏后的反应）、现代知识碾压、废物变王炸。
- 释放节奏：一个历史节点 5–10 章闭环，闭环之间用新历史节点衔接。围观者反应是调味剂，但不可喧宾夺主。

## 冲突发动机

现代知识 × 历史惯性。矛盾来源：朝堂权谋、皇权压制、历史事件的既定走向、旧势力的阻挠。主角的现代知识/金手指给「破套路」的能力，历史惯性给阻力，两者对撞产生冲突。续杯方式：主角每改一个历史节点，时间线推进到下一个历史事件，新的对手和更大的局自动到位。

## 节奏规范

- 单章：一个朝堂局面或一次脑洞变现，章章有信息增量或笑点。
- 前期：快速亮出穿越/金手指，第一个反套路打脸对象（往往是历史反派/权臣）就位。
- 中期：从朝堂扩展到天下/外战，历史进度推进，脑洞玩法升级（从剧透到改写历史）。
- 后期：从「反套路」转向「改写历史走向」，主角开始正面影响大时代，警惕「历史改完没事干」。
- 红线：穿越知识不能剧透太满——留「历史变了之后的未知」才有张力。

## 场景颗粒与正文落点

- 颗粒：金銮殿、朝班位次、奏折、圣旨、军帐、边关、粮草清单、科举考棚；官职品级、俸禄数字、兵力编制。
- 落点：开场落在历史事件即将发生或主角介入朝堂的现场；冲突落在皇权/旧势力的压制；结尾落在反套路即将引爆或新历史节点到来。

## 对话与声线

历史语言要稳（自称、敬语、官职称呼有规矩），但主角的内心独白可以现代吐槽风——这是脑洞历史的语言特色，正经朝堂台词配不正经吐槽，反差即笑点。皇帝说话有帝王腔，权臣说话绵里藏针，武将说话直白。不同朝代语言风格要有别，不能明清腔套到先秦。

## 成长体系

人物卡「能力」字段 = 官职/品级 + 现代知识储备 + 金手指类型与等级 + 势力资源 + 历史进度。成长 = 官职跃迁 + 势力扩张 + 脑洞玩法升级 + 历史改写进度。注意：脑洞历史的成长不只是官职涨，更是「改写历史的程度」涨——从顺应历史到改写历史到创造新历史。

## 常见雷区与禁止漂移

- 历史失真：官制、器物、称谓穿帮，历史的壳一破全破。
- 剧透疲劳：穿越知识把每个历史事件下一步都说透，读者失去悬念，要留「历史变了之后的未知」。
- 脑洞套路化：反套路本身变成新套路（每次都是「提前布局打脸」），需要脑洞翻新。
- 现代知识万能：主角靠现代知识无脑碾压，古代人全是傻子，失去张力。
- 搞笑过头：纯为笑点牺牲历史质感，脑洞文变成段子集，没有正剧的分量托底。

## 平台适配要点

- 番茄：历史脑洞在男频有稳定盘，要求开篇即爽、穿越/金手指三页内亮出；搞笑尺度注意平台红线。
- 起点：穿越历史脑洞有长线空间，读者要求历史考据扎实、脑洞有逻辑自洽性（历史为什么能被改写），可写深。
- 七猫/塔读：轻快脑洞受欢迎，一个脑洞一章引爆，章节短平快。

## 开篇要点

前三章必须完成：①主角穿越的处境（具体、有共鸣点，往往穿成历史炮灰/废柴）；②金手指/穿越知识亮出并展示第一次反套路变现（具体、解气、好笑）；③第一个被反套路的历史人物就位，读者已等着看他被打乱节奏的反应。

## 专属禁用词

开书时把下列词汇拷入书籍工程的 `设定/禁用词.txt`（机器闸口自动加载）：

```
倒吸一口凉气 瞳孔骤缩 不可置信 全场死寂 脸色大变 纷纷变色 龙颜大怒 倒退三步
```

说明：以上是历史文「震惊体」和「朝堂套话」高频词，命中即换具体的反应动作（笏板脱手、茶盏一歪、官帽歪了）。同类新词发现后自行追加。

## 正文层规范（九件事）

> 以下九件事与上方 12 栏目互补：12 栏目管「写什么」，九件事管「怎么落笔」。两者一起读。

### 1. 题材核心

现代人玩转古代朝堂——预知历史+反套路操作，历史的壳配现代的核。脑洞要持续翻新，反套路不能变成新套路。

### 2. 主线目标

**改写历史。** 主角用穿越知识/系统/现代思维，改写既定的历史走向。具体目标会换（活命→翻身→掌权→改写天下），但目标类型始终是「把历史命运踩在脚下」。副目标常有「打脸历史反派/反套路」，但打脸服务于改写历史，不喧宾夺主。

### 3. 冲突发动机

现代知识 × 历史惯性。**续杯方式**：主角每改一个历史节点，时间线推进到下一个历史事件——更高级的对手、更大的局、更深的阴谋永远是下一关。现代知识给「破」的能力，历史惯性给「压」的阻力，主角破一层改一段历史，时间线推进一节，新局自动到位。

### 4. 爽点定位

- 主选：**剧透打脸感**——预知历史走向，提前布局，看反派按历史惯性走然后踩进陷阱。
- 次选：**反套路解气感**——把朝堂权谋老梗（陷害、党争、夺嫡）玩出新解法。
- 辅助：**历史人物围观感**——皇帝/权臣/名将被打乱节奏的反应，是这题材独有的乐趣。
- 注意：围观反应是调味剂，同一批人「震惊」不超过三次。

### 5. 常见情绪转化

**压制 → 脑洞 → 碾压 → 新局。** 主角被皇权/旧势力/历史惯性压制（压制）→ 现代知识或反套路成形（脑洞）→ 提前布局引爆，历史反派踩进陷阱（碾压）→ 历史进度推进，新的事件节点逼近（新局）。四拍循环，注意「碾压」要快、要准、要好笑或解气，拖泥带水就泄气。

### 6. 场景颗粒

- 朝堂：细到朝班位次、奏折用语、官制品级——历史细节即真实感。
- 打脸：围观者的反应要换花样写（皇帝的茶盏、权臣的笏板、武将的刀柄），不反复用「不敢置信」。
- 脑洞：现代知识的运用要具体（用会计查贪腐、用化肥增粮产、用印刷术搞舆论），不能空泛。
- 红线：历史失真——官制、器物、称谓穿帮，历史的壳一破全破。

### 7. 正文落点

每章至少落一个，脑洞引爆章可叠两个：
- 情绪落点：碾压后的「爽」、被压制时的「憋」、脑洞成形时的「期待」。
- 信息落点：历史走向的新一角、反派底牌的一角、系统新功能。
- 悬念落点：下一个历史节点逼近、系统即将进化、反派新阴谋。
- 关系落点：皇帝/权臣态度变化、新盟友登场、旧识反目。
- 常用组合：脑洞引爆章落在「情绪落点 + 悬念落点」（爽完留新钩）；布局章落在「信息落点 + 关系落点」。

### 8. 前中后期打法

- **前期（1–50 章）**：
  - 建立：主角穿越处境、金手指核心玩法、第一个反套路打脸对象。
  - 展示：脑洞变现核心快感连给 3–5 次，让读者确认「这就是我要的味道」。
  - 压住：主角的真实来历/系统的完整形态/历史的深层秘密，前期只露一角。
- **中期（51–200 章）**：
  - 扩展：舞台从朝堂到天下/外战，历史进度推进到中段大事件。
  - 升级：脑洞玩法升级（从剧透到改写历史），主角从「顺应历史」到「改写历史」。
  - 引入：新对手规格升级（从权臣到皇权到外敌），防审美疲劳。
- **后期（200+ 章）**：
  - 兑现：主角真实来历、系统来源、历史的终极秘密逐一揭晓。
  - 收束：从「反套路」升华到「改写历史」，结局要有格局高度。
  - 升华：从「个人改写」到「影响时代走向」，让结局有分量。

### 9. 禁止漂移

最容易漂移到**传统历史权谋**——脑洞文写成正经权谋正剧，金手指沦为辅助，失去反套路乐趣。防止手段：
- 占比红线：脑洞反套路玩法相关内容不低于全书 50%，且打脸胜利必须由反套路驱动而非单纯靠权谋硬刚。
- 回拉机制：连续 3 章纯权谋无脑洞兑现，必须用一个反套路场景（用现代知识破局、用穿越记忆提前布局）回拉。
- 自检问题：每卷自问——「这卷主角的脑洞出新玩法了吗？还是靠权谋硬刚？」

次级漂移：漂移到**系统面板流**——章节变系统日志，主角变任务机器。防止：系统面板出现频率克制，读者要的是反套路结果不是数据流。

# 豪门总裁 题材卡

## 读者契约

读者来看「普通女孩被最高规格地偏爱」+「高不可攀者为她破例」。必须持续兑现：
男主的偏爱可见可感（砸资源/破原则/当众站队）、女主不憋屈（有底气、有还手）、
误会不过夜太久。一切剧情都要能折算成「他有多在乎她」的证据。

## 爽点类型

- 主爽点：当众维护（宴会上打脸羞辱者）、资源碾压（一句话解决女主的难题）、
  身份揭晓（她竟是××）、男主破例（他不近女色却……）。
- 次爽点：恶毒女配/极品亲戚吃瘪、前任后悔、女主事业被认可。
- 释放节奏：偏爱要「垫误解再兑现」——先让读者替女主委屈，再给超额补偿。
  连续两章无偏爱证据=节奏失速。

## 冲突发动机

门第差 × 恶毒配角觊觎 × 契约/误会驱动。三方压力轮流上岗：家族反对、
女配作妖、旧情/身世秘密。男主的保护欲 vs 女主的自尊心是最耐用的内在矛盾。

## 节奏规范

- 单章：受委屈 → 男主出手或女主自证 → 小结算 → 新波澜，四拍齐全。
- 前期（约前 50 章）：快立契约/闪婚关系，羞辱与反羞辱高频，偏爱证据密集投放。
- 中期：身世秘密、前任回归、家族斗争三线轮换；每次误会必须换来关系实质升级。
- 后期：收网恶毒配角，公开身份/婚礼大场面结算；事业线与感情线并线收束。
- 红线：女主不能长期逆来顺受。每次受气=当章或次章内还手，隔夜气读者不答应。

## 场景颗粒与正文落点

- 颗粒：宴会厅、总裁办公室、豪宅餐厅、医院走廊；黑卡、定制礼服、合同、
  验资报告、热搜截图。道具必须挂在「偏爱证据」或「羞辱/反羞辱」上出场。
- 落点：开场落在被轻视/被误解的现场；冲突落在尊严缺口；结尾落在男主态度
  突变、新羞辱者到场、秘密即将揭穿。

## 对话与声线

男主话少但每句是判断或命令，宠溺只在她面前漏出来；女主柔中带刺，不当应声虫；
恶毒配角阴阳怪气但有自己的利益逻辑。禁忌：全员霸道腔。

## 成长体系

人物卡「能力」字段 = 明面身份/职业 + 隐藏身份/底牌 + 可调动的资源 +
感情进度（契约→动心→认定）。身份揭晓节奏在开书时排进总纲。

## 常见雷区与禁止漂移

- 女主长期受气不还手：读者弃书第一原因。
- 男主只会砸钱没有「破例」细节：偏爱不可感。
- 误会靠「不说人话」硬撑：一句话能解释的误会是侮辱读者。
- 恶毒配角为坏而坏、工具化：打脸不爽。
- 中途跑偏去搞事业/商战忘了偏爱主线。

## 平台适配要点

- 番茄：先婚后爱/闪婚/萌宝是最稳抓手；短章高频，羞辱-反羞辱当章结算。
- 起点：非主场，除非走男频反套路（赘婿视角转都市脑洞）。
- 晋江：主场之一，吃细腻情感与双洁设定，可慢热；追妻火葬场变体吃香。

## 开篇要点

前三章必须完成：①女主被轻视/被算计的具体场面；②与男主绑定关系成立
（闪婚/契约/一夜情重逢）；③第一次「破例」证据或羞辱对象的首次亮相。

## 专属禁用词

开书时把下列词汇拷入书籍工程的 `设定/禁用词.txt`（机器闸口自动加载）：

```
邪魅 狂狷 女人你在玩火 磨人的小妖精 该死的甜美 刀削般的 薄唇轻启
```

说明：以上为过气霸总腔模板词，正文中出现即替换为具体动作；女主内心吐槽
可放宽，叙述语言不放宽。

## 依据

经验综合（番茄/晋江豪门总裁类榜单高分作品的共性拆解）+ 追妻火葬场/先婚后爱
细分套路的读者反馈校准。修订方法：每次拆该题材对标书后回写本卡「爽点类型」
与「开篇要点」。

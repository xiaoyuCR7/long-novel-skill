# 儿童童话 题材卡

## 读者契约

读者（往往是家长和孩子）要的是「安全的好奇心冒险」——要有冒险的刺激，但绝不能有真正的伤害与绝望。兑现点：世界要奇幻温暖，主角要让孩子能代入，故事要传达正向价值观但不爹味说教。睡前故事体裁还要考虑「单篇可读完」的长度与「听完能安睡」的情绪收束。不写成人化的权谋与黑暗，写的是善恶分明、童心看世界。

## 爽点类型

- 主爽点：奇妙发现（新世界/新朋友/新能力）、化险为夷（用智慧或勇气脱困）、友情/亲情的温暖瞬间。
- 次爽点：小主角被认可、反派的滑稽吃瘪、愿望达成。
- 释放节奏：单元冒险式结算，一个冒险 1–3 章（睡前故事单篇闭环）；冒险之间用日常过渡。情绪曲线要有「紧张—化解—安心」的收束，不留悬惧。

## 冲突发动机

好奇心 × 危险。矛盾来源：迷路、走失、被欺负、遇到怪物/坏人、愿望出了岔子、朋友闹别扭。小主角的好奇心/善意制造「主动冒险」，外部危险制造「压力」，但危险必须有儿童能理解的安全边界。续杯方式：一个冒险化解，新的好奇心驱动下一个冒险，世界逐层展开。

## 节奏规范

- 单章：一个小冒险或一次情绪推进，章章有画面感和情绪落点。
- 前期：建立奇幻世界/日常世界、小主角的性格与伙伴、第一次冒险的勇气亮出。
- 中期：冒险规格升级（从身边到远方），伙伴增加，世界规则逐层展开。
- 后期：主线收束，成长兑现，温暖收尾，不写开放式或悲剧结局。
- 红线：绝不出现真正的死亡、血腥、恐怖、绝望——反派可以坏，但要有滑稽或可转化的一面。

## 场景颗粒与正文落点

- 颗粒：森林里会说话的动物、糖果屋、云朵上的城堡、月光下的秘密花园；小主角的背包、手电筒、毛绒伙伴、魔法道具。
- 落点：开场落在新奇世界或冒险开始的瞬间；冲突落在小危险或小别扭；结尾落在化险为夷后的安心与温暖。

## 对话与声线

语言要浅白、有韵律、可朗读——这是儿童文学的语言底线。角色对话要鲜明：小主角天真但有主见，动物伙伴各有性格口音，反派说话滑稽或夸张。不用复杂从句，不用生僻词，但可以用拟声词和重复句式（儿童喜欢重复）。内心独白要符合儿童认知，不写成人式的反思。

## 成长体系

人物卡「能力」字段 = 年龄/心智 + 勇气值 + 善良品质 + 特殊能力（如有）+ 伙伴关系。成长 = 勇气增加 + 善良被验证 + 伙伴增多 + 心智成熟一寸。注意：儿童童话的成长是「软成长」——不是打怪升级，而是「变得更勇敢/更善良/更会体谅」。

## 常见雷区与禁止漂移

- 成人化：写出成人式的权谋、算计、爱情，失去童真。
- 说教爹味：价值观硬塞，每个故事结尾强行「这个故事告诉我们」，孩子反感。
- 危险失控：出现真正的死亡、血腥、恐怖，超出儿童承受边界。
- 语言晦涩：用词过难、句子过长，不适合朗读或儿童理解。
- 悬惧不收：睡前故事留恐怖悬念不化解，孩子不敢睡。

## 平台适配要点

- 番茄：儿童文学体量小，亲子/睡前故事有稳定需求，要求单篇可读完、语言可朗读；尺度严守平台红线。
- 起点：儿童文学有长线空间（系列童话），读者要求世界观完整、成长有逻辑。
- 微信读书/亲子平台：睡前故事、绘本故事有声化需求大，重韵律与画面感。

## 开篇要点

前三章必须完成：①奇幻世界/日常世界建立（要有让孩子好奇的新奇点）；②小主角的性格与善意亮出（让孩子想代入）；③第一次冒险或奇妙相遇开始，读者（孩子）想看下去。

## 专属禁用词

开书时把下列词汇拷入书籍工程的 `设定/禁用词.txt`（机器闸口自动加载）：

```
倒吸一口凉气 毛骨悚然 血流如注 死亡 血腥 残忍 阴森 狰狞 不寒而栗 肝肠寸断
```

说明：以上是儿童文学必须回避的「恐怖/暴力/成人情绪」词汇，命中即替换为儿童友好的表达（害怕说成「吓得缩了缩脖子」，危险说成「糟糕的情况」）。同类词发现后自行追加。

## 正文层规范（九件事）

> 以下九件事与上方 12 栏目互补：12 栏目管「写什么」，九件事管「怎么落笔」。两者一起读。

### 1. 题材核心

安全的好奇心冒险——要有冒险的刺激，绝不能有真正的伤害与绝望。世界奇幻温暖，主角让孩子能代入，价值观正向但不爹味。

### 2. 主线目标

**温暖成长。** 小主角在奇幻/日常世界里冒险，变得更勇敢、更善良、更会体谅。具体目标会换（找回走失的伙伴→化解森林危机→帮朋友实现愿望→成为更好的自己），但目标类型始终是「在冒险里长大一点点」。副目标常有「交到新朋友/学会一个道理」，但道理要融在故事里，不硬塞。

### 3. 冲突发动机

好奇心 × 危险。**续杯方式**：一个冒险化解，小主角的好奇心驱动下一个冒险，世界逐层展开。好奇心给「主动冒险」，外部危险给「压力」，但危险必须有儿童能理解的安全边界——化解危险的方式也要符合儿童认知（智慧、勇气、善意、友情，而非暴力）。

### 4. 爽点定位

- 主选：**奇妙发现感**——新世界/新朋友/新能力，让孩子的好奇心被满足。
- 次选：**化险为夷感**——用智慧或勇气脱困，让孩子觉得「我也能行」。
- 辅助：**温暖陪伴感**——友情/亲情的瞬间，让孩子有安全感。
- 注意：冒险的刺激要有，但「紧张—化解—安心」的情绪曲线必须收束，不留悬惧。

### 5. 常见情绪转化

**好奇 → 冒险 → 紧张 → 化解安心。** 小主角因好奇心动身（好奇）→ 进入冒险（冒险）→ 遇到小危险或小别扭（紧张）→ 用智慧/勇气/善意化解，回到安心温暖（化解安心）。四拍循环，注意「紧张」要可控、「化解」要让孩子有参与感、「安心」要让睡前故事能收尾。

### 6. 场景颗粒

- 世界：细到会说话的动物、糖果屋、云朵城堡——奇幻要有画面感，能激发想象。
- 冒险：危险要具体但可控（迷路、被困、被追赶），化解方式要符合儿童认知。
- 语言：浅白、有韵律、可朗读，拟声词和重复句式是儿童喜欢的节奏。
- 红线：绝不出现真正的死亡、血腥、恐怖、绝望——危险可以「可怕」但不能「绝望」。

### 7. 正文落点

每章至少落一个，冒险化解章可叠两个：
- 情绪落点：发现的「惊奇」、紧张的「揪心」、化解的「安心」、陪伴的「温暖」。
- 信息落点：世界规则的一角、新伙伴的一角、主角能力的一角。
- 悬念落点：下一个冒险的钩子、新朋友登场、愿望即将达成。
- 关系落点：友情加深、新伙伴加入、与家人/老师的和解。
- 常用组合：冒险章落在「情绪落点 + 悬念落点」（紧张化解完留新钩）；日常章落在「信息落点 + 关系落点」。

### 8. 前中后期打法

- **前期（1–30 章）**：
  - 建立：奇幻/日常世界、小主角性格与善意、第一个伙伴。
  - 展示：冒险+温暖的核心节奏连给 3–5 次，让孩子确认「我还想听」。
  - 压住：世界的深层秘密/主角的特殊来历，前期只露一角。
- **中期（31–100 章）**：
  - 升级：冒险规格升级（从身边到远方），伙伴增加，世界规则展开。
  - 换挡：从「单次冒险」转向「主线浮现」，单次冒险开始串联。
  - 引入：新世界区域、新伙伴，防审美疲劳。
- **后期（100+ 章）**：
  - 兑现：主线收束，主角成长兑现，世界的秘密揭晓。
  - 收束：温暖收尾，不写开放式或悲剧结局。
  - 升华：从「小冒险」到「成为更好的自己」，让结局有成长分量。

### 9. 禁止漂移

最容易漂移到**成人奇幻/玄幻**——儿童童话写出成人式的权谋、算计、黑暗，失去童真。防止手段：
- 占比红线：儿童视角/童真相关内容不低于全书 70%，且冲突必须由儿童能理解的原因（好奇、善意、别扭）驱动而非成人式利益算计。
- 回拉机制：连续 2 章出现成人化情节（权谋、黑暗、暴力），必须用一个童真场景（动物伙伴、奇妙发现、温暖瞬间）回拉。
- 自检问题：每卷自问——「这卷孩子能看懂吗？有真正的伤害或绝望吗？道理是融在故事里还是硬塞的？」

次级漂移：漂移到**说教寓言**——每个故事结尾强行「这个故事告诉我们」，孩子反感。防止：道理要融在故事和角色的选择里，让孩子自己悟，不替孩子总结。

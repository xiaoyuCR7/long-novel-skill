# 敏感词替换表（武道重生：我在都市练纯阳）

> 用途：正文写作前的敏感词处理预案。凡是可能触发平台审核、或让真实世界穿帮的
> 真实地名/机构/人物，正文一律用本表代称书写，保证全书一致。
> 方法论：`references/craft/sensitive-word-replacement.md`。平台规则会变，以平台后台最新公告为准。

## 一、地名代称系统（真实地名 → 虚构代称）

| 真实地名 / 真实暗示 | 正文代称 | 使用位置 | 备注 |
|---|---|---|---|
| 中国 | 华夏 | 全书 | 已用；不出现「中国」「中华」全称 |
| 北京 | 京城 | 北境武道大学所在地 | 全书写「京城」，绝不写「北京」 |
| 北方城市 | 北境 | 三大学府之首所在 | 语义可联想，读者脑内定位不费力 |
| 江南地区 | 江南 | 江南武道学院所在 | 泛称可用 |
| 四川/西南 | 西蜀 | 西蜀武学院所在 | 泛称可用 |
| 各国/外国 | 各国（不点名） | 境外势力、武圣级战力 | 不出现真实国名 |
| 荧惑陨石落点 | 太平洋深处（不具名海域） | 灵气复苏起点 | 不绑定真实坐标 |

> 规则：一个真实地名 → 一个全书统一代称。新增地名当场登记，不口头约定。

## 二、别称置换规则（机构 / 职务 / 群体）

| 真实指称 | 正文置换 | 规则 | 示例 |
|---|---|---|---|
| 军队 / 武警 | 军方 | 统一用「军方」，不写番号 | 「军方退役上将周无极」 |
| 上将 | 上将（虚构军衔，不绑定真实授衔） | 军衔可保留，人物全虚构 | — |
| 大学 / 高校 | 学府 / 学院 | 全校一制 | 「北境武道大学」→「北境学府」 |
| 国家教育机构 | 华夏武道教育体系 | 不出现真实机构全称 | 「华夏官方武道教育体系」 |
| 世家（现实宗族） | 武道世家 | 纯虚构概念，不影射真实家族 | 「华夏六大世家」 |
| 政府机构 | 官方 / 上头 | 不出现真实机构全称 | 「传统国家机器」 |

## 三、地名脱敏处理方法（写法层面）

1. **架空化**：本书设「灵气复苏」平行时空，公元纪年保留但真实国家/城市名全部代称化。
2. **模糊化**：城市细节不写真实行政区划全称，用「北境」「江南」「西蜀」定位。
3. **时间脱敏**：灵气复苏事件为完全架空设定，不与真实历史事件绑定。
4. **人物脱敏**：武圣/大宗师等高层战力全虚构，不影射真实人物。
5. **专名避雷**：写前查一遍与真实地名/品牌/人名重名的词，宁改不赌。

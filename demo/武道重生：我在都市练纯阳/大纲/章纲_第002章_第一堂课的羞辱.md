# 章纲：第002章 第一堂课的羞辱

## 一、基本信息

- **章节号**：第002章
- **章节标题**：第一堂课的羞辱
- **字数目标**：约3000字
- **节奏档位**：中档
- **所属卷**：第一卷 寒门觉醒

## 二、本章核心情绪

**隐忍→屈辱→爆发→震惊**

从林辰低调隐忍进入教室，到赵天霸当众羞辱激起的屈辱感，再到武道测试上实力爆发的震惊全场。先抑后扬，用羞辱铺垫爽点，让读者期待感拉满。

## 三、场景列表

### 场景一：高三教室——风起云涌

- **地点**：南星高中高三（7）班教室
- **人物**：林辰、王胖子、赵天霸、众同学、苏清雪
- **核心冲突/事件**：
  - 林辰走进教室，引来一阵窃窃私语，大家都在议论今天的月度武道测试
  - 王胖子赶紧拉林辰坐下，告诉他赵天霸今天放话要让林辰"好看"
  - 赵天霸带着两个狗腿子走进来，故意撞掉林辰的课本，当众嘲讽："哟，这不是我们班的'武道天才'林大废柴吗？今天又准备考倒数第一？"
  - 全班哄笑，林辰目光冰冷，却暂时隐忍不发
  - 苏清雪走进教室，全场安静，她淡淡地瞥了一眼这边，面无表情地坐到自己的位置上
  - 赵天霸立刻换上谄媚的表情，想跟苏清雪搭话，被无视
- **情绪目标**：压抑、屈辱、期待反击
- **字数分配**：约800字

### 场景二：武道馆——测试开始

- **地点**：学校武道馆
- **人物**：林辰、王胖子、赵天霸、张老师（武道课老师）、全班同学、苏清雪
- **核心冲突/事件**：
  - 月度武道摸底测试开始，张老师宣布测试项目：力量测试、速度测试、修为检测
  - 同学们依次测试，赵天霸成绩亮眼：淬体六重，拳力800斤，获得一片赞叹
  - 赵天霸挑衅地看向林辰："某些人不会连300斤都打不出来吧？"
  - 苏清雪测试，修为淬体七重，拳力1200斤，全场震惊，不愧是全校第一天才
  - 轮到林辰，全班目光聚焦，多数是等着看笑话的表情
  - 张老师也摇头叹气，对林辰不抱希望
- **情绪目标**：铺垫、期待、众人轻视
- **字数分配**：约1000字

### 场景三：力量测试——初露锋芒

- **地点**：武道馆力量测试区
- **人物**：林辰、赵天霸、张老师、全班同学、苏清雪
- **核心冲突/事件**：
  - 林辰走到力量测试仪前，深吸一口气
  - 回忆上一世自己打出280斤的成绩，被全班嘲笑的场景
  - 这一世，他运转纯阳真气，拳头上隐隐有金芒一闪而逝
  - 一拳轰出——测试仪屏幕数字疯狂跳动：500斤、700斤、900斤、1000斤！
  - 最终定格：1028斤！
  - 全场死寂，所有人目瞪口呆
  - 赵天霸脸色大变："不可能！他明明只有淬体三重！"
  - 张老师激动地冲过来："快，测修为！"
- **情绪目标**：震惊、不敢置信、爽感初现
- **字数分配**：约800字

### 场景四：修为检测——五重境界

- **地点**：武道馆修为检测区
- **人物**：林辰、赵天霸、张老师、全班同学、苏清雪
- **核心冲突/事件**：
  - 林辰将手放在修为检测仪上
  - 检测仪亮起三道光——不，四道——五道！
  - 淬体五重！
  - 全班炸锅，上个月还是淬体三重，一个月突破两重？这怎么可能！
  - 赵天霸脸色铁青，死死盯着林辰，眼神中充满嫉妒和怨毒
  - 苏清雪终于正眼看向林辰，美眸中闪过一丝诧异
  - 张老师激动得手都在抖："天才！真正的天才！"
  - 林辰面无表情，内心却在冷笑：这才只是开始
- **情绪目标**：震惊全场、爽感爆发、埋下冲突种子
- **字数分配**：约400字

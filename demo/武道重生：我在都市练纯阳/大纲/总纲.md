# 总纲：武道重生：我在都市练纯阳

## 一、核心设定

**书名**：武道重生：我在都市练纯阳
**题材**：都市高武
**平台**：番茄小说
**目标读者**：18-35岁男性，喜欢爽文、升级流、都市异能
**预计字数**：200万字
**预计卷数**：8卷

### 世界观

灵气复苏三十年后，全球进入高武时代。武道成为衡量个人价值的核心标准，武馆林立，高校开设武道专业，武者地位尊崇。

- **武道境界**：淬体→通脉→内息→外罡→宗师→大宗师→武圣→武神
- **修炼体系**：主修+辅修双轨制，主修决定战力上限，辅修丰富战斗手段
- **势力格局**：六大世家 + 三大学府 + 军方 + 民间武馆

### 金手指

**纯阳道种**：主角重生时带来的神秘道种，具有三大特性：
1. **百倍悟性**：修炼任何功法都能瞬间领悟，举一反三
2. **纯阳真气**：至阳至刚，净化一切阴邪，对邪道功法有天然克制
3. **道种空间**：可加速修炼，内部时间流速是外界的10倍

### 核心卖点

1. **重生+系统+都市高武** 三重爽点叠加
2. **百倍悟性** = 读者代入感强，一路碾压
3. **纯阳道种** 设定新颖，有足够的升级空间
4. **都市背景** 贴近生活，代入感强
5. **节奏明快**，每三章一个小高潮，每卷一个大高潮

## 二、主线脉络

**主线一：武道巅峰** — 从淬体境一路修炼到武神，登顶武道巅峰
**主线二：身世之谜** — 揭开纯阳道种的来源和上一世的真相
**主线三：守护羁绊** — 保护身边的人，建立自己的势力

## 三、八卷大纲

### 第一卷：寒门觉醒（第1-50章）
- 主角林辰重生回到高三，获得纯阳道种
- 从废柴逆袭，考入三大武道学府之一的「星武大学」
- 卷末高潮：新生大比夺冠，震惊全校

### 第二卷：星武风云（第51-150章）
- 进入星武大学，崭露头角
- 结识伙伴，组建团队
- 卷末高潮：校级交流赛夺冠，获得秘境名额

### 第三卷：秘境奇遇（第151-250章）
- 进入上古秘境，获得重大机缘
- 实力突飞猛进，突破外罡
- 卷末高潮：秘境boss战，以弱胜强

### 第四卷：都市风云（第251-400章）
- 回归都市，处理家族事务
- 建立自己的势力「纯阳阁」
- 卷末高潮：六大世家联手打压，主角绝境翻盘

### 第五卷：全国大比（第401-550章）
- 参加全国武道大比
- 一路过关斩将，获得冠军
- 卷末高潮：决赛对战第一天骄，惊天逆转

### 第六卷：世界舞台（第551-750章）
- 代表国家参加世界武道大会
- 揭开国际势力格局
- 卷末高潮：世界武道大会夺冠，名震全球

### 第七卷：天地异变（第751-950章）
- 灵气浓度暴增，天地异变
- 上古遗迹纷纷出世
- 卷末高潮：武圣之战，守护华夏

### 第八卷：武道巅峰（第951-1000章）
- 突破武神，揭开道种真相
- 最终决战，守护世界
- 大结局：登顶武道巅峰，守护挚爱

## 五、读者契约

### 核心承诺
1. **爽点密集**：每三章至少一个小爽点，绝不压抑
2. **主角无敌**：同阶无敌，越阶挑战是常态
3. **节奏明快**：不拖沓、不水字数，每章都有推进
4. **女主纯洁**：感情线专一，不搞暧昧后宫
5. **反派智商在线**：不降智，每个反派都有存在感

### 终局储备
1. 纯阳道种的终极秘密（上一世林辰就是武神，道种是他自己留下的）
2. 苏清雪的真实身份（上古仙女转世，与林辰有万世情缘）
3. 灵气复苏的真相（上古大能的实验，为了培养继承者）

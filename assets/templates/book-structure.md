# 书籍工程目录规范

每本书一个独立目录，固定子目录。开书时按本规范创建（流程见
`references/workflow/book-init.md`），之后所有读写都遵守这个布局。

```
{书名}/
├── 大纲/
│   ├── 总纲.md                  # 全书卷级鸟瞰（模板：outline-master.md）
│   ├── 卷纲_第1卷.md            # 每卷一份（模板：outline-volume.md）
│   ├── 卷纲_第2卷.md
│   ├── 章纲_第001章.md          # 每章一份，滚动补纲（模板：outline-chapter.md）
│   └── beat-sheet_第XXX章.md    # 复杂章的 Beat Sheet（模板：beat-sheet.md）
├── 设定/
│   ├── 题材定位.md              # 主题材/平台/更新计划——决定加载哪张题材卡（模板：genre-profile.md）
│   ├── 读者契约.md              # 核心快感/兑现频率/红线（模板：reader-contract.md）
│   ├── 世界观.md                # 只写「不写就会崩」的核心规则
│   ├── 文风锚.md                # 六维量化基线 + 样板段落（模板：style-fingerprint.md）
│   ├── 禁用词.txt               # 题材专属禁用词 + 个人避讳词
│   └── 角色/
│       ├── {主角名}.md          # 人物卡，一人一档（模板：character-card.md）
│       └── {配角名}.md
├── 正文/
│   ├── 第001章_{标题}.md        # 章节号三位起补零，保证排序
│   └── 第002章_{标题}.md
├── 追踪/
│   ├── 伏笔台账.md              # 模板：foreshadowing-ledger.md
│   ├── 角色状态.md              # 模板：character-state.md
│   ├── 章节摘要.md              # 模板：chapter-summary.md
│   ├── 时间线.md                # 模板：timeline.md
│   ├── 节奏配额.md              # A/B/C 配额 + 事件冷却 + 档位记录（模板：rhythm-quota.md）
│   ├── entity_index.json        # 关键实体→章节号索引（由 entity_index.py build 自动生成）
│   └── 门禁/                    # 每章 gate 报告落盘（由 check_text.py --gate-report 自动生成）
│       └── gate_ch{NNN}.json    # 退出码 0 = 通过，1 = 有问题
├── 对标/                        # 拆文产出（可选，有对标书时创建）
│   └── {对标书名}/             # 拆文产出（角色/剧情/节奏/情绪模块/文风）
└── 参考资料/                    # 扫榜报告、调研资料（可选）
```

## 命名纪律

- 章纲与正文的章节号保持一致且三位补零（`第007章` 不是 `第7章`），否则排序和检索都会乱。
- 正文文件名带标题，章纲文件名不带（章纲的标题写在文件内容里）。
- Beat Sheet 文件名带章节号（`beat-sheet_第037章.md`），与章纲一一对应。
- 新增文件类型先想「它属于大纲/设定/正文/追踪/对标/参考资料哪一类」，想不清楚就问作者，不随手乱放。

## 隔离纪律

- `正文/` 里只有能直接发布的章节正文，任何元信息、批注、TODO 都不进这个目录。
- 模板文件（`assets/templates/`）是母版，拷贝到书籍工程后填写；不要在模板里写书的内容。
- 一本书的追踪文件不引用另一本书的内容；跨书联动（如系列文）在各自的题材定位里注明。
- `对标/` 里的拆文产出是参考素材，不直接拷进正文；拆的是结构，不是内容。
